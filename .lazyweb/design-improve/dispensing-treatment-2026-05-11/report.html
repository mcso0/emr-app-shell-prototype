Design Improvement: 조제/처치 화면

TL;DR
가장 큰 개선 기회는 작업 우선순위, 오더 안전 변경, 담당/진행 액션을 표 안팎에서 한눈에 읽히게 만드는 것입니다. 현재 화면은 정보가 풍부하지만, 반복 컬럼과 가로 스크롤 때문에 "지금 무엇부터 처리해야 하는지" 판단에 시선 이동이 많습니다.

Lazyweb MCP health check가 타임아웃되어 Lazyweb DB 결과는 사용하지 못했습니다. 이번 리포트는 로컬 화면 캡처와 웹 레퍼런스를 기준으로 작성했습니다.

Current State

Improvement Ideas

1. 상태 필터를 업무 우선순위 바로 승격 ⭐

중앙 본문 시작부에 재요청, 미지정, 내 담당, 변경 있음 같은 작업 우선순위 pill을 count와 함께 노출합니다.

오늘 작업 12   [재요청 1] [미지정 8] [내 담당 2] [변경 2]  검색

2. 표를 안전 확인 중심으로 재배열

기본 컬럼은 오더명, 상태, 변경/주의, 처방 요약, 담당, 액션으로 줄이고 세부 투약 필드는 확장 영역으로 묶습니다.

오더명 | 상태 | 변경/주의 | 처방 요약 | 담당 | 액션

3. 재요청/변경 경고를 검수 카드로 바꾸기

변경 사유, 이전값/변경값, 요청자, 확인/문의 액션을 행 아래 검수 카드로 붙여 경고를 처리 흐름으로 연결합니다.

4. 좌측 큐에 SLA/담당 공백 신호 추가

좌측 카드와 상태 그룹 header에 최장 대기 시간, 미지정 여부, 재요청 여부를 같은 위치로 정렬합니다.

What's Working

  • Shell 구조가 안정적이고 각 패널의 역할이 분명합니다.
  • 환자 컨텍스트 바가 상단에 고정되어 환자 식별 정보를 잃지 않습니다.
  • 오더 그룹 단위 workflow와 상태 badge가 이미 잘 잡혀 있습니다.
  • 재요청/완료/취소 상태와 변경 row가 있어 안전 UX를 강화할 재료가 충분합니다.
