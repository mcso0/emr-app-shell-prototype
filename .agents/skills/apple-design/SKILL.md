# Apple Design

Use for explicitly relevant Apple-style interaction/design work, drawing on the existing WWDC-derived references. Preserve the product's approved design language and shared tokens; ordinary UI work does not require adopting this style.

Select the reference for the task:

- [Motion and gestures](references/motion-and-gestures.md): direct manipulation, springs, interruptibility, momentum, and edge behavior.
- [Materials, accessibility, and typography](references/materials-accessibility-typography.md): depth/translucency, reduced motion, feedback, and text treatment.
- [Design foundations](references/design-foundations.md): broader design rationale or a requested process review.

Keep the requested scope. Reviews are read-only; approved fixes include implementation and focused verification. Reference examples do not override EMR component contracts, accessibility, privacy, or dependency/permission boundaries. Do not load all references or impose the full design process on a narrow change.
