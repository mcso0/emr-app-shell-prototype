수정 방향

  1. 파일 이동 없이 CLAiR Docs registry를 먼저 확장한다.
  2. 상단 탭을 기획, 디자인, 개발로 재구성한다.
  3. 좌측은 영역별 보기와 기능별 보기를 전환한다.
  4. 본문은 선택한 기능의 문서 패키지를 보여준다.
  5. 개발 문서는 승인된 문서만 노출한다.

주의

사이트 IA와 repo 폴더 구조를 1:1로 맞추지 않는다. Repo 구조는 agent와 link 안정성을 위해 유지하고, 사이트는 사람이 읽기 쉬운 가상 목차로 구성한다.
