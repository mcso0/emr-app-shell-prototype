# Wireframes

Static HTML wireframes live here when the team needs to review information architecture, navigation, or screen structure before implementation.

These files are design artifacts, not product code. Keep the source Markdown and registry decisions in their canonical docs, and use wireframes to make structure easier to discuss.

- `clair-docs-ia-wireframe.html`: proposed CLAiR Docs information architecture for planning, design, and development document discovery.
