# Design Docs

Design docs capture UX flows, reference screens, design system notes, and UI QA criteria.

Planned subareas:

- `flows/`: task sequence, navigation, and cross-screen continuity
- `screens/`: concrete screen-level layout, density, state, and interaction rules
- `system/`: reusable UI foundations, tokens, components, and conventions
- `reference-screen-index.md`: canonical index of reference screen assets
- `assets/reference-screens/`: checked-in reference images
- `ux-flows/`: compatibility area for existing user journeys and interaction flows; prefer `flows/` for new docs
- `qa/`: visual and interaction QA checklists
- `decisions/`: durable UX, visual, or interaction decisions

Current canonical files:

- `docs/design/reference-screen-index.md`
- `docs/design/assets/reference-screens/`
- `docs/design/changelog.md`

Use `docs/_meta/intake-rules.md` when routing design instructions from chat.
