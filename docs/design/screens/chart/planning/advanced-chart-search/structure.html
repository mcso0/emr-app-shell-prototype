화면 구조와 전환

검색 결과를 비교하는 자리는 유지하고, 대상 차트에 쓸 때만 확인 창을 연다.

독립 검색 탭

레일에서 직접 열기

‘진료/차트’ 아래의 ‘차트 상세 검색’을 선택한다. 검색 메뉴와 상단 업무 탭이 활성화되고 본문에 최근 완료 차트가 보인다. 진료 대기열은 진료 탭에서만 표시한다. 통합 검색의 빠른 실행도 같은 검색 탭을 연다.

레일 진입 시안

작성하던 차트로 복귀

차트 안에서 검색을 열면 제목 옆에 ‘두부 차트로 돌아가기’가 보인다. 같은 방문의 같은 차트에서 입력을 이어간다. 검색 탭을 다시 누르면 필터·스크롤·열어 둔 원본이 남아 있다.

차트 복귀 시안

결과 목록과 원본

도구 모음　차트 상세 검색 · 출발 차트가 있으면 환자명 복귀 버튼　｜　정렬 · 필터 · 진료 담당의 · 내 차트 · 진료일 · 검색어 · 보기 폭

기본은 넓게 보기이며, 좌우 여백을 제외한 전체 공간을 쓴다. 제목·필터·검색어가 있는 상단 바는 두 보기 모두 작업 영역의 가로 폭을 채운다. ‘좁게 보기’를 누르면 결과 목록만 최대 1120px로 중앙에 모인다. 결과 건수와 ‘작성 중 차트 포함’을 목록 위에 둔다.

행 왼쪽 · 첨부

첨부 이름·설명에 검색 단어가 들어간 첫 사진이나 영상 정지 화면을 표시한다. 검색어가 없거나 일치가 없으면 차트 본문의 첫 첨부를 표시한다. 좌우 화살표로 넘기고, 이미지를 누르면 크게 본다. 사진·영상이 없는 행도 같은 자리에 ‘없음’을 표시해 모든 진료 요약의 시작 위치를 맞춘다.

행 오른쪽 · 진료 요약

날짜·환자·보호자·품종 → 방문 목적 또는 일치한 명칭 → 작성자·진료의·상태, S/O·진단·처방 → 오더 종류. 오른쪽 위에 복사 메뉴와 원본 열기를 둔다.

제목이나 원본 열기를 누르면 작업 영역 오른쪽 끝에서 원본 서랍이 열린다. 좁게 보기와 넓게 보기를 전환해도 서랍은 그 자리에 붙어 있다. 작은 화면에서는 원본이 작업 영역의 가로 폭을 채운다. 닫으면 같은 결과와 스크롤 위치로 돌아간다.

복사와 생성

행 또는 원본의 복사 메뉴 → 대상 차트 한 건 → 가져올 항목 → 변경 전후 확인 → 적용

경로대상 선택 후적용 후
기존 차트날짜별 카드에서 환자·보호자·방문 목적·작성자·상태를 확인하고 한 건을 고른다. 다음 화면에서 문단·진단·오더를 선택한다. A/P 교체와 처방 수정은 여기서 지정한다.같은 검색 목록에 머무른다. ‘나비 차트 보기’처럼 복사 대상의 이름이 표시된 버튼에서 편집과 이력을 확인한다.
진행 중인 방문환자와 방문을 고르고 새 차트에 추가할 내용을 검토한다.선택한 방문 안에 초안 한 건이 생긴다.
대기 또는 새 방문선택 항목 유지 → 대기 접수 선택 또는 접수 → 검색 닫기 → 호출 → 해당 방문의 첫 차트에서 복사 이어가기.준비된 첫 차트에 적용하고 검색으로 복귀한다.

상태와 복귀 지점

  • 필터 창을 닫으면 완성된 조건과 필터 건수를 목록에서 확인한다.
  • 결과가 없으면 조건을 수정하거나 초기화한다. 다른 결과를 고르면 원본만 바뀐다.
  • 미리보기에서 뒤로 가면 항목 선택과 입력을 유지한다. 적용 전 취소는 대상을 바꾸지 않는다.
  • 대상이 갱신된 경우 다시 비교한다. 서명 또는 권한 변경으로 수정할 수 없으면 적용을 중단한다.

프로젝트 컴포넌트 사용

업무 탭은 WorkspaceChromeTabs, 제목은 지시서의 EmrInstructionTitleBar, 원본 서랍 헤더는 EmrRightPanelHeader를 사용한다. 목록에는 피그마의 사진·진료 요약 배치를 적용한다. 검색에는 기존 ReceptionSearchInput, 문단 편집에는 Textarea, 동작에는 Button, 선택에는 RadioGroup·Radio·Checkbox·Switch·Select를 사용한다. 상태는 EmrStatusBadge, 필터는 EmrFilterToggle·EmrTableFilterTrigger·EmrTableFilterBuilder와 기존 조건 계산을 사용한다. 복사 메뉴는 DropdownMenu, 필터 창은 Popover, 복사 확인 창은 Dialog와 EmrDialogShell을 사용한다. 결과 행과 원본 비교 영역은 이 화면에 맞춰 조합한다.
