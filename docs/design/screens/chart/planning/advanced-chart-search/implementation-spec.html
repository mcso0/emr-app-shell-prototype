조회 단위와 정렬

계약규칙
대상병원과 열람 권한으로 제한한 차트 한 건이 결과 한 행이다. 서명·정정한 차트가 기본이다. 작성 중 포함을 켜면 접근 가능한 초안을 추가한다. 첫 방문 접수만 있고 차트가 없는 경우는 제외한다.
검색어공백으로 나눈 모든 단어가 같은 차트 안에 있어야 한다. 방문 목적·주호소, 기본·계통별·자유 SOAP, 차트 귀속 진단명·오더명을 찾는다. 단어 순서와 중복은 대상 집합을 바꾸지 않는다.
관련도명시적 부정에만 일치한 증상은 관련도순 뒤에 둔다. 같은 차트에 같은 증상의 일반 일치가 하나라도 있으면 해당 증상은 일반 그룹이다. 같은 그룹에서는 진단·오더 정확 일치, 방문 목적·주호소, S/O와 기타 본문을 우선순위로 삼는다. 진단명이 정확히 일치하면 확진·의심·감별을 목록에 표시하고 최근 진료일, 차트 ID 순으로 동점을 구분한다. 진료일 정렬은 관련도에 우선한다.
필터내 차트는 개별 차트 작성자 기준, 진료 담당의는 방문 담당자 기준이다. 진료일은 병원 운영 날짜 경계를 쓴다. 동물·보호자·동물종·품종·진단 계통·진단·오더·검사 오더 있음(취소되지 않은 임상병리·영상 오더, 미수행 포함) 조건을 한 그룹과 그룹 사이에서 AND/OR로 결합한다.
첨부차트 본문이 참조하고 현재 열람할 수 있는 첨부만 본문 순서로 본다. 첨부 이름·설명에 검색 단어가 하나라도 있으면 첫 일치 자료, 아니면 첫 첨부다. 동영상은 정지 화면으로 열고 파일이 없으면 같은 자리에 없음이 보인다. 첨부 이름만으로 검색 결과를 늘리지 않는다.
페이지와 근거서버에서 권한·조건·관련도순을 모두 적용한 뒤 페이지를 나눈다. 건수·근거·미리보기에도 같은 가시성 조건을 쓴다. 목록의 문장과 원본에서 같은 단어를 강조한다. 빈 목록과 조회 실패를 구분하고 재시도 중 조건을 보존한다.

SOAP 문서이전 단일 블록 문서와 계통별 문서, 문서가 없는 이전 텍스트를 처리한다. 자유 문단과 표의 직접 작성 텍스트를 검색하고 첨부 파일 내부는 읽지 않는다.
진단 · 오더차트의 평가 스냅샷과 해당 차트가 원본인 오더를 읽는다. 같은 방문의 다른 차트에 속하거나 출처가 확인되지 않은 과거 오더는 일치 근거나 복사 후보에서 제외한다.
첨부 권한본문의 첨부 참조를 현재 병원·진료 건과 대조한다. 원본 파일은 열람 시점 권한을 확인하고 기존 비공개 첨부 경로로 연다.

항목과 적용

항목미리보기와 저장
대상한 번에 한 차트. 내 작성 중 차트가 먼저 나오고 수정 가능한 동료 차트로 범위를 넓힐 수 있다. 원본 자체와 완료한 차트는 제외한다.
S/O · A/P빈 원본 문단은 건너뛴다. S/O와 A/P는 선택한 문단을 대상의 같은 항목 끝에 추가한다. A/P만 수의사가 지정한 한 문단을 바꿀 수 있다. 교체 전후를 미리 본다. 가져온 문단에는 새 식별자를 준다.
진단중복은 이미 있음으로 표시한다. 진단 구분과 주진단 여부는 별개다. 새 진단의 주진단 표시는 기본 해제하며 직접 선택하면 기존 주진단도 유지한다.
오더약·검사·처치를 개별 선택한다. 수의사가 과거 용량·횟수·기간과 단위를 검토하거나 수정한다. 원본 오더명과 처방 내용은 차트 열람 범위에 속한다. 현재 단가와 사용 가능 여부는 service_catalog:view 권한으로 조회한다. 오더를 포함한 복사 대기와 적용 시 DB가 같은 권한을 다시 확인한다. 대기 중 권한을 잃으면 선택했던 오더의 단가를 숨기고 대기 취소는 허용한다. 같은 오더는 기본 해제하고 명시적으로 중복 추가할 수 있다.
원본 유지첨부·바이탈·검사 결과, 이전 실행·조제·청구·수납·서명 이력은 원본에서 확인한다. 복사는 이번 진료의 처방 확정이나 외부 요청을 발생시키지 않는다.

접수 후 첫 차트에서 재개

새 방문은 접수 완료 시, 대기 중인 방문은 해당 방문을 선택해 넘길 때 원본과 선택값을 방문에 연결한다. 검색 창을 닫아도 선택한 문단·처방 수정값을 유지한다. 해당 방문이 호출되어 첫 차트가 열리면 수의사가 복사 이어가기를 눌러 변경 내용을 다시 비교한다.

서버는 최초 선택자 또는 그 방문의 현재 담당 수의사인지, 첫 차트가 수정 가능한지 확인한다. 최초 선택자만 대기를 취소할 수 있다. 적용 시 대기를 잠그고 복사 이력에 최초 선택자와 실제 적용자를 기록한다. 다른 환자나 같은 환자의 다른 방문에 표시하지 않는다. 대기 중인 방문의 호출은 기존 첫 차트 준비 경로를 쓴다. 이미 첫 차트가 있으면 그 차트를 사용한다. 서명·권한 변경 시 적용을 차단한다. 명시적 취소나 적용 완료 후에는 대기 항목을 지운다.

호출 및 첫 차트 준비

저장과 충돌

원본·대상 식별자, 방문, 선택한 원본 항목, 대상 문단, 검토한 처방 및 진단 값, 버전과 요청 식별자를 전달한다. 서버가 로그인 사용자, 병원 소속, 열람·수정 권한을 다시 확인한다. 복사 대기·기존 차트 적용·새 차트 생성·첫 차트 재개 시에는 방문에 연결된 대상 환자의 행을 같은 트랜잭션에서 잠그고 삭제 상태를 확인한다. 삭제된 경우 서버는 409 target_patient_deleted를 반환한다. 화면은 원본과 검색 조건을 유지하고 대상 목록을 다시 읽는다. 새로 선택한 대상에는 이전 방문의 복사 대기를 연결하지 않는다. 환자명, 가격, 작성자를 브라우저 입력에서 신뢰하지 않는다.

대상 편집기의 미저장 입력을 먼저 저장한다. SOAP 수정 시각, 진단 버전, 진료 건의 오더 버전 중 관련 값이 달라지면 변경 전후를 다시 비교한다. 복사 항목, 원본·대상·적용자·전후 이력, 중복 방지 기록은 한 트랜잭션에서 저장한다. 같은 요청의 재시도는 최초 적용 결과를 반환한다. 권한 해제·서명·저장 실패 시 일부 항목만 남기지 않는다.

실제 코드와 요청

검색과 복사 요청은 인증 세션의 사용자와 병원 권한을 확인한다. 최근 완료 목록은 요청 페이지의 차트만 펼친다. 상세 조건이나 검색어가 있으면 검색에 필요한 필드를 500건씩 읽어 조건과 관련도를 적용한다. 최종 25건의 원본·첨부·단가만 다시 조회한다. 단일 차트 조회와 최근 완료 목록은 각각 전용 경로를 쓴다. 건수·담당의 선택지·페이지는 같은 열람 범위에서 만든다.

원본을 열 때 선택한 한 차트를 다시 읽는다. 새 접수는 기존 접수 화면이 돌려준 방문 ID에 연결한다. 복사 이력에는 원본·대상·적용자·시각·교체 전후와 미확정 오더를 남긴다. 원본 서랍의 ‘진료 차트 열기’로 기존 EMR 차트를 확인하고, ‘검색 결과로 돌아가기’로 작업을 이어간다.
