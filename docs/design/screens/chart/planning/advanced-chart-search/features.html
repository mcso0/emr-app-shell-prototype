세부 기능화면 구조인터랙티브 시안

세부 기능 기획

수의사가 비슷한 과거 사례를 찾고, 어느 환자의 어떤 차트에 어떤 내용이 들어갈지 확인한 뒤 이번 진료에 활용한다.

피그마 개선안과 연결되는 동작

장표시안에서 확인할 동작
30 · 스마트 필터상단의 ‘필터’를 열고 같은 그룹의 조건을 묶는다. 다른 그룹을 추가하면 두 그룹 사이의 AND/OR 관계도 화면에서 바꿀 수 있다.
31 · 차트 리스트첨부가 있는 행에서 사진을 넘기며 오른쪽의 방문 목적·S/O·진단·처방을 비교한다. 검색어는 일치한 문장에서, 필터 값은 해당 필드에서 노란색으로 표시한다.
32 · 복사·생성행 오른쪽 복사 아이콘에서 기존 차트로 복사하거나 새 차트를 만든다. 기존 차트는 날짜별 카드에서 한 건을 선택한 뒤 가져올 문단·진단·오더를 고른다.

검색과 사례 비교

기능행동과 화면 반응
진입 · ⑥⑦작성 중 차트와 통합 검색에서 같은 화면을 연다. 처음에는 최근 완료 차트가 보인다. 차트 입력 내용은 보존하고, 통합 검색에서는 복사할 때 대상을 정한다.
조건 · ⑤⑧⑨검색어는 방문 목적·주호소, 기본·계통별 SOAP, 자유 기록, 차트별 진단과 오더에 적용한다. 동물명·보호자명은 필터로 찾는다. 상단 도구 모음에서 정렬·진료 담당의·내 차트·진료일을 바로 선택한다. 결과 건수 옆에서 작성 중 포함을 켤 수 있다. ‘필터’를 열어 동물명·보호자명·동물종·품종·진단 계통·진단명·오더명·검사 포함 여부를 AND/OR로 조합한다.
여러 단어 검색 · ⑭공백으로 나눈 단어가 같은 차트에 모두 있어야 한다. 방문 목적의 ‘구토’와 오더의 ‘초음파’처럼 서로 다른 항목의 일치도 허용한다. 검색 결과와 원본에서 각 단어가 들어간 대목을 강조한다.
순서와 근거 · ⑩⑪⑮‘구토’의 관련도순에서는 모카(식후 구토)와 탄이(어제 새벽 구토 3회, 오늘은 구토 없음)가 보리(구토 없음)보다 먼저 보인다. 보리도 결과에 포함하고 부정 표현까지 읽을 수 있게 한다. 각 그룹 안에서는 진단·오더의 정확한 일치를 우선하고 동점은 최근순이다. 진료일순을 선택하면 세 차트를 날짜순으로 보여준다.
좁게·넓게 보기기본은 넓게 보기다. 좁게 보기는 지시서와 같은 최대 1120px로 결과 목록을 중앙에 모은다. 넓게 보기는 남은 가로 공간을 사용한다. 제목과 검색 도구가 있는 상단 바는 두 보기 모두 작업 영역의 가로 폭을 채운다. 차트 원본 서랍은 두 보기 모두 작업 영역의 오른쪽 끝에 붙는다. 두 폭이 같으면 전환 버튼을 숨긴다. 전환해도 검색 조건, 선택한 차트와 첨부 순번을 유지한다.
결과 행과 원본방문 목적이 구체적이면 증상과 함께 읽고, 접수 기본 문구라면 실제 일치 정보를 우선한다. 선택한 차트에 귀속되는 진단과 오더만 표시한다. 모든 행에 같은 크기의 썸네일 영역을 둔다. 사진·영상이 없으면 ‘없음’을 표시한다. ⑯에 따라 이름이나 설명에 검색 단어가 하나라도 있는 첫 첨부를 미리 보여준다. 검색어가 없거나 일치가 없으면 본문의 첫 첨부를 보여준다. 화살표로 자료를 넘기고 현재 순번과 전체 개수를 확인한다. 행 오른쪽에서 날짜·환자·보호자·품종, 방문 목적, S/O·진단·처방을 함께 읽는다. 제목이나 원본 열기를 누르면 전체 기록이 열린다.

재사용할 기록과 적용 방식

대상복사 규칙
문진·관찰 S/O · ③다른 환자의 기록도 문단별로 가져온다. 대상 차트의 해당 항목 끝에 붙이고, 대상에서 해당 문단을 수정한다.
평가·계획 A/P · ②추가가 기본이다. 교체를 고르면 대상 문단과 새 문장을 함께 확인한다. 기존의 다른 문단은 보존한다.
진단가져올 진단의 주진단은 기본 해제한다. 직접 선택하면 기존 주진단과 함께 유지한다. 이미 있는 진단은 미리보기에서 확인한다.
오더 · ④사용 가능한 항목을 선택한다. 약은 과거 용량·횟수·기간을 채워 두고 이번 값을 확인해 미확정으로 추가한다. 중복은 명시적으로 선택한다. 확정·수행·수납 이력, 결과 첨부는 원본에서 열람한다.
복사 대상 · ①⑫행이나 원본의 복사 메뉴에서 시작한다. 날짜별로 묶인 내 작성 중 차트 카드에서 한 건을 고른다. ‘수정 가능한 차트’로 전환하면 동료 차트도 선택한다. 적용 직전에 대상 버전과 수정 가능 상태를 확인하고 복사 기록에 작성자와 적용자를 구분한다.
새 방문 · ⑬진행 중인 진료에는 추가 차트를 만든다. 새 접수가 필요하면 선택을 보존한 채 접수·대기·호출을 거친다. 검색 창을 닫아도 해당 방문의 첫 차트에서 ‘복사 이어가기’를 눌러 선택값을 확인하고 한 번 적용한다.

시안에서 확인할 장면

  1. 검색 화면에서 ‘구토’와 ‘복부 초음파’를 차례로 검색한다. 결과의 첫 줄과 일치 문장이 어떻게 달라지는지 비교한다.
  2. 모카 행에서 ‘초음파’(이름 일치, 2/3), ‘촉진’(설명 일치, 3/3), ‘식욕’(첫 사진, 1/3)을 차례로 검색한다. 원본을 연 뒤 ‘좁게 보기’를 눌러 서랍이 작업 영역 오른쪽 끝에 붙어 있는지 확인한다.
  3. ‘필터’에서 동물종 조건을 추가하고 ‘작성 중 포함’을 바꾼다. 원본을 열고 돌아왔을 때 조건과 선택, 목록 위치를 확인한다.
  4. 모카 행의 복사 메뉴에서 ‘기존 차트에 복사’를 고른다. 두부 카드를 선택하고 S 문단, P 문단, 약을 선택한다. P만 교체하고 약의 기간을 수정한 뒤 적용한다. 대상 차트에서 복사한 S를 수정하고 이력을 확인한다.
  5. ‘새 차트로 만들기’에서 새 방문 또는 대기 접수를 선택한다. 접수 후 검색을 닫고 해당 방문을 호출한다. 첫 차트에서 ‘복사 이어가기’를 눌러 적용한다.

진료 기록과 접수는 합성 사례다. 고양이 사진은 공개 사용이 허용된 예시 사진이다. 초음파는 미디어 동작을 확인하기 위한 합성 영상이다. 화면을 새로 고치면 초기화된다. 권한·동시 수정·접수 상태는 시안 안에서 재현한다.
