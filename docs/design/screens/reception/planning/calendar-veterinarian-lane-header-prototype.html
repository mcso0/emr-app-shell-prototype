눈 아이콘으로 레인 숨기기

  1. 데이터는 삭제하지 않는다. 해당 의사 ID만 hiddenLaneIds에 넣고, 헤더·캘린더 바디·현재시간선의 열 모델에서 제외한다.
  2. 남은 레인은 자동으로 채운다. 가시 레인 수 n에 대해 56px repeat(n, minmax(220px, 1fr))를 헤더와 바디에 동일하게 적용한다. 따라서 3→2→1 레인으로 줄어도 남은 열이 가용 폭을 균등하게 채운다.
  3. 색상 매핑은 ID 기준으로 유지한다. 숨겼다가 다시 표시해도 같은 의사는 반드시 같은 기존 tone index를 사용한다. 남은 레인의 순서에 따라 색을 재배정하면 안 된다.
  4. 마지막 한 레인은 숨기지 않는다. 마지막 레인의 눈 버튼은 비활성화하거나 기존 의사 선택 필터로 복원하게 한다. 이 시안의 ‘숨긴 레인 모두 표시’는 동작 검증용이며, 실제 앱에서는 기존 의사 선택 제어를 재사용한다.
  5. 접근성을 유지한다. 버튼은 aria-label="이승욱 레인 숨기기"를 가지며, hover뿐 아니라 키보드 focus에서도 노출된다.
