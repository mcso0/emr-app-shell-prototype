# 문서 이동 안내

`WP-05A`는 임상병리가 상위 계획의 다섯 번째 카테고리 단계에 배치됐다는
뜻이었고 실제 진행 순서를 뜻하지 않았다. 현재 작업 순서로 오해하기 쉬워
임상병리 작업을 `OED-LAB` 별도 계열로 바꿨다.

현재 기준 문서는
[OED-LAB-00: 임상병리 요구사항 및 조사 계약](./OED-LAB-00-requirements-and-research-contract.md)이다.
후속 작업은 `OED-LAB-01` 외부 전체 구조 조사부터 시작한다.
