# Reception / Appointment Epic Index

이 문서는 접수 / 예약 기능 패키지의 Epic 목록 진입점이다. CLAiR Docs viewer는 이 페이지에서 registry metadata 기반 Epic table을 표시한다.

## Index Rules

- Epic은 기능 패키지 안의 큰 작업 단위다.
- Epic 상세 문서는 목적, 배경, 범위, 사용자 스토리, 완료 기준, 예외 케이스, 관련 문서를 포함한다.
- User Story는 이번 단계에서 별도 파일로 분리하지 않고 Epic 상세 문서 안의 섹션으로 둔다.
- Linear issue는 구현 작업 단위이고, Epic은 product planning 단위다. 필요하면 Epic 상세 문서에서 관련 Linear issue를 연결한다.
