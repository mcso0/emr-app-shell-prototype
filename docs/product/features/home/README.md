# Home Feature Planning

This folder holds product planning source docs for the Home screen.

Current docs:

- `home-command-entry-planning.md`: Draft direction for changing Home from a role dashboard into a staff work-entry surface.
- `home-operations-work-status-contract-v0.md`: Approved contract for the hospital-wide `원내 현황` operations board, common status model, work generation rules, and API/read-model direction.
- `home-v1-epic-plan.md`: Draft Home v1 epics, user stories, acceptance criteria, and verification themes.
- `home-v1-reference-research.md`: Public product/reference research for Home v1 interaction patterns.
- `home-v1-ui-spec.md`: Draft UI structure for the Home v1 work-entry screen.
- `home-work-generation-rules-v0.md`: Draft rules for generating Home `내 업무` items from workflow requests and assignments.
