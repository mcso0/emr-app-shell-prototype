목적과 근거

수의사는 진료 기록을 작성하거나 과거 사례를 검토할 때 비슷한 증상·진단·처방이 담긴 차트를 찾는다. 현재 EMR의 차트 이력은 선택한 환자를 기준으로 열린다. 상세 검색에서는 같은 병원에서 열람할 수 있는 여러 환자의 차트를 함께 찾는다.

근거 장표관찰한 문제와 설계 의도
26–27 · 목적과거 차트를 찾은 뒤 진단과 처방을 참고하거나 새 차트를 작성한다. 진료 중 재사용과 사례 검토가 모두 사용 목적이다.
28–29 · 이탈 원인장표의 사용 기록 분석에서 조건 설정과 결과 탐색 단계에 이탈이 집중됐다. 수의사 7명의 사용성 테스트와 인터뷰에는 복사를 위해 화면을 오가는 불편도 기록됐다.
30 · 조건 설정자주 쓰는 필터에 바로 접근하고, 필요한 조건만 선택해 묶는다.
31 · 결과 판단방문 목적, 진단, 처방, 이미지·영상과 검색어가 일치한 부분을 목록에서 확인한다.
32 · 복사와 생성상세 화면에서 진행 중인 차트로 복사하거나 신규·재진 차트를 만든다. 장표 원안에는 여러 대상 차트 선택과 기존 내용 덮어쓰기가 포함돼 있다.

첫 버전은 한 번에 한 차트에 복사하고 검색 결과를 유지한다. 기본 동작은 추가이며, 교체는 선택한 A/P 문단에만 허용한다. 다른 환자의 S/O도 가져와 이번 진료에 맞게 수정할 수 있다. 과거 처방은 수의사가 용량·횟수·기간을 검토한 뒤 미확정 오더로 추가한다.

검색과 결과 탐색

  1. 진입. 차트 상단의 ‘차트 이력’ 옆과 EMR 통합 검색 양쪽에서 같은 ‘차트 상세 검색’을 연다. 차트에서 열면 작성 중인 환자·진료·차트와 입력 내용을 유지한다. 통합 검색에서는 환자를 먼저 선택할 필요 없이 사례를 찾고 원본을 읽을 수 있다.
  2. 첫 화면과 정렬 · 확정. 두 경로 모두 새로 열면 열람 가능한 최근 완료 차트를 바로 보여준다. 조건을 입력하면 해당 조건을 충족하는 차트만 표시한다. 검색어가 있으면 검색어와 더 잘 맞는 사례를 먼저 보여준다.
  3. 검색할 차트 상태. 기본은 완료한 차트만 표시한다. 완료 여부는 개별 차트의 서명을 기준으로 하며, 서명 후 정정한 차트도 포함한다. ‘작성 중 차트 포함’을 켜면 같은 검색 조건을 충족하고 열람 권한이 있는 작성 중 차트도 결과에 추가한다. 해당 행에는 ‘작성 중’을 표시한다. 옵션을 끄면 다른 검색 조건을 유지한 채 완료한 차트만 다시 표시한다.
  4. 검색어. 방문 목적·주호소, 수의사가 작성한 SOAP 전체 본문(기본·계통별 기록과 자유 작성 문단), 해당 차트의 진단명·오더명을 함께 찾는다. 공백으로 구분한 단어가 같은 차트 안에 모두 있으면 결과에 포함한다. 단어는 서로 다른 항목이나 문단에 있어도 되고 입력 순서는 무관하다. 예를 들어 ‘구토 초음파’는 방문 목적에 ‘구토’, 오더명에 ‘복부 초음파’가 있는 차트를 찾는다. 동물명·보호자명은 개별 필터로 찾는다.
  5. 부정 표현과 관련도순 · 확정. ‘구토’를 검색하면 ‘구토 없음’에만 일치한 차트도 결과에 남기되 뒤에 둔다. 같은 문장이나 다른 항목에 ‘어제 구토 3회’처럼 구토를 기록한 대목이 하나라도 있으면 일반 관련도 순서를 적용한다. 여러 단어를 검색하면 각 단어의 문맥을 따로 본다. 결과에는 부정 표현을 포함한 원문을 보여준다. 사용자가 진료일순을 선택하면 날짜를 우선한다.
  6. 조건 설정. 상단에 ‘내 차트’, ‘진료 담당의’, ‘진료일’을 둔다. ‘내 차트’는 로그인한 사용자가 작성한 차트, ‘진료 담당의’는 해당 방문의 담당 수의사를 기준으로 한다. ‘조건 추가’에서 동물명·보호자명·동물종·품종·진단 계통·진단명·포함된 오더명·검사 오더 있음(취소되지 않은 임상병리·영상 오더, 미수행 포함)를 선택한다.
  7. 복합 검색. 한 그룹 안에서 ‘모두 충족(AND)’ 또는 ‘하나 이상 충족(OR)’을 선택한다. 그룹 간 관계도 화면에 표시한다. 예를 들어 ‘내 차트 AND (진단명 A OR 진단명 B)’는 내가 작성했고 두 진단 중 하나 이상이 기록된 차트를 찾는다. 각 조건을 개별로 수정하거나 지울 수 있다.
  8. 화면 폭. 제목·필터·검색어가 있는 상단 바는 좁게 보기와 넓게 보기 모두에서 작업 영역의 전체 가로 폭을 채운다. 좁게 보기는 결과 목록을 최대 1120px로 중앙에 배치한다. 차트 원본 서랍은 두 보기 모두 작업 영역의 오른쪽 끝에 붙는다. 원본을 연 채 보기 폭을 바꿔도 같은 위치에서 같은 차트를 보여준다.
  9. 결과 목록. 차트 한 건을 한 행으로 표시하고 일치한 근거를 먼저 보여준다. 증상 검색에서는 구체적인 방문 목적과 일치한 S/O 문장을, 진단·오더 검색에서는 일치한 진단명·오더명과 진료 맥락 한 줄을 먼저 표시한다. 방문 목적이 비어 있거나 ‘현장 접수’처럼 일반적인 문구라면 실제 일치 문장을 앞에 둔다. ‘구토 없음’처럼 의미를 좌우하는 앞뒤 문구를 함께 표시한다. 환자·동물종·확인 가능한 나이·날짜·진료의, 해당 차트의 진단 구분과 대표 오더를 함께 볼 수 있다. 모든 행에 같은 크기의 썸네일 영역을 둔다. 해당 차트에서 열람 가능한 사진·동영상이 있으면 대표 미리보기와 자료 수를 표시하고, 없으면 같은 자리에 ‘없음’을 표시한다. 동영상은 정지 화면으로 표시하고 전체 자료는 상세에서 연다.
  10. 대표 썸네일 · 확정. 해당 차트 본문에서 열람 가능한 사진·동영상을 차례로 살핀다. 이름이나 설명에 검색 단어가 하나라도 들어간 첫 자료를 목록에 보여준다. 검색어가 비어 있거나 일치하는 자료가 없으면 본문의 첫 자료를 보여준다. 첨부 이름과 설명은 이미 찾은 차트의 썸네일 선택에만 쓴다. 화살표와 순번은 본문 순서를 따른다.
  11. 상세 확인. 결과 옆에서 원본을 읽고 ‘기존 차트에 복사’ 또는 ‘새 차트로 만들기’를 선택한다. 기존 차트에 복사를 완료하거나 취소하면 검색 조건, 결과 목록, 선택한 원본과 스크롤 위치를 유지한다. 같은 자리에서 다음 복사를 시작할 수 있다.

결과가 없을 때 적용한 조건을 그대로 보여주고 바로 수정할 수 있게 한다. 조회 실패 시에는 같은 조건으로 재시도한다. 열람 권한이 없는 차트는 목록, 건수, 미리보기에서 모두 제외한다.

항목별 복사 정책

수의사가 원본에서 가져올 항목을 고른다. 같은 화면에 원본과 대상의 환자명·진료일·차트 작성 시각을 함께 표시한다. 다른 환자에게 적용할 때는 대상 환자명을 최종 적용 버튼 가까이에도 표시한다.

원본 항목현재 차트에 적용할 방식
S/O
문진·관찰 소견		기본 선택은 해제한다. 같은 환자와 다른 환자 모두 문단별로 선택할 수 있다. 원본 환자와 진료일을 확인하고, 선택한 S 문단은 대상의 S 끝에, O 문단은 O 끝에 추가한다. 수의사는 가져온 문단을 대상 차트에서 이번 문진과 관찰 내용에 맞게 직접 수정해 저장한다.
A/P
평가·계획 서술		선택한 문단은 대상의 같은 항목 끝에 추가하는 것이 기본이다. 수의사가 ‘선택한 문단 교체’를 고른 경우에만 지정한 대상 문단을 교체한다. P의 처방 문구를 복사해도 오더를 생성하지 않는다.
진단명진단을 개별 선택하고 이번 진료의 확진·의심·감별 구분을 확인한다. 가져온 진단의 주진단 표시는 기본 해제한다. 수의사가 직접 선택하면 기존 주진단과 함께 유지한다. 같은 진단이 있으면 ‘이미 있음’으로 표시한다. 기존 진단의 상태와 분류를 자동 변경하지 않는다.
약·검사·처치 오더약·검사·처치는 현재 병원에서 사용 가능한 항목을 새 미확정 오더로 가져온다. 약을 선택하면 과거 처방의 용량·횟수·기간을 편집 가능한 입력란에 미리 채운다. 수의사가 세 값을 그대로 확인하거나 이번 환자에 맞게 수정한 뒤, 최종 값으로 대상 차트에 미확정 오더를 추가한다. 과거 오더명은 차트 조회 권한으로 볼 수 있다. 현재 단가와 사용 가능 여부를 보거나 미확정 오더로 복사할 때는 일반 오더 입력과 같은 병원 오더 목록 조회 권한이 필요하다. 같은 오더가 있으면 기존 행을 보여주고 중복 추가는 기본 해제한다. 현재 사용할 수 없는 항목은 사유를 표시한다.
바이탈·검사 결과·첨부원본에서 확인한다. 이전 측정값, 결과 파일, 이미지·영상을 이번 방문의 새 측정값·첨부로 등록하지 않는다.
서명·실행·수납 이력원본에 남긴다. 오더 확정, 검사·조제 요청, 수행 완료, 청구·수납 상태는 복사 대상에서 제외한다. 기존 차트에 적용해도 그 차트의 환자·보호자 정보, 작성자, 차트 진료 시각은 유지한다.

덮어쓰기와 새 차트

기존 차트에 복사

  1. 대상 한 건 선택. 내가 작성했고 현재 수정할 수 있는 작성 중 차트를 먼저 보여준다. 차트 안에서 시작하면 현재 내 차트가 대상 조건에 맞을 때 미리 선택한다. 필요하면 ‘수정 가능한 차트’에서 같은 병원의 동료가 작성했고 내가 수정할 수 있는 작성 중 차트도 고른다. 환자·진료·차트 작성자를 확인하고 한 건만 선택한다. 통합 검색에서는 ‘기존 차트에 복사’를 누를 때 대상을 정한다. 원본 자체와 서명 완료 차트는 대상에서 제외한다.
  2. 추가·교체 선택. 빈 항목은 ‘채우기’, 내용이 있으면 ‘아래에 추가’를 기본으로 한다. ‘선택한 문단 교체’는 A/P 서술에서만 제공한다. 빈 원본 값으로 대상 내용을 지우지 않는다.
  3. 변경 전후 확인. 교체할 때는 기존 문단과 새 문단을 함께 보여준다. 적용 버튼 위에 ‘P 문단 1개 교체 · 진단 1개 이미 있음 · 오더 초안 2개 추가’처럼 실제 변경 내역을 요약한다.
  4. 적용. 작성 중인 입력을 먼저 저장한다. 저장에 실패하면 입력과 선택을 보존하고 적용을 멈춘다. 서버가 원본 열람 권한, 대상 수정 권한, 상태와 최신 버전을 다시 확인한다. 대상이 달라졌으면 변경된 내용을 다시 비교한다. 복사 대기와 최종 적용 직전에 대상 환자의 삭제 상태를 확인한다. 삭제됐으면 새 차트나 선택 항목을 저장하지 않고 원본과 검색 결과를 유지한다. 사용자는 다른 대상을 골라 가져올 항목을 다시 확인한다. 선택 항목을 한 번에 저장하며, 재시도해도 중복 생성하지 않는다.

복사 후 대상 차트를 열면 가져온 S/O를 일반 문단처럼 편집할 수 있다. 복사 이력에는 원본과 대상 차트, 적용자·시각, 적용 항목, 교체 전후 기록을 남긴다. 복사본을 편집해도 원본에는 원래 문구가 남는다.

새 차트로 만들기

대상 환자와 진료 건을 먼저 선택한다. 진행 중인 진료에 추가 차트가 필요하면 현행 ‘새 차트’ 흐름을 사용한다. 새 차트 작성자는 로그인한 수의사이며, 차트 진료 시각의 기본값은 생성 시점이다. 새 방문이 필요하면 원본 차트와 선택 항목을 해당 환자의 접수·대기 동안 유지한다. 접수 후 검색 창을 닫아도 원본과 선택값을 해당 방문에 보관한다. 호출 후 복사를 시작한 수의사와 현재 배정된 담당 수의사는 수정 권한이 있으면 그 방문의 첫 차트에서 ‘복사 이어가기’를 눌러 원본·대상·변경 내용을 확인하고 한 번만 적용한다. 기존 대기 접수가 있으면 해당 방문을 이용한다. 환자·방문·원본·권한을 확인할 수 없으면 자동 적용하지 않는다.

적용 예시 수의사가 과거 차트에서 계획 한 문단과 약 한 건을 선택한다. 약의 용량과 횟수는 그대로 확인하고 기간만 수정해 적용한다. 대상 차트의 P 끝에 문단이 추가되고, 오더 목록에는 수정한 기간으로 미확정 약 한 건이 생긴다.

수용 기준과 측정

아래는 구현 후 합성 차트로 확인할 조건이다.

확인 장면기대 결과
두 진입 경로차트에서 열면 작성 중인 입력이 유지된다. 환자를 선택하지 않은 상태에서도 통합 검색에서 같은 상세 검색 화면을 열어 원본을 읽을 수 있다. 이 경로에서는 기존 차트에 복사할 때 대상 한 건을 선택한다.
첫 결과와 검색 순서처음 열었을 때 최근 완료 차트가 보인다. 조건을 추가하면 일치하는 차트만 남는다. 검색어를 입력하면 오래된 차트도 최근 차트보다 검색어에 더 잘 맞을 때 앞에 올 수 있다. 복사 후 돌아오면 최초 목록으로 초기화되지 않는다.
복합 조건 검색작성자 조건과 두 진단의 OR 그룹을 조합하면 해당 차트만 한 번씩 나온다. 같은 진료에 조건을 충족하는 차트가 두 건이면 두 행이 나온다.
작성 중 차트 포함같은 진료에 검색 조건을 충족하고 열람 가능한 완료 차트와 작성 중 차트가 한 건씩 있다. 기본 결과는 완료 차트 1건이다. 옵션을 켜면 두 건이 보이고 작성 중인 행에 ‘작성 중’이 표시된다. 다시 끄면 같은 조건에서 목록과 건수가 완료 차트 1건으로 돌아간다.
여러 단어 검색‘구토 초음파’와 ‘초음파 구토’는 같은 차트 집합을 반환한다. 목록과 원본에서 두 단어의 일치 위치를 확인할 수 있다. 한 단어만 있거나 같은 방문의 서로 다른 차트에 단어가 나뉘어 있으면 해당 차트는 결과에서 제외한다.
부정 표현의 순위‘구토’를 검색하면 ‘식후 구토’, ‘어제 새벽 구토 3회, 오늘은 구토 없음’, ‘구토 없음’ 세 차트가 모두 보인다. 관련도순에서는 앞의 두 사례가 부정 표현만 있는 사례보다 먼저 보인다. 부정 기록이 더 최근이어도 같은 규칙을 적용한다. 최근 진료순으로 바꾸면 세 사례를 진료일 순서로 볼 수 있다.
검색 범위와 일치 근거계통별 SOAP 또는 자유 작성 문단에만 검색어가 있어도 해당 차트를 찾을 수 있다. ‘구토 없음’은 부정 표현까지 보인다. 같은 방문의 다른 차트에서 작성한 오더는 이 차트의 일치 근거에 포함되지 않는다.
필터와 목록상단의 세 조건과 ‘조건 추가’에 정의한 항목을 선택할 수 있다. 방문 목적이 ‘현장 접수’이고 진단명이 일치하면 해당 진단이 먼저 보인다. 열람 가능한 동영상이 있으면 정지 미리보기에서 상세로 이동할 수 있다.
대표 썸네일모카 차트에서 ‘초음파’는 이름이 일치하는 두 자료 중 먼저 나오는 동영상의 정지 화면(2/3)을, ‘촉진’은 설명에만 일치하는 정지 영상(3/3)을 보여준다. ‘식욕’을 검색하거나 검색어를 지우면 첫 사진(1/3)으로 돌아온다. 열람 가능한 자료가 없는 차트는 같은 자리에 ‘없음’을 표시한다.
원본 서랍 위치원본을 연 상태로 좁게 보기와 넓게 보기를 전환하면 결과 목록의 폭이 바뀐다. 서랍의 오른쪽 가장자리는 두 보기에서 작업 영역의 오른쪽 끝과 맞닿는다.
결과 비교사용자가 목록에서 일치 근거를 찾고 원본을 확인할 수 있다. 연속으로 두 결과를 확인해도 검색 상태와 작성 중인 입력이 유지된다.
연속 복사복사 대상을 A 차트에서 B 차트로 바꾸고 적용하면 B에만 반영된다. 완료 후 같은 조건·결과 목록·선택한 원본·스크롤 위치에서 재검색 없이 A에 대한 별도 복사를 시작할 수 있다.
동료 차트에 복사내 작성 중 차트가 먼저 보인다. ‘수정 가능한 차트’에서 수정 권한이 있는 동료의 작성 중 차트 한 건을 선택해 적용할 수 있다. 열람만 가능한 차트와 서명 완료 차트는 선택할 수 없다. 이력에서 원래 작성자와 실제 적용자를 구분할 수 있다.
추가와 선택 교체P에 ‘보호자 안내’와 ‘재진 계획’이 있을 때 기본으로 적용하면 기존 두 문단 뒤에 새 문단이 붙는다. ‘재진 계획’을 교체 대상으로 지정하면 미리보기에서 확인한 해당 문단만 바뀐다. A도 같은 규칙을 따른다. 교체 대상은 A/P 서술 문단으로 한정한다.
다른 환자의 S/O 복사·수정환자 A의 S와 O에서 문단을 하나씩 골라 환자 B에 복사한다. B의 기존 S와 O 끝에 각각 문단이 추가된다. B에서 두 문단을 수정하고 다시 열면 수정한 문구가 보인다. A에는 원래 문구가 남고, B의 복사 이력에서 원본을 확인할 수 있다.
처방값 검토와 오더 추가약을 선택하면 입력란의 용량·횟수·기간이 원본과 일치한다. 그대로 확인해 적용하면 세 값이 모두 같은 미확정 오더가 생긴다. 기간만 수정해 적용하면 초안의 기간에 수정값이 반영된다. 적용 전에 취소하면 새 오더는 0건이다. 가격과 사용 가능 여부는 현재 기준으로 확인하며, 복사로 오더 확정·수행 요청·청구가 발생하지 않는다.
충돌·중복·권한다른 기기가 대상을 수정하거나 서명하면 적용이 중단된다. 권한이 바뀌거나 저장에 실패하면 일부 항목만 반영되는 일이 없다. 같은 요청을 재시도해도 한 번만 적용된다.
주진단 함께 유지기존 주진단 A가 있는 차트에서 다른 진단 B를 가져온다. 기본은 A만 주진단이다. B도 주진단으로 선택해 적용하면 A와 B의 주진단 표시가 함께 남는다.
접수 후 이어받기대상 환자를 접수하고 검색 창을 닫은 뒤 해당 방문을 호출하면 해당 방문의 첫 차트에서 원본과 선택 항목을 다시 확인할 수 있다. 수의사가 확인해 적용하면 한 번만 반영된다. 기존 대기 접수를 선택한 경우 추가 접수나 복사용 두 번째 차트가 생기지 않는다.
새 차트 생성선택한 진료에 새 초안 한 건만 생기며 선택한 항목만 들어간다. 원본 및 다른 진료 건의 기록은 바뀌지 않는다.

사용성 평가

사례 열람 과제는 ‘원하는 사례를 찾아 일치 근거를 설명했는가’, 복사 과제는 ‘지정한 대상에 필요한 항목만 적용했는가’로 평가한다. 검색 조건 설정, 결과 판단, 복사 확인 단계별 이탈과 소요 시간을 살핀다. 비슷한 두 사례 중 하나를 고르는 과제에서 방문 목적·일치 문장·미리보기 중 무엇을 보고 판단했는지도 확인한다. 단순 열람 세션까지 복사 실패로 집계하지 않는다.

장표 26과 28에는 개선 전 완료율이 각각 20%와 38%로 제시돼 있다. 두 값의 집계 기준을 확인하기 전까지 이번 EMR의 기준값이나 목표치로 사용하지 않는다.

결정 현황

① 확정 · 복사 대상과 결과 유지. 첫 버전은 한 번에 기존 차트 한 건에만 복사한다. 복사 후에도 검색 결과를 유지해 같은 목록에서 다음 복사를 이어간다.

② 확정 · 기존 내용 교체 범위. 기본은 기존 내용에 추가하는 것이다. 수의사가 필요할 때만 평가(A)·계획(P)에서 대상 문단을 직접 선택하고, 변경 전후를 확인한 뒤 그 문단을 교체한다.

③ 확정 · 다른 환자 기록 재사용. 다른 환자의 S/O와 A/P 문단, 진단명, 오더를 개별 선택할 수 있다. 가져온 S/O는 대상 차트에 추가한 뒤 수의사가 현재 환자에 맞게 수정해 재사용한다.

④ 확정 · 과거 처방 적용. 과거 처방의 용량·횟수·기간을 미리 채운다. 수의사가 그대로 확인하거나 수정한 뒤 미확정 오더로 추가한다. 최종 확정은 이번 진료의 기존 오더 확정 절차를 따른다.

⑤ 확정 · 검색 결과의 차트 상태. 기본은 완료한 차트만 보여준다. ‘작성 중 차트 포함’을 켜면 열람 가능한 작성 중 차트도 함께 보여준다.

⑥ 확정 · 검색 진입 경로. 차트 안과 통합 검색에서 같은 상세 검색 화면을 연다. 통합 검색에서는 환자 선택 없이 사례를 검토하고, 복사할 때 대상 차트를 고른다.

⑦ 확정 · 검색 첫 화면. 새로 열면 최근 완료 차트를 바로 보여주고, 조건을 입력하면 그 조건에 맞는 차트를 보여준다.

⑧ 확정 · 검색어의 범위. 방문 목적·주호소, 직접 작성한 SOAP 전체 본문, 해당 차트의 진단명·오더명을 함께 찾는다. 동물과 보호자는 이름 필터로 찾는다.

⑨ 확정 · 첫 버전 필터. ‘내 차트·진료 담당의·진료일’은 바로 제공한다. 동물명·보호자명·동물종·품종·진단 계통·진단명·포함된 오더명·검사 오더 있음는 ‘조건 추가’에 둔다. S/O·진단·Plan 서술은 검색어로 찾는다. 진료 당시 나이 범위와 본문 항목별 제한 검색은 후속 후보로 둔다. 사망 여부·일시와 별도 주치의 필터는 활용 과제를, 차트 타입은 분류 데이터가 갖춰졌는지를 확인한 뒤 검토한다.

⑩ 확정 · 결과 순서. 검색어가 있으면 관련도가 높은 사례부터 보여준다. 부정 표현의 순위는 ⑮를 따른다. 같은 그룹에서는 진단명·오더명이 정확히 일치하는 사례를 본문 언급보다 앞에 둔다. 같은 진단명이 정확히 일치하면 진료일이 최근인 사례부터 보여주고 목록에 확진·의심·감별을 표시한다. 필터만 적용하거나 관련도가 같아도 최근순이다.

⑪ 확정 · 목록의 정보 우선순위. 증상은 방문 목적과 일치한 소견, 진단·오더는 일치한 명칭을 먼저 보여준다. 사진·동영상은 해당 차트에서 열람 가능한 자료가 있을 때 대표 한 장과 나머지 자료 수를 표시한다.

⑫ 확정 · 복사 대상 후보. 내 작성 중 차트를 먼저 보여준다. 필요하면 현재 수정 권한이 있는 동료의 작성 중 차트도 선택할 수 있다. 차트 작성자를 표시하고 실제 적용자는 복사 이력에 기록한다.

⑬ 확정 · 새 방문으로 이어가기. 원본과 선택 항목을 접수·대기 동안 유지한다. 호출 후 해당 방문의 첫 차트에서 수의사가 선택 내용을 확인하고 한 번만 적용한다.

⑭ 확정 · 여러 단어 검색. 단어별로 검색 대상 항목을 확인하고, 모든 단어가 같은 차트에 있는 경우에만 그 차트를 한 번 표시한다.

⑮ 확정 · 부정 표현만 일치한 차트. 관련도순에서 부정 표현에만 일치한 차트는 뒤에 둔다. 같은 차트에 해당 증상이 있었다는 기록도 있으면 일반 순위를 유지한다.
