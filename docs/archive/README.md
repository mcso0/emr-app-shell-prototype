# Archive

Archive docs preserve historical plans, prompts, and records that are no longer active guidance.

Do not start new implementation work from archive documents unless an active work item or source-of-truth document explicitly points here.

Before moving a document here, mark or describe why it is no longer active guidance: `superseded`, `deprecated`, or `archived`.

Compatibility stubs may remain at old paths outside `archive/` when needed to protect existing links. Stubs should point to the canonical path and should not become a new source of truth.
