요청

스테이징 Cheongdam workspace 진입은 성공하지만 접수 본문에 26.05.01, 콩이/나비/코코/하루 같은 legacy daily work가 보이는 문제를 수정한다. Cheongdam은 새로 개업한 병원처럼 준비된 마스터/설정 데이터만 있고 active daily work는 기본 노출되지 않아야 한다. Sales Demo clair-demo는 삭제하지 않고 명시적 legacy demo로 보존한다.

변경 요약

  • workspace-clair-cheongdam을 prepared empty clinic 기본 workspace로 분리했다.
  • Reception helper가 workspace/date scope를 받아 Cheongdam에서는 legacy appointment, encounter, queue fixture를 섞지 않게 했다.
  • Reception 날짜 기준을 workspace별로 계산해 Cheongdam은 현재 운영일, clair-demo는 기존 2026-05-01 fixture date를 유지한다.
  • 로그인 기본 이동 경로를 Cheongdam reception으로 변경했고, Sales Demo launcher는 계속 clair-demo를 사용한다.
  • stale mock flash 방지를 위해 Cheongdam loading/error/local fallback 계산에서도 legacy daily work가 나오지 않도록 테스트를 추가했다.
