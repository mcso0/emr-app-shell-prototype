DEMO-DATA-PR-002 Candidate 5 Sales Demo Launcher Removal

작성일: 2026-06-17

요청

리팩터링 후보 5번인 Sales Demo launcher, fixed May 2026 scenario route, kong-vomit helper 정리를 진행했다. 목적은 Cheongdam seed/API 검증을 old Sales Demo 진입점이 가리지 않게 하는 것이다.

변경 내용

  • Home의 view=demo 분기를 제거해 /w/clair-demo/home?view=demo가 더 이상 old Sales Demo launcher를 열지 않게 했다.
  • old launcher component인 src/features/home/demo-launcher.tsx를 삭제했다.
  • 앱에서 import되지 않던 placeholder launcher module인 src/features/placeholders/module.tsx를 삭제했다.
  • launcher 전용 helper인 createDemoHref, getGoldenDemoScenario, GOLDEN_DEMO_SCENARIO_ID, DemoRoleId, unused demo query alias를 제거했다.
  • Home 회귀 테스트는 old launcher가 더 이상 열리지 않는 것을 확인하도록 바꿨고, legacy Kong flow 테스트는 direct explicit fixture route 기준으로 조정했다.

중요한 미변경 범위

  • scenario=kong-vomit, LEGACY_FIXTURE_OPERATING_DATE, fixed May 2026 mock data는 아직 삭제하지 않았다.
  • 이유는 여러 route-contract 테스트와 module regression 테스트가 이 fixture를 명시적으로 사용하기 때문이다.
  • 이 fixture 삭제는 Cheongdam seed/API replacement coverage가 같은 행동을 검증하게 된 뒤 별도 후보로 진행한다.
  • 원격 Supabase mutation, staging replay, production deploy는 수행하지 않았다.
