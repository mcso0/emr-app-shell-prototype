DEN-99 포트폴리오 가상 병원 데모 데이터셋 보고서

작성일: 2026-05-19 · Linear: DEN-99 · Project 04 / 00 Clinical Persistence Scope & Data Contract

요청

실제 런칭용 의료 데이터가 아니라, 포트폴리오용으로 실제 업무 프로그램처럼 작동하는 EMR MVP를 만들기 위한 가상 병원 데모 데이터셋 1차 기준을 정리했다.

결과

  • VIP동물의료센터 청담점을 고급형 중형 동물의료센터로 정의했다.
  • 접수부터 수납까지 이어지는 대표 외래 시나리오 5개를 만들었다.
  • 기본 오더, 세트오더, 템플릿, 진단계통, 진단명 샘플을 정의했다.
  • 데스크, 수의사, 테크니션, 수납, 병원관리자 역할별 업무 흐름을 정리했다.
  • 나중에 mock/seed/DB 데이터로 바꾸기 위한 handoff 문서를 작성했다.

참고 자료

AAHA guideline/standards, WSAVA vaccination guideline, ISFM/AAFP cat-friendly guideline, VetSCT, FDA/openFDA animal adverse event resources를 참고했다. 이 자료들은 실제 의료 데이터로 가져온 것이 아니라, 업무 흐름과 데이터 항목을 현실감 있게 설계하기 위한 참고 근거로만 사용했다.

제외 범위

  • 실제 환자/보호자/병원 데이터 접근 또는 저장
  • 실제 의료 데이터 import
  • 의료 정확성 보장 또는 수의사 검수 대체
  • remote Supabase, 실서버, production deploy
  • 오더/진단명 UI 구현 또는 DB migration 추가 구현
