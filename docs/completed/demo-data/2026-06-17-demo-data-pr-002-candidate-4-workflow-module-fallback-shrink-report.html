DEMO-DATA-PR-002 Candidate 4 Workflow Module Fallback Shrink

작성일: 2026-06-17

요청

리팩터링 후보 4번인 workflow module의 allowMockFallback 및 fixture fallback 경로를 줄였다. 목적은 Cheongdam seed/API 검증이나 일반 workspace 검증이 legacy fixture 성공처럼 보이지 않게 하는 것이다.

변경 내용

  • chart의 mock bundle fallback, queue fixture, fixed fixture date label을 명시적 legacy Sales Demo workspace에서만 허용하도록 변경했다.
  • lab/imaging의 result/study detail fallback, queue fixture, history fixture, right-panel fixture summary를 clair-demo에서만 허용하도록 좁혔다.
  • dispensing/treatment의 queue fixture, selected fixture fallback, history fixture, 기본 order table fixture cloning을 explicit Sales Demo fallback으로 제한했다.
  • billing의 invoice/detail fallback, queue rows, invoice/payment store fallback, fixed May 2026 side-panel date를 explicit Sales Demo fallback으로 제한했다.
  • workflow modules가 다시 !isPreparedEmptyClinicWorkspace(workspaceId) 기준으로 broad mock fallback을 열지 못하도록 회귀 테스트를 추가했다.

중요한 미변경 범위

  • 명시적 Sales Demo launcher, fixed scenario route, kong-vomit helpers는 삭제하지 않았다.
  • server-core mock gateways와 route-contract fixture는 변경하지 않았다.
  • 원격 Supabase mutation, staging replay, production deploy는 수행하지 않았다.
