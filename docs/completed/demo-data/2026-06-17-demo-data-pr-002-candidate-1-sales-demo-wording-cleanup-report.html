DEMO-DATA-PR-002 Candidate 1 Sales Demo 문구 정리

작성일: 2026-06-17

요청

리팩터링 후보 1번인 “Sales Demo 보존 전제 남은 테스트/문구 정리”를 먼저 진행했다. 목표는 Sales Demo가 현재도 보존 요구사항처럼 읽히는 문구를 없애고, Cheongdam seed workspace 검증이 현재 운영 기준임을 더 분명히 하는 것이다.

변경 내용

  • 오래된 demo-data work item의 “Sales Demo fallback을 보존한다”는 표현을 “historical scope” 또는 DEMO-DATA-PR-002 cleanup debt로 바꿨다.
  • DEN-64 Sales Demo preservation 문서를 superseded로 표시하고, 현재 기준은 workspace-clair-cheongdam seed 검증이라고 명시했다.
  • auth briefing, work order, QA, reception persistence 문서에서 Sales Demo golden path가 현재 제품 검증 기준처럼 읽히는 표현을 legacy fixture coverage로 낮췄다.
  • Sales Demo 관련 Playwright 테스트 제목을 “golden path/preserved”에서 “legacy/explicit fixture path”로 바꿨다. 테스트 동작은 바꾸지 않았다.
  • cleanup inventory와 active work item에 Candidate 1 진행 상태를 기록했다.

중요한 미변경 범위

  • runtime Sales Demo behavior, /w/clair-demo navigation, fixture constants는 삭제하지 않았다.
  • Cheongdam fixture guard, global entry point, workflow module fallback 축소는 후보 2-4번 범위로 남겼다.
  • local mock mode 자체는 삭제하지 않았다. 단, seed/API 검증 증거로 쓰지 않는다는 기준은 유지했다.

검증 기준

  • 직접적인 “Sales Demo 보존” 문구가 남아 있는지 rg로 재검색한다.
  • npm run docs:check를 실행한다.
  • npx tsc --noEmit를 실행한다.
  • 테스트 제목만 바꿨으므로 Playwright 전체 실행은 필수 검증이 아니다. 필요하면 후보 2-4번에서 focused UI 회귀를 실행한다.

다음 단계

후보 2번으로 넘어가면 Home, shell, command palette, notification의 /w/clair-demo 기본 진입점을 Cheongdam 중심으로 전환하거나 제거하는 작업을 진행한다.
