DEMO-DATA-PR-002 Candidate 2 전역 진입점 Workspace Scope 정리

작성일: 2026-06-17

요청

리팩터링 후보 2번인 Home, shell, command palette, notification의 /w/clair-demo 기본 진입점을 제거하거나 Cheongdam 기준으로 전환하는 작업을 진행했다.

변경 내용

  • Home mock dashboard가 반환하는 task, hospital task, empty launcher, flow summary, role-next-action link를 현재 workspaceId 기준으로 다시 scope하도록 변경했다.
  • 병원 전체 흐름 카드의 fallback href를 legacy /w/clair-demo/home에서 Cheongdam prepared clinic workspace home으로 바꿨다.
  • notification fixture route는 raw legacy fixture로 보존하되, shell runtime에서는 getWorkspaceScopedNotifications(workspaceId)를 사용해 notification source navigation이 현재 workspace를 벗어나지 않도록 했다.
  • command palette는 이미 quick action href를 active workspaceId로 만들고 Cheongdam에서 legacy fixture search를 숨기고 있어 코드 변경이 필요하지 않았다.
  • Home/notification workspace-scope 계약 테스트를 추가했다.

중요한 미변경 범위

  • 명시적 Sales Demo launcher와 LEGACY_SALES_DEMO_WORKSPACE_ID는 삭제하지 않았다.
  • raw fixture literal의 /w/clair-demo 문자열은 후속 삭제 후보로 남겼다.
  • Cheongdam module fallback 차단과 workflow module allowMockFallback 축소는 후보 3-4번 범위다.

주의사항

기본 3000번 포트에는 다른 worktree의 Next dev server가 떠 있어 Playwright가 잘못된 서버를 재사용할 수 있었다. 이번 검증은 별도 포트의 PLAYWRIGHT_BASE_URL로 실행했다. 또한 중단된 Playwright 실행이 만든 깨진 .next/dev/types generated cache를 제거하고 next typegen으로 정상 generated types를 사용했다.
