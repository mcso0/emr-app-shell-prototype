DEMO-DATA-PR-002 Candidate 3 Cheongdam Module Fallback Guard

작성일: 2026-06-17

요청

리팩터링 후보 3번인 Cheongdam 화면에서 legacy fixture가 조용히 섞이는 fallback 차단 작업을 진행했다. 이번 범위는 mock 전체 삭제가 아니라, workspace context가 누락될 때 legacy Sales Demo로 복구되는 기본값을 Cheongdam seed 검증 기준으로 바꾸는 데 한정했다.

변경 내용

  • src/lib/emr-domain/demo-workspaces.ts에 workspace route/path resolver를 추가했다. 기본 fallback은 workspace-clair-cheongdam이며, clair-demo는 명시적으로 들어온 경우에만 유지된다.
  • customer, reception, registration drawer, lab/imaging, dispensing, billing 화면에서 누락된 workspace 값을 직접 clair-demo로 보정하던 코드를 공통 resolver로 교체했다.
  • missing workspace fallback이 Cheongdam seed verification scope로 해석되고, explicit legacy route는 그대로 유지되는 회귀 테스트를 추가했다.

중요한 미변경 범위

  • server-core mock gateways와 route-contract fixture는 변경하지 않았다.
  • 명시적 Sales Demo launcher와 fixed May 2026 scenario route는 삭제하지 않았다.
  • workflow module의 broad allowMockFallback 축소는 후보 4번 범위로 남겼다.

다음 단계

후보 4번에서는 workflow module의 allowMockFallback 경로를 Cheongdam seed/API 검증 기준으로 더 좁히고, API 실패가 local mock 성공처럼 보이지 않도록 각 module의 loading/error/empty 상태를 점검한다.
