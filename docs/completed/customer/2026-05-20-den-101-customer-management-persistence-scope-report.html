DEN-101 고객관리 Persistence 범위 및 민감정보 경계

Project 06을 시작하기 전에 고객관리 persistence가 어디까지 책임지는지와 어떤 개인정보성 데이터를 저장하지 않을지 확정했다. 이 작업은 다음 schema 설계 이슈인 DEN-102의 기준 문서 역할을 한다.

핵심 결정

  • Project 06은 Project 03의 최소 접수 등록 스키마를 확장해 보호자/동물 master data를 다룬다.
  • 포함 범위는 보호자 상세, 동물 상세, 동의/내원경로, 보호자-동물 관계, 주 보호자 변경, soft delete/restore, 고객관리 read surface다.
  • 실제 보호자/동물/병원 데이터, 실제 고유식별정보, 메시지 provider, remote Supabase, production deploy는 제외했다.
  • Project 04 이후 화면이 소비할 patient/guardian 필드는 display-safe context로 제한하고, 권한 source로 쓰지 않는다고 명시했다.

민감정보 원칙

데이터 처리 원칙
전화번호/주소/이메일 검색과 표시를 위한 synthetic demo value만 저장한다.
현금영수증 번호 실제 식별번호가 아니라 demo placeholder만 허용한다.
주민등록번호 계열 실제 원문 저장 금지. masked display value와 non-real placeholder token만 허용한다.
동의/삭제 이력 상태, actor, time, reason만 저장하고 raw provider payload나 실제 서명 파일은 제외한다.
