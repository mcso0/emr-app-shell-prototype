고객관리 스키마 Migration

고객관리 상세 프로필을 저장할 local-first DB 기반을 추가했다. 접수용 기존 보호자/동물/관계/동의 테이블을 확장하고, 내원경로·중복 override·주치의 배정·변경 이력을 별도 테이블로 보강했다.

Status: Human Review

구현 내용

  • guardians, patients, patient_guardians, consents에 고객관리 상세 필드를 추가했다.
  • guardian_referral_sources, guardian_duplicate_overrides, patient_staff_assignments, customer_profile_change_logs를 추가했다.
  • customer_profile_deletion_locks view로 삭제 잠금 소스를 조회할 수 있게 했다.
  • supabase/seed.sql에 synthetic fixture와 masked placeholder 값을 추가했다.

보호한 경계

  • 실제 주민등록번호, 현금영수증 식별값, 주소/전화/이메일, provider payload는 추가하지 않았다.
  • remote Supabase, production deploy, staging/live migration은 진행하지 않았다.
  • hard delete는 추가하지 않고 soft delete/unlink 기반으로 설계했다.
  • Project 03 seed가 사용하는 관계 conflict target은 유지했다.
