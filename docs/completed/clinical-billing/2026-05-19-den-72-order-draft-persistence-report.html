DEN-72 오더 draft 저장 완료 보고

차트 오더 테이블의 청구서명, 수량, 삭제 draft 변경을 서버 route-backed 저장 흐름에 연결했다. 금액은 클라이언트 입력값을 믿지 않고 서버의 단가 snapshot 기준으로 다시 계산한다.

요청

  • Project 04의 DEN-72 02-02 Persist editable order draft table changes 구현.
  • DEN-100 chart-applied order snapshot 구조 사용.
  • mock fallback과 local-first boundary 유지.
  • Linear는 Human Review까지만 이동.

변경 내용

  • GET/PATCH /api/workspaces/[workspaceId]/chart/order-drafts route를 추가했다.
  • server core에서 chart:view, chart:update, active membership, encounter workspace scope를 확인한다.
  • billing display name과 quantity 저장을 지원하고, line total은 server unit price snapshot으로 재계산한다.
  • 차트 오더 테이블의 Order 업데이트 버튼이 route save를 호출한다.
  • 뒤늦게 도착한 draft load가 사용자의 빠른 입력을 덮어쓰지 않도록 draft touch boundary를 추가했다.
  • local-first Supabase RPC migration을 추가했다. remote Supabase 적용은 하지 않았다.
