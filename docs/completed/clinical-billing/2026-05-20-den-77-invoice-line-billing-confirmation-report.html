DEN-77 청구 라인/청구 확정 저장 완료 보고

수납 화면의 청구 항목 수량 수정과 청구 확정을 route-backed persistence로 연결했다. 금액은 클라이언트 입력값을 믿지 않고 서버가 단가와 수량으로 다시 계산한다.

작업 내용

  • GET/PATCH /api/workspaces/[workspaceId]/billing/invoice-lines 추가
  • active workspace membership, billing:view, billing:issue 확인
  • invoice workspace ownership과 invoice line ownership 검증
  • 청구 확정 시 status=issued, actor, timestamp 저장
  • 수납 화면 수량 편집과 청구 확정 버튼에 저장 중/저장됨/실패 상태 연결
  • local-first Supabase RPC migration 추가

검증

  • npx playwright test tests/billing-invoice-line-persistence-server.spec.ts --reporter=line: 통과
  • npx playwright test tests/billing.spec.ts --reporter=line: 통과

제외 범위

  • PG/payment provider, 영수증, 현금영수증, 세금 정산, 환불 workflow는 제외했다.
  • remote Supabase, 실서버, 실제 환자/병원 데이터는 사용하지 않았다.
