DEN-70 차트 작성완료 저장 리포트

차트 화면의 차트 작성완료 버튼이 더 이상 화면만 닫는 동작이 아니라, 서버 route를 통해 작성완료 상태와 작성자를 저장하도록 연결했다.

비개발자 요약

  • 수의사가 차트를 작성완료로 확정하면 그 상태가 새로고침 후에도 남는다.
  • 차트 완료는 수납 준비 상태로 넘기는 의미이며, 결제 완료와 섞지 않았다.
  • 권한 없는 역할은 차트 완료 상태를 저장할 수 없다.
  • 이번 작업은 synthetic demo-data와 local-first mock fallback 범위에서만 검증했다.

구현 범위

  • GET/PATCH /api/workspaces/[workspaceId]/chart/completion route 추가
  • active workspace membership, chart:view, chart:update, encounter workspace scope 검사
  • mock fallback과 Supabase RPC gateway 분리
  • chart_completed_at, chart_completed_by_user_id local-first migration 추가
  • 차트 헤더에 차트 완료 상태와 SOAP 상태를 분리 표시

검증

  • npx playwright test tests/chart-completion-persistence-server.spec.ts --reporter=line
  • npx playwright test tests/chart.spec.ts --reporter=line
  • npx tsc --noEmit
  • npm run build
  • npm run docs:check
  • npm run security:secrets

안전 경계

  • remote Supabase, 실서버, 실제 환자/병원 데이터에는 접근하지 않았다.
  • service role, DB password, secret 값은 추가하거나 노출하지 않았다.
  • Linear는 Human Review까지만 이동한다.
