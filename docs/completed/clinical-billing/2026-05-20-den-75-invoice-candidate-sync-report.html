DEN-75 수납 후보 동기화 완료 보고

확정/청구 후보 상태의 차트 오더를 수납 invoice candidate line으로 동기화하는 서버 경계를 추가했다. 금액은 클라이언트 입력이 아니라 서버의 오더/청구 snapshot 기준으로 계산한다.

변경 내용

  • GET/PATCH /api/workspaces/[workspaceId]/billing/invoice-candidates route 추가.
  • billing:view, billing:issue, encounter/order ownership 확인.
  • 동일 invoice/order pair 중복 candidate 생성 방지.
  • local-first Supabase RPC migration 추가. remote Supabase 적용은 하지 않음.

검증

  • npx playwright test tests/billing-invoice-candidate-sync-server.spec.ts --reporter=line: 통과
  • npx playwright test tests/chart.spec.ts tests/billing.spec.ts --reporter=line: 통과
  • npx tsc --noEmit: 통과
  • npm run build: 통과
  • npm run docs:check: 통과
  • npm run security:secrets: 통과

제외 범위

  • 결제 상태, 청구 확정, 환불/할인 고급 규칙은 제외했다.
  • 실서버, remote Supabase, 실제 환자/병원 데이터는 사용하지 않았다.
