DEN-78 수납 상태 저장 완료 보고

결제 수단 선택, 미납 처리, 수납 완료 상태를 route-backed persistence로 연결했다. 실제 PG 승인 없이도 포트폴리오 외래 흐름을 저장된 수납 상태로 닫을 수 있게 했다.

작업 내용

  • GET/PATCH /api/workspaces/[workspaceId]/billing/payment-status 추가
  • active workspace membership, billing:view, billing:issue 확인
  • 결제수단, 미납 사유, payment_state, paid_at 저장
  • 수납 완료 시 synthetic approved payment row 생성
  • local-first RPC에서 수납 완료 encounter를 completed로 마감
  • 수납 화면 결제수단/미납/수납완료 액션을 persisted route로 연결

검증

  • npx playwright test tests/billing-payment-status-persistence-server.spec.ts --reporter=line: 통과
  • npx playwright test tests/billing.spec.ts --reporter=line: 통과

제외 범위

  • PG transaction confirmation, refund provider, accounting settlement는 제외했다.
  • remote Supabase, 실서버, 실제 환자/병원 데이터는 사용하지 않았다.
