DEN-71 진단명 저장 완료 보고

차트의 진단명 선택, 자유 입력, 확진/중점 표시, 표시 순서를 서버 route-backed 저장 흐름에 연결했다. 이제 진단명 row는 SOAP와 차트 작성완료처럼 encounter와 workspace 기준으로 저장/조회되는 형태를 갖췄다.

요청

  • Project 04의 DEN-71 02-01 Persist diagnosis selection and free text rows 구현.
  • mock fallback과 local-first boundary 유지.
  • active workspace membership, permission, encounter ownership boundary 확인.
  • Linear는 Human Review까지만 이동.

변경 내용

  • GET/PATCH /api/workspaces/[workspaceId]/chart/diagnoses route를 추가했다.
  • server core에서 chart:view, chart:update, active membership, encounter workspace scope를 확인한다.
  • 진단 row는 catalog-linked/free-text, suspected/differential/confirmed, 중점 표시, row order를 보존한다.
  • 차트 진단명 패널의 추가, 확진 토글, 중점 토글, 삭제가 route save를 호출한다.
  • local-first Supabase RPC migration을 추가했다. remote Supabase 적용은 하지 않았다.
  • DB/migration 작업 전 docs/work와 demo-data/diagnosis 데이터 문서를 확인하라는 시작 문서 guardrail을 추가했다.
