DEN-69 SOAP 저장/autosave persistence 결과 보고

이번 작업은 차트 SOAP 기록을 화면 안 임시 상태가 아니라 서버 route를 통해 저장하고, 다시 열었을 때 같은 encounter 기준으로 읽어오게 만든 첫 chart persistence 단위다.

무엇이 바뀌었나

  • GET/PATCH /api/workspaces/[workspaceId]/chart/soap-notes route를 추가했다.
  • SOAP subjective, objective, assessment, plan field와 autosave timestamp를 저장/조회한다.
  • 서버 core에서 active workspace membership, chart:view/chart:update, encounter workspace scope를 확인한다.
  • 차트 SOAP editor에 수동 SOAP 저장과 autosave route 호출을 연결했다.
  • local-first Supabase RPC migration boundary를 추가했지만 remote Supabase에는 접근하지 않았다.

왜 중요한가

DEN-69로 차트 화면이 “새로고침하면 사라지는 기록”에서 벗어나기 시작했다. 아직 전체 EMR live persistence는 아니지만, Project 04의 chart/order/billing route-owned 저장 패턴을 하나 고정했다.
