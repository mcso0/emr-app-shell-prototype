DEN-73 오더 확정/청구 액션 저장 완료 보고

차트에서 선택한 오더의 Order 확정과 Order 청구 액션을 서버 route-backed 저장 흐름에 연결했다. 청구 액션은 invoice/payment 완료가 아니라 billing candidate hook point까지만 저장한다.

요청

  • Project 04의 DEN-73 02-03 Persist order confirmation and selected order submit action 구현.
  • DEN-100 chart-applied order snapshot 구조 사용.
  • mock fallback과 local-first boundary 유지.
  • Linear는 Human Review까지만 이동.

변경 내용

  • GET/PATCH /api/workspaces/[workspaceId]/chart/order-actions route를 추가했다.
  • server core에서 chart:view, chart:update, active membership, encounter/order scope를 확인한다.
  • Order 확정은 confirmation status, actor, timestamp를 저장한다.
  • Order 청구는 billing candidate status와 id만 저장하고 invoice/payment finalization은 하지 않는다.
  • 차트 확인 dialog의 confirm action이 route save를 호출하고, 저장 후 row status를 반영한다.
  • local-first Supabase RPC migration을 추가했다. remote Supabase 적용은 하지 않았다.
