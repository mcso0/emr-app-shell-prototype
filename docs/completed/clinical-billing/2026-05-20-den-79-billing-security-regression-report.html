DEN-79 수납 권한/금액 무결성 회귀 테스트 완료 보고

수납 mutation에서 권한 없는 사용자를 차단하고, 클라이언트가 보낸 금액을 믿지 않고, 서버가 저장된 단가와 수량으로 금액을 다시 계산한다는 점을 자동 테스트로 고정했다.

보호한 위험

  • 수의사 role 같은 unauthorized actor의 billing mutation 차단
  • 승인된 billing/admin role의 정상 mutation path 보존
  • client가 lineTotal, unitPrice, totalAmount를 조작해 보내도 서버 계산값 유지
  • payment_state가 none, unpaid, paid로 명시적으로 전환되는지 확인

검증

  • npx playwright test tests/billing-security-regression.spec.ts --reporter=line: 통과
  • npx playwright test tests/billing.spec.ts --reporter=line: 통과

남은 gap

  • 실제 PG 승인, 환불 provider, 회계 export 검증은 후속 범위다.
  • remote Supabase, 실서버, 실제 환자/병원 데이터는 사용하지 않았다.
