DEN-76 차트/수납 공통 읽기 완료 보고

차트와 수납 화면이 같은 persisted order/action/lifecycle/candidate 상태를 읽도록 연결했다. 수납 화면은 candidate overlay를 invoice line에 병합하고 총액을 다시 계산한다.

검증

  • npx playwright test tests/chart.spec.ts tests/billing.spec.ts --reporter=line: 통과
  • npx tsc --noEmit: 통과
  • npm run build: 통과
  • npm run docs:check: 통과
  • npm run security:secrets: 통과

제외 범위

  • 결제 완료 mutation, chart editor 변경, 외부 모듈 연동은 제외했다.
  • remote Supabase, 실서버, 실제 환자/병원 데이터는 사용하지 않았다.
