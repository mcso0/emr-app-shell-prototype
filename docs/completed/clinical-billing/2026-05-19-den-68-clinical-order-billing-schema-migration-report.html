DEN-68 Clinical Order Billing Schema Migration 보고서

대표 요약

차트, 오더, 수납을 실제 저장 흐름으로 바꾸기 위한 최소 DB 구조를 local-first migration으로 추가했다. 이제 다음 이슈부터 SOAP 저장 같은 실제 기능 연결을 시작할 수 있다.

추가된 테이블 묶음

영역테이블
서비스/가격 기초service_categories, service_items, service_item_prices
차트/진단soap_notes, soap_note_revisions, diagnosis_catalog, diagnoses
오더order_groups, orders, order_events, order_revisions, order_revision_fields
수납invoices, invoice_lines, payments

중요한 결정

  • 모든 clinical/billing row에 workspace_id를 넣었다.
  • encounter_id 기반 테이블은 workspace-scoped FK를 사용해 다른 병원 데이터와 섞이지 않게 했다.
  • 금액은 numeric(12,2)를 사용하고, order/invoice line total은 generated column으로 계산되게 했다.
  • 모든 새 테이블에 RLS를 켰지만, 최종 domain RLS policy는 후속 작업으로 남겼다.
