DEN-74 오더 lifecycle 저장 완료 보고

차트 오더의 요청, 진행, 완료, 취소 같은 최소 workflow 상태를 route-backed 저장 흐름에 연결했다. 서버에서 encounter/order 소속과 권한, 상태 전환 규칙을 확인한다.

변경 내용

  • GET/PATCH /api/workspaces/[workspaceId]/chart/order-lifecycle route 추가.
  • server core/gateway, mock fallback, local-first Supabase RPC migration 추가.
  • invalid transition, permission gap, cross-workspace/order mismatch 테스트 추가.
