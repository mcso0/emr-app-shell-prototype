# Completed Work Documents

이 폴더는 완료된 작업의 closeout 문서를 모으는 곳이다. 진행 중 계획이나 기준 문서는 `docs/implementation/`에 두고, 작업이 끝난 뒤 결과/검증/남은 후속 작업이 정리된 문서만 이곳으로 보관한다.

## 규칙

- 작업별 하위 폴더를 만든다. 예: `docs/completed/auth/`, `docs/completed/billing/`, `docs/completed/reception/`
- 파일명은 `YYYY-MM-DD-<work-slug>.md` 형식을 사용한다.
- 완료 문서에는 최소한 아래 내용을 남긴다.
  - 완료 날짜
  - 최종 목표와 실제 결과물
  - 변경한 주요 파일
  - 사용한 스킬
  - 통과한 검증 명령
  - 남은 후속 작업
- 작업 완료 시에는 완료 문서만 만들지 말고, `docs/implementation/mvp-current-status.md` 또는 해당 작업의 기준 문서도 함께 갱신한다.
