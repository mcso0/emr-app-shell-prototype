병원관리자 직원 초대 생성 Contract 보고

병원 실무진이 공개 가입으로 워크스페이스에 들어오지 못하도록, 병원관리자 서버 route 기반 직원 초대 생성 계약을 보강했다.

Status: Human Review Ready

구현 요약

  • POST /api/workspaces/[workspaceId]/invitations 성공 응답에 email/link approval gate를 명시했다.
  • 성공 응답은 emailDelivery: not_sent_approval_gated와 inviteLink: not_generated_approval_gated를 반환한다.
  • mock fallback 서버 gateway에서도 pending invitation 중복과 active member email을 차단한다.
  • raw invite token, OTP, magic link, provider payload는 응답/로그 계약에 포함하지 않는다.
