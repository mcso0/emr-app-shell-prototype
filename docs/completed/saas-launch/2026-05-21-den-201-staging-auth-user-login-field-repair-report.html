요약

DEN-200으로 synthetic auth.identities는 원격 staging에 적용되었지만, Supabase hosted Auth password login은 계속 invalid_credentials를 반환했다. read-only DB 확인에서는 identity, email confirmation, password hash match가 모두 정상이라, 후속 원인을 auth.users hosted login field shape로 좁혔다. 승인 후 repair migration을 원격 staging에 적용했고, synthetic password login smoke가 통과했다.
