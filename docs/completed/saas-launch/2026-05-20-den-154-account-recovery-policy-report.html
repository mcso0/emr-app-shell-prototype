계정 복구 및 초대 계정 충돌 정책 보고

파일럿 전 필요한 비밀번호 재설정, 계정 복구, 기존 계정 초대 충돌, 비활성/정지/재초대 정책을 정리했다. 결론은 명확하다. 비밀번호와 세션은 Supabase Auth가 맡고, 병원 접근 권한은 CLAiR 앱의 invitation과 membership이 결정한다.

Status: Account Recovery Policy Defined

핵심 결정

  • CLAiR EMR은 자체 password system을 구현하지 않는다.
  • Supabase Auth는 password reset, recovery redirect, authenticated password update, session, email verification, future MFA를 담당한다.
  • CLAiR app DB/server는 tenant approval, invitation, app user row, membership, role, permission, duplicate handling, audit을 담당한다.
  • Public self-signup은 launch foundation에서 계속 제외된다.

상황정책
비밀번호 재설정Supabase resetPasswordForEmail로 안내 메일 발송 후 recovery session에서 updateUser 사용
존재하지 않는 이메일계정 존재 여부를 노출하지 않는 generic response
