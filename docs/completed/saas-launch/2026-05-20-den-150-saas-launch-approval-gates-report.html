DEN-150 / SaaS Launch Foundation / 2026-05-20

SaaS 런치 승인 게이트 보고

런치 준비 중 실수로 위험한 작업이 실행되지 않도록 승인 게이트를 명문화했다. 이제 remote Supabase, 실제 이메일, production deploy, role policy 변경, real data, payment 작업은 “프로젝트 진행”과 별개로 승욱의 명시 승인을 받아야 한다.

Status: Approval Gates Defined

핵심 결정

  • 이슈나 프로젝트 승인이 곧 위험 작업 실행 승인을 의미하지 않는다.
  • 승인은 target environment, operation, input/source, verification, rollback/stop condition을 포함해야 한다.
  • 문서, local/mock 구현, local-first 검증은 범위가 명확하면 계속 가능하다.
  • remote/staging/live 작업, 실제 이메일, production deploy, 권한 정책 변경은 별도 승인 없이는 실행하지 않는다.

승인 게이트 목록

Gate위험 영역승인 전 금지되는 작업
G1Remote Supabase stagingsupabase link, remote migration push, remote SQL, dashboard mutation, staging secret use

G7Real datareal clinic, staff, guardian, patient, medical, billing data import
G8Payment/subscriptionprovider setup, billing logic, subscription enforcement, seat billing

런치 Blocker

  • remote Supabase target과 migration/RLS gate 승인
  • multi-instance 배포 전 shared production rate-limit store
  • launch route의 request id와 safe logging helper 적용
  • Supabase advisor와 security-definer RPC review
  • production log redaction
  • 실제 invite/password/account email delivery gate
  • password reset/account recovery policy
  • tenant approval과 최초 병원 관리자 초대 audit path
  • workspace/tenant isolation regression
  • deploy/remote DB rollback 또는 forward-fix plan

Local-First 단계에서 Blocker가 아닌 것

  • payment/subscription provider integration
  • SSO, SCIM, domain auto-join
  • active workspace를 만들지 않는 public request-access form
  • 실제 이메일 발송 없이 copyable invite link로 개발하는 것
  • real clinic/patient data import

검증

  • manual-linear-ops guardrail과 current-status guardrail을 비교했다.
  • DEN-29/DEN-30 local-first Supabase 및 secret-handling gate를 재사용했다.
  • DEN-96 API error/telemetry, DEN-97 rate limit, DEN-98 remote/staging blocker를 반영했다.
  • npm run docs:check로 문서 링크 무결성을 확인했다.
  • git ls-files '.env*' '.vercel/.env*' '**/.env*'로 tracked env 파일이 없음을 확인했다.
  • npm run security:secrets로 secret scan을 통과했다.
  • remote Supabase, DB/RLS 실행, 실제 이메일, production deploy, role policy 변경, real data 작업은 수행하지 않았다.
