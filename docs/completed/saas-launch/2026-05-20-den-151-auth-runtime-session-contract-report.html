Auth Runtime Session Contract 보고

로그인 런타임이 mock/local demo 경로와 Supabase Auth 경로를 어떻게 구분하는지 테스트와 문서로 고정했다. 이 작업으로 staging 준비 전에 “어떤 모드에서 무엇이 진짜 session source인가”가 더 명확해졌다.

Status: Runtime Contract Verified

핵심 결과

  • getAuthRuntimeMode() helper를 추가해 provider, client session source, server session source, missing config behavior를 한 곳에서 설명하게 했다.
  • useAuthClient()가 같은 helper를 사용하도록 정리했다.
  • NEXT_PUBLIC_AUTH_MODE별 동작을 테스트로 고정했다.
  • 명시적 supabase 모드에서 env가 없으면 mock fallback으로 위장하지 않고 configuration error 경로로 남긴다.
