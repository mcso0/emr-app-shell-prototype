승인 병원 워크스페이스 및 최초 관리자 초대 Action 보고

승인된 병원 tenant에 대해서만 워크스페이스와 최초 hospital_admin 초대 record를 생성하는 local-first server route를 추가했다. 실제 이메일 발송과 remote Supabase 실행은 여전히 승인 gate 뒤에 둔다.

Status: Server Action Boundary Implemented

생성 Flow

  1. readServerSession()으로 actor identity 확인
  2. mock fallback에서만 demo actor header 허용
  3. server-owned operator adapter로 CLAiR operator 권한 확인
  4. tenant_approval:manage 권한 요구
  5. 승인된 tenant이고 기존 workspace/first admin invite가 없을 때만 생성
  6. workspace record와 first hospital_admin pending invitation record 반환
  7. audit hook event 2개 준비
