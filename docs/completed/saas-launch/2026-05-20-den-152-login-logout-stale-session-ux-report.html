로그인/로그아웃/세션 UX 보강 보고

보호된 화면에 세션 없이 접근하거나 로그아웃했을 때 사용자가 왜 로그인 화면에 있는지 알 수 있도록 로그인 화면의 상태 안내를 보강했다. 안전하지 않은 next redirect는 계속 기본 워크스페이스로 떨어진다.

Status: Auth UX Hardened

수정된 UX 상태

상태URL signal메시지
세션 없음/만료reason=session_required로그인이 필요하거나 세션이 만료되었습니다.
로그아웃 완료reason=signed_out안전하게 로그아웃되었습니다.
권한 없음 placeholderreason=unauthorized이 워크스페이스에 접근할 권한이 없습니다.

변경 내용

  • AuthGate가 세션 없는 workspace 접근을 reason=session_required와 함께 로그인으로 보낸다.
  • LoginForm이 auth reason별 안내 메시지를 표시한다.
  • TopMenu와 WorkspaceTabsBar의 로그아웃 redirect가 /login?reason=signed_out로 통일됐다.
  • 외부 URL이 들어온 next는 기본 MVP 워크스페이스로 fallback되는 회귀 테스트를 추가했다.
