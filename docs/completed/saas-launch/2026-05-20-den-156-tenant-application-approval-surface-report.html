DEN-156 / SaaS Launch Foundation / 2026-05-20

Tenant Application 승인 모델 및 운영 화면 보고

승인제 SaaS에서 병원이 바로 워크스페이스로 들어가지 않도록, tenant application 상태 모델과 CLAiR 내부 운영자가 승인 대상을 볼 수 있는 최소 화면을 추가했다.

Status: Tenant Approval Surface Implemented

상태 머신

상태의미워크스페이스 생성
pending_review승인 대기tenant_not_approved로 차단
on_hold추가 확인 필요tenant_not_approved로 차단
approved승인됨workspace가 없을 때만 생성 가능
rejected반려됨tenant_rejected로 차단

구현된 화면

  • /ops/tenant-approvals route 추가
  • 승인 대기, 보류, 승인됨, workspace 연결 상태를 한 queue에서 표시
  • 미승인 병원이 workspace/member flow에 들어가지 않는다는 안내 표시
  • workspace 생성 가능/차단/연결 상태 표시
  • audit hook point 표시

중요한 제한

이 화면은 local/mock read-only surface다. 기존 AuthGate로 로그인 여부는 확인하지만, DEN-155의 server operator guard를 완성한 것은 아니다. 실제 승인 mutation, workspace 생성, 최초 관리자 초대는 DEN-157 이후 server-only boundary에서 구현해야 한다.
