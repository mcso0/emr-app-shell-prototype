synthetic 병원 데이터로 대표 리허설을 다시 확인했다. 현재 Preview 배포는 로그인 이후 홈, 접수, 진료, 검사, 영상, 조제, 수납, 고객관리 화면을 이동하며 핵심 데모 흐름을 보여줄 수 있다. 다른 병원 workspace 접근은 로그인/권한 안내로 막혔다.

결론은 조건부 Go다. 승욱이 직접 진행하는 synthetic staging 대표 시연은 가능하다. 다만 실제 병원 파일럿이나 외부 초대까지 열려면 real email invite dry-run(DEN-187)과 Human Review 승인이 남아 있다.

Launch Blockers

  • DEN-187 real email invite dry-run이 남아 있다. 실제 발송은 provider/from/test recipient 승인 전까지 하지 않는다.
  • Human Review 상태의 이슈들은 승욱 검토 후 Done 처리해야 한다.
  • Production, real customer/patient data, 결제/구독, enterprise onboarding은 이번 리허설 범위 밖이다.

Non-Blockers / Caveats

  • 직접 browser tab으로 audit API URL을 열 때 ERR_BLOCKED_BY_CLIENT가 한 번 발생했다. DEN-188에서 audit API read는 이미 통과했고, 이번 UI 리허설에는 영향이 없었다.
  • local Playwright 로그에 기존 tiptap duplicate extension warning이 표시됐다. 테스트 실패는 아니며, 이번 go/no-go의 launch blocker로 보지 않는다.
  • 05 Demo UX Sales Readiness 전체 polish는 아직 별도 트랙으로 남아 있을 수 있다. 현재 판단은 guided synthetic staging rehearsal 기준이다.

Recommended Next Step

DEN-189는 Human Review로 넘긴다. 다음 launch gate는 DEN-187 real email invite dry-run이다. 이 작업은 실제 이메일 발송 가능성이 있으므로 provider/from domain/test recipient 범위가 명확히 승인된 뒤 진행하는 것이 안전하다.
