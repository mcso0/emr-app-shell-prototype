DEN-268 초대 비밀번호 설정 및 재로그인 UX 완료 리포트

2026-05-24 · Initiative: CLAiR EMR SaaS Launch Foundation · Project: 03 Invite-Based Member Onboarding

요약

초대받은 신규 구성원이 이메일 인증 코드로 본인 확인을 마친 뒤 비밀번호를 설정하고, 이후에는 이메일과 비밀번호로 다시 로그인할 수 있도록 초대 로그인 흐름을 보강했다.

이번 변경은 Google/SNS 로그인을 도입하지 않고도 병원 직원 온보딩에 익숙한 계정 연결 경험을 제공하는 데 초점을 맞췄다.

변경 내용

  • Supabase Auth client에 verified session password update 경계를 추가했다.
  • 초대 OTP 로그인 화면에 Supabase 모드 전용 새 비밀번호/확인 입력을 추가했다.
  • 비밀번호는 8자 이상 및 확인값 일치를 클라이언트에서 먼저 검증한다.
  • OTP 검증 후 Supabase Auth로 비밀번호를 설정하고 초대 화면으로 복귀한다.
  • 이미 수락된 초대 화면에는 중복 멤버십 생성 대신 워크스페이스 이동 CTA를 제공한다.
  • repo work item과 auth handoff 문서를 DEN-268 기준으로 갱신했다.

보안 및 범위

  • 비밀번호 원문, OTP, magic link, raw invite token은 문서와 로그에 남기지 않았다.
  • 비밀번호 저장과 해싱은 Supabase Auth 책임으로 유지했다.
  • production Supabase, production deploy, DB/RLS/migration, 실고객 메일은 변경하지 않았다.
  • Google, SNS 로그인, SSO, MFA는 이번 범위에서 제외했다.
