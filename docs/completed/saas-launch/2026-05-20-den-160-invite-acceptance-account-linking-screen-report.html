초대 수락 계정 연결 화면 보고

직원이 초대 링크를 열었을 때 신규 계정 또는 기존 계정 연결 방식을 선택하고, 유효한 초대만 워크스페이스 멤버십으로 활성화되도록 local-first 화면을 추가했다.

Status: Human Review Ready

구현 요약

  • /invite/[invitationId] public invite acceptance page를 추가했다.
  • pending 초대는 신규 계정으로 시작과 기존 계정에 연결 모드를 제공한다.
  • 수락 성공 시 서버 accept route를 호출하고 local mock session과 active membership을 저장한다.

  • expired/canceled/accepted/missing 초대는 계정 및 멤버십 생성을 차단한다.
