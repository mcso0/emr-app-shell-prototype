DEN-321 Live Fulfillment Row QA Report

2026-05-30에 fixed staging 배포를 갱신하고, Supabase Auth staging runtime에서 fulfillment work item이 더미 fixture가 아니라 live row로 보이도록 1차 rework를 적용했다. 이후 DEN-323 범위로 접수에서 생성한 live encounter를 차트로 넘기는 handoff를 추가했고, DEN-326 범위로 encounterId 기반 billing candidate readback을 추가했다.

검수 링크

  • Fixed staging: https://emr-app-shell-prototype-staging-mcso0s-projects.vercel.app
  • Current preview: https://emr-app-shell-prototype-72mpsg5sd-mcso0s-projects.vercel.app

수정 내용

  • 임상병리/영상 화면은 Supabase Auth runtime에서 /fulfillment/work-items?queueType=lab|imaging 결과를 실제 queue/detail row로 변환한다.
  • 조제/처치 화면은 Supabase Auth runtime에서 fixture queue에 덮어쓰지 않고 live fulfillment work item을 standalone row로 보여준다.
  • local/mock demo runtime에서는 기존 Sales Demo fixture fallback을 유지한다.
  • 담당자 action은 기존 PATCH /fulfillment/work-items/[workItemId] 경로를 계속 사용한다.
  • 접수 화면에서 live 환자/보호자 lookup 결과를 세션 profile store에 병합해, Supabase Auth runtime에서 walk-in 생성 직후 side panel과 drawer가 같은 환자/보호자 context를 유지한다.
  • 접수 카드와 drawer의 차트보기 액션은 live encounter/patient/guardian context를 sessionStorage handoff로 저장한 뒤 /w/:workspaceId/treatment?encounterId=...로 이동한다.
  • 차트 화면은 mock bundle에 없는 live encounter id라도 handoff가 있으면 같은 encounter id로 환자 context와 chart draft/order confirm API 경계를 열 수 있다.
  • Billing 화면은 ?encounterId=...로 들어온 live encounter handoff와 /billing/invoice-candidates?encounterId=... 결과를 합쳐 LIVE-<진료번호> 청구 detail과 candidate line을 렌더링한다.

제한 사항

  • Headless/curl staging 검증은 Vercel SSO 보호로 401에서 막혔다. 대표 로그인 세션의 in-app browser에서 수동 검수가 필요하다.
  • production deploy는 하지 않았다.
  • 실데이터 import, 원격 RLS replay, 승인 없는 staging DB migration은 하지 않았다.
  • 접수부터 chart 진입은 DEN-323에서 같은 브라우저 세션 기준으로 연결했다. 새로고침 이후 live 환자/보호자 context까지 완전 복원하려면 reception queue RPC가 patient/guardian snapshot을 반환하거나 별도 live chart encounter read API가 필요하다. 이 DB/API 확장은 승인 gate 전에는 적용하지 않았다.
  • lab/imaging 수의사 확인 gate와 billing candidate 화면 readback은 DEN-326의 최소 readback까지 연결했다. 단, lab/imaging 담당 수의사 확인 후 billing advance는 아직 별도 버튼/API 흐름으로 staging 수동 검수가 필요하다.
  • 전체 fixed staging replay와 Human Review 이동은 후속 하위 이슈 DEN-327에서 계속 진행해야 한다.
