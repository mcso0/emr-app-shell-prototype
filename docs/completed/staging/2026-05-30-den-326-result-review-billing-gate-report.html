DEN-326 Result Review Billing Gate Report

lab/imaging fulfillment 완료 후 차트에서 바로 수납으로 넘어가지 않고 수의사 확인 필요로 보이게 했고, 담당 수의사가 확인하면 billing candidate가 생성되는 gate를 연결했다.

검수 링크

  • Fixed staging: https://emr-app-shell-prototype-staging-mcso0s-projects.vercel.app
  • Current preview: https://emr-app-shell-prototype-ktennfsms-mcso0s-projects.vercel.app

수정 내용

  • 새 API PATCH /api/workspaces/:workspaceId/chart/result-review-billing를 추가했다. 이 route는 chart:update 권한이 있는 actor만 lab/imaging 완료 work item을 billing candidate로 advance할 수 있게 한다.
  • fulfillment core에 syncVetReviewedBillingCandidates를 추가해, lab/imaging work item이 completed 상태가 아닐 때는 invalid_review_gate로 막는다.
  • 차트 오더 테이블은 completed lab/imaging row에 billing candidate가 없으면 수의사 확인 필요 상태와 수의사 확인 버튼을 보여준다.
  • 수의사 확인 성공 후 같은 row가 수납 후보로 바뀌고, 기존 billing candidate readback 화면에서 후보 line을 확인할 수 있다.

검증 결과

  • npx tsc --noEmit --pretty false: 통과
  • npm run security:secrets: 통과
  • npx eslint ...: 에러 없음. 기존 chart hook dependency warning 2개는 남아 있다.
  • PLAYWRIGHT_BASE_URL=http://localhost:3109 npx playwright test tests/fulfillment-work-item-server.spec.ts -g "fulfillment completion holds lab and imaging billing until vet review" --reporter=line: 1개 통과
  • PLAYWRIGHT_BASE_URL=http://localhost:3109 npx playwright test tests/chart.spec.ts -g "result readback holds lab billing until veterinarian review" --reporter=line: 1개 통과
  • Vercel preview deploy 성공: https://emr-app-shell-prototype-ktennfsms-mcso0s-projects.vercel.app
  • Fixed staging alias 갱신 성공: https://emr-app-shell-prototype-staging-mcso0s-projects.vercel.app

제한 사항

  • 기존 local dev server는 in-memory fulfillment 상태가 terminal 상태로 남아 있어 full route replay 일부가 409 invalid_transition에 걸렸다. DEN-327에서는 fresh fixed staging session 기준 full replay가 필요하다.
  • production deploy는 하지 않았다.
  • 실데이터 import, 원격 RLS replay, staging DB migration은 하지 않았다.
  • Vercel 보호/로그인 세션이 필요한 fixed staging 화면 검수는 대표 브라우저에서 이어가야 한다.

판단

DEN-326은 Human Review로 넘길 수 있다. 다음 작업은 DEN-327에서 fixed staging 기준 병원관리 Order 생성부터 chart 확인, lab/imaging 수의사 확인, billing candidate readback까지 전체 replay를 수행하는 것이다.
