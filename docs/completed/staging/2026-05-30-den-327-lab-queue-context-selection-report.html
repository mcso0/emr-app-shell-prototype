DEN-327 임상병리 대기열 환자 컨텍스트 및 기본 선택 보강

임상병리/영상 live fulfillment queue가 chart 확정 컨텍스트의 환자명과 보호자명을 잃고 DB encounter fallback 이름을 표시하던 경로를 보강했다. 또한 lab/imaging 진입 시 fulfillment queue의 첫 업무가 detail로 즉시 이어지도록 queue cache와 fallback detail 선택을 추가했다.

변경 요약

  • chart order confirmation catalog selection에 patientName, guardianName을 포함했다.
  • server applied snapshot과 fulfillment order snapshot이 환자/보호자 표시명을 보존하도록 확장했다.
  • Supabase fulfillment sync 직후 기존 order_fulfillment_work_items.source_snapshot을 chart snapshot으로 보강 저장한다.
  • lab/imaging live rendering은 같은 브라우저 세션의 chart handoff 환자/보호자를 우선 사용한다.
  • lab/imaging fulfillment queue fetch 결과를 모듈 내 cache로 공유해 side panel, header, content가 같은 첫 row를 사용한다.
  • staging demo encounter bridge UUID를 원래 chart demo encounter로 되돌려 lab/imaging read 화면에서 기존 rows도 chart 환자/보호자명으로 표시한다.
  • chart order action 전 draft 저장 응답이 일부 row만 반환해도 현재 chart row를 보존하도록 mutation merge를 보강했다.
  • fulfillment work item snapshot enrichment update 실패는 표시명 보강 실패로만 취급하고 order confirmation 자체를 막지 않도록 조정했다.
  • mock chart encounter id가 current staging synthetic encounter number 후보로 resolve되도록 server bridge를 확장해 특정 fixture 환자만 저장되는 경계를 완화했다.
  • lab/imaging readback bridge에 E-DEN194-0002, E-DEN194-0004 역매핑을 추가해 chart 환자/보호자 표시명을 유지했다.
