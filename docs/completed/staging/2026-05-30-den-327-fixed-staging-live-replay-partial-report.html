DEN-327 Fixed Staging Live Order E2E 부분 검증 리포트

새 live 접수 환자 준하 / 이순재를 기준으로 fixed staging에서 reception, chart live queue, order confirm, treatment fulfillment completion, chart lifecycle readback까지 검증했다. billing candidate readback은 새 live encounter에서 비어 있어 DEN-329 blocker로 분리했다.

변경 사항

  • PATCH /api/workspaces/[workspaceId]/fulfillment/work-items/[workItemId] route에 DB-backed workspace permission adapter를 연결했다.
  • GET/PATCH /api/workspaces/[workspaceId]/chart/order-lifecycle route에 DB-backed workspace permission adapter를 연결했다.
  • Supabase session actor가 admin일 때도 live fulfillment completion과 chart lifecycle readback 권한을 서버에서 workspace membership 기준으로 판정한다.

Staging Replay 결과

  • 통과: 새 접수 준하 / 이순재가 reception queue와 chart live queue에 표시됨.
  • 통과: chart에서 고정스테이징 처치 mprv3quc order 추가/저장/확정 완료.
  • 통과: 조제/처치 queue 첫 row에 준하 / 이순재와 같은 order명이 표시됨.
  • 통과: 조제/처치 UI에서 담당하기 후 완료 처리, work item API status가 completed로 readback됨.
  • 통과: chart lifecycle API에서 해당 treatment order가 completed로 readback됨.
  • 차단: billing invoice candidate API는 새 live encounter에 대해 candidates: []를 반환함.
