DEN-84 / Project 05

Live MVP Audit Log Persistence 보고서

후속 mutation route들이 “감사 로그를 남길 수 있는” DB 구조와 서버 helper 경계를 만들었다.

무엇이 생겼나

  • audit_events 테이블 migration을 추가했다.
  • workspace, actor, target, before/after, metadata를 담는 append contract를 만들었다.
  • route들이 부를 수 있는 server-only append helper를 추가했다.
  • 민감 키가 들어오면 DB에 쓰기 전에 차단한다.

중요한 안전 결정

  • audit table은 직접 client mutation을 열지 않는다.
  • append는 clair_append_audit_event RPC와 server helper를 통해서만 한다.
  • 시크릿, token, raw provider payload, stack trace, SQL error, 전체 SOAP/차트 본문은 payload에 저장하지 않는다.
  • 아직 실제 mutation route에 event emit을 연결한 것은 아니다. 그건 DEN-85 범위다.

검증

  • npx playwright test tests/live-audit-log-persistence.spec.ts --reporter=line: 통과
  • npx tsc --noEmit: 통과
