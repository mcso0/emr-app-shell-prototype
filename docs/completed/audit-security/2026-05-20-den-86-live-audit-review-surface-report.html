Project 05 / DEN-86 / Human Review

Live Audit Review Surface Report

병원관리자가 주요 audit event를 확인할 수 있는 최소 화면을 추가했다. 병원관리 모듈의 감사 로그 메뉴에서 시간, 이벤트, actor, target, 안전한 요약을 볼 수 있다.

작업 범위

항목내용
UI 진입점병원관리 > 감사 로그
서버 routeGET /api/workspaces/[workspaceId]/audit/events
DB read RPCpublic.clair_list_audit_events(...)
권한hospital_admin만 허용, non-admin은 접근 제한
필터검색어와 event type 최소 필터

제외한 것

분석 차트, 다운로드/내보내기, 보관 정책 UI, 외부 compliance export, 실제 운영 데이터 접근은 제외했다. Audit payload도 DEN-83 기준대로 전체 SOAP/chart body, raw payload, secret/token류를 노출하지 않는다.
