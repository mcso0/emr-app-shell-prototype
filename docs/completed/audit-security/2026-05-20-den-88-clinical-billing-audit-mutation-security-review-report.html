Clinical Billing Audit Mutation Security Review Report

차트, 오더, 수납, 감사 로그 경계를 보안 관점에서 점검했다. 코드 수정 없이 source review와 focused regression으로 확인했다.

대표 판단 요약

분류결론
High새로운 High severity route bug는 발견하지 못했다.
MediumDEN-83 audit matrix 전체 기준으로는 일부 mutation audit emission이 아직 빠져 있다.
Mediumremote/live 전 clinical/billing domain RLS local replay와 advisor review는 계속 필요하다.
Lowdenial UX 문구와 fallback 오해 가능성은 DEN-90 QA에서 추가 확인하면 된다.

확인한 방어선

  • chart/order/billing mutation은 active workspace membership과 domain permission을 확인한다.
  • encounter와 invoice는 workspace ownership을 확인한다.
  • billing amount는 client 제출값이 아니라 server-owned unit price와 quantity로 재계산한다.
  • audit payload는 SOAP 전문, raw payload, secret, stack trace, SQL error를 저장하지 않는 방향으로 제한되어 있다.

후속 후보

  • diagnosis.changed, order.draft_changed, order.status_changed audit emission 추가
  • billing.invoice_candidate_generated, billing.invoice_line_changed, billing.invoice_issued audit emission 추가
  • invoice line edit와 billing confirmation audit fail-closed regression 추가
