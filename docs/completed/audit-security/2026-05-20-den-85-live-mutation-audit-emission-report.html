Project 05 / DEN-85 / Human Review

Live Mutation Audit Emission Report

DEN-84에서 만든 audit 저장 기반을 실제 주요 mutation 흐름에 연결했다. 이제 워크스페이스 구성원 변경, 접수, 차트, 오더, 수납 상태 변경이 안전한 요약 audit event를 남기는 구조가 됐다.

연결한 이벤트

영역MutationAudit event
워크스페이스구성원 역할 변경workspace.membership_roles_changed
워크스페이스구성원 상태 변경workspace.membership_status_changed
접수현장 접수 생성reception.walk_in_created
접수예약 체크인reception.appointment_checked_in
차트SOAP 저장chart.soap_saved
차트차트 완료/수납 handoffchart.completed
오더오더 확정/청구 후보 요청order.confirmed, order.billing_candidate_requested
수납결제 상태 변경billing.payment_state_changed

안전 기준

Audit payload에는 actor, workspace, target id, encounter/patient/guardian id, request id, enum 상태 요약만 남긴다. 전체 SOAP 본문, raw request payload, token, password, service role, stack trace, SQL error, 실제 환자/병원 데이터는 남기지 않는다.
