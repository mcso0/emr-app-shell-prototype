AUTH-PR-046 · 2026-08-30

업로드한 프로필 사진이 상단 메뉴에도 이어져

직원 프로필에서 올린 사진을 현재 사용자 전용 읽기로 연결했다. 사진이 없으면 한글은 한 글자, 영문은 두 글자로 안정적으로 표시한다.

구현 및 로컬 범위 검증 완료

무엇이 달라졌나

  • 상단 프로필과 펼침 메뉴가 기존 shadcn/Base UI Avatar를 사용한다.
  • 현재 사용자의 private avatar pointer를 서버에서 읽어 5분 signed URL로 전달한다.
  • 응답은 private, no-store이며 signed URL은 브라우저 저장소에 남기지 않고 만료 전에 갱신한다.
  • 업로드·삭제·이름 저장 직후 상단 프로필이 자동으로 다시 읽힌다.
  • 한글 폴백은 한 글자, 영문 폴백은 두 글자를 유지한다.

검증

  • 개인 프로필 GET 인증·live-only·no-store 경계 검증
  • 프로필 메뉴와 한글/영문 폴백 브라우저 검증
  • 기존 직원 private/legacy avatar 해석 회귀 검증
  • TypeScript 검사 통과

범위와 주의점

이번 변경은 애플리케이션 읽기와 표시만 바꾼다. DB 스키마, RLS, Storage 정책, 업로드 검증, 원격 데이터와 환경 설정은 변경하지 않는다. signed URL은 발급 후 최대 5분 동안 유효한 기존 계약을 그대로 따른다.
