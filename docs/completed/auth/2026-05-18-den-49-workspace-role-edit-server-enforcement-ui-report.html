DEN-49 Workspace Role Edit Server Enforcement UI 보고서

작성일: 2026-05-18

역할 수정 UI가 이제 서버 권한검사를 통과한 뒤에만 화면 상태를 바꾼다. 실제 DB 저장은 DEN-50으로 남겼다.

변경

  • POST /api/workspaces/[workspaceId]/memberships/[membershipId]/roles를 UI confirm path에 연결했다.
  • 서버 거절/실패 시 안전한 오류 문구를 표시한다.
  • Mock permission adapter의 동적 workspace/member id 회귀를 보정했다.

검증

  • npx playwright test tests/auth.spec.ts tests/server-permission-enforcement.spec.ts -g "edit active member roles|role update server" --reporter=line 통과
  • npx tsc --noEmit 통과
  • npm run build 통과

제외 범위

  • DB role write persistence는 구현하지 않았다.
  • remote Supabase와 실제 데이터는 건드리지 않았다.
