DEN-35 Local Migration Validation And Auth Seed 보고서

Workspace auth migration을 재현 가능하게 검증하기 위한 local Supabase 절차와 deterministic auth seed contract를 추가했다. 현재 환경은 Docker가 없어 실제 local DB apply는 실행하지 못했다.

추가한 산출물

  • supabase/seed.sql: local auth seed contract
  • docs/engineering/auth-security/auth-login/workspace-auth-local-validation-and-seed.md: local validation, reset, rollback 절차
  • tests/workspace-auth-seed-contract.spec.ts: seed contract regression

Seed contract summary

  • Workspace: clair-demo
  • Users: admin@clair.local, vet@clair.local, technician@clair.local, front-desk@clair.local
  • Canonical roles: hospital_admin, vet, technician, front_desk
  • Permission policies: role-scope allow-only MVP policy rows
  • Legacy compatibility: nurse -> technician, billing_admin -> hospital_admin

검증 환경과 명령

  • npx supabase --version returned 2.98.2
  • npx supabase db reset --help, npx supabase db lint --help, npx supabase stop --help 확인
  • docker info --format '{{.ServerVersion}}'는 docker: command not found로 실패
  • npx supabase migration list --local은 local Postgres 127.0.0.1:54322 미기동으로 실패
