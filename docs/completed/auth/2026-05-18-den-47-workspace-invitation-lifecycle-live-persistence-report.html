DEN-47 Workspace Invitation Lifecycle Live Persistence 보고서

작성일: 2026-05-18

초대 재발송, 취소, 수락이 이제 서버 route와 local Supabase DB transaction을 거친다. 실제 이메일과 공개 초대 링크는 아직 제외했다.

무엇이 바뀌었나

  • 초대 재발송, 취소, 수락 route를 추가했다.
  • public.clair_resend_workspace_invitation(), public.clair_cancel_workspace_invitation(), public.clair_accept_workspace_invitation() DB 함수를 추가했다.
  • 재발송은 pending 유지와 resend count 증가를 저장한다.
  • 취소는 pending 초대를 canceled로 바꾼다.
  • 수락은 pending 초대를 accepted로 바꾸고 active membership을 만든다.

제외 범위

  • 실제 이메일 발송은 구현하지 않았다.
  • 공개 초대 링크/랜딩 페이지는 구현하지 않았다.
  • seat billing enforcement는 구현하지 않았다.
  • remote Supabase와 실제 데이터는 건드리지 않았다.
