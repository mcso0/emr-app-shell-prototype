DEN-52 Personal Profile Live Persistence 보고서

작성일: 2026-05-18

개인 프로필 설정을 서버 route와 로컬 Supabase DB 저장 경계에 연결했다. 이름, 이니셜, 연락처, 알림 설정만 저장하며 역할/권한/멤버십 판단에는 사용하지 않는다.

변경 사항

  • PATCH /api/users/me/profile route 추가
  • src/features/auth/server-personal-profile.ts 서버 저장 경계 추가
  • public.clair_save_personal_profile(...) 로컬 DB RPC migration 추가
  • 프로필 설정 UI를 route-backed save 흐름으로 연결
  • 권한 source 분리 회귀 테스트 추가
