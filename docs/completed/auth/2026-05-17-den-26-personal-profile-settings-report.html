개인 프로필 설정

사용자가 본인 표시 정보를 수정하되, 권한 판단 source와는 분리되도록 session-only 프로필 설정을 추가했습니다.

요청 사항

대표 요구사항 중 “사용자가 자신의 개인 프로필 설정이 가능해야 한다” 항목을 구현했습니다. 단, 사용자가 직접 수정할 수 있는 프로필 정보가 역할이나 권한 판단에 사용되지 않도록 경계를 분리했습니다.

구현 내용

  • 프로필 메뉴에 개인 프로필 설정 진입점을 추가했습니다.
  • /profile 페이지를 auth gate 뒤에 두어 로그인 사용자만 접근하게 했습니다.
  • 이름, 이니셜, 연락처, 운영 알림 placeholder를 수정할 수 있게 했습니다.
  • 저장된 이름과 이니셜은 shell profile menu에 반영됩니다.
  • 역할/권한 정보는 읽기 전용 문구로만 제공하고 self-service 변경 UI는 만들지 않았습니다.

권한 분리 기준

구분이번 구현이유
개인 프로필사용자 표시 정보 저장사용자 경험을 위한 정보이며 권한 source가 아닙니다.
역할/권한읽기 전용 표시권한은 workspace membership과 permission policy에서만 판단해야 합니다.
저장 위치clair.personalProfiles.v1기존 session-only prototype 경계를 유지합니다.
