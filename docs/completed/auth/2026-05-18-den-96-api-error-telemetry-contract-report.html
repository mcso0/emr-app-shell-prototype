DEN-96 API Error And Telemetry Contract 보고서

작성일: 2026-05-18

workspace/member/profile API가 실패할 때 사용할 공통 응답 모양, 상태 코드 기준, request id와 안전 로그 기준을 문서화했다.

확정 내용

  • ok, requestId, error, denialReason, fieldErrors 중심의 failure envelope
  • 400, 401, 403, 404, 409, 429, 500 status matrix
  • server log 허용 context와 raw secret/error leak 금지 기준
  • 후속 route 적용 checklist

검증

  • rg -n "Response.json|NextResponse.json|catch|requestId|denialReason|db_write_failed" src/app/api src/features/auth로 현재 route shape 검토
  • npm run docs:check 통과

후속

공통 helper 적용, requestId 일괄 주입, 429 rate-limit 응답 적용은 DEN-97 이후 구현 범위로 남긴다.
