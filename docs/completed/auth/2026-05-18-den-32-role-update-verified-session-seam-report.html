DEN-32 Role Update Verified Session Seam 보고서

Role update Route Handler의 actor identity source를 DEN-31의 verified server session seam으로 전환했다. Demo header는 mock fallback mode에서만 허용된다.

변경 사항

  • POST /api/workspaces/[workspaceId]/memberships/[membershipId]/roles route가 readServerSession()을 먼저 호출한다.
  • Supabase session이 authenticated이면 sessionUserId가 actor identity source가 된다.
  • Demo header x-clair-demo-session-user-id는 server session reader가 mock_mode를 반환할 때만 허용된다.
  • Missing/invalid Supabase session이 있으면 demo header가 있어도 401로 거절된다.

왜 중요한가

기존 server permission enforcement slice는 권한 계산 자체는 서버에서 했지만 actor identity가 demo-only header였다. 이번 변경으로 production-shaped path에서는 검증된 서버 세션이 권한 source의 출발점이 된다.
