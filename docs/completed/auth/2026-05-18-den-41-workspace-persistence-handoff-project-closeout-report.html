DEN-41 Workspace Persistence Handoff & Project Closeout 보고서

Project 01 Live Auth & Supabase DB/RLS Foundation의 결과를 Project 02가 이어받을 수 있도록 정리했다. Project 01은 Human Review로 넘길 수 있지만, 실제 pilot/live 적용은 DB/RLS execution gate 통과 전까지 보류해야 한다.

완료된 foundation

  • Local-first Supabase validation mode와 secret/env gate
  • auth.getClaims() 기반 server-only session reader
  • Role update route의 verified session identity seam
  • Workspace auth schema migration과 seed contract
  • Last active hospital_admin DB guard foundation
  • Workspace auth table RLS baseline
  • DB-backed permission adapter boundary
  • Cross-workspace denial regression
  • Security review와 blocker/follow-up 분류

남은 risk

  • Docker/local Postgres 부재로 실제 migration/RLS execution은 아직 실행하지 못했다.
  • 역할/구성원 관리 UI는 아직 session-only다.
  • Real Supabase gateway와 live DB write path는 아직 연결되지 않았다.
  • Chart/order/billing domain table RLS는 Project 01 범위 밖이다.

Project 02 추천 첫 이슈

Project 02는 구현부터 시작하지 말고, 먼저 Project 01 migrations와 seed를 Docker-backed local Supabase에 적용하고 admin/member/non-member 실제 RLS 동작을 검증하는 DB execution gate부터 시작하는 것을 추천한다.

하지 말아야 할 것

  • 승욱이 명시적으로 요청하기 전 Project 02 실행을 시작하지 않는다.
  • 승욱이 승인하기 전 Project 01 이슈를 Done으로 넘기지 않는다.
  • 대표 승인 없이 remote Supabase link/push/SQL, service-role key, DB password, secret key를 사용하지 않는다.
  • Actual DB/RLS execution test 전 pilot/live ready라고 표시하지 않는다.
