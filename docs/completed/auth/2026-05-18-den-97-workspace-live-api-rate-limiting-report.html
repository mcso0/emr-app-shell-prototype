DEN-97 Workspace Live API Rate Limiting 보고서

작성일: 2026-05-18

workspace/member/profile mutation API 앞단에 route-level rate limit boundary를 추가해 반복 요청과 invite/role/profile abuse를 429로 차단한다.

적용 범위

  • workspace creation
  • invitation create/resend/cancel/accept
  • membership role/status mutation
  • personal profile update

기준

기본값은 actor + workspace/self + operation + client fingerprint 기준 60초 60회다. 초과 시 429, Retry-After, rate_limited를 반환한다.

검증

  • npx playwright test tests/workspace-rate-limit-server.spec.ts --reporter=line 통과: 2 passed
  • npx playwright test tests/workspace-rate-limit-server.spec.ts tests/server-permission-enforcement.spec.ts tests/workspace-invitation-server.spec.ts --reporter=line 통과: 11 passed
  • npx tsc --noEmit 통과

제외 범위

외부 Redis/Upstash/Vercel KV provision, production analytics, clinical/domain route 적용, bot detection, WAF 구성은 진행하지 않았다.
