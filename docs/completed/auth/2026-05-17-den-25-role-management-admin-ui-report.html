역할 관리 관리자 UI

병원관리자가 구성원 역할을 보고 수정할 수 있는 session-only 관리 UI를 추가했습니다. 마지막 병원관리자 보호 규칙도 계약 함수와 화면 흐름에 함께 반영했습니다.

상태 Human Review 준비
진입점 병원관리 / 병원구성원 관리
핵심 보호 마지막 병원관리자 강등/비활성화 차단
검증 auth 23개 통과

대표 요약

이제 병원관리자는 구성원 목록에서 활성 멤버의 역할을 수정하고, 여러 역할이 합쳐졌을 때 어떤 권한을 갖는지 쉽게 확인할 수 있습니다. 역할 변경과 구성원 비활성화는 확인 절차를 거치며, 마지막 활성 병원관리자는 실수로 권한을 잃거나 비활성화될 수 없습니다.

제품 의미: 직원 초대에서 역할을 부여하는 단계를 넘어, 실제 운영 중 역할 변경과 관리자 보호까지 연결되었습니다. 다만 아직 실제 DB 저장이나 감사 로그 기록은 아닙니다.

구현 내용

  • 병원구성원 관리 테이블에 권한 요약과 활성 멤버 역할 관리 작업을 추가했습니다.
  • 활성 멤버는 역할 수정 dialog에서 병원관리자, 수의사, 테크니션, 데스크 역할을 복수 선택할 수 있습니다.
  • 역할 변경 전 역할 변경 확인 dialog를 거치도록 했습니다.
  • 활성 멤버 비활성화도 확인 dialog를 거치도록 했습니다.
  • updateSessionWorkspaceMembershipRoles, deactivateSessionWorkspaceMembership 계약 함수를 추가했습니다.
  • 마지막 활성 hospital_admin 강등과 비활성화를 계약 함수와 UI에서 모두 차단했습니다.

보안 판단

  • 적용됨 마지막 활성 병원관리자 강등/비활성화 차단
  • 적용됨 비관리자 mock role의 초대/멤버십 변경 차단 유지
  • 후속 필요 실제 DB transaction 또는 private RPC 기반 마지막 관리자 보호
  • 후속 필요 역할 변경 감사 로그와 서버 API enforcement
