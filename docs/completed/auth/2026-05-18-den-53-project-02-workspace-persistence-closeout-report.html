DEN-53 Project 02 Workspace Persistence Closeout 보고서

작성일: 2026-05-18

Project 02는 workspace, 구성원, 초대, 역할/상태, 개인 프로필 흐름을 local-first server/DB persistence 경계로 옮겼고 Human Review 준비 상태다.

완료 범위

  • Docker local Supabase DB/RLS 실행 gate
  • workspace creation persistence
  • active membership 기반 workspace selector
  • invitation create/resend/cancel/accept persistence
  • member status read
  • role/status write persistence와 last-admin 보호
  • personal profile persistence와 권한 source 분리
  • secret scan, API error contract, route-level rate limit, security review

다음 프로젝트 handoff

접수/encounter persistence는 server session actor, workspace active membership, membership/permission policy source를 기준으로 설계해야 한다. Profile display data는 권한 source로 쓰면 안 된다.

남은 리스크

  • remote/staging live 전 shared rate limit store 필요
  • requestId와 safe logging helper route-wide 적용 필요
  • remote migration 전 Supabase advisors와 RPC security review 필요
  • production logging 전 secret redaction 기준 필요

Project 03 구현, remote Supabase, 실데이터, production deploy는 진행하지 않았다. 승욱 리뷰와 별도 승인 전 시작하면 안 된다.
