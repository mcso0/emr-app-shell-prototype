요청 내용

CSO 검토에서 Next.js 16.2.4 보안 업데이트 필요성이 확인되어, DEN-23 워크스페이스 생성 구현 전에 별도 티켓으로 패치와 회귀 검증을 수행했다.

왜 중요한가

로그인, 워크스페이스 진입, 권한 enforcement는 Next.js proxy/middleware와 라우팅 계층을 신뢰하게 된다. 취약한 버전 위에서 DEN-23 이후 작업을 쌓으면 권한 설계가 맞아도 실행 계층이 약점이 될 수 있으므로, 구현 전 선행 패치가 맞다.

리스크와 주의사항

  • 주의 현재 로컬 Node v23.11.0은 eslint-visitor-keys@5.0.1의 지원 범위가 아니어서 npm install 시 EBADENGINE 경고가 난다. 검증은 통과했지만, 개발/CI 환경은 Node 22 LTS 또는 Node 24 이상으로 맞추는 편이 안전하다.
  • Playwright 출력의 NO_COLOR/FORCE_COLOR 경고와 Tiptap duplicate extension warning은 이번 패치로 새로 생긴 실패가 아니며 테스트를 막지 않았다.
  • 워크스페이스 생성, 권한 resolver, migration/RLS, Supabase live validation은 이번 범위가 아니다.
