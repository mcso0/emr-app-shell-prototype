DEN-34 Workspace Auth Schema Migration 보고서

Project 01의 workspace auth schema foundation migration을 local-first로 작성했다. Remote Supabase project에는 연결하거나 SQL을 실행하지 않았다.

생성된 migration

  • supabase/migrations/20260518023715_workspace_auth_schema_foundation.sql

생성/변경 table

  • public.users: 앱 사용자 프로필, auth.users.id와 같은 UUID
  • public.workspaces: route-safe workspace scope
  • public.user_profiles: 권한 source가 아닌 개인 설정 확장
  • public.user_memberships: workspace membership과 additive roles source
  • public.workspace_invitations: 초대 lifecycle
  • public.permission_policies: allow-only role/user permission source

주요 constraint/index

  • Canonical role은 hospital_admin, vet, technician, front_desk로 제한했다.
  • Active membership은 role이 비어 있을 수 없다.
  • user_memberships는 unique (workspace_id, user_id)를 가진다.
  • Pending invitation은 workspace/email 기준으로 중복을 차단한다.
  • Permission policy는 role scope와 user scope별 unique index를 가진다.
  • 후속 RLS/permission resolver를 위해 workspace/status/scope index를 추가했다.
  • 모든 public auth table에 RLS를 enable했지만, policy SQL은 후속 이슈로 남겼다.
