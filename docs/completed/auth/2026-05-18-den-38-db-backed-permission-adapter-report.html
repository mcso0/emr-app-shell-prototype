DEN-38 DB-Backed Permission Adapter 보고서

기존 permission resolver interface를 유지하면서 DB row를 resolver adapter로 변환하는 경계를 추가했다. Mock adapter와 DB-backed adapter가 같은 resolver를 사용한다.

Adapter 선택 방식

  • Mock/local path: 기존 createMockWorkspacePermissionAdapter()
  • DB-backed path: gateway rows → loadWorkspacePermissionAdapterFromDb() → resolveWorkspacePermission()
  • server-only wrapper와 testable core를 분리했다.

DB query boundary

  • listMemberships(workspaceId, userId)
  • listUsers(userIds)
  • listPermissionPolicies(workspaceId)

남은 policy 결정

  • Custom roles, deny rules, user override policy는 아직 제품 결정 전이다.
  • 실제 Supabase client gateway 구현과 local DB execution test는 후속 검증이 필요하다.
  • Role management UI live persistence는 아직 연결하지 않았다.

검증

  • Red: adapter module 부재로 npx playwright test tests/db-workspace-permission-adapter.spec.ts --reporter=line 실패
  • Red: Node test runtime에서 direct server-only import가 실패해 core/wrapper로 분리
  • npx playwright test tests/db-workspace-permission-adapter.spec.ts tests/permission-resolver.spec.ts --reporter=line 통과
  • npx tsc --noEmit 통과
  • npm run lint -- --ignore-pattern '.worktrees/**' 통과
  • npm run docs:check 통과

범위 준수

  • Role management UI live persistence 없음
  • 업무 screen mutation 연결 없음
  • Permission policy 제품 변경 없음
  • Remote Supabase project 변경 없음
  • Project 02 작업 없음
