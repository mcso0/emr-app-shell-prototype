DEN-37 Workspace Membership RLS Baseline 보고서

Workspace auth table에 active membership 기반 RLS baseline을 추가했다. Hospital admin 관리 action과 일반 멤버 read boundary를 분리했다.

추가된 RLS policy 목록

  • users_select_self_or_workspace_member
  • workspaces_select_active_member, workspaces_update_admin
  • user_profiles_select_self_or_workspace_member, user_profiles_insert_self, user_profiles_update_self
  • user_memberships_select_active_member, user_memberships_insert_admin, user_memberships_update_admin, user_memberships_delete_admin
  • workspace_invitations_*_admin
  • permission_policies_select_active_member, permission_policies_*_admin

허용/차단 시나리오

  • Active workspace member는 같은 workspace의 auth rows를 읽을 수 있다.
  • 다른 workspace membership은 현재 workspace 접근 권한이 아니다.
  • Membership, invitation, permission policy write는 hospital admin policy로 분리했다.
  • Anonymous policy는 만들지 않았다.
  • Clinical/business domain table RLS는 아직 만들지 않았다.

  • Remote Supabase project 변경 없음
  • Project 02 작업 없음
