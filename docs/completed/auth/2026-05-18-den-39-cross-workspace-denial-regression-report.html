DEN-39 Cross-Workspace Denial Regression 보고서

Server enforcement와 RLS baseline이 같은 방향으로 workspace boundary를 막는지 확인하는 focused regression을 추가했다.

Denial matrix

  • Server route: workspace-a admin이 workspace-b role mutation을 시도하면 403 workspace_membership_missing
  • Resolver: 다른 workspace membership은 현재 workspace permission으로 인정하지 않는다.
  • RLS helper: membership.workspace_id = p_workspace_id와 membership.user_id = auth.uid()를 함께 확인한다.
  • RLS policy: row workspace_id를 helper에 넘긴다.

검증

  • npx playwright test tests/server-permission-enforcement.spec.ts tests/workspace-membership-rls-migration.spec.ts tests/permission-resolver.spec.ts --reporter=line 통과

  • npx tsc --noEmit 통과
