DEN-43 Workspace/Member Server Route Contract 보고서

작성일: 2026-05-18

Project 02의 실제 저장 구현 전에 서버 route 계약을 확정했다. 이제 workspace 생성, 초대, 역할 변경, 프로필 저장이 각자 어떤 권한 검사를 통과해야 하는지 기준이 생겼다.

요청

DEN-43에서 workspace/member mutation을 위한 server route contract를 설계하고, follow-up 구현 이슈들이 따를 permission, denial reason, mock fallback, test strategy를 정리한다.

핵심 결정

영역 결정
Actor identity readServerSession() 기준. Demo header는 mock mode fallback에서만 허용.
관리 권한 초대, 역할 변경, 멤버 비활성화는 active membership과 role_permission:manage 필요.
프로필 본인 프로필만 저장 가능. role, permission, membership authority field는 거부.
마지막 관리자 보호 서버 authorization과 DB guard 양쪽에서 last_admin_protected를 유지.
제외 범위 remote Supabase, 실제 이메일, 결제/구독, Project 03+ clinical persistence는 승인 전 제외.
