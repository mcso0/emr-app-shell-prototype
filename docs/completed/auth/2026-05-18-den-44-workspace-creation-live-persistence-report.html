DEN-44 Workspace Creation Live Persistence 보고서

작성일: 2026-05-18

워크스페이스 생성이 이제 브라우저 저장소에만 머무르지 않고 서버 route를 먼저 통과한다. Supabase mode에서는 local DB transaction RPC가 workspace와 생성자 병원관리자 멤버십을 함께 만든다.

무엇이 바뀌었나

  • POST /api/workspaces route를 추가했다.
  • 워크스페이스 생성 transaction RPC public.clair_create_workspace_with_creator를 추가했다.
  • /workspace/new UI가 서버 route 성공 후 새 workspace home으로 이동하게 했다.
  • mock/local fallback은 기존 session-compatible state를 유지한다.

왜 중요한가

제품 MVP에서 새 병원 workspace는 새로고침 이후에도 유지되어야 한다. 이번 작업은 그 첫 저장 경계를 만들고, 생성자를 자동으로 active hospital_admin으로 저장하는 길을 열었다.

제외 범위

  • remote Supabase link/push/SQL 실행 없음
  • secret/service-role/DB password 사용 없음
  • 실제 이메일, 결제, 구독 provider 연동 없음
  • 직원 초대와 역할 변경 live persistence는 후속 이슈
  • Project 03+ 접수/환자/차트 persistence는 시작하지 않음
