DEN-33 Auth Guard Server Session Regression 보고서

Verified server session seam 도입 후, client auth guard와 server route identity boundary가 섞이지 않도록 auth/app-shell regression을 보강했다.

변경 사항

  • tests/auth.spec.ts에 server session mode regression test를 추가했다.
  • Client AuthGate는 계속 useAuthClient()를 사용하고, server session reader나 demo header를 직접 알지 않도록 고정했다.
  • Role update route는 readServerSession()을 통해 actor identity를 받는 것을 테스트로 확인했다.
  • Mock fallback에서는 demo header가 허용되고, Supabase missing session에서는 demo header가 있어도 거절되는 matrix를 테스트했다.

왜 중요한가

Supabase live session 전환은 로그인, guard, route identity 경계를 동시에 흔들 수 있다. 이번 회귀 테스트는 기존 mock/local 진입 흐름을 보존하면서 server session path가 별도 서버 경계에 남아 있는지 확인한다.
