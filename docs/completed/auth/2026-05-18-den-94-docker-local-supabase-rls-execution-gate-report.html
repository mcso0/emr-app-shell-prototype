DEN-94 Docker Local Supabase RLS Execution Gate 보고서

Docker 기반 local Supabase를 실제로 띄우고 Project 01 DB/RLS migration과 seed를 적용했다. 첫 실행에서 RLS helper 권한 문제가 발견됐고, 새 migration으로 수정한 뒤 관리자/직원/외부 사용자 접근 검증과 마지막 관리자 보호 검증을 통과했다.

비개발자 요약

실제 서버를 건드리지 않고 내 컴퓨터 안에 테스트용 병원 DB를 띄웠고, 병원 직원만 자기 병원 데이터를 볼 수 있는지 확인했다. 중간에 보안 규칙을 실행하는 데 필요한 내부 권한 하나가 빠진 것을 발견해 고쳤다.

완료한 일

  • Docker Desktop 기반 local Supabase 실행 확인
  • Project 01 migration 4개와 seed 적용 확인
  • RLS helper authenticated execution grant migration 추가
  • 관리자/직원/알 수 없는 사용자 조회 결과 검증
  • 마지막 active hospital_admin 강등 차단 검증

검증 결과

  • Seeded users: 4
  • Seeded workspace: 1
  • Seeded memberships: 4
  • Admin/member workspace read: pass
  • Unknown user workspace/member read denial: pass
  • Last-admin DB guard: pass
  • Playwright migration tests: 6 passed

주의사항

  • Supabase CLI가 출력한 local secret 값은 문서/Linear/채팅에 기록하지 않았다.
  • Remote Supabase는 건드리지 않았다.
  • 실제 병원/보호자/환자 데이터는 사용하지 않았다.
  • 이번 검증은 workspace auth table RLS 범위이며 chart/order/billing RLS는 아직 후속 범위다.
