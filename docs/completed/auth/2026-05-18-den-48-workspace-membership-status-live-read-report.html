DEN-48 Workspace Membership Status Live Read 보고서

작성일: 2026-05-18

병원구성원 관리 화면이 이제 서버에서 active, pending, inactive 상태 목록을 읽을 수 있다. 서버 읽기 실패 시 기존 mock/browser 상태를 유지한다.

무엇이 바뀌었나

  • GET /api/workspaces/[workspaceId]/memberships를 추가했다.
  • public.clair_list_workspace_member_statuses() DB reader RPC를 추가했다.
  • 구성원 UI의 카운트와 목록이 서버 rows를 반영할 수 있게 했다.
  • 서버 읽기 loading/error fallback 문구를 추가했다.

제외 범위

  • 역할 변경과 멤버 상태 변경 write persistence는 구현하지 않았다.
  • 실제 이메일 발송과 profile persistence는 구현하지 않았다.
  • remote Supabase와 실제 데이터는 건드리지 않았다.
