DEN-45 Workspace Membership List Live Read 보고서

작성일: 2026-05-18

Workspace selector가 이제 서버의 persisted membership list를 읽을 수 있다. mock/demo 흐름은 기존 브라우저 fallback을 유지한다.

무엇이 바뀌었나

  • GET /api/workspaces를 추가했다.
  • public.clair_list_active_workspaces_for_current_user() DB reader RPC를 추가했다.
  • Workspace switcher display hook이 서버 list에서 persisted display name을 가져오게 했다.
  • Mock fallback에서는 기존 browser workspace state가 계속 작동한다.
