DEN-95 Live Persistence Secret Scanning Gate 보고서

작성일: 2026-05-18

live persistence 작업에서 비밀키가 커밋되는 일을 줄이기 위해 로컬/CI secret scan gate를 추가했다.

변경 사항

  • scripts/scan-secrets.mjs 추가
  • npm run security:secrets 추가
  • .github/workflows/secret-scan.yml 추가
  • OpenAI, Stripe, Supabase token, JWT-like secret, DB URL, secret env assignment, tracked env file 검사 추가

검증

  • node scripts/scan-secrets.mjs --self-test 통과
  • npm run security:secrets 통과
  • git ls-files '.env*' '.vercel/.env*' '**/.env*' 결과: tracked env file 없음

제외 범위

실제 secret 생성/저장, secret rotation, remote Supabase/Vercel/Stripe/OpenAI 설정, production deploy 변경은 진행하지 않았다.
