DEN-278 최종 감사: 초대 링크 비밀번호 온보딩

AUTH-PR-043 초대 링크 비밀번호 온보딩은 현재 구현 완료 후 Human Review 단계로 보는 것이 맞다. 새 Linear 프로젝트나 새 이슈는 만들지 않고 기존 DEN-278 안에서 상태를 정리했다.

현재 판정

  • pending 신규 초대는 초대 링크 컨텍스트에서 바로 비밀번호 설정 화면을 보여주며, 유효성 통과 전까지 워크스페이스로 이동 CTA가 비활성화된다.
  • pending 기존 계정 초대는 초대 이메일을 고정한 로그인 화면을 보여주며, 비밀번호 입력 전까지 로그인 CTA가 비활성화된다.
  • expired/canceled 초대는 관리자에게 재요청 경로와 success/failure feedback을 제공한다.
  • accepted 초대는 중복 membership 생성을 유도하지 않고 workspace entry만 제공한다.
  • missing/invalid 초대는 account creation이나 membership mutation 없이 blocked state로 처리된다.
  • production invite UI에는 prototype-only state tab, raw invite token, OTP 원문, password 값, secret 패턴이 노출되지 않는다.
