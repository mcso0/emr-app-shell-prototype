DEN-31 Server Session Reader Contract 보고서

Project 01의 verified server session 첫 구현 단위로, Next.js server boundary에서 Supabase verified user claims를 읽는 contract와 server-only entrypoint를 추가했다.

변경 사항

  • readServerSessionFromSupabase() contract를 추가해 authenticated, mock fallback, unauthenticated, misconfigured, error 상태를 typed result로 반환한다.
  • readServerSession() server-only entrypoint를 추가하고 Supabase server client의 auth.getClaims()를 사용한다.
  • NEXT_PUBLIC_AUTH_MODE=mock과 env-missing auto mode는 기존 mock fallback으로 유지한다.
  • browser storage와 client global에 의존하지 않는 것을 테스트로 고정했다.

왜 중요한가

기존 첫 server permission enforcement slice는 demo-only header로 actor identity를 받았다. 이번 변경은 DEN-32에서 그 헤더를 Supabase verified session seam으로 교체할 수 있는 최소 기반이다.
