DEN-30 Auth DB Env/Secret/Verification Gates 보고서

Project 01의 두 번째 readiness 이슈로, Supabase auth/DB/RLS 작업에 필요한 env matrix, secret handling rule, verification gate를 문서화했다.

결정

  • NEXT_PUBLIC_AUTH_MODE, NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY만 browser-safe public env로 둔다.
  • Supabase secret key, legacy service_role, DB password, connection string, JWT secret, CLI token은 server/admin secret으로 분리한다.
  • Playwright 기본 회귀는 계속 NEXT_PUBLIC_AUTH_MODE=mock에 고정한다.
  • remote Supabase secret 사용이나 project mutation은 별도 대표 승인 전까지 금지한다.
