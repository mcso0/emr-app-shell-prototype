DEN-36 DB-Level Last Admin Protection 보고서

마지막 active hospital_admin을 DB 경계에서 보호하기 위한 private trigger와 private membership update helper skeleton을 추가했다.

선택한 DB protection 방식

  • private.clair_assert_not_last_active_hospital_admin(): direct update/delete를 막는 trigger guard
  • private.update_workspace_membership_roles(...): 후속 trusted server write가 사용할 private helper skeleton
  • 두 함수 모두 private schema에 두고 public, anon, authenticated 실행 권한을 revoke했다.

보호 시나리오

  • 마지막 active hospital_admin의 role 강등 차단
  • 마지막 active hospital_admin의 inactive 전환 차단
  • 마지막 active hospital_admin row 삭제 차단
  • 마지막 active hospital_admin를 다른 workspace로 옮기는 update 차단
