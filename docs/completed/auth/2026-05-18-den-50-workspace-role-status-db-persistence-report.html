DEN-50 Workspace Role Status DB Persistence 보고서

작성일: 2026-05-18

역할 변경과 멤버 비활성화가 local Supabase DB transaction wrapper를 갖게 됐다. 마지막 병원관리자 보호는 DB trigger가 막는다.

변경

  • public.clair_update_workspace_membership_roles()를 추가했다.
  • public.clair_update_workspace_membership_status()를 추가했다.
  • PATCH /api/workspaces/[workspaceId]/memberships/[membershipId]/status를 추가했다.
  • 비활성화 UI도 서버 route를 먼저 확인한다.

검증

  • 42 passed 관련 Playwright 회귀 통과
  • npx tsc --noEmit 통과
  • npx supabase db reset --local 통과
  • local SQL role/status update, last-admin guard, non-admin denial 통과
  • npm run build 통과

제외 범위

  • audit persistence 전체 구현은 하지 않았다.
  • billing/seat enforcement와 remote Supabase는 건드리지 않았다.
