접수 캘린더 Task 생성 UX 완료 보고서

접수/예약 day 캘린더에서 피그마 CDS V2의 celanderTask 스타일을 기준으로 task 카드를 정리하고, 사용자가 캘린더 빈 시간대를 클릭하거나 드래그해서 15분 단위 접수 task를 만들 수 있게 했다.

요청 사항

  • 피그마 컴포넌트를 기준으로 접수 캘린더 task 카드에 적용할 위치와 수정 대상을 파악하고 반영.
  • Notion Calendar처럼 빈 시간대를 클릭하거나 드래그해 접수 task를 생성.
  • 생성 단위는 임의 시간이 아니라 HH:00, HH:15, HH:30, HH:45로 고정.
  • 생성 UX는 팝오버가 아니라 기존 CLAiR 우측 드로어로 연결.

변경 내용

  • 예약, 접수완료, 노쇼, 추가 상태를 피그마 task 카드 톤에 맞춰 day 캘린더 카드로 정리했다.
  • day view 빈 슬롯을 15분 단위 버튼/드래그 영역으로 나눴다.
  • 클릭 시 기본 15분 접수 task 드로어가 열리고, 드래그 시 선택 범위가 15분 단위로 스냅된다.
  • 드로어에서 환자, 담당의, 시작 시간, 소요시간, 방문 목적을 확인한 뒤 생성하면 세션 전용 접수 task가 캘린더와 대기 목록에 반영된다.

남은 리스크와 범위 밖 항목

  • 이번 구현은 세션 전용 UI 생성이다. 실제 예약/접수 영속화, DB 스키마, RLS, RPC는 별도 승인 범위가 필요하다.
  • 기존 task의 드래그 이동/리사이즈 편집은 이번 범위가 아니다.
  • week/month view 생성은 이번 범위가 아니며 day view를 우선 완성했다.
