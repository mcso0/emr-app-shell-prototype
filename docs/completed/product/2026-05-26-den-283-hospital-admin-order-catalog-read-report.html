DEN-283 / 2026-05-26 / Hospital Admin Catalog UX

병원관리 Order 테이블 Workspace Catalog Read 연결 보고서

병원관리 Order 관리 화면이 더 이상 화면 전용 seed만 보지 않고, workspace-scoped order catalog read route에서 받은 병원별 오더 카탈로그를 표시하도록 연결했다.

Status: Human Review Remote DB: Not applied

무엇이 바뀌었나

  • /api/workspaces/{workspaceId}/hospital-admin/order-catalog admin read 결과를 병원관리 Order 테이블 row로 변환해 표시한다.
  • API read가 성공하면 화면에 workspace catalog 기준 row가 반영된다.
  • API read 실패나 fallback 상황에서는 기존 세션 seed가 유지되도록 했다.
  • 진료, 예방, 검사, 영상, 처치, 수술, 입원, 치료, 처방/조제/의료물품을 표현할 수 있도록 UI category/subcategory 모델을 확장했다.
  • 기존 검색, 사용여부, 청구, 업무유형 필터와 테이블 정렬/row action regression을 workspace catalog row 기준으로 갱신했다.

왜 중요한가

이 연결이 있어야 병원관리 Order 관리 화면이 실제 병원별 오더 마스터 목록의 조회 화면이 된다. 후속 DEN-284의 drawer create/update/사용중지 mutation은 이 read boundary 위에 붙이면 된다.
