Live Chart Confirmation Gateway 연결

Supabase session에서 차트 오더 확정이 mock catalog/billing fallback이 아니라 live workspace catalog와 live billing gateway를 사용하도록 연결했다.

Status: Human Review 준비 DEN-289 P1 finding mitigated Remote DB/RLS/Deploy: Not run

비개발자용 요약

실제 로그인 세션에서는 병원별 오더 카탈로그와 청구 후보가 mock 데이터로 섞이면 안 된다. 이번 변경으로 live chart confirmation 경로는 병원 workspace catalog RPC를 통해 snapshot을 다시 읽고, billing-only 후보도 live billing RPC로 생성한다.

변경 사항

  • Chart order action route에 createSupabaseOrderCatalogGateway 를 연결했다.
  • Chart order action route에 createSupabaseInvoiceCandidateSyncGateway를 연결했다.
  • Workspace-scoped chart catalog search RPC clair_list_order_catalog_chart_search migration 파일을 추가했다.
  • Supabase session route가 live catalog/billing gateway를 주입하는지 regression을 추가했다.
