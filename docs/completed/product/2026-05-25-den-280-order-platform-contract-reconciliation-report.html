DEN-280 / 2026-05-25 / Workspace Order Catalog Platform

Order Platform 기존 구조 대조 및 정책 고정

기존 Project 07의 오더 카탈로그 기반과 Project 08의 후속 업무 전달 기반을 재사용 대상으로 확인하고, 구현 전에 필요한 제품 정책을 새 source-of-truth 문서로 고정했다.

Status: Human Review Implementation: Not started

무엇이 결정됐나

  • 1차 오더 범위는 검사, 영상, 예방, 처치, 수술, 입원, 치료, 처방/조제/의료물품을 모두 포함한다.
  • 1차 오더 관리 권한은 병원관리자만 가진다.
  • CLAiR 기본 프리셋은 자동 병합하되, 병원이 수정한 값은 덮어쓰지 않는다.
  • 삭제 UX는 사용 중지로 잡고, 과거 차트/청구 snapshot은 유지한다.
  • 가격 변경은 1차에서 즉시 적용하되, 과거 기록은 확정 시점 snapshot으로 보호한다.
  • lab/imaging은 결과 완료 후 차트로 돌아가 담당 수의사 확인을 거친 뒤 수납으로 갈 수 있다.
  • technician은 오더 업무를 취소하지 않고 차트로 반려만 할 수 있다.
  • CSV는 1차에서 import 기능 없이 템플릿 설계만 한다.
