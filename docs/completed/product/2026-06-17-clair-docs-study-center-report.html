CLAiR Docs Study Center v1 완료 보고서

2026-06-17 / CLAIR-DOCS-PR-001

요약

클레어 독스에 스터디 탭을 추가하고, 승욱과 루멘의 프로젝트 학습 기록을 docs/study Markdown으로 남길 수 있는 구조를 만들었다. 이번 변경은 개인/내부 학습용이며 Supabase, 권한, 실제 데이터, 외부 공개, 배포 범위는 건드리지 않았다.

변경 내용

  • /docs를 클레어 독스의 권장 진입점으로 추가했다.
  • 기존 /prd는 product 문서 링크 호환용으로 유지했다.
  • 기획, 디자인, 개발, 스터디 탭을 가진 curated docs viewer로 확장했다.
  • docs/study에 홈, 학습 목차, 용어 사전, 다이어그램, 1강 수업 기록, 템플릿을 추가했다.
  • Mermaid 코드블록을 학습용 다이어그램 박스로 보여주는 lightweight preview를 추가했다.
  • 문서 포털과 agent RAG map에 Study Center 경로를 연결했다.
  • Playwright 테스트를 CLAiR Docs와 Study 탭 기준으로 갱신했다.

검증

  • npm run docs:check 통과
  • npx eslint ...focused files... 통과
  • npx tsc --noEmit 통과
  • npx playwright test tests/prd-viewer.spec.ts 통과
  • npm run build 통과

주의 사항

  • 전체 npm run lint는 이번 작업 외부의 reception 미완성 변경에서 React hook lint 오류가 발생해 실패했다. 이번 Study Center 변경 파일의 focused lint는 통과했다.
  • Study 문서는 학습 보조 자료이며 제품/보안/DB/런칭 기준의 source of truth가 아니다.
  • 실제 Mermaid SVG 렌더링, 학습 진도 저장, 사이트 안 실시간 퀴즈 생성은 후속 후보로 남겼다.
