DEN-281 / 2026-05-25 / Preset & Workspace Catalog

오더 프리셋 초기화·자동 병합 계약 보고서

CLAiR 기본 오더 프리셋을 병원별 workspace catalog로 복사하고, 이후 프리셋 업데이트가 병원 수정본을 덮어쓰지 않도록 필요한 데이터 계약을 문서화했다.

Status: Human Review Implementation: Not started

핵심 결정

  • CLAiR system preset과 workspace order catalog를 별도 데이터 가족으로 본다.
  • 신규 workspace 초기화는 eligible preset을 workspace catalog row로 복사한다.
  • 초기화는 idempotent해야 하며, 같은 preset을 중복 생성하면 안 된다.
  • 새 preset은 자동 추가하고, 병원이 수정하지 않은 row는 자동 업데이트한다.
  • 병원이 수정한 row는 보존하고, conflict/review UX는 후속으로 둔다.
  • Sales Demo와 mock fallback은 deterministic id와 synthetic data를 유지한다.
