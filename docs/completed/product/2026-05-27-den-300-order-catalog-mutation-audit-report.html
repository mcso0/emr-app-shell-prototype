Order Catalog Mutation Audit Event 추가

병원관리 Order Catalog의 생성, 수정, 사용 중지 mutation에 감사 이벤트를 남기도록 구현했다.

Status: Human Review 준비 DEN-289 P2 finding mitigated Remote DB/RLS/Deploy: Not run

비개발자용 요약

오더 카탈로그는 진료 선택지와 수납 금액의 기준이다. 누가 어떤 오더명, 청구명, 가격, 사용 상태를 바꿨는지 나중에 추적할 수 있도록 성공한 변경마다 감사 이벤트를 남기게 했다.

변경 사항

  • order_catalog.created, order_catalog.updated, order_catalog.paused event type을 추가했다.
  • Catalog mutation 성공 후 actor, workspace, request id, target item id, changed fields, before/after snapshot을 audit payload에 남긴다.
  • Hospital-admin catalog route에서 Supabase session일 때 live audit append gateway를 연결했다.
  • Audit event type check constraint를 넓히는 repo-local migration을 추가했다.

남은 범위

Audit payload는 raw SOAP, provider payload, token, secret을 포함하지 않도록 regression을 추가했다. Remote Supabase 적용, 원격 RLS replay, production deploy, 실데이터 import는 수행하지 않았다.
