DEN-335 Order Billing State Policy Report

2026-05-31 · CLAiR EMR Order Billing State Separation & Billing Sync Reliability

요청

차트의 Order 청구가 업무 완료 여부나 draft 저장 성공에 묶이지 않고, 모든 오더 유형에서 수납 후보를 만들 수 있도록 정책 기준을 정리했다.

결정된 정책

  • 업무 상태와 수납 후보 상태는 별도 축으로 본다.
  • Order 청구는 lab, imaging, dispensing, treatment 모두에서 수납 후보 생성 액션이다.
  • 미완료 오더도 수납으로 진행할 수 있지만 확인 다이얼로그가 필요하다.
  • 확인 문구는 아직 완료되지 않은 오더가 있습니다. 수납을 진행할까요?로 고정한다.
  • 수납 후보 생성은 업무 완료 처리가 아니며, 기존 업무 상태를 바꾸지 않는다.
  • 수의사 확인/재요청은 결과 검토 UX로 남기되 기본 billing gate로 사용하지 않는다.
