수납 보호자 정보바 구현 및 스테이징 배포 보고

수납 화면 상단 보호자 정보바를 보호자 중심 응대 정보로 재정리하고, 수납 요약 버튼을 페이지 타이틀 우측으로 이동했다. Figma 지정 보호자 아이콘을 SVG asset으로 추가했고, 환자 그룹 앞에는 기존 동물 아이콘을 배치했다.

요청 내용

  • 수납 정보바에서 수납대기/미납/보호자 메모 정보를 유지한다.
  • 정보바 오른쪽의 divider, 수납 번호 표시, 수납대기 뱃지, 수납 요약 버튼을 제거한다.
  • 수납 요약 버튼은 페이지 타이틀 오른쪽에 둔다.
  • Figma 보호자 아이콘을 SVG로 프로젝트에 추가해 사용한다.
  • 환자 앞에는 동물 아이콘을 추가한다.
  • 우측 사이드 패널 헤더 높이를 48px로 맞춘다.
  • 보호자 정보바와 우측 사이드 패널 헤더의 하단 border 위치를 1px 오차 없이 맞춘다.
  • 수납 요약 토글 버튼의 선택 상태는 파란 accent가 아니라 opacity 계열 토큰으로 표현한다.
  • 진료, 임상, 영상, 조제/처치, 수납 화면의 이력 아이콘 버튼 선택 상태도 같은 opacity 계열 토큰으로 통일한다.
  • 스테이징 preview 배포까지 완료한다.

변경 내용

  • BillingGuardianContextBar에 보호자 아이콘과 환자 동물 아이콘을 추가했다.
  • 정보바의 마지막 액션 영역을 제거해 오른쪽 divider와 invoice 표시가 보이지 않게 했다.
  • 보호자 메모 칩은 실제 guardian memo를 우선 표시하고, 메모가 없을 때만 미납 주의/메모 없음으로 fallback한다.
  • BillingTitleCard의 우측 actions에 수납 요약 패널 토글 버튼을 배치했다.
  • 수납 우측 사이드 패널 헤더를 h-12, 즉 48px 높이로 조정했다.
  • 보호자 정보바도 border를 포함한 h-12 박스로 바꿔 우측 패널 헤더와 같은 top/bottom 좌표를 갖게 했다.
  • 수납 요약 토글 선택 상태의 border/background를 black-alpha-16/black-alpha-4 토큰으로 변경했다.
  • EmrInstructionHistoryToggle과 EmrPatientContextBar의 selected 상태도 같은 opacity 계열 토큰으로 변경해 모듈 공통 이력/패널 토글 버튼에 적용했다.
  • HTML 시안과 캡처 증거도 최신 구조로 갱신했다.
