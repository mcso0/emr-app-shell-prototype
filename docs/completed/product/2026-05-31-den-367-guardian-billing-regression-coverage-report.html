Guardian-Centered Billing Regression Coverage

DEN-367은 보호자 중심 수납 화면의 핵심 흐름을 focused regression으로 고정했다. 테스트 중 live encounter 후보가 중앙 checkout 작업대에 반영되지 않는 회귀도 발견해 함께 수정했다.

보호하는 흐름

  • 보호자 정보바: 보호자 연락처/소유 환자/주의 메모가 보이고 환자 바이탈성 정보는 빠진다.
  • 왼쪽 큐: 수납대기, reason-backed 미납, 완료 분류와 row badge를 고정한다.
  • 보호자 ledger: 날짜 quick range, 상태 필터, ledger row 선택, co-guardian toggle 조건을 고정한다.
  • 중앙 checkout: 선택된 invoice/candidate가 checkout 작업대와 항목 테이블에 반영된다.
  • 오른쪽 요약: 수납 진행, 수납 완료, 미납 처리가 분리되고 청구 확정 copy가 노출되지 않는다.
  • server route/core: 사유 없는 mark_unpaid는 400으로 막힌다.

수정된 회귀

live candidate detail이 기본 invoice selection에 묻히지 않게 수정했다.

  • live encounter handoff detail의 invoice가 store invoice 목록 밖에 있으면, 중앙 checkout group을 해당 live detail에서 직접 구성한다.
  • 이로써 live candidate row가 청구 항목 테이블에 바로 보인다.
