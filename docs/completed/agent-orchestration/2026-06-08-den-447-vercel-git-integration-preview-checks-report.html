Vercel Git Integration 확인 보고서

실제 원격 설정을 변경하지 않고, Vercel Git Integration과 PR preview 체크가 현재 증거로 확인되는지 점검했다.

확인읽기 전용 점검 결과

  • Vercel CLI는 project Git 연결 상태를 읽는 명령을 제공하지 않고, git connect/disconnect만 제공한다.
  • 현재 fixed staging target deployment JSON에는 gitSource나 GitHub metadata가 노출되지 않았다.
  • GitHub deployments API는 Vercel deployment 기록을 반환하지 않았다.
  • GitHub main check runs에는 GitHub Actions만 보였고 Vercel check run은 보이지 않았다.
  • GitHub repo hooks는 비어 있었지만 GitHub App 연동은 이 목록에 안 보일 수 있어 단정 근거로 쓰지 않았다.
  • Vercel Preview env 변수는 존재했고 값은 encrypted로만 표시되어 secret 값은 노출되지 않았다.

결론

  • 현재 CLI/GitHub evidence만으로는 Vercel Git Integration 활성 상태를 증명할 수 없다.
  • PR preview check가 GitHub에 표시되는 상태도 확인되지 않았다.
  • 다음 단계는 Vercel Dashboard에서 Git repo 연결, production branch, PR preview/comment/check 설정을 확인하는 승인 작업이다.

다음 실행 후보

  • 02-03 Connect or confirm Vercel Git Integration for PR previews
  • 승인 후에만 Vercel Git 연결, production branch main 설정, PR preview 검증용 test branch/PR 생성을 진행한다.

제외한 것

  • Vercel/GitHub 설정을 변경하지 않았다.
  • fixed staging alias를 변경하지 않았다.
  • production deploy/promote를 하지 않았다.
  • secret 생성, 저장, 회전 작업을 하지 않았다.

검증

  • npm run docs:check
  • npm run security:secrets
  • git diff --check
