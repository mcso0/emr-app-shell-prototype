제외한 것

  • Vercel/GitHub 자동화 설정은 변경하지 않았다.
  • fixed staging 재배포 또는 alias 변경은 하지 않았다.
  • production deploy/promote는 하지 않았다.
  • secret 생성, 저장, 회전, remote Supabase, real data, email, payment, provider integration 작업은 하지 않았다.
