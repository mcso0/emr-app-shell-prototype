검수 포인트

  • 앞으로 개별 작업 thread는 PR preview까지만 공유한다.
  • fixed staging은 staging 브랜치 기준으로만 반영한다.
  • main merge는 production release로 취급한다.
  • private/free 환경에서는 GitHub required checks가 강제되지 않으므로 merge 전에 사람이 CI와 Secret Scan을 확인한다.
  • production release는 source SHA, 포함 PR/이슈, fixed staging evidence, smoke path, rollback 후보가 있어야 승인할 수 있다.
