DEN-451 Production Release From Staging To Main

2026-06-09 · CLAiR EMR Release & Deployment Operations

요약

staging 검수 완료분을 main production으로 반영하기 전 필요한 승인 패킷, preflight, smoke, rollback, stop condition을 별도 runbook으로 고정했다.

이번 작업은 문서/스킬 정리만 수행했다. production 배포, main merge, Vercel alias 변경은 하지 않았다.

핵심 결정

항목 결정
staging fixed staging review candidate
main Vercel Production branch
production release 승욱의 명시 승인 없이는 중단
rollback release 승인 전에 이전 production deployment id 또는 revert 후보 기록

승인 패킷

production release 전 Codex는 아래 항목을 제시하고 멈춰야 한다.

  • Target: production / main
  • Source: staging commit SHA
  • Compare target: 현재 origin/main SHA 또는 production deployment id
  • Included work: PR, Linear issue, closeout report
  • Fixed staging evidence: URL, deployment, smoke result
  • Verification: GitHub checks and local preflight
  • Secret/env safety: secret 값 미노출 확인
  • Production operation: 승인 후 실행할 정확한 작업
  • Smoke path: production 확인 경로
  • Rollback candidate: 이전 production deployment 또는 revert 후보
  • Stop condition: 취소/중단 기준

검증 명령

runbook에 고정한 최소 production preflight:

  • npm run security:secrets
  • npm run docs:check
  • git diff --check
  • npm run lint
  • npx tsc --noEmit
  • npm run build

실제 production release 때는 포함된 변경 범위에 맞춰 focused Playwright/spec을 추가한다.

남은 리스크

  • 이 문서는 production release 절차이지, production release 실행 결과가 아니다.
  • production smoke path는 실제 포함 PR/이슈에 따라 release 시점에 구체화해야 한다.
  • remote Supabase, real data, provider, email, payment, RLS, migration이 섞이면 별도 승인이 필요하다.
