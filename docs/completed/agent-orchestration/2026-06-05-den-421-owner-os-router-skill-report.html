Added the repo-local clair-owner-os-router skill. It routes broad Owner OS requests before implementation by classifying task type, depth level, autonomy level, approval gates, source-doc needs, output shape, parent model tier, 5.5 escalation posture, and subagent cost posture.

Routing Behavior

  • Classifies requests as answer, planning, docs, code, review, qa, linear, or safety.
  • Uses progressive depth levels L0 through L4.
  • Separates autonomy levels from answer_only through external_action_gated.
  • Stops before approval-gated operations and routes safety reviews to $emr-owner-safety-os.
  • Routes Linear work through $manual-linear-ops and cost-justified custom subagent selection through $codex-agent-router.
  • Allows lower-cost parent models for simple low-risk work and escalates to 5.5 for ambiguity, safety, broad synthesis, failed verification, or approval-gated scope.
  • Subagent summaries are evidence, not final authority.
