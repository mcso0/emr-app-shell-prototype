Clinical Order Fulfillment Handoff Persistence / DEN-237 / 2026-05-23

진료 오더 확정과 후속 업무 생성 연결

Chart의 order confirm 액션이 성공하면 fulfillment work item sync가 같이 실행되도록 연결했다. 이제 진료실에서 확정한 오더는 서버 응답과 fulfillment read route를 통해 후속 queue 업무 항목으로 확인할 수 있다.

Status: Human Review Ready

핵심 변경

항목내용
Confirm hooksaveChartOrderAction에서 confirm 성공 후 fulfillment sync gateway를 호출한다.
ResponseConfirm 응답에 fulfillmentWorkItems가 포함된다.
Readback생성된 work item은 GET /fulfillment/work-items에서 같은 encounter/queue 기준으로 다시 읽힌다.
Billing 분리bill 액션은 fulfillment sync를 실행하지 않아 billing candidate 흐름과 분리된다.
Supabase modeSupabase session mode에서는 chart action route가 fulfillment RPC gateway를 함께 전달한다.
