무엇이 가능해졌나

항목내용
SyncPOST /fulfillment/work-items/sync-from-orders가 encounter/order ids를 받아 work item을 생성 또는 갱신한다.
ReadGET /fulfillment/work-items가 queue type, encounter, order, status 기준으로 업무 항목을 조회한다.
MutationPATCH /fulfillment/work-items/[workItemId]가 requested, accepted, in_progress, completed, cancelled, returned 상태 전이를 검증한다.
권한Chart sync는 chart:update, queue mutation은 lab/imaging/dispensing complete 권한을 요구한다. Treatment는 현재 permission model상 dispensing 권한 경계를 사용한다.
DB 계약Repo migration에 order_fulfillment_work_items table과 3개 RPC 계약을 추가했다. Remote staging push는 하지 않았다.
