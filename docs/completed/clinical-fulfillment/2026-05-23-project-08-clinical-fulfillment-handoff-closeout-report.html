Project 08 closeout 및 staging readiness

Project 08은 chart에서 확정된 order가 lab, imaging, dispensing, treatment 업무 queue로 생성되고, 각 부서의 처리 상태가 다시 order lifecycle과 billing candidate readback으로 이어지는 local-first persistence handoff를 완성했다. 대표 검수 기준으로는 Human Review 준비가 되었고, remote Supabase staging replay와 production claim은 별도 승인 gate가 남아 있다.

Status: Project Human Review Ready Remote staging mutation not run

비개발자용 요약

  • 진료실에서 order를 확정하면 후속 부서 업무 항목이 생기는 서버 경계가 생겼다.
  • 검사, 영상, 조제, 처치 화면이 해당 업무 항목을 읽고 상태 변경을 보낼 수 있다.
  • 후속 업무 완료는 진료 order lifecycle과 수납 후보로 다시 이어진다.
  • Kong synthetic scenario로 chart confirmation부터 billing readback까지 replay 검증을 통과했다.
  • 아직 실제 staging Supabase DB에 migration push/replay를 하지는 않았다.
