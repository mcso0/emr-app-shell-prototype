Clinical Order Fulfillment Handoff Persistence / DEN-240 / 2026-05-23

Fulfillment 완료 결과의 진료/수납 동기화

후속 부서의 fulfillment 상태 변경이 chart order lifecycle과 billing candidate sync로 돌아오도록 연결했다. 완료된 청구 가능 업무는 서버가 가진 invoice line 금액 snapshot으로 후보를 만들고, 반려/취소/진행 중 상태는 billing 후보를 만들지 않는다.

Status: Human Review Ready

핵심 변경

  • updateFulfillmentWorkItem 성공 후 downstream sync summary를 반환한다.
  • Order lifecycle gateway와 billing invoice candidate gateway를 fulfillment update route에 연결했다.
  • 완료 상태의 billing sync는 기존 billing core를 사용하므로 client-submitted amount를 받지 않는다.
  • order.status_changed와 billing.invoice_candidate_generated audit event를 남긴다.
