병원 로고 비공개 저장

2026-07-23 · HOSPITAL-ADMIN-LIVE-PR-022

요청과 결과

로고 위에 마우스나 키보드 포커스를 올리면 딤드와 편집 아이콘이 나타나고, Dialog에서 미리보기·저장·기본 이미지 복원이 가능한 일반적인 편집 흐름을 구현했습니다. 저장은 워크스페이스별 비공개 Storage를 사용합니다.

주요 변경

  • 5MB 이하 PNG/JPEG, 최소 256px, 최대 25MP 검증
  • 정적 512×512 WebP 정규화 및 메타데이터 제거
  • 서명된 격리 업로드와 서버 생성 경로만 허용
  • 현재 로고만 일반 멤버가 서명 읽기 가능하도록 RLS 분리
  • CAS 포인터 교체, 실패 보상, 이전 객체와 임시 객체 정리
  • 업로드·적용·삭제·충돌·정리 실패 결과를 Toast로 안내

검증

로컬 SQL RLS/CAS 재생과 실제 Storage API의 서명 업로드, 격리 접근 차단, 현재 멤버 읽기, 포인터 복구, 다른 관리자의 정리, 잔여 객체 제거를 통과했습니다.

남은 경계

원격 bucket 생성, 마이그레이션 적용, 배포와 실제 환경 smoke는 수행하지 않았습니다.
