요청과 결과

한 페이지에서 스크롤하던 병원 설정을 병원 기본 설정, 연락처 및 채널, 운영시간 관리의 독립 화면으로 분리했습니다. 사이드 패널도 병원 설정, 조직 및 접근, 진료 카탈로그로 그룹화했습니다.

주요 변경

  • 브레드크럼과 상단 저장 상태 툴바 제거
  • 요일 선택을 단일 ToggleGroup으로 통합하고 중복 스위치 제거
  • 요일 행은 왼쪽 설명, 오른쪽 시간 편집 액션으로 정리
  • 연락처 메모를 다중 행 Textarea로 확대
  • 로고 hover/focus 편집 버튼과 접근 가능한 Dialog 적용
  • 저장·삭제·복사·검증 등 명시적 액션 결과를 Toast로 안내

검증

병원관리 브라우저 테스트 35건, 전체 lint, TypeScript, 프로덕션 빌드, Storybook 빌드, 문서 링크 검사, 한국어 존댓말 검사를 통과했습니다.
