검사/오더 검색 DB 계약 경계 확인 보고서

이 보고서는 검사/오더 검색이 현재 어디에서 데이터를 공급받는지, 어떤 DB 계약이 이미 존재하는지, 그리고 live Supabase 검증이나 migration/RLS 변경이 필요한 지점을 분리한다.

없음

승인 필요

결론
부분 연결

chart search는 DB 계약 있음, 일부 live gateway는 미완성

최종 결론: 차트의 신규 Order 검색은 Supabase session 기준으로 clair_list_order_catalog_chart_search RPC를 통해 active workspace catalog와 active order set을 읽는 DB 계약이 존재한다. 다만 remote Supabase에서 실제 replay 검증은 승인 전 미수행이며, set confirmation, live order-set expansion, live lab delete-lock, lab result/device ingestion은 별도 후속 범위다.

현재 데이터 공급 경계

흐름 현재 공급원 판정
차트 + Order 검색 /hospital-admin/order-catalog?mode=chart-search demo header면 mock gateway, Supabase session이면 live RPC gateway

Fulfillment queue read /fulfillment/work-items Supabase session이면 live fulfillment gateway 사용 가능

관련 DB 계약

계약 역할 상태
order_catalog_items workspace-owned 개별 order catalog rows local-first migration 및 Supabase table gateway 존재
order_sets, order_set_items order set master와 포함 order 구성 migration/RLS/read contract는 있으나 live expansion gateway는 미구현
lab_test_categories, lab_test_items 검사 결과 항목 metadata migration/RLS/read contract는 있으나 live delete-lock gateway는 미구현

clair_list_order_catalog_chart_search 차트 검색용 active individual/set row snapshot 반환 repo-local RPC migration과 gateway mapping 존재
lab_test_item_delete_locks linked order 또는 saved result 사용 여부 기반 삭제 잠금 view contract는 있으나 route의 Supabase gateway 연결은 없음
