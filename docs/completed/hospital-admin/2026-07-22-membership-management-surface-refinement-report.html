병원 구성원 화면 구성 보완

구성원 정보를 보면서 목록 작업을 이어가는 흐름과, 직원 초대에 집중하는 흐름을 목적에 맞게 분리했다.

구현 및 집중 검증 완료

변경 내용

  • 검색 옆 필터는 원시 값 all 대신 모든 직군, 모든 부서를 표시한다.
  • 구성원 행을 누르면 dim 없이 380px 우측 프로필 패널이 열리고, 목록 검색과 다른 행 선택을 계속할 수 있다.
  • 패널은 기존 직원 운영 프로필의 헤더 높이, 아바타, 라인 탭, 우측 패널 토큰을 재사용한다.
  • 직원 초대와 초대 정보 수정은 640px 중앙 Dialog와 dim 처리로 전환했다.
  • 기존 권한 변경, 초대 상태, 보관·복구, API 경계와 실제 이메일 미발송 범위는 유지했다.

검증

  • 필터 한국어 표시, 상세 패널 비모달 동작, Escape 종료와 포커스 복귀, 중앙 초대 Dialog 회귀 테스트
  • 초대 생성·중복·재발송·수락·취소와 구성원 권한 수정 회귀 테스트
  • 변경 파일 ESLint, TypeScript, Git diff whitespace 검사
