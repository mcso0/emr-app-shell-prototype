병원관리 설정 콘텐츠 폭 통일 결과

병원관리의 주요 설정 화면이 같은 시각 경계를 사용하도록 본문 최대 너비를 920px에서 720px로 통일했다.

720px실제 설정 surface
6개공통 적용 화면
752px역할 화면 외부 래퍼
390px모바일 검증 너비

변경 범위

  • 병원 기본 설정, 연락처 및 채널, 운영시간 관리
  • 공간 관리, 바이탈 관리
  • 역할 및 권한 허브와 권한 역할·직무·업무 기본값 상세 화면
  • 공통 레이아웃 토큰을 사용해 화면별 폭 재분산 방지

보존한 계약

  • 가로 중앙 정렬, 좁은 화면의 자연스러운 축소, 모바일 좌우 여백
  • 카드·폼·버튼·Dialog·저장·권한·API·데이터 모델
  • 역할 화면의 16px 외부 여백과 실제 720px 설정 surface 관계
  • 본문과 별도인 808px 하단 변경사항 바

검증과 현재 상태

  • 데스크톱 DOM 폭과 390px 좁은 화면 overflow 검증 통과
  • 역할 상세의 긴 메타데이터도 720px 경계 안에서 수축 확인
  • 데스크톱·모바일·Dialog를 포함한 집중 Playwright 8개 통과
  • 전체 lint·타입·빌드·문서·비밀정보·diff 검사 통과

남은 위험과 다음 단계

  • 콘텐츠 밀도가 높아진 화면은 운영 배포 후 실제 데이터 길이로 한 번 더 확인
  • 이번 변경에는 데이터·권한·저장 동작 변경이 없음
  • PR 검증 완료 후 승인된 운영 머지 절차로 배포
