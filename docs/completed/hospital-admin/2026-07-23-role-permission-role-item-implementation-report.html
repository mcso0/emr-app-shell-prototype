권한 역할을 하나의 연결된 설정 단위로 바꿨어요

분리돼 보이던 역할 탭과 권한 목록을 한 번에 하나만 열리는 역할 항목으로 통합했다. 각 역할은 배정 구성원, 요약, 세부 권한을 같은 surface 안에서 소유하고, 권한 상태는 체크 표시 대신 명확한 스위치로 보여준다.

구현 및 집중 검증 통과

변경한 구조

역할 탐색

소유자·관리자·일반·커스텀 역할을 하나의 divided surface에 배치하고 관리자 역할을 기본으로 연다.

연결감

열린 역할의 구성원과 권한을 바로 아래에 이어서 표시한다. 같은 항목을 다시 눌러도 닫히지 않는다.

구성원

실제 워크스페이스 배정 이름을 전부 표시하고, 배정이 없으면 빈 상태를 숨기지 않고 명시한다.

권한 제어

권한 행은 스위치와 허용·차단 텍스트를 사용한다. 시스템 역할은 읽기 전용이고 커스텀 역할만 저장할 수 있다.

화면 검증

데스크톱 · 1440×1000

역할 목록과 열린 관리자 역할의 권한 행이 920px 콘텐츠 경계 안에 표시되고 문서 폭은 뷰포트를 넘지 않는다.

모바일 · 390×844

역할 설명과 요약이 한 열에서 줄바꿈되며 가로 넘침이 없다.

확인한 항목

  • 소유자 → 일반 전환 뒤에도 정확히 하나의 역할 패널만 열림
  • 열린 역할을 다시 눌러도 패널이 유지되고 aria-expanded 상태가 일치함
  • 시스템 역할 스위치 16개가 읽기 전용으로 표시됨
  • 커스텀 역할의 인라인 권한 변경·취소·저장 집중 테스트 통과
  • 데스크톱 1440×1000, 모바일 390×844에서 가로 넘침 없음
  • 브라우저 콘솔 오류 없음

유지한 경계

기존 역할·구성원·권한 데이터 모델과 저장 경로를 재사용했다. 실제 권한 정책, 서버 API, RLS, 구성원 배정 방식은 변경하지 않았다. 현재 검토 워크스페이스에는 시스템 역할 배정자가 없어 화면은 실제 빈 상태를 표시한다.
