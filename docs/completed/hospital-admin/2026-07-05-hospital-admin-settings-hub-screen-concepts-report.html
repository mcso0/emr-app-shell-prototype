병원관리 설정 허브 화면 시안 결과 보고

CLAiR EMR의 병원관리 모듈을 관리자용 병원 운영 설정 허브로 정리하고, 우선순위 설정 화면의 제품 기획, UX 흐름, 화면-only 시안을 반영했습니다.

요청 내용

  • 병원관리 안에서 병원 기본 설정, 구성원 관리, 근무표, 역할별 업무 관리, 공간/시간 관리, 바이탈 관리를 기획하고 화면 시안으로 확인할 수 있게 만들기
  • 감사 로그가 필요한지 재검토하기
  • DB/API 연동 없이 화면과 향후 개발 스펙 기반을 먼저 만들기

주요 결정

  • 병원관리를 병원 전체 설정의 단일 허브로 유지했습니다.
  • 상단 톱니바퀴 설정 버튼은 병원관리와 겹치므로 제거했습니다.
  • 감사 로그는 MVP에서 없애지 않고 최소 관리자 변경 이력 화면으로 유지하기로 정리했습니다.
  • 역할별 업무 관리는 구성원 권한 편집이 아니라 역할별 기본 업무/배정/화면 접근 기준을 다루는 화면으로 분리했습니다.
