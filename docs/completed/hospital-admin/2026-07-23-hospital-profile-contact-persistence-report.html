병원 프로필·연락처 저장

2026-07-23 · HOSPITAL-ADMIN-LIVE-PR-021

요청과 결과

병원 정보와 연락처가 화면 임시값에 머물지 않도록 워크스페이스 단위의 DB, RPC, API, 권한 경계를 연결했습니다. 등록 정보 변경은 즉시 덮어쓰지 않고 검토 대기 요청으로 저장됩니다.

주요 변경

  • 병원 프로필 및 등록 정보 변경 요청 테이블 추가
  • 활성 멤버 읽기, 관리자 변경, 교차 워크스페이스 차단
  • revision 기반 동시 수정 충돌 방지
  • 엄격한 입력 키·본문 크기·URL·메모 길이 검증과 rate limit
  • 연락처 원문이나 요청 상세를 남기지 않는 안전한 감사 이벤트
  • 화면별 독립 draft, 저장, 되돌리기, 새로고침 readback

검증

로컬 Supabase 전체 마이그레이션과 프로필/RLS/감사 트랜잭션 재생, 모델·서버·마이그레이션·운영시간 회귀 테스트를 통과했습니다.

남은 경계

원격 마이그레이션, 외부 알림 전송, 운영자 승인 화면, 프로덕션 배포는 수행하지 않았습니다.
