역할 및 권한 화면 구성 개선

넓게 펼쳐져 역할 차이와 설정 순서를 파악하기 어려웠던 화면을 병원 기본 설정과 같은 폭과 정보 흐름으로 정리했습니다.

Human Review 준비

변경 내용

  • 콘텐츠 최대 폭을 920px로 맞췄습니다.
  • 권한 역할 / 직무 / 업무 기본값을 하나의 구분선 목록으로 묶고, 각 행이 독립 상세 화면으로 이동하게 바꿨습니다.
  • 상세 화면은 URL query와 브라우저 이력으로 표현하며 명확한 역할 및 권한 뒤로가기를 제공합니다.
  • 권한 역할 상세에서는 소유자·관리자·일반 역할과 배정 인원을 작은 탭에서 바로 비교할 수 있습니다.
  • 선택한 역할의 배정 인원, 허용 권한 수, 역할 유형을 먼저 보여줍니다.
  • 세부 권한은 접지 않고 범주 제목과 설명·읽기 전용 체크박스가 있는 설정 행으로 보여줍니다.

왜 중요한가

관리자는 먼저 허브에서 설정 종류를 선택하고, 한 상세 화면에서 한 가지 설정에만 집중할 수 있습니다. 권한·직무·업무 기본값의 위계와 차이가 화면 이동 구조 자체로 드러납니다.

검증

  • 역할 화면 집중 Playwright 테스트 통과
  • 모바일 가로 넘침, 키보드 행 활성화, 브라우저 뒤로가기 확인
  • TypeScript와 ESLint 확인
  • 내부 브라우저에서 새 세로 위계와 실제 렌더링 확인

범위와 주의점

이번 변경은 화면 구성과 상호작용만 다룹니다. 역할 데이터, 구성원 배정, 서버 권한 검사, 저장 방식은 변경하지 않았습니다.

병원관리 전체 테스트는 26개 중 25개가 통과했습니다. 역할·권한 관련 테스트는 모두 통과했고, 별도 병원 기본 설정 저장 테스트 1개는 기존 대표 전화 * 필드를 기다리다 재실행에서도 타임아웃됐습니다.
