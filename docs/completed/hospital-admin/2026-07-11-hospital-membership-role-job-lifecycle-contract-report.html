병원 구성원·역할·직무 lifecycle 기능정의

HOSPITAL-ADMIN-PR-004 · 2026-07-11 · 제품 계약 승인 완료

결론

구성원 관리에서 삭제 용어를 제거하고 활성 / 비활성 / 보관됨으로 구분했다. 권한 역할은 대체 역할 지정 후 비활성화하고, 직무는 기존 구성원 이력을 유지하면서 신규 선택만 차단한다.

왜 중요한가

  • 휴직·일시 정지와 퇴사·계약 종료를 구분한다.
  • 구성원 이력과 진료·감사 로그의 처리자 연결을 보존한다.
  • 역할 비활성화 과정에서 권한 공백이나 마지막 소유자 유실을 방지한다.
  • 직무가 권한 소스로 오해되지 않도록 역할과 lifecycle을 분리한다.

승인된 핵심 정책

대상정책
구성원active / inactive / archived. 복구는 항상 inactive.
권한 역할커스텀 역할만 비활성화 가능. 활성·비활성 구성원과 초대 대기는 대체 역할로 원자적 이전.
직무기존 구성원 배정 유지. 신규 선택 차단. 초대 대기는 필요할 때 대체 직무 지정.
초대대기·수락·취소·만료 이력 보존. 보관 구성원의 이메일은 새 멤버십 대신 복구 흐름으로 연결.
삭제구성원·역할·직무 Hard delete 및 자동 삭제 스케줄러는 MVP 제외.

현재 상태와 제외 범위

기능정의와 작성된 제품 계약은 승욱의 최종 승인을 받았다.

이 결과는 구현 완료, 원격 migration 정합화 완료, 원격 DB 적용, RLS 보안 완료를 의미하지 않는다. 저장소의 기존 soft_deleted 구현 초안은 새 계약과 호환되도록 forward migration과 코드 전환이 필요하다.
