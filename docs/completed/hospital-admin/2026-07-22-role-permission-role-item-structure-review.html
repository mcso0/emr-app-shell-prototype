권한 역할 상세 구조 재검토

현재 탭은 역할 선택과 아래 설정이 서로 다른 덩어리처럼 보여, 역할을 바꿨을 때 내용이 바뀐다는 인과가 약합니다. 역할 자체를 하나의 설정 아이템으로 만들고 그 안에 구성원과 권한을 넣는 방향을 검토합니다.

01 · Diagnosis

탭과 아래 내용이 연결되지 않는 이유

문제는 탭 자체보다 선택 영역과 결과 영역 사이의 시각적·데이터적 연결이 약한 데 있습니다.

01하나의 컨테이너가 아니다

탭은 회색 segmented surface에 있고, 선택 결과는 큰 여백 뒤의 별도 제목과 surface에서 시작합니다. 경계가 끊겨 있어 같은 컴포넌트의 머리와 몸처럼 보이지 않습니다.

02선택 변화의 시각적 신호가 작다

역할명과 설명만 바뀌고 레이아웃은 거의 동일합니다. 아래 권한이 스크롤 아래에 있으면 사용자는 무엇이 바뀌었는지 즉시 확인하기 어렵습니다.

03관리자와 일반의 현재 노출 권한이 같다

현재 화면에 노출한 16개 기준에서는 관리자와 일반이 모두 12/16으로 보여, 탭을 전환해도 차이가 더 약하게 느껴집니다. 구조 문제와 데이터 표현 문제가 동시에 있습니다.

04구성원이 숫자로만 보인다

‘0명/1명’만으로는 역할의 실제 사용자가 떠오르지 않습니다. 구성원 이름이 역할 아이템 안에 들어가야 역할과 사람, 권한이 하나의 설정 단위로 연결됩니다.

02 · Recommendation

추천: 역할 아이템 아코디언

상위 ‘역할 및 권한 허브 → 권한 역할 상세’ 구조는 유지하고, 상세 화면 안에서만 소유자·관리자·일반을 역할 아이템으로 묶습니다.

한 번에 한 역할만 연다

세 역할은 동시에 켜지는 독립 설정이 아니라 서로 다른 권한 정의입니다. 하나를 선택하면 그 역할의 구성원과 권한이 바로 아래에 붙어 열리는 방식이 관계를 가장 강하게 보여줍니다.

  • 아이템 헤더: 역할명, 시스템/커스텀 상태, 구성원 이름, 인원, 허용 권한 수
  • 펼친 영역: 전체 구성원, 역할 설명, 범주별 권한 토글
  • 권한 범주는 다시 접지 않고 항상 노출

이전 아코디언과 다른 점

허브의 ‘권한 역할·직무·업무 기본값’은 서로 독립된 목적이므로 페이지 이동이 맞습니다. 반면 상세의 ‘소유자·관리자·일반’은 하나의 역할을 선택해 보는 관계이므로 단일-open 아코디언이 자연스럽습니다.

04 · Alternatives

세 가지 구조 비교

역할 수와 관리 목적을 기준으로 비교하면 현재 범위에서는 역할 아이템 아코디언이 가장 직접적입니다.

구조연결감장점주의점판단
연결형 탭 + 동일 panel중간현재 코드 변경이 가장 작고 전환이 빠름구성원과 긴 권한 목록을 담으면 탭과 panel 사이가 다시 멀어질 수 있음차선
역할 아이템 아코디언높음역할명·구성원·권한이 한 덩어리로 보임한 역할의 권한이 길어지므로 동시에 하나만 열어야 함추천
좌측 역할 목록 + 우측 상세높음역할이 8개 이상으로 늘어날 때 탐색과 비교가 좋음920px와 모바일에서 2열 구조 부담이 큼확장안
05 · Switch Semantics

체크박스는 토글로 변경해도 괜찮습니다

다만 시스템 역할과 커스텀 역할에서 토글이 의미하는 상태를 분명히 구분해야 합니다.

시스템 역할

토글 값은 보여주되 disabled 처리하고 ‘읽기 전용’ 설명을 함께 둡니다. 꺼진 것인지 비활성화된 것인지 혼동하지 않게 ‘허용/차단’ 텍스트를 붙입니다.

커스텀 역할

토글을 편집 가능하게 하고 변경 시 하단 contextual save bar를 표시합니다. 저장 전에는 ‘저장하지 않은 변경’ 상태가 분명해야 합니다.

소유자 전용

일반 역할에서는 토글을 끈 상태로 잠그고 ‘소유자 전용’ 설명을 표시합니다. 토글만 disabled 처리해 이유를 숨기지 않습니다.

06 · Implementation Contract

다음 시안 수정 범위

실제 화면 수정 시 데이터 정책은 유지하고 표현과 연결감만 바꿉니다.

유지920px 콘텐츠 폭, 허브 → 상세 이동, URL 뒤로가기, 기존 역할/구성원/권한 데이터, 커스텀 역할 dialog와 구성원 관리 sheet
변경segmented tabs를 역할 아이템 목록으로 교체하고, 선택한 역할의 세부 내용을 같은 아이템 안에 펼칩니다.
권한 컨트롤체크박스를 switch로 교체합니다. 시스템 역할은 읽기 전용, 커스텀 역할만 편집 가능합니다.
구성원 표시아이템 헤더에 이름 요약을, 펼친 영역에 배정 구성원 전체 이름을 보여주고 ‘구성원 관리’ 액션을 유지합니다.
아코디언 규칙역할은 한 번에 하나만 엽니다. 권한 범주는 다시 아코디언으로 감추지 않습니다.
정책 범위실제 권한 정책, API, RLS, 배정 방식은 변경하지 않습니다. 관리자와 일반의 실질 권한 차이는 별도 제품 정책 결정이 필요합니다.
