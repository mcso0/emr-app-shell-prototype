사용자에게 달라지는 점

  • 주간 운영시간과 공휴일·예외일 설정이 시안의 920px 콘텐츠 폭, 구역 간격, 행 높이, 버튼 및 배지 규격으로 정렬됩니다.
  • 운영시간과 휴게시간이 서로 다른 배지로 구분되고, 휴무일은 비활성 시간 버튼과 상태 배지로 명확히 표시됩니다.
  • 예외일 날짜가 한국어 형식으로 표시되며 추가·수정·삭제 동작은 기존 CDS 아이콘과 공용 컴포넌트를 사용합니다.
  • 모바일 390px 화면에서도 가로 스크롤 없이 설정 내용을 확인하고 편집할 수 있습니다.

데이터 및 보안 계약

  • 기존 운영시간 GET/PUT API와 workspace 범위 제한을 변경하지 않았습니다.
  • 구성원 조회, 관리자 수정 권한, 감사 로그 원자성, 향후 예약 충돌 검증을 그대로 유지했습니다.
  • API 형식, DB 스키마, migration, RPC, RLS, Storage 및 패키지 의존성 변경은 없습니다.
