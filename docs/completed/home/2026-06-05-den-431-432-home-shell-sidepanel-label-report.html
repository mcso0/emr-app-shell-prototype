DEN-431/432 홈 원내 현황 사이드패널 결과 보고

작성일: 2026-06-05

홈 좌측 패널을 홈 콘텐츠 내부 커스텀 aside에서 제거하고, 접수/예약과 같은 shell module side panel 슬롯으로 이동했다. 또한 화면 라벨을 `홈`/`다음 행동`이 아니라 `원내 현황` 중심으로 정리했다.

요청 사항

  • 홈 좌측 패널이 접수/예약처럼 공통 side panel 컴포넌트와 shell gutter를 사용해야 한다.
  • 패널 hover 시 접수/예약처럼 타이틀 옆 접기 버튼이 나와야 한다.
  • `다음 행동` 표기는 `원내 현황`으로 바꿔야 한다.
  • nav rail 홈 아이콘 hover tooltip도 `홈`이 아니라 `원내 현황`으로 보여야 한다.

변경 내용

  • Home module에 실제 sidePanel을 등록했다.
  • Home side panel을 EmrSubpanel, EmrSubpanelTitle, EmrSubpanelBody, shared side-panel card primitives로 구성했다.
  • setModulePanelOpen(false)를 연결해 hover collapse affordance를 복원했다.
  • Home side panel과 main Kanban이 같은 selected task/detail 상태를 쓰도록 home-workspace-store를 추가했다.
  • Home module/nav/top menu/workspace tab label을 원내 현황으로 정리했다.
  • /w/:workspaceId/home route와 home module id는 유지했다.
