DEN-430 홈 워크스페이스 프레임 정렬 결과 보고

작성일: 2026-06-05

홈 화면의 좌측 다음 행동 패널과 업무 현황 영역이 접수/진료 화면처럼 하나의 워크스페이스 프레임 안에서 이어지도록 정리했다. 기존에는 홈 내부에서 한 번 더 패딩과 둥근 테두리 카드 프레임을 만들어, 쉘과 콘텐츠가 분리된 것처럼 보였다.

요청 사항

세부 카드가 아니라 페이지 레이아웃 관점에서, 홈 화면의 navigation rail, left side panel, content section이 접수/진료 화면처럼 하나의 프레임으로 구성되도록 수정한다.

변경 내용

  • HomeContent의 내부 p-2 래퍼를 제거했다.
  • 홈 Kanban workspace 루트의 중첩 border, radius, bg-card 프레임을 제거했다.
  • 로딩 스켈레톤도 동일한 좌측 패널/콘텐츠 프레임 구조를 따르도록 정리했다.
  • Home 회귀 테스트에 내부 workspace root가 별도 테두리/라운딩을 갖지 않고, 좌측 패널과 보드 상단이 정렬되는 검증을 추가했다.

  • npx tsc --noEmit: 통과.
  • npm run build: 통과.
  • npx playwright test tests/home.spec.ts --reporter=line: 16개 통과.
  • npm run docs:check: 통과.
  • Browser 확인: CSS 1920x1080에서 workspace 내부 border/radius 0, 좌측 패널과 보드 y/height 정렬, 상세 패널 비모달 유지 확인.

리스크와 제외 범위

  • 홈 필터, 칸반 카드 내용, 상세 패널 내용 구조는 이번 범위에서 변경하지 않았다.
  • 전역 WorkspaceFrame 동작은 변경하지 않았다.
  • 스테이징/프리뷰는 Vercel Deployment Protection이 적용될 수 있다.
