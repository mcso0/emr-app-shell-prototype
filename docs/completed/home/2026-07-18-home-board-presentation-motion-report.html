홈 원내 현황 모션 도입 결과

운영 업무를 바꾸지 않고, 보드를 읽고 정리하는 경험만 개선했다. 카드의 원본 업무 상태·권한·소스 화면 연결은 그대로다.

적용 내용

  • dnd kit: 전체 흐름에서 업무 열을 마우스로 드래그해 이 화면 안에서 재배치할 수 있다.
  • 키보드 접근성: 각 열의 순서 변경 버튼에 초점을 둔 뒤 좌·우 화살표로 열을 옮길 수 있다.
  • NumberFlow: 배정 누락, 주의 업무, 내 업무 수치가 값 변경 시 자연스럽게 전환된다. 운영체제의 모션 축소 설정도 기본적으로 따른다.

검증

  • 홈 칸반 기본 렌더, 운영 모드 정렬, 키보드·포인터 열 재배치: 통과
  • npx tsc --noEmit --pretty false: 통과
  • npm run lint -- --quiet: 통과
  • npm run docs:check: 통과
  • git diff --check: 통과

범위와 다음 단계

열 순서는 새로고침하면 초기화되는 세션 범위다. 개인별 영구 저장, 예약·진료·수납 카드의 드래그 상태 변경, 서버·DB·RLS 변경은 이번 범위에서 제외했다. 실제 사용자 검토 후 영구 저장이 필요하면 사용자·워크스페이스 경계를 포함한 별도 작업으로 다룬다.
