DEN-417~419 Home 업무 현황 UI 후속 정리

작성일: 2026-06-05 · Linear: DEN-417, DEN-418, DEN-419

요약

홈 업무 현황에서 task를 훑는 흐름을 막던 모달형 상세 드로어를 비모달 우측 패널로 바꿨다. task 카드는 기존 대기열에서 쓰는 공용 queue card UI를 재사용하고, 카드 내부 이동 CTA와 반복 세로 띠/보조 설명 텍스트를 제거했다.

변경 내용

  • Sheet 기반 task detail을 제거하고 오른쪽 고정 aside 패널로 교체했다.
  • 상세 패널이 열려 있어도 칸반보드와 다른 task를 계속 볼 수 있고 선택할 수 있다.
  • 상세 패널 footer를 접수/예약 드로어처럼 full-width primary CTA와 2열 secondary CTA로 정리했다.
  • 홈 칸반 task 카드를 공용 EmrTaskQueueCard 기반으로 바꿨다.
  • task 카드 내부의 진료 대기열 열기, 검사 큐 열기 같은 ghost CTA를 제거했다.
  • 선택 task 카드와 상태 그룹 제목의 왼쪽 세로 띠 UI를 홈 칸반에서 제거했다.
  • 업무 현황 제목 아래 설명과 각 칸반 컬럼 제목 아래 설명을 제거했다.

범위 밖

  • 실제 담당 배정, 메모 저장, 완료 처리 같은 mutation 구현
  • live DB, Supabase, RLS, server enforcement
  • Home 외 대기열 화면의 동작 변경
  • production deploy
