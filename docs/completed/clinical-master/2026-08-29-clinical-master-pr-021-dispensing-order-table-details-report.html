데이터와 임상 의미

  • 함량과 제형은 조제 lineage snapshot만 읽고 제품명에서 추론하지 않는다.
  • 서비스 검토용 CLAiR master는 임상 미검토, 가격이 설정된 사용 가능 상태는 별도 사용으로 표시한다.
  • 값이 없는 임상 항목은 미설정으로 표시한다.
  • 서로 다른 단위를 직접 비교하지 않도록 1회 용량과 처방 총량 정렬은 비활성화했다.
  • 청구서명과 판매금액은 기본 노출하되 고정 영역에는 포함하지 않는다.

검증 결과

  • TypeScript, 전체 ESLint, production build, docs links, Korean UX copy, secret scan, git diff --check 통과.
  • 조제 108행, 표시값, 컬럼 순서, 검색, 제형 필터, drawer 연계를 포함한 focused Hospital Admin Playwright 6건 통과.
  • 1024, 1280, 1440, 1920px에서 524px 고정 폭과 가로 overflow를 확인하고, 스크롤 뒤 두 Order명 셀의 좌표가 유지됨을 검증했다.
  • 공유 컬럼 grip의 포인터 회귀와 키보드 8px/Shift 24px 리사이즈 및 min/max 제한을 확인했다.
  • 독립 read-only 리뷰는 APPROVE, MUST-FIX 0, SHOULD-FIX 0으로 종료됐다.

변경하지 않은 경계

  • 비조제 Order 표의 컬럼, 고정, 정렬과 필터 계약은 유지했다.
  • Airtable, Supabase, migration, RLS, workspace catalog, 가격, 임상 승인과 사용 상태는 변경하지 않았다.
  • PR, exact-SHA Release Check, merge, production deployment 증거는 릴리스 시스템에서 별도로 확인한다.
