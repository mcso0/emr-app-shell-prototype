이번에 바꾼 것

저장 분류 조회 연결을 로컬에서 구현했다. 원격 DB에는 아직 적용하지 않았다. 각 오더에 저장된 분류 ID를 따라가서 분류명·경로·코드를 상세창에 표시하도록 했다. 최신 마스터의 다른 분류로 바꿔 읽지 않는다.

이름을 보고 채우지 않고 저장 분류 조회 불가와 세부 분류 미설정을 구분했다. 미분류·종료·불일치 상태도 따로 표시한다. 저장 후 분류 재조회가 실패하면 저장 성공은 유지하되 조회 불가를 표시한다.

새 오더·임의 기본값을 주입하지 않았다. 기존 조제 검토 정책과 가격·업무 값도 변경하지 않았다.

실제 DB에서 확인한 한계

검증 결과와 한계

계약 테스트 128개와 로컬 PostgreSQL 검증을 통과했다. 기존 응답 값·오더 수 유지, 분류 ID 일치, 권한 없는 사용자의 조회 차단, 익명·서비스 역할의 실행 권한 차단을 확인했다. 테스트용 변경은 모두 되돌렸고 잔여 데이터가 없는 것도 확인했다.

수정 파일 린트도 통과했다. 전체 타입 검사는 기존 BlockNote 의존성 오류로 실패했다. 이번 수정 파일의 타입 오류는 남아 있지 않다. 기존 문서의 persona-guide 누락 링크도 남아 있다.

독립 검토의 추가 수정 요구는 없다. 원격 확인은 저장 구조와 집계에 한정한 읽기 전용 검사였다. 로그인한 EMR 화면 검증과 배포는 아직 하지 않았다. 이 보고서의 화면 검증은 EMR 기능 검증과 별개다.

다음 작업은 무엇인가?

세부 분류를 실제로 저장할 필드와 매핑표를 정한다. 오더의 업무 유형과 화면 분류를 구분하고 마스터에서 워크스페이스로 복사·수정할 기준도 함께 정한다.

522개 마스터 오더와 기존 미분류 오더를 구분해 다루고 원격 적용 범위를 별도로 확정한다. 이후 저장된 세부 분류로 테이블·상세창·저장 후 재조회가 일치하는지 확인한다. 이름 추정이나 임시 목록으로 대신하지 않는다.

Slice 03은 아직 진행 중이다. 이 분류 기준과 적용 범위를 확정한 뒤 Slice 04의 병원관리·차트 검색 후보 비교로 넘어간다. 임상병리 외부 조사를 처음부터 반복하는 작업은 아니다.
