조제 마스터 Order 관리 노출 수정

원격 DB에 존재하던 조제 마스터 108건이 병원관리의 처방으로 잘못 분류되어 조제 0으로 보이던 화면 매핑을 수정했다.

원인

청담점에는 기존 medication 54건과 조제 마스터 108건이 있었다. 화면이 조제 마스터 lineage를 확인하지 않고 모두 일반 medication으로 분류해 처방 162, 조제 0을 표시했다.

변경

  • dispensing lineage가 있는 마스터는 병원관리 조제에 배치한다.
  • 마스터 스냅샷의 영문 제품명과 한글 검토명을 목록에 표시한다.
  • 임상 미활성 상태는 검토 대기, 미정 가격은 미설정으로 표시한다.
  • 기존 처방, 마스터 원본, 임상 승인, 가격, 활성화 상태는 변경하지 않는다.

검증

브라우저 회귀 테스트에서 108건을 주입해 조제 108, A001270의 영문·한글 제품명, 검토 대기, 미설정 표시를 확인한다.

남은 경계

이 변경은 서비스 운영 검토용 노출만 수정한다. 실제 진료용 임상 활성화는 계속 별도 승인과 임상 검토가 필요하다.
