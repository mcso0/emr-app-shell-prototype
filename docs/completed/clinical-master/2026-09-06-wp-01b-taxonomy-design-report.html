설계안 작성 완료 · 아직 구현·적용하지 않음

마스터 오더와 병원별 복사본에 두 필드를 저장하는 안을 정리했다. 이번 단계에서는 코드나 DB를 바꾸지 않았다.

필드예시역할
화면 세부 분류 코드임상병리 · 초음파 · 마취오더를 찾고 묶어서 보는 기준
검사군 코드CBC · 혈액화학임상병리 안에서 구분할 기준

CBC는 임상병리와 CBC, 혈액화학은 임상병리와 혈액화학으로 구분한다. 상위 카테고리는 저장된 코드의 정의로 표시하고 이름을 보고 추정하지 않는다.

업무 유형과 수행 경로는 별도로 유지한다. 화면에서 마취를 수술 아래로 분류하더라도 기존 처치 업무 경로가 자동으로 바뀌지는 않는다. 과거 차트에 확정된 분류도 나중 값으로 다시 쓰지 않는다.

예시는 저장 구조 설명용이며 실제 오더에 적용된 값이 아니다. 전체 분류 목록은 다음 매핑 작업에서 검증한다.

병원이 수정한 값은 보존

병원이 수정한 값은 마스터가 업데이트돼도 보존한다. 수정하지 않은 값만 갱신하고 두 값의 조합이 맞지 않으면 기존 값을 유지하면서 충돌을 알린다.

값을 직접 지운 경우도 병원의 수정으로 기록한다. 마스터 값으로 돌아가려면 별도 동작을 사용한다. 분류를 수정해도 가격·용량·업무 경로·사용 상태는 바꾸지 않는다.

이 동작은 설계 목표다. 현재 구현됐다는 의미가 아니다. 마스터 → 병원별 복사 → 수정 보존을 실제로 검증해야 한다.

억지 분류와 임시 대체는 금지

경구·주사에 맞지 않는 외용제나 방사선·초음파에 맞지 않는 영상 오더를 억지로 분류하지 않는다. 다음 매핑 작업에서 필요한 분류를 명시적으로 추가한다. 기타는 모르는 값을 대신 채우는 용도로 쓰지 않는다.

검사군은 화면에서 찾아보기 위한 분류다. CBC 세트 안에 WBC·RBC가 들어가는 구성, 결과 입력, 장비별 정상범위는 별도 검사 구조 작업으로 유지한다. 이번 설계 때문에 그 작업을 처음부터 다시 조사하지 않는다.

기존 영상검사 메뉴가 방사선만 가리키는 문제도 구현 체크 항목에 넣었다. 초음파 값을 저장하는 것만으로 화면 노출까지 완료됐다고 보지 않는다.

바로 다음은 522개 매핑표 작성

522개 마스터 오더의 비적용 분류 매핑표와 빠진 분류 목록을 만든다. 각 오더에 제안 분류·근거·출처를 기록한다. 기존 청담점 미분류 오더 13개는 별도로 다룬다. 이 숫자는 이전 조사에서 확인한 값이며 실제 적용 전에 다시 확인한다.

분류를 배포하기 전에는 WP-02 중 이 두 필드의 복사·수정 보존 부분을 먼저 구현하고 검증해야 한다. 전체 상속 작업을 한꺼번에 앞당기는 것은 아니다.

순서: 매핑표 검증 → 로컬 구현·테스트 → 원격 적용 범위 확정 → DB 적용·앱 배포 → 로그인 화면 확인. 지금은 배포 단계가 아니다.
