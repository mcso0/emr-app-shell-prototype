이번에 바뀐 것

01 · 같은 저장값

읽기 규칙을 한곳으로 모았다

공통 기본값을 먼저 읽는다. 공통 값이 없는 기존 오더는 같은 오더 안의 구형 저장 필드만 제한적으로 읽고 출처를 함께 전달한다. 다른 오더나 임시 데이터로 대체하지 않는다.

02 · 누락을 숨기지 않기

값이 없으면 미설정

용량·단위·경로·횟수·일수·총량을 임의로 채우던 값을 제거했다. 차트의 표시·수정·검증에서도 스키마의 예시 기본값을 읽지 않는다. 숫자 0과 false는 없는 값과 구분한다.

03 · 편집과 저장

지운 값이 되살아나지 않게

병원관리에서 수정하거나 지운 값이 두 저장 표현에 동일하게 반영되도록 맞췄다. 수동 총량 사유와 권한 정보는 저장 내용에 보존하되 차트의 임상 입력값과는 분리한다.

04 · 계산 조건

계산할 근거가 있을 때만

환자당 용량과 총량의 단위가 같고 필요한 값이 있을 때만 총량을 계산한다. 체중·체표면적·다른 단위의 변환을 추정하지 않는다. 새 조제 오더도 용량이나 투약 경로를 미리 채우지 않는다.
