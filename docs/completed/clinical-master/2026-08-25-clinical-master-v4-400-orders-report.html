사용 경계

이 패키지는 세일즈 데모용 합성 데이터다. 실제 병원 수가나 한국 표준 수가를 나타내지 않으며, 약품은 성분·제형 이름까지만 포함하고 용량·투여 빈도·처방 추천·상품 SKU·마약류를 포함하지 않는다. 검사에도 기준 범위나 결과 해석을 넣지 않았다.

용어와 업무 범위는 AAHA 예방·마취·치과·수액 자료, RECOVER 응급 지침, WSAVA 백신 지침, Cornell AHDC 임상화학 자료를 확인하는 용도로만 사용했다. 발행 provenance는 계속 synthetic이며 임상 승인이나 진료 권위로 바뀌지 않는다.

가격은 각 워크스페이스가 소유하는 양의 정수 KRW 합성값이다. 기존 V3 120개 가격은 그대로 보존하고, 새 V4 280개만 100원 단위로 반올림된 비중복 값을 사용한다. 중앙 publisher payload와 완전히 분리했다. Order Set의 고정가·구간가 구성항목은 이중 청구 방지를 위해 기본 청구 반영을 끈 상태다.
