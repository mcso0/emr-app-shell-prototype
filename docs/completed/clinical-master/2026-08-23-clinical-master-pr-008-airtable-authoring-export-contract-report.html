CLAiR Clinical Master / PR-008 / 2026-08-23

Airtable 작성·검토용 내보내기 계약

이번 작업은 임상 마스터 데이터를 나중에 안전하게 검토·내보내기 위한 형식과 점검 규칙을 코드로 고정한 작업이다. 실제 임상 콘텐츠를 출시한 작업은 아니다.

상태: 로컬 구현 완료 실제 Airtable·DB·배포 없음

무엇이 정해졌나

구분내용
작성용 표Release Drafts, Sources, Master Records, Names, Classification Paths, Lab Panel Items, Lab Order Profiles, Diagnosis Category Links의 정확히 8개 물리 표를 계약으로 정의했다.
보기 화면Code Dictionary, Orders, Vocabularies, Diagnosis Systems, Disease Groups, Diagnoses, Ready for Export는 보기 전용이며 원본 권한이 아니다.
검토 게이트승인된 release, published/normal record, synthetic source, 의미 있는 stable key, 정확한 이름·참조·타입만 통과시킨다.
범위분류·주문·단위·검체·검사·패널과 진단 계통/질병 그룹/진단을 포함한 13개 authoring record type을 지원한다.

안전하게 막는 항목

  • 중복·불안정 key, 잘못된 lifecycle/review/source, 잘못된 record type과 관계를 거부한다.
  • 진단 링크는 질병 그룹만 가리키며 진단마다 primary 링크를 정확히 하나 요구한다. 진단 authoring 데이터는 현재 publisher가 사용할 수 없다.
  • Airtable ID, formula, lookup, 생성된 revision·timestamp·hash 같은 값을 export 권한으로 인정하지 않는다.
  • 가격 필드는 canonical_price_forbidden, set/range/weight-tier 가격 필드는 workspace_order_set_pricing_forbidden으로 거부한다. 이 가격 권한은 public.order_set_revision_price_ranges에 남는다.

이번에 하지 않은 것

  • 실제 Airtable Base를 만들지 않았고, 실제 Airtable 데이터나 외부 임상 데이터를 생성·가져오지 않았다.
  • export를 publish하지 않았고, release/version/review 데이터를 원격에 쓰지 않았다.
  • DB schema, migration, RLS, seed, runtime UI/routes, chart 동작, current SQL publisher를 변경하지 않았다.
  • Supabase 등 원격 상태를 읽거나 변경하지 않았다.
