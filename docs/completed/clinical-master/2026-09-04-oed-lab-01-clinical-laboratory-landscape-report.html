결론

86개를 로컬 고정 목록·V4 표본·기존 비적용 후보와 대조했다. 검사군별 외부 자료는 구조를 정리하는 데 사용했으며 개별 검사법·수치까지 검증한 것은 아니다. 로컬 표본에는 검사 세트와 개별 결과 정의가 일부 있지만 세트 → 독립 하위 오더 → 결과값 구조는 보완이 필요하다.

로컬 V4 표본의 CBC에는 WBC·HCT·PLT 세 항목만 연결돼 있다. 72개 검사 정의 중 16개는 독립 order profile이 없다. 건강검진·노령·응급 검사 조합은 기존 패널 하나를 가리키며, 종·검체·검사법·장비별 정상범위와 판별 규칙을 담은 버전 프로필도 이 표본에서 확인되지 않는다. 실제 DB와 앱의 지원 범위는 OED-LAB-03에서 별도로 확인한다.

이번 단계에서 한 일은 이 구조와 빈틈을 확인한 것까지다. 앱, DB, Airtable, Supabase, 마스터 오더에는 아무것도 적용하지 않았다. 다음 작업인 OED-LAB-02에서는 CBC 하나를 표본으로 삼아 정확한 하위 항목과 프로토타입용 대표 값을 고정한다.

2026-09-06 보정 결과

86건의 분류와 검체 표기, 근거 연결을 다시 대조했다. 범백혈구감소증 항원 검사는 CBC에서 감염성 검사로, 마취 전 확장 검사 조합은 혈액화학에서 복합 검사 조합으로 바로잡았다. 미등록 ID를 혈액화학으로 자동 분류하던 처리도 제거했다.

이전 WP-01A 비적용 후보의 검체와 로컬 V4 표본의 검체 표기가 충돌하는 항목은 5건이다. 요단백 평가 패널, 감염성 선별 패널, 개 파보 항원, 개 디스템퍼 항원, 고양이 범백혈구감소증 항원 검사다. 두 자료를 비교한 결과이며 특정 제품에서 허용하는 검체를 확정한 것은 아니다. 패널은 하위 검사마다 검체가 다를 수 있다.

나머지는 같은 검체 표기 27건, 혈액 채취·처리 조건 미지정 38건, 후보 검체 없음 12건, 채취 검체와 표본 제작 형태의 구분 필요 2건, 후보가 other로만 지정된 항목 1건, 로컬 검사 연결 없음 1건이다. 검체가 일치해도 임상 검증 완료를 뜻하지 않는다. 원본 후보와 표본은 수정하지 않았다.

기존 currentDefaultSummary라는 이름 때문에 이전 후보가 현재 기본값처럼 보였다. 이를 priorCandidateDefaults로 바꾸고 비적용 후보라는 출처를 명시했다. 실제 원격 마스터·병원관리 값을 읽은 결과는 아니다.

검사군 자료가 있다는 이유로 개별 검사까지 확인 완료로 표시하던 처리도 수정했다. 85건은 source_partial, 레거시 예외 1건은 functional_fixture_required다. 이 상태는 조사 근거를 어디까지 확보했는지만 나타낸다. 오더 사용 가능 상태나 검수 대기 상태는 바꾸지 않는다. 검사별 정확한 방법과 정상범위 숫자는 이번 단계에서 추출하지 않았다.

수행 경로와 장비는 검사군 후보로만 표시한다. 개별 검사에 대한 지원 여부는 후속 조사에서 확인한다. 개별 오더에 검사군 전체 하위 목록을 붙이던 추천도 제거했다.

다음은 OED-LAB-02에서 CBC의 하위 항목, 대표 프로필, 단위·정상범위·판별, 단일 항목 재검 후보를 완성하는 일이다. 이번 보정은 조사 파일과 보고서에만 반영했다. 앱·DB·마스터에는 적용하지 않았다.

보정 검증은 로컬 회귀 테스트 7개 통과, 생성 원문과 최종 보고서 표 일치, 입력 파일·산출물 해시 일치까지 확인했다. HTML은 전체 86건, CBC 검색 4건, 범백 검색 1건이며 데스크톱·모바일 너비에서 가로 넘침과 브라우저 오류가 없었다. 실제 앱 화면 검증은 이번 범위에 포함하지 않았다. 전체 문서 검사는 기존 persona 안내서 링크 오류 1건으로 실패했고 해당 파일은 수정하지 않았다.

조사 범위와 경계

  • 기준 목록은 WP-00의 clinical_lab 86건이다.
  • 레포의 V4 authoring fixture에 있는 72개 검사 정의, 18개 패널, 120개 연결, 85개 오더 프로필을 함께 대조했다.
  • 외부 근거는 표준기관, 수의임상병리 전문단체, 수의과대학 검사실, 제조사 공식 메뉴·설명서만 사용했다.
  • 숫자 정상범위를 마스터 후보로 옮기지 않았다. 이 조사에서 확인한 것은 구조, 값의 형태, 자료 확보 가능성과 대표 수행 경로다.
  • 실제 병원의 장비 보유나 시스템 연동을 가정하지 않았다. 장비 결과 입력은 현재 모두 not_integrated + manual_entry다.
  • 찾지 못한 값은 런타임 fallback으로 채우지 않는다. 필요한 경우 후속 단계에서 CLAiR 데모 프로필의 synthetic_functional_fixture로 명시한다.

외부 조사에서 확인한 공통 구조

1. 주문 세트와 결과를 분리해야 한다

LOINC에서 패널은 여러 하위 결과를 묶은 주문 단위다. FHIR 역시 검사 요청은 ServiceRequest, 최종 값은 Observation, 결과를 모은 보고서는 DiagnosticReport로 구분한다. 이 기준을 따르면 CBC 부모 오더 하나에 결과값을 넣는 것이 아니라, CBC를 주문했을 때 WBC·RBC·HGB 같은 독립 결과가 만들어져야 한다.

특히 하위 항목을 따로 재검할 수 있어야 하므로 단순 component만으로는 부족하다. 각 항목에 별도 order/result identity를 주고, 재검할 때는 기존 결과를 덮어쓰지 않은 채 새 주문을 만들어 최초 세트와 직전 결과를 연결해야 한다.

2. 정상범위는 검사명 하나에 붙는 값이 아니다

ASVCP와 대학 검사실 자료에서 정상범위는 고정된 숫자 한 쌍이 아니다. 동물종과 연령, 필요한 경우 품종·성별뿐 아니라 검체, 전처리, 검사법, 분석 장비와 시약에 따라서도 달라진다. 따라서 WBC 정상범위 하나를 모든 병원에 공통으로 적용할 수는 없다.

마스터에는 버전이 있는 결과 프로필 후보를 둔다. 각 워크스페이스는 그중 실제 사용하는 장비·수기·외부검사실 프로필을 명시적으로 선택한다. 결과를 저장할 때는 당시 단위, 정상범위, 판별 규칙과 프로필 버전까지 함께 스냅샷으로 남긴다.

3. 검사마다 결과 모양이 다르다

  • CBC·화학·응고: 주로 수치, 단위, 미달·정상·초과, 장비 플래그
  • 신속 항원·항체와 PCR: 양성·음성·검출·미검출·무효·판정 불가
  • 요시험지: 항목별 반정량 코드와 일부 수치
  • 요침사·분변 현미경: 반복 관찰값, 개수나 등급, 이미지, 소견
  • 혈액도말·세포검사: 형태, 등급, 서술, 이미지와 종합 해석
  • 코르티솔 동적검사: 프로토콜과 채혈 시간점별 여러 수치

하나의 numeric/text/coded 칸만으로는 이 결과들을 안전하게 표현할 수 없다.

대표 구조 예시

CBC

외부 자료의 CBC 구성은 적혈구계, 백혈구계, 혈소판계와 형태 검토로 이어진다. 최소한 WBC, 백혈구 감별 절대수·비율, RBC, HGB, HCT, MCV, MCH, MCHC, RDW, PLT, MPV는 각각 결과를 기록할 수 있어야 한다. 망상적혈구와 혈액도말은 조건에 따라 붙이거나 별도 검사로 연결할 수 있다.

로컬 CBC 표본에는 WBC·HCT·PLT 세 항목만 연결돼 있다. RBC와 HGB 정의는 이미 fixture에 있지만 독립 order profile과 CBC 패널 연결이 없다. OED-LAB-02에서는 이 차이를 먼저 기능 표본으로 구체화한다.

요검사

요검사는 물리적 관찰, 비중, 시험지, 침사, 필요한 경우 UPC까지 묶는 검사다. 지금처럼 시험지와 침사를 각각 한 줄로만 두면 pH·단백·당·케톤·빌리루빈·혈액, RBC·WBC·세균·상피·원주·결정, 이미지와 소견을 따로 기록할 수 없다. 시험지·비중·침사·UPC를 하위 세트로 나누고, 최종 관찰값은 독립 결과로 두는 구조가 필요하다.

감염성 검사

같은 질환 이름을 쓰더라도 항원, 항체와 PCR은 서로 다른 검사다. 현재 감염성 질환 선별 패널은 개·고양이 검사와 분변 검사, 신속키트, PCR까지 한 번에 섞어 둔다. 실제 제품에서는 동물종·검사법·패널 버전을 구분하고, 항목마다 양성·음성·무효·판정 불가 상태를 따로 저장해야 한다.

세포검사와 혈액도말

세포검사와 혈액도말에는 일괄적인 low/high 숫자 범위를 억지로 붙이지 않는다. 대신 검체 부위와 채취법, 적합성, 세포·미생물·염증 소견, 진단과 감별, 이미지와 판독자 의견을 남긴다. 관절액처럼 단백, 점도, 세포수와 감별계수 같은 수치 결과가 더해지는 검사는 복합 패널로 다룬다.

장비와 수행 경로 결론

대표 장비 후보는 실제 보유 장비를 추정하기 위해서가 아니라 기능 구조를 확인하기 위해 골랐다. 혈구분석기, 화학분석기, 응고분석기, 요시험지 분석기, 요침사 분석기, 세포 분석기, 신속키트 판독기와 수기 현미경·원심분리기·굴절계가 서로 다른 결과 흐름을 만든다는 점을 구분했다.

보고서에 적힌 장비가 청담점이나 다른 워크스페이스에 실제로 있다는 뜻은 아니다. 프로토타입에서는 워크스페이스가 사용할 수행 프로필을 직접 선택하고, 화면에는 수동 입력과 연동 안 됨을 사실대로 표시한다. 선택하지 않은 장비 프로필이나 화면 목업값으로 자동 대체하는 fallback은 두지 않는다.
