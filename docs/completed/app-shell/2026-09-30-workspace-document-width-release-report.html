최신 main 통합과 검증

최종 통합 기준: 6f70a24583bde034b84ed4f913e614d9cf988463 (접수 캘린더 drawer #880 및 프로필 UI 통합 #882 포함). 기존 프로필 패널 복구, 출력 메뉴·링크 복사, 실제 수행기록, 최신 오더 및 수납 정책을 보존했어. 이전 pilot와 primary의 미완료 작업도 유지했어.

  • 범위에 맞춘 119개 검증 통과: 폭·입력·포커스·스크롤, 검사 결과 저장, 실제 수행기록, 수납 금액·권한과 패널 회귀.
  • 최신 프로필 통합 #882까지 rebase한 뒤 레이아웃·공통 패널·접수 overlay·프로필 상태/모션·차트 배치 61개 검증 통과.
  • 타입·lint·UX 문구·최신 main 기반 production build 통과. 기존 WP10 lint 경고 5개와 docs reader build 경고는 남아 있어.
  • 차트 전체 검사는 green이 아니야. 후보의 초기 결과는 67 통과 / 34 실패, 동일 main은 69 통과 / 32 실패였어. 31개 실패가 같고, main의 기존 이미지 기준도 실패했어. 후보의 폭·툴바 관련 추가 검증 3개는 수정 후 통과했어.
  • 조제의 기존 바이탈 fixture 실패도 main에서 재현했어. 바이탈 동작을 바꾸지 않았고, 이 한 건을 제외한 범위 검증을 진행했어.

검증 수치와 기존 실패 목록

좁은 공간에서는 최근에 연 보조 패널을 모달로 표시해. Tab/Escape·포커스 복귀·reduced motion·입력 유지·외부 프로필 공존은 별도 자동 검증을 사용해. 960 CSS px는 zoom-equivalent 검증이며 실제 브라우저 확대나 임상 사용자 수용 검증을 뜻하지 않아.
