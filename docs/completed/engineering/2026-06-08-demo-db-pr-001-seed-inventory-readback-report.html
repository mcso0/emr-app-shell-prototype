Demo DB PR 1 Seed Inventory Readback Report

요청

clair-demo synthetic seed가 어떤 EMR 데모 workflow를 증명하는지 정리하고, local/dev Supabase에서 읽어 확인할 수 있는 readback contract를 추가하는 작업이었다. UI 변경, remote Supabase, production DB, 실제 병원/환자 데이터는 범위에서 제외했다.

변경

  • docs/engineering/data-model/demo-seed-inventory-readback-contract.md를 추가해 seed coverage와 gap을 문서화했다.
  • supabase/snippets/demo_seed_inventory_readback.sql을 추가해 read-only JSON readback을 제공했다.
  • tests/demo-seed-inventory-readback-contract.spec.ts를 추가해 문서, SQL, 현재 seed gap 주장이 어긋나지 않게 했다.
  • Engineering README, data-model README, work index에 새 계약 문서와 work item을 연결했다.

현재 판단

이 프로젝트는 단순 프론트엔드 mock만 있는 상태는 아니다. Supabase 기반 auth, workspace, membership, reception, chart, order, billing, audit foundation과 synthetic seed가 일부 구축되어 있다. 다만 hospital-admin order catalog, order set, lab result-sheet catalog, precomputed fulfillment work item seed는 아직 gap으로 남아 있어 완전한 seeded demo DB 상태는 아니다.

리스크와 제외 범위

  • 이번 PR은 supabase/seed.sql을 확장하지 않았다. gap은 의도적으로 기록만 했다.
  • readback SQL은 local/dev/test DB 전용이다. remote/staging/production replay에는 별도 승인이 필요하다.
  • 실제 병원, 보호자, 환자, 결제, 의료 데이터는 사용하지 않았다.
