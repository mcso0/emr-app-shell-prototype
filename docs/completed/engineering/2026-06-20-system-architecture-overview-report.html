시스템 아키텍처 문서 보강 결과

기존 문서를 조사한 결과, CLAiR EMR의 아키텍처 정보는 앱 셸, mock/live 경계, API 경계, 데이터 모델, 인증/보안 문서에 나뉘어 있었지만 처음 읽는 사람을 위한 단일 시스템 아키텍처 개요 문서는 없었습니다.

변경 내용

  • docs/engineering/architecture/system-architecture-overview.md를 추가했습니다.
  • 엔지니어링 README, docs 포털, agent RAG map에서 새 overview로 진입할 수 있게 했습니다.
  • 내부 /docs 뷰어의 개발 영역 registry에도 새 문서를 등록했습니다.
  • 작업 추적용 ENGINEERING-ARCH-PR-001 work item을 추가했습니다.

중요한 경계

  • 이번 작업은 문서와 docs-reader registry에만 한정했습니다. 제품 앱 동작, DB, RLS, 배포, 외부 연동은 변경하지 않았습니다.
  • 새 overview는 세부 계약을 대체하지 않고 현재 source-of-truth 문서로 연결하는 허브입니다.
  • remote Supabase, production/live, 실데이터, 결제, 이메일, provider 연동 완료 주장은 하지 않았습니다.

검증

  • npm run docs:check 통과
  • npm run security:secrets 통과
  • npx tsc --noEmit 통과
  • npm run lint 통과: 기존 경고 5개는 이번 범위 밖입니다.
  • npx playwright test tests/prd-viewer.spec.ts --reporter=line --timeout=90000 통과
  • npm run build 통과: 기존 docs reader 동적 파일 읽기 경로 관련 Turbopack NFT trace warning이 있습니다.
  • 로컬 /docs?area=development&doc=system-architecture-overview 응답 200 및 새 문서 렌더링을 확인했습니다.
