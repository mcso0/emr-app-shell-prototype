알림 v1 Event Producer Foundation 작업 결과

2026-07-05 · NOTIFICATION-PR-018 · synthetic/demo-data scope

요청

알림 drawer가 live API를 읽는 단계 다음으로, source workflow 서버 코드가 안전하게 알림을 생성할 수 있는 내부 producer foundation을 추가하는 작업이었다.

결과

  • local/dev synthetic notification event store를 추가했다.
  • 내부 서버 helper인 emitLiveNotificationEvent를 추가했다.
  • 같은 dedupeKey 이벤트는 새 row를 늘리지 않고 기존 알림을 bump/update한다.
  • 새 bumped event가 들어오면 이전 read/archive 상태를 지워 새 신호가 다시 unread로 보이게 했다.
  • 생성된 알림도 기존 live reader의 workspace, recipient, source-route safety, safe DTO 경계를 그대로 통과한다.
