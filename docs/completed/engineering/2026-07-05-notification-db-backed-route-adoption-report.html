알림 DB-backed Route Adoption 결과

2026-07-05 · NOTIFICATION-PR-024 · Supabase-session route scope

요청

알림 v1 DB persistence foundation을 실제 notification route 경계에 연결해, Supabase-session actor가 알림 목록과 읽음/보관 상태를 DB gateway를 통해 다루도록 했다.

결과

  • Supabase-session notification route actor에 notification persistence gateway를 붙였다.
  • 목록/count route는 persisted event와 persisted user state를 읽는다.
  • read/archive/restore/read-all route는 user state를 DB RPC로 저장한다.
  • demo-header mock mode는 기존 scoped in-memory store를 계속 사용한다.
  • 기존 DTO mapping, role recipient filter, source permission filter, badge count, safe source route 규칙은 그대로 재사용한다.
  • state list RPC를 보강해 persisted read/archive 상태가 다음 list response에 반영될 수 있게 했다.
