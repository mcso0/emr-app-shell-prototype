ENGINEERING-DB-PR-001 · 2026-07-12

Supabase migration 장부 정리

같은 DB 작업이 서로 다른 번호로 기록된 문제를 정리했다. 실제 업무 데이터나 DB 기능은 바꾸지 않고 적용 기록과 저장소 파일만 맞췄다.

0원격에만 남은 기록
12동일 SQL 번호 연결
17실제 미배포 작업

무엇을 바꿨나

  • SQL 내용이 완전히 같은 12개 작업을 두 번호가 같은 작업임을 알 수 있도록 연결했다.
  • 원격에만 있던 실제 SQL 4개를 저장소에 보존했다.
  • 로컬 전체 DB를 처음부터 다시 만들어 새 기록 구조가 재현되는지 확인했다.

무엇을 바꾸지 않았나

  • 환자·보호자·직원·결제 등 업무 데이터는 수정하지 않았다.
  • 저장소에만 있는 17개 기능을 원격에 적용하지 않았다.
  • 미배포 작업을 적용된 것처럼 허위 기록하지 않았다.

앞으로의 규칙

  • 원격 DB 변경은 저장소 migration 파일을 먼저 확정한 뒤 한 명이 적용한다.
  • 적용한 migration 파일의 타임스탬프는 변경하지 않는다.
  • 기록을 고칠 때는 파일명이 아니라 실제 SQL 내용과 DB 상태를 확인한다.
