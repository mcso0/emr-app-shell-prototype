요청

좌측 네비바에서 알림을 제거하고, 상단 bell 버튼을 전역 알림 진입점으로 유지한 뒤, 알림 기능의 상세 기획, UX flow, 구현/API 스펙, 예외 케이스, 구현 계획을 문서화하고 첫 구현 슬라이스를 TDD로 검증하는 작업이었다.
