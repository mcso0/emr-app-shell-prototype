알림 v1 Visible Drawer Live API 채택 결과

2026-07-05 · NOTIFICATION-PR-017 · synthetic/demo-data scope

요청

상단 bell 버튼과 오른쪽 알림 drawer를 실제 live notification API에 연결하고, 읽음/보관 상태를 브라우저 localStorage가 아니라 서버 API 상태로 검증하는 작업이었다.

결과

  • AppShell 알림 drawer가 active/archived 알림 목록을 서버 API에서 읽도록 연결했다.
  • top-bar badge와 drawer count summary가 서버 counts를 사용한다.
  • 읽음, 전체 읽음, 보관, 복구가 모두 서버 mutation route를 호출한다.
  • source navigation은 서버가 안전화한 source route만 사용하고, route가 null이면 fallback detail을 보여준다.
  • v0 브라우저 localStorage 문구를 v1 API-backed 상태 문구로 교체했다.
  • demo E2E 격리를 위해 read/archive 상태를 demo browser session별로 분리했다.

남은 범위

이번 작업은 visible drawer의 live API 채택까지다. DB migration, RLS replay, realtime delivery, notification event producer, Kakao/SMS/email/browser push, production deployment, real data 사용은 별도 승인된 작업 범위가 필요하다.
