수납 준비 알림 Producer 연결 결과

2026-07-05 · NOTIFICATION-PR-020 · synthetic/demo-data scope

요청

알림 v1 live producer를 실제 업무 신호에 더 연결하기 위해, 완료된 오더가 수납 후보로 반영되는 순간을 직원용 알림으로 연결했다.

결과

  • fulfillment 완료 후 billing candidate sync가 성공하면 billing_waiting_ready 알림을 생성한다.
  • lab/imaging 오더는 vet review gate를 통과해 수납 후보가 생긴 뒤 같은 알림을 생성한다.
  • 생성 알림은 billing role queue 대상으로 drawer-only, non-badge, reference-priority 상태다.
  • source action은 같은 workspace의 수납 후보 context로만 이동한다.
  • 알림 payload에는 환자/오더 식별용 label과 candidate id만 사용하고 금액, 결제 상세, 보호자 연락처는 담지 않았다.
  • source-domain view permission이 없는 사용자는 role queue가 맞아도 알림 row/source route를 받지 못한다.
  • synthetic/dev producer 이벤트는 demo client session으로 scope할 수 있게 해 테스트 간 drawer count 오염을 막고, scoped bump는 같은 client session의 state만 갱신한다.
  • vet review로 수납 후보가 생성되는 경로도 audit event를 남긴 뒤 알림을 생성한다.

남은 범위

이번 작업은 fulfillment/vet-review가 만든 수납 후보 알림까지만 다룬다. standalone billing candidate PATCH 알림, clinical result completion, explicit recheck request, DB persistence, RLS replay, realtime delivery, 외부 메시지/결제 제공자 연동, production launch, real data 사용은 후속 작업 범위다.
