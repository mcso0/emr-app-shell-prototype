오더 재확인 요청 알림 Producer 연결 결과

2026-07-05 · NOTIFICATION-PR-022 · synthetic/demo-data scope

요청

알림 v1 live producer를 명시적인 오더 재확인 요청 업무에 연결하기 위해, 임상 권한이 있는 사용자가 대상 역할 또는 사용자에게 재확인 사유를 전달하는 서버 경계를 추가했다.

결과

  • order-recheck-requests route가 order_recheck_requested 알림만 생성한다.
  • generic create-notification API는 만들지 않았다.
  • 요청 payload는 source domain/kind/entity/route, recipient, order label, requester label, reason을 필수로 검증한다.
  • 요청자는 chart:update 또는 대상 도메인 completion 권한이 있어야 한다.
  • 검사 담당자 같은 대상 role queue에는 알림이 보이고, front-desk에는 보이지 않는다.
  • front-desk actor는 재확인 요청 알림 자체를 만들 수 없다.
  • 생성 알림은 high-priority, badge-eligible, actionable, role-active toast eligible 상태다.

남은 범위

이번 작업은 재확인 요청 알림 생성까지만 다룬다. 재확인 요청 자체의 durable storage, order lifecycle의 re_requested 전환, assigned-user lookup, inpatient routing, DB-backed notification persistence, RLS replay, realtime delivery, 외부 메시지 발송, production launch, real data 사용은 후속 작업 범위다.
