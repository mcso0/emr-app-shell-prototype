알림 DB 이벤트 Persistence Foundation 결과

2026-07-05 · NOTIFICATION-PR-023 · local/dev/test scope

요청

알림 v1 live producer가 서버 메모리 store에만 의존하지 않도록, 후속 route adoption에서 사용할 DB 이벤트 저장 계약과 사용자별 읽음/보관 상태 저장 기반을 추가했다.

결과

  • notification_events 테이블을 추가해 workspace-scoped live notification event를 저장할 수 있게 했다.
  • notification_user_states 테이블을 추가해 사용자별 read/archive 상태를 저장할 수 있게 했다.
  • 두 테이블 모두 RLS를 켜고 active workspace member boundary를 사용한다.
  • clair_emit_notification_event, clair_list_notification_events, clair_list_notification_user_states, clair_upsert_notification_user_state RPC 계약을 추가했다.
  • TypeScript Supabase gateway가 고정 RPC 이름으로 emit/list/state list/state upsert를 호출하고 stable error category로 매핑한다.
  • 이번 slice는 visible notification route를 DB로 전환하지 않는다. 현재 drawer는 기존 live memory store를 계속 사용한다.
