Demo DB PR 5 Billing Checkout Session Family Seed Report

요청

UI를 바꾸지 않고 clair-demo local/dev seed에 billing checkout session family를 추가해, 결제 체크아웃과 payment allocation까지 readback으로 증명할 수 있게 만드는 작업이었다. remote Supabase, production DB, 실제 병원/환자/결제 데이터는 범위에서 제외했다.

변경

  • billing_checkout_sessions paid row 2개를 추가했다.
  • billing_checkout_session_invoices invoice snapshot row 2개를 추가했다.
  • payment_allocations allocation row 2개를 기존 approved payment에 연결했다.
  • Nabi card checkout과 Mango cash checkout을 deterministic ID로 시드했다.
  • readback SQL과 focused test를 checkout seed가 baseline으로 필요하도록 갱신했다.
  • seed inventory 문서에서 current seed-family gap이 닫혔고, 남은 일이 UI/API adoption임을 기록했다.

현재 상태

이제 demo DB reset 이후 billing_checkout_sessions, billing_checkout_session_invoices, payment_allocations는 비어 있지 않아야 하며, readback은 결제수단, 총액, invoice snapshot, allocation 금액 일치를 확인한다.

리스크와 제외 범위

  • 이번 변경은 seed/readback/test/doc 범위이며 UI 연결은 하지 않았다.
  • Payment provider, receipt, refund, settlement, accounting은 포함하지 않았다.
  • 실제 병원, 보호자, 환자, 결제, 의료 데이터는 사용하지 않았다.

다음 추천

다음 작업은 mock/local-store 화면을 seeded DB API/server boundary로 재연결하고, login부터 reception, chart, fulfillment, lab, billing checkout, audit까지 이어지는 end-to-end synthetic demo test를 만드는 것이다.
