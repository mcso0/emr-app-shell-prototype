차트 Figma 충실도 후속 수정 결과

2026-08-13 · CHART-PR-019 · Figma 27946:58868

요청과 결과

차트 화면에서 Figma 시안과 달라진 헤더·섹션·도구 모음의 시각 규칙을 바로잡고, 작동하지 않던 진료 이력 버튼의 기존 동작을 복원했다.

주요 변경

  • 차트 제목 옆 진료 이력 버튼을 24 × 24px로 복원하고, URL 상태와 연결된 이력 패널 열기·닫기를 다시 활성화했다.
  • 차트 헤더 아래 선을 제거하고 헤더 및 작업 캔버스 배경을 #FCFCFC로 맞췄다.
  • Subject/Object, Assessment, History, Plan/Order 섹션은 공통 흰색 토큰을 사용하도록 정리했다.
  • 각 섹션의 크게 보기·추가·더보기 액션은 마우스 호버 또는 키보드 포커스 때 표시하고, 터치 환경에서는 항상 접근 가능하게 유지했다.
  • Plan/Order 오른쪽 도구 모음은 기존 sm 컴포넌트 변형을 사용해 모두 28px 높이로 통일했다.

변경 범위

  • src/features/chart/components/chart-figma-workspace.tsx: 화면 표면과 섹션 액션 표시 규칙
  • src/features/chart/module.tsx: 진료 이력 연결, 섹션 색상, 도구 모음 크기
  • tests/chart.spec.ts, tests/app-shell.spec.ts: 상호작용·스타일·통합 회귀 검증
  • docs/work/chart/CHART-PR-019-figma-exact-chart-screen.md: 요구사항, 조사, 구현, 검증 기록

검증 결과

  • 핵심 Figma 계약 및 앱 셸 Chromium 테스트 4건 통과
  • 로컬 브라우저에서 진료 이력 열기·닫기, 패널 액션 호버, 배경·크기 계산값을 직접 확인했다.
  • ESLint, TypeScript, 문서 링크 검사, diff 검사, production build 통과
  • 기존 1540 × 1024 시각 회귀 기준은 변경 없이 통과

전체 차트 테스트를 하나의 장기 실행 개발 서버에서 돌린 진단에서는 Base UI/Tiptap 팝업 분리와 서버 연결 불안정으로 4건이 비결정적으로 실패했다. 기존 SOAP 메뉴 자동화 1건은 새 서버의 격리 재실행에서도 클릭 대상 DOM이 교체되는 위치를 바꾸며 재현됐다. 실제 로컬 브라우저와 이번 변경의 집중 회귀는 정상이며, 해당 자동화 안정성은 별도 위험으로 남긴다.

범위와 다음 단계

데이터, 권한, 저장, 주문 및 원격 환경 계약은 변경하지 않았다. 다음 단계는 정확한 후보 커밋에 대한 secret scan, GitHub Release Check, Vercel Preview 확인 후 운영 main 머지 여부를 최종 판단하는 것이다.
