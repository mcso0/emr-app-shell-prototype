두 다이얼로그가 비슷한 CSS를 따로 갖는 상태를 끝내고, 열·제목/개수·검색 헤더·목록 행·선택 목록·그랩 재정렬 행을 같은 React 컴포넌트로 연결했다. 오더 최초 조회 중에는 빈 후보 영역이나 임시 0개 대신 “오더를 불러오는 중입니다”, 목록 스켈레톤, 카테고리·헤더 카운트 스켈레톤을 표시한다.

  • 오더 후보만 상세 정보와 가격을 담는 56px 변형을 사용
  • 선택한 오더의 개별 해제, 전체 삭제, 포인터·키보드 순서 변경 유지
  • 환자 종 필터, 카테고리 범위 검색, 가상화, 이미 추가된 항목 차단, 일괄 추가 순서 계약 유지
