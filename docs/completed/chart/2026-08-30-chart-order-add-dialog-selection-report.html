2026-08-30 · 진료/차트 > Order > + Order

기존 즉시 추가형 검색 모달을 Assessment 분류검색을 참고한 3단 선택기로 교체했다. 선택한 오더는 오른쪽 목록에서 해제·전체 삭제·그랩 재정렬할 수 있으며, 정렬된 배열 순서가 새 draft row의 sortOrder로 이어진다. Order 세트가 섞인 선택도 기존 구성 다이얼로그를 순차 적용해 선택 순서를 보존한다.

  • 선택 순서를 보존하는 복수 오더 일괄 추가
  • 로딩·빈 결과·오류·권한 없음·이미 추가됨 상태와 반응형 적층
