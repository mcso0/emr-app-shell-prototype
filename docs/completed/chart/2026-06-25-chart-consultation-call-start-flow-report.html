진료/차트 호출-진료시작 흐름 구현 리포트

작성일: 2026-06-25 KST · 대상: CHART-PR-008

요청

접수 후 진료/차트 화면에서 대기 환자가 곧바로 차트 작성완료로 넘어가지 않도록 접수 대기 → 호출하기 → 진료 시작 → 차트 작성완료 순서로 흐름을 고쳤다.

변경

  • chart/consultation-flow API와 server core를 추가해 call, start를 분리했다.
  • DB migration에 consultation call/start RPC와 encounter_call_events local outbox를 추가했다.
  • 차트 completion은 waiting/called 상태에서 ready_for_billing로 갈 수 없게 막았다.
  • 상단 CTA와 확인 모달, 상태 문구를 queue 상태 기준으로 갱신했다.

범위 밖

실제 DID 장비/provider 호출, 재호출, 호출 취소, 진료실 배정, real data 사용은 이번 범위에 포함하지 않았다.
