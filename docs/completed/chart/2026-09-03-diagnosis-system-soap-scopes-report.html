기본 SOAP와 진단계통 SOAP의 입력 공간을 분리했다

2026-09-03 · 진료/차트 · CHART-PR-033

이제 기본 S/O와 근골격계 같은 진단계통 탭은 서로 다른 내용을 보관한다. 기본 탭의 자유 입력이 계통 탭에 그대로 나타나지 않고, 각 계통 탭은 처음 열 때 빈 S/O/A/P 입력 공간을 제공한다.

무엇을 바꿨나

  • 한 진료의 SOAP 한 건은 유지하되, 문서 안을 기본·진단계통별 범위로 나눴다.
  • 탭을 바꾸면 해당 범위만 편집하고 저장할 때는 전체 범위를 하나의 문서로 합친다.
  • 과거 자유 입력은 기본 탭에만 남기고 계통 탭으로 추측 복사하지 않는다.
  • 기존 이력 화면이 읽는 S/O/A/P 텍스트는 계속 기본 탭에서만 만든다.
  • 중첩 계통 템플릿을 만들 수 있던 슬래시 명령은 라이브 차트에서 제거했다.

안전장치

식별표시 이름이 아니라 진단 마스터의 안정적인 계통 ID로 저장 범위를 구분한다.
기존 기록V1 기록은 읽을 때만 V2로 올리며, 파괴적인 일괄 변환은 하지 않는다.
동시 저장기존 단일 자동저장 순서와 updatedAt 충돌 방지를 유지한다.
권한·감사워크스페이스·진료 상태·chart:update·사용자 일치·트랜잭션 감사 경계를 유지한다.
구버전 보호V2 기록을 구버전 writer가 V1으로 낮추는 저장은 DB에서 거부한다.

검증 결과

문서·저장·진단 계약 테스트와 브라우저의 탭 분리·자동저장·새로고침 회귀 테스트를 통과했다. PostgreSQL에서는 V3 저장, 기본 탭 전용 투영, 구버전 downgrade 차단, 재수정, 권한을 합성 데이터로 실행하고 전체 트랜잭션을 롤백했다. 원격 additive 마이그레이션 20260903110347 적용 뒤 기존 SOAP 행의 문서·투영 해시와 수정 시각이 그대로인 것도 확인했다.

PR #702는 Release Check를 통과해 origin/main에 병합됐고, 프로덕션 배포 dpl_F3BESnEy2Vd6SLqYdHqtmfLP6E7W는 공식 주소에서 Ready다. 인증된 실제 화면에서도 기본 내용은 기본 탭에만 남고 근골격계 탭은 별도의 빈 S/O/A/P를 표시했으며, 브라우저 오류와 SOAP 행 변경은 없었다.

범위 밖

SOAP 서명·개정 이력, 실시간 공동 편집, AI 생성, 이미지·동영상·장비 연동은 이번 변경에 포함하지 않았다. 앱 롤백 시 additive DB 계약은 남겨 V2 기록을 보호한다.
