관리자 바이탈 입력 권한 변경

CHART-PR-016 · 2026-07-20 · 구현 및 로컬 검증 완료

결과

진료 대기 화면의 오늘 바이탈 입력·수정 기능을 병원 관리자도 사용할 수 있도록 권한 조건을 확장했다. 수의사와 테크니션은 기존처럼 사용할 수 있고, 접수 담당자는 계속 제외된다.

변경된 권한

구성원바이탈 입력추가 조건
병원 관리자허용활성 hospital_admin 구성원 + 유효한 vital:write
수의사·테크니션허용활성 임상 직무 또는 기존 호환 역할 + 유효한 vital:write
접수 담당자차단vital:write가 있어도 관리자·임상 자격이 없으면 차단

안전 경계

  • 버튼 표시와 서버 저장이 동일한 관리자·임상 자격 검사를 사용한다.
  • 활성 워크스페이스 구성원, 로그인 사용자 일치, 대기 중 접수·진료 큐 조건을 계속 검증한다.
  • 오늘 행만 수정하며 과거 바이탈은 수정하지 않는다. 값 비우기는 행 삭제가 아니라 감사 정보가 남는 값 비움이다.

검증

  • 관리자 허용 테스트는 구현 전 403으로 실패한 뒤 구현 후 통과했다.
  • 보안 검사, 전체 lint, 타입 검사, 프로덕션 빌드가 통과했다.
  • 바이탈·진료 전 문맥 서버 테스트 15건과 입력·수정·값 비우기 UI 테스트 1건이 통과했다.

남은 운영 단계

이번 작업에서는 원격 Supabase 마이그레이션 적용, 커밋·PR·머지, 프로덕션 배포를 수행하지 않았다. 운영 화면에 반영하려면 두 바이탈 마이그레이션을 순서대로 적용하고 배포한 뒤 관리자 계정으로 버튼 표시와 실제 저장을 검증해야 한다.
