SOAP를 실제 BlockNote 방식으로 시험할 수 있게 했다

2026-08-31 · 진료/차트 · CHART-PR-029

임의로 노션 UI를 흉내 낸 화면이 아니라, 무료·오픈소스 범위의 BlockNote ShadCN 에디터 자체를 사용한 인터랙티브 시안을 만들었다. 구현 전 대표 검토를 위해 저장되지 않는 Storybook 환경으로 분리했다.
인터랙티브 시안 열기

기획·UX 스펙

  • 네 개의 카드가 아니라 한 개의 연속된 블록 문서로 S/O/A/P를 작성한다.
  • 블록 hover 시 BlockNote 기본 왼쪽 +와 드래그 핸들을 사용한다.
  • /와 왼쪽 +는 같은 블록·SOAP 템플릿 메뉴를 연다.
  • 텍스트 선택 시 BlockNote 기본 플로팅 포맷 툴바를 사용한다.
  • 기본 SOAP와 근골격계 SOAP 템플릿을 한 번에 삽입한다.
  • 이미지·동영상은 브라우저 세션 안에서 추가하고 인라인 미리보기·재생을 시험한다. 광학검사는 장치 계약 전까지 “장치 필요”로 유지한다.

이번에 변경한 것

  • @blocknote/core, react, shadcn 0.54.0을 정확 버전으로 추가
  • SOAP 섹션 커스텀 블록과 두 종류의 한국어 템플릿 추가
  • BlockNote의 메뉴·드래그·선택 툴바는 유지하고 CLAiR 토큰과 Pretendard만 적용
  • BlockNote 기본 이미지·동영상 블록, 업로드 패널, 이미지 미리보기 전환, 영상 재생 컨트롤을 세션 전용 object URL로 연결
  • 향후 저장 정본 검토를 위한 BlockNote JSON 인스펙터 추가

검증 결과

PASS · 인터랙션 35개 Storybook 상호작용: SOAP 삽입, 슬래시·플러스 메뉴, 왼쪽 추가·드래그 컨트롤, 선택 툴바, 접는 제목, 기본 블록 입력, 이미지·영상 업로드/미리보기/재생, 잘못된 파일 복구, 320px 반응형
PASS · 빌드 전체 ESLint, TypeScript, Storybook 빌드, Next.js 프로덕션 빌드
PASS · 저장소 문서 링크, 비밀정보, diff whitespace 점검. 운영 의존성 audit 수치는 기존 체크아웃과 동일하다.

현재 경계와 다음 결정

이번 시안의 로컬 미디어 URL은 새로고침 시 유지되지 않으며 네트워크·DB에 저장하지 않고 라이브 진료 화면도 교체하지 않았다. 승인 후 다음 작업에서 BlockNote JSON 정본, 기존 S/O/A/P 필드 호환 투영, 과거 기록 hydration, autosave·충돌·감사 계약을 먼저 정한 뒤 라이브 에디터를 전환한다. 그 전까지 기존 직접 Tiptap 의존성은 제거하지 않는다.
