진료 호출 모달/차트 잠금 UX 보완 결과

2026-06-25 · CHART-PR-009 · synthetic Cheongdam demo scope

요청

호출하기 모달을 진료실 선택 기반 UX로 바꾸고, 진료 시작 전에는 차트 입력과 오더 작업을 할 수 없도록 보완했다.

변경 내용

  • 호출 모달에 환자/보호자, 접수 시각, 담당 수의사, 진료실 dropdown을 2열 form 구조로 배치했다.
  • 진료실 미선택 시 호출하기 버튼을 비활성화하고, call API payload에 roomId를 요구한다.
  • 호출 event에 roomId, roomName snapshot을 저장한다.
  • waiting/called 단계에서는 SOAP, 진단명, 오더, 차트 작성완료 mutation UI를 잠그고 안내 상태를 보여준다.
  • SOAP, diagnosis, order draft, order action 서버 코어에서 진료 시작 전 mutation을 409 stale_status로 차단한다.

남은 리스크 / 후속

  • 실제 DID provider 전송은 여전히 범위 밖이다.
  • hospital_spaces schema와 병원 관리의 공간/진료실 CRUD는 후속 PR로 분리했다.
  • 원격 Supabase 적용 전에는 새 migration 적용 순서와 기존 room 없는 RPC 권한 회수 동작을 확인해야 한다.
