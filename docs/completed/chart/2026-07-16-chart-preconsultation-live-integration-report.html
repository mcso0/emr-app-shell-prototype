진료 시작 전 환자 맥락 화면 구현 결과

2026-07-16 · CHART-PR-012 · synthetic/demo workspace scope

요청

접수 완료 후 호출 전 수의사가 환자와 보호자, 방문 목적, 접수 맥락, 바이탈, 과거 이력을 한 화면에서 빠르게 파악하도록 승인된 시안을 실제 EMR 흐름에 연결했다.

변경 내용

  • 호출 전 전용 헤더와 1440px 최대 폭의 정보 위계를 적용하고, 기존 상단 환자 컨텍스트 바는 호출 후 차트에서만 보이도록 했다.
  • 환자 사진 필드가 없는 현재 스키마에 맞춰 CLAiR 동물 아이콘을 fallback 아바타로 사용했다.
  • 환자 정보, 방문 목적, 접수 메모, 바이탈 비교, 과거 진료 이력을 기존 테이블에서 읽는 단일 RPC/API 경계를 추가했다.
  • 환자 정보 버튼은 shadcn Sheet를 열고, 호출하기는 기존 진료실 선택 및 차트 전환 흐름을 그대로 사용한다.
  • 로딩, 권한/읽기 실패 재시도, 바이탈·이력 없음 상태를 더미 데이터 없이 명시적으로 처리했다.

데이터와 보안

  • 새 테이블 없이 기존 encounters, waiting_queue_entries, 환자/보호자, 예약, 바이탈, SOAP, 진단 테이블을 연결했다.
  • 읽기는 활성 멤버십과 chart:view, 호출/대기 복귀는 chart:update와 세션 사용자 일치를 요구한다.
  • 원격 staging migration 적용과 인증 RPC probe에서 encounter/queue, 바이탈 1건, 과거 이력 2건을 확인했다. 검증 데이터는 생성하지 않았다.
