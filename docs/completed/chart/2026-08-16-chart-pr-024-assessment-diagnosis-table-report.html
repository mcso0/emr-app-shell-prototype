무엇이 달라졌나

Figma 기반 표 구조

진단계통, 진단명, 주진단, 확진, 종결, 수의사 순서와 소스 화면의 간격·타이포·행 높이를 반영했다.

공용 체크박스와 토큰

기존 EmrTableCheckbox에 호환 가능한 tone을 추가했다. 주진단만 의미 토큰을 통해 sky/500을 사용하고 기존 표의 neutral 기본값은 유지한다.

상태와 접근성

주진단은 한 건만 선택되고 확진·종결은 독립적이다. 정렬 헤더에는 키보드 동작과 aria-sort를 적용하고 삭제는 hover·focus·터치에서 사용할 수 있다.

종결 감사 정보

새 closed_at, closed_by_user_id 필드가 최초 종결 시점과 작업자를 보존하고 재개 시 비워지도록 기존 진단 저장 RPC를 확장했다.

데이터·보안 경계

  • 읽기는 활성 workspace 멤버와 chart:view 권한을 다시 확인한다.
  • 쓰기는 인증 세션과 actor 일치, 활성 멤버십, chart:update 권한을 다시 확인한다.
  • 클라이언트와 서버 입력 경계에서 주진단이 두 건 이상 저장되는 것을 차단한다.
  • 실제 진단 카탈로그, 임상 추천, 청구 자동화와 기존 SOAP·Order 정책은 변경하지 않는다.

원격 synthetic/demo Supabase에 migration 20260816062243을 적용했다. 현재 Vercel production과 staging이 같은 프로젝트를 사용하므로 별도 production DB 적용 대상은 없다.
