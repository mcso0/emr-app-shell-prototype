대기 차트 오늘 바이탈 입력 구현 결과

2026-07-20 · CHART-PR-015 · synthetic/demo scope

요청과 결과

호출 전 대기 환자의 오늘 바이탈을 차트에서 입력·수정·값 비움 처리하고, 다른 화면의 환자 정보 바가 다음 조회에서 최신값을 보이도록 구현했다.

주요 변경

  • 바이탈 정보 제목 오른쪽에 오늘 바이탈 입력/수정 다이얼로그를 추가했다.
  • 체중, 체온, 수축기/이완기 혈압, 호흡수만 입력하며 혈압은 한 쌍으로 검증한다.
  • 마지막 값까지 비워도 오늘 행을 지우지 않고 cleared_at, cleared_by_user_id로 값 비움 기록을 남긴다.
  • 입력은 대기 상태의 선택 encounter 한 건만 수정한다. 과거 방문과 같은 encounter 안의 시간별 반복 측정은 이번 범위에 포함하지 않았다.
  • 차트·검사/영상·조제·처치의 환자 정보 바는 표시 전용이며 서버 최신 바이탈을 다음 화면 조회 시 읽는다.

데이터와 권한

  • 새 writer는 활성 workspace membership, vital:write, 수의사/테크니션 직무, actor 일치, workspace/encounter 소유, encounter와 consultation queue의 waiting 상태를 서버에서 다시 검증한다.
  • 최신 요약은 선택 encounter로 환자를 식별한 뒤 가장 최근 바이탈 행을 읽는다. 값 비움 행도 최신으로 유지되어 과거 값으로 되돌아가지 않는다.
  • 직접 테이블 쓰기는 사용하지 않고 authenticated RPC만 실행할 수 있다.

검증

  • npm run security:secrets, npm run docs:check, git diff --check
  • npm run lint, npx tsc --noEmit, npm run build
  • 바이탈 writer/latest reader 서버 계약과 차트 입력 → 저장 → 전체 값 비움 Playwright 흐름

범위와 다음 단계

이번 릴리스에는 병원별 바이탈 설정 UI, 심박수·장비 연동, 실시간 push, 원격 Supabase migration 적용이 포함되지 않는다. 원격 DB 적용은 별도 승인과 migration replay 뒤에 진행한다.
