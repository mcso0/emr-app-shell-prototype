오늘 접수/예약 보기 구현 결과

전역 커맨드의 오늘 보기 액션이 항상 오늘 운영일의 접수/예약 화면으로 이동하도록 고쳤다. 이제 다른 날짜를 보던 중에도 커맨드를 누르면 오늘 접수/예약 캘린더와 대기 목록으로 정확히 돌아온다.

요청

  • 오늘 예약 보기 액션을 오늘 접수/예약 보기로 정리한다.
  • 클릭 시 오늘 운영일을 계산해 접수/예약 화면 URL에 date를 포함한다.
  • 직접 진입한 date도 접수/예약 캘린더와 대기 목록 조회에 반영한다.
  • 이번 범위는 오늘 보기만 포함하고, 신규 접수/등록 명령은 포함하지 않는다.

변경 내용

  • 전역 커맨드 액션명을 오늘 접수/예약 보기로 변경했다.
  • 커맨드 실행 시 /w/{workspaceId}/reception?modulePanel=open&date={todayOperatingDate}로 이동한다.
  • 접수/예약 모듈은 URL의 date를 검증하고 유효한 경우 선택 운영일로 반영한다.
  • 잘못된 date는 화면을 깨뜨리지 않고 기본 운영일로 fallback한다.
  • 라우트 날짜 적용 시 캘린더 드래그와 임시 선택 상태를 정리한다.

백엔드 범위

  • 신규 API, DB migration, RPC, RLS 변경은 하지 않았다.
  • 기존 캘린더/대기열 read API가 date를 받는 구조를 그대로 사용했다.
  • 검증에서 캘린더와 대기열 요청이 선택 날짜를 사용하는 것을 확인했다.

남은 범위

  • 운영일 개념을 다른 모듈로 확장하는 작업도 이번 PR 범위가 아니다.
