DEN-390 접수 캘린더 Invalid Selection Feedback 보고서

접수/예약을 만들 수 없는 15분 slot과 drag range가 정상 선택처럼 보이지 않도록 invalid 시각 상태를 추가했다. invalid selection은 기존처럼 drawer와 draft card를 만들지 않으며, drag preview에도 막힌 이유를 표시한다.

변경 내용

  • 각 15분 slot에 validation 결과를 연결하고 invalid slot에 aria-disabled=true 부여
  • invalid slot hover/focus 스타일을 danger 배경과 border로 표시
  • drag selection preview가 invalid일 때 danger 스타일과 reason message를 표시
  • invalid click/drag는 drawer와 temporary schedule card를 만들지 않도록 유지
  • Playwright 테스트에서 invalid slot의 aria-disabled와 invalid preview 문구를 확인

변경 파일

  • src/features/reception/module.tsx
  • tests/reception.spec.ts

검증

  • npm run lint -- src/features/reception/module.tsx tests/reception.spec.ts 통과
  • PLAYWRIGHT_BASE_URL=http://127.0.0.1:3109 npx playwright test tests/reception.spec.ts --grep "15-minute calendar click|clears the draft schedule card|invalid calendar draft selections|dragged calendar range" 통과, 4 tests
  • npx tsc --noEmit는 DEN-392 최종 QA 재실행에서 통과했다.

주의 및 제외 범위

이번 이슈는 invalid feedback과 drawer gating에 집중했다. reverse drag, lane/date/duration 재선택 lifecycle의 세부 검증은 DEN-391에서 이어갔다.
