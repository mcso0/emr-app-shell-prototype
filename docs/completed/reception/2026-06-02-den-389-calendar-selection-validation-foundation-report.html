DEN-389 접수 캘린더 선택 Validation Foundation 보고서

접수 캘린더의 클릭/드래그 task 생성 전에 15분 단위 normalization과 invalid reason 검증을 통과하도록 foundation을 추가했다. 이제 영업시간 밖, 점심시간, 기존 일정 겹침은 draft drawer나 temporary schedule card를 만들지 않는다.

변경 내용

  • validateReceptionCalendarSelection validation foundation 추가
  • 15분 단위 start/end normalization 공통화
  • invalid reason 구분: 영업시간 밖, unavailable time, overlap, too-short, too-long
  • 점심시간 12:00-13:00 session-only unavailable block 추가
  • 기존 appointment와 session-only walk-in draft overlap 판정 추가
  • click/drag 생성 진입점을 validation 결과에 연결
  • invalid selection Playwright 회귀 테스트 추가

변경 파일

  • src/features/reception/module.tsx
  • tests/reception.spec.ts

검증

  • npm run lint -- src/features/reception/module.tsx tests/reception.spec.ts 통과
  • npx tsc --noEmit 통과
  • PLAYWRIGHT_BASE_URL=http://127.0.0.1:3109 npx playwright test tests/reception.spec.ts --grep "15-minute calendar click|clears the draft schedule card|invalid calendar draft selections|dragged calendar range" 통과, 4 tests

주의 및 제외 범위

invalid selection의 세부 hover/drag 시각 feedback은 DEN-390에서 다룬다. 이번 이슈는 drawer와 draft card가 생성되지 않도록 막는 validation foundation에 집중했다.
