DEN-393 캘린더 Drag Preview 단일화 보고서

접수 캘린더에서 여러 시간대에 drag preview가 동시에 남는 문제를 수정했다. 새 drag가 시작되면 이전 cell의 임시 preview를 즉시 정리하고, pointerup, pointercancel, drawer open, window blur 시점에도 preview를 제거한다.

요청 배경

캘린더에서 여러 파란색/빨간색 임시 블록이 동시에 남아, 사용자가 실제로 몇 개의 접수 task를 만든 것처럼 오해할 수 있었다. 원인은 확정 draft 상태는 하나지만 각 ScheduleSelectionCell이 별도 local drag state를 가지는 구조였다.

변경 내용

  • calendar drag 시작/정리용 browser event를 추가했다.
  • 새 pointerdown 시 다른 cell의 local drag preview를 정리한다.
  • pointerup, pointercancel, drawer open, window blur에서 preview가 남지 않게 했다.
  • Playwright에 active selection preview가 최대 1개인지 검증하는 회귀 테스트를 추가했다.
