DEN-508 접수 입력 UX 기본값 수정 리포트

결과: 구현 완료. 접수 QA에서 나온 입력 UX 결함 중 생년월일 자동 하이픈, 동물 나이 단위 표시, 빈 환자 검색 dropdown 숨김을 수정했다.

요청 내용

신규 보호자/동물 등록과 진료 접수 모달에서 사용자가 입력 중 헷갈리는 지점을 줄이는 것이 목표였다. 특히 날짜와 나이 단위, 빈 검색어 상태의 dropdown 노출이 데모 신뢰도를 떨어뜨리고 있었다.

변경 사항

  • 생년월일 입력에 숫자 기반 자동 하이픈 포맷을 적용했다. 예: 19931123 → 1993-11-23.
  • 날짜 형식은 자동 보정하되, 존재하지 않는 날짜는 기존 검증 메시지로 막는다. 예: 19931340.
  • 동물 나이 입력 필드 안에 년, 개월 단위를 항상 보이도록 표시했다.
  • 동물 나이 입력은 숫자만 받고 3자리로 제한했다.
  • 진료 접수 모달의 환자 검색은 focus만으로 dropdown을 열지 않고, 한 글자 이상 입력했을 때만 결과 dropdown을 보여준다.

왜 중요한가

접수 화면은 데모의 첫 진입점이다. 날짜와 나이 입력이 명확하지 않거나 빈 dropdown이 보이면 사용자는 실제 데이터 연결이 불안정하다고 느낄 수 있다. 이번 변경은 접수 입력의 불필요한 혼란을 줄이고 Reception 시작 단계의 사용감을 안정화한다.

주의 사항

  • 원격 staging 배포나 DB 변경은 하지 않았다.
  • in-app Browser 확인도 시도했으나, 브라우저 탭 세션이 사라지는 런타임 문제가 있어 최종 증거는 Playwright focused 테스트로 대체했다.
  • 전화번호 자동 하이픈, 주소 입력, 중복 보호자 UX는 이번 범위가 아니다.
