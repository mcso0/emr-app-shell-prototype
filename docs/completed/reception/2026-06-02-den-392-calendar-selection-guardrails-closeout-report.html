DEN-392 접수 캘린더 Selection Guardrails 최종 보고서

접수 캘린더에서 15분 클릭/드래그로 task를 만들 때, 생성 가능한 시간만 drawer와 draft card로 이어지도록 guardrail을 추가했다. 불가 시간, 영업시간 밖, 기존 일정 겹침, 너무 긴 drag range는 생성되지 않고 invalid feedback을 보인다.

완료된 작업

  • Project 19와 마일스톤 4개, Linear 이슈 DEN-388부터 DEN-392까지 생성
  • selection guardrail contract와 edge-case matrix 작성
  • 15분 단위 validation/normalization foundation 구현
  • 영업시간 밖, 점심시간, 기존 일정 겹침, 240분 초과 selection 차단
  • invalid slot에 aria-disabled=true와 danger visual feedback 적용
  • invalid drag preview에 reason message 표시
  • drawer open 중 새 selection이 기존 draft card를 교체하는 lifecycle 검증
  • 역방향 drag normalization 검증
