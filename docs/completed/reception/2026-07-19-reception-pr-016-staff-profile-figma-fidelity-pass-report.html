프로필 사이드패널 Figma 정렬 1차 구현

프로필 탭의 기본 화면을 Figma 380×1105 기준에 맞췄다. 실제 직원 정보·권한·일정 읽기 계약은 그대로 유지했다.

반영한 내용

  • 오늘 근무 정보 → 계정 정보 → 다가오는 일정 순서와 구분선을 Figma와 동일하게 배치했다.
  • 32px 섹션 헤더, 330×70px 카드, 42px 날짜 타일, 173px 기본 상태 메시지 폭을 적용했다.
  • 이메일과 전화번호 복사 아이콘을 값이 있을 때 항상 보여주고, 실제 복사 동작은 유지했다.
  • 일정이 없을 때 예정된 일정이 없습니다를 표시한다.

검증

통과

  • 대상 파일 ESLint
  • TypeScript no-emit 검사
  • Storybook에서 패널 380×1105, 헤더 378×150, 본문 시작 위치 167/314/523px, 근무 카드 330×70px 확인

남은 확인

전체 리셉션 Playwright 스펙은 로컬 세션/대기열 읽기 실패로 프로필 테스트 전에 막혔다. 업무현황의 모듈별 집계와 패널 내부 일정 날짜 탐색은 새 데이터·권한 계약이 필요해 이번 변경에 포함하지 않았다.

다음 단계

실제 로그인 가능한 리셉션 환경에서 프로필 패널의 사진, 긴 이름, 상태 메시지 편집, 빈/오류 상태를 Figma 캡처와 나란히 확인한다.
