접수/예약 캘린더 소요시간 반영 개선 결과 보고

접수 생성 및 수정 시 설정한 시작 시각과 소요시간이 day/week 캘린더 카드 위치와 높이에 반영되도록 개선했다. 예를 들어 15:13 + 30분 접수는 캘린더에서도 15:13-15:43 범위로 표시된다.

요청 사항

  • 15분 단위 grid line은 안내선으로 유지한다.
  • 시작 시각은 현재시각 기반이므로 15분 단위로 스냅하지 않는다.
  • 접수/예약 큐와 day/week 캘린더가 동일한 시작 시각과 소요시간을 사용한다.
  • 프론트, API, DB/RPC 계약을 함께 확인한다.

변경 사항

  • day/week 캘린더 카드를 hour-row flex 배치에서 time-axis absolute 배치로 전환했다.
  • startMinutes와 durationMinutes 기반으로 카드 top/height를 계산하는 순수 헬퍼를 추가했다.
  • walk-in 생성 및 encounter 수정 서버 경로에서 durationMinutes가 양수 15분 단위인지 검증하도록 고정했다.
  • 기존 DB/RPC 스키마는 변경하지 않고, duration_minutes, checked_in_at, entered_at, scheduled_end_at 필드 계약을 테스트로 보강했다.

검증 결과

  • 서버/API/DB 계약 focused Playwright spec 20개 통과
  • day/week 캘린더 및 드래그 회귀 focused Playwright spec 4개 통과
  • npx tsc --noEmit 통과
  • npm run --silent lint 통과. 기존 warning 5개는 이번 작업 범위 밖이라 유지했다.

범위 밖

  • 겹치는 일정 자동 분할 레이아웃은 이번 변경에 포함하지 않았다.
  • DB 스키마 migration은 추가하지 않았다.
  • 기존 dirty 파일 .codex/config.toml은 건드리지 않았다.
