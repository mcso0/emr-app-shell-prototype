접수/예약 생성 우측 사이드패널 전환

2026-07-08 · Reception QA side-panel follow-up

요청

접수 상세에 이어 접수 생성과 예약 생성도 피그마 시안과 같은 우측 사이드패널 문법으로 맞추고, 기존 생성 계약은 유지한다.

변경 사항

  • 접수 생성 폼을 380px 우측 사이드패널에 맞는 1열 아이콘 라벨 구조로 전환했다.
  • 예약 생성 폼도 동일한 사이드패널 문법으로 정리하고 예약일, 예약시간, 예상소요시간, 담당의, 체중, 메모 입력을 유지했다.
  • 기존 POST /reception/walk-in-encounters, POST /reception/appointments API payload와 검증 흐름은 변경하지 않았다.
  • 관련 Playwright 회귀 테스트를 global drawer 기준에서 right panel 기준으로 갱신했다.

검증

  • npm run lint 통과
  • npx tsc --noEmit --pretty false 통과
  • PLAYWRIGHT_BASE_URL=http://127.0.0.1:3100 npx playwright test tests/reception.spec.ts --grep "walk-in reception drawer removes helper chrome|reservation create drawer uses DB-backed patient lookup states|reception creates a reservation through the unified check-in menu|reception creates a walk-in waiting row" --reporter=line 통과
  • 수동 Playwright 확인으로 접수 생성/예약 생성 모두 workspace-drawer 없이 reception-right-panel 380px 안에 렌더링되는 것을 확인했다.

주의 사항

이번 작업은 화면 표시 방식 정렬이 목적이다. 새로운 바이탈 저장 필드, 예약 API 계약, DB/RPC 변경, 원격 Supabase 작업은 포함하지 않았다.
