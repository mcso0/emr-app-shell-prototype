UX/UI 판단

  • 적용: 환자/보호자 → 바이탈 → 진료과/담당의 → 접수 정보(일정·방문 목적) 순서로 연속해서 훑을 수 있게 했다.
  • 적용: 체중의 Kg는 입력 행의 보조 정보로 유지해 값과 단위를 분리했다.
  • 제안만: 저장 실패/권한 없음/유효성 오류는 panel 중앙이 아니라 해당 필드 또는 footer 행동 바로 위에 표시하는 상태 규칙을 별도 work item으로 정의한다.
  • 제안만: 추가 바이탈을 Figma처럼 기본 노출하려면 새 임상 데이터의 source of truth, 권한, validation을 먼저 확정한다.

검증

  • 동일 1280px viewport에서 원격 기존 화면과 로컬 수정 화면을 비교했다. 수정 후 380px 폭, 56px 헤더, 76px 방문 목적 textarea, 접수 정보 내 방문 목적을 확인했다.
