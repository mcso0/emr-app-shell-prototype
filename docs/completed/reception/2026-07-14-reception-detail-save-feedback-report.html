UX/UI 결과

  • 적용: 입력 문제는 해당 입력값 바로 아래에, 행동/권한 문제는 저장 액션 바로 위에 표시한다.
  • 적용: 일시적·알 수 없는 저장 실패만 재시도 가능하며, 인증·권한·업무 상태 제한에는 반복 요청을 유도하지 않는다.
  • 적용: 오류 메시지는 중앙 빈 상태로 바뀌지 않으므로 본문 스크롤과 고정 footer의 구조가 유지된다.
  • 제안만: 서버가 복수 필드 오류를 반환할 때 첫 오류 필드로 자동 포커스를 옮길지 여부는 현재 사용자의 입력 맥락을 끊을 수 있어 별도 접근성 결정이 필요하다.
