DEN-58 Reception Patient Guardian Registration Write 보고서

작성일: 2026-05-19

접수 화면의 신규 환자·보호자 등록을 서버 route가 소유하는 최소 저장 경계로 연결했다. 아직 진료 접수 생성까지 저장하지는 않고, 접수 전에 필요한 환자·보호자 등록만 분리해서 live persistence 기반으로 옮긴 상태다.

무엇을 만들었나

  • POST /api/workspaces/[workspaceId]/reception/patient-guardian-registration route
  • server-owned registration core, mock fallback writer, Supabase writer gateway
  • 환자·보호자 최소 등록용 local-first SQL writer function migration
  • 접수 환자/보호자 등록 dialog의 최종 등록 submit route 연결
  • active workspace membership, reception:create, route-level rate limit 적용
  • 보호자 휴대전화, 마이크로칩, 동물등록번호 중복의 안정적인 차단 응답

왜 중요한가

이제 현장 접수를 만들기 전에 필요한 새 보호자와 새 환자를 서버 경계에서 등록할 수 있다. 다음 DEN-60의 현장 접수 encounter 생성은 이 등록 결과를 기반으로 이어질 수 있다.
