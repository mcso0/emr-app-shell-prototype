RECEPTION-PR-017 · 2026-07-20

예약 업무 담당자가 모든 직원 프로필에 보이도록 변경

예약의 담당 수의사는 그대로 유지하면서, 별도의 업무 담당자를 모든 역할의 활성 직원에게 지정할 수 있게 했다. 담당자는 프로필의 오늘 근무 정보와 업무현황에서 같은 예약을 확인한다. 연차·휴무·근무 일정은 이 변경과 분리되어 있다.

모든 역할수의사·테크니션·데스크·수납·관리자
2곳 표시오늘 근무 정보와 업무현황
원격 적용 완료기존 7건의 담당 수의사 이관 확인

바뀐 내용

  • 예약 생성 화면에 여러 명을 선택할 수 있는 업무 담당자 입력을 추가했다.
  • 예약 데이터에 업무 담당자 목록을 별도 저장한다. 담당 수의사는 진료 책임자로 유지된다.
  • 직원 프로필은 역할과 관계없이 자신에게 배정된 예약을 예약 진료와 접수/예약 업무 카드로 보여준다.
  • 취소·노쇼 예약과 다른 직원의 예약은 제외한다.

검증

  • TypeScript 검사, 관련 lint, Playwright 29개 테스트를 통과했다.
  • 테크니션에게 배정된 예약이 프로필 두 위치에 보이는 화면 흐름을 확인했다.
  • 원격 DB에서 테이블·RLS·직접 권한 없음·기존 7건 이관·조회 함수 교체를 확인했다.

범위와 다음 단계

  • 일정 탭, 연차, 휴무와 근무표 의미는 변경하지 않았다.
  • 새 테이블은 직접 공개하지 않고 권한 검증된 예약 RPC를 통해서만 사용한다.
  • 다음 단계는 최신 origin/main 기준 코드 PR을 생성하고 병합하는 것이다.
