DEN-509 Reception Time and Veterinarian Readback Fix

Reception QA에서 발견된 진료시간/담당 수의사 readback 불일치를 수정했다. 접수 생성 시점의 운영 시간, 캘린더 카드, 접수 drawer, Chart queue/context가 같은 KST 표시 규칙과 같은 담당 수의사 source를 사용하도록 맞췄다.

변경 요약

  • walk-in 접수 모달의 진료시간이 placeholder가 아니라 현재 운영 시각을 표시하고, 같은 값을 plannedStartAt으로 전송한다.
  • prepared-empty workspace에서는 현재 KST 시각을 사용하고, legacy fixture workspace는 기존 고정 운영 시각을 유지한다.
  • Reception 대기 카드, 캘린더 card, 접수 drawer의 날짜/시간 표시를 demo-date KST helper 기준으로 통일했다.
  • Reception side panel이 live vet staff list를 읽어 UUID 담당 수의사도 카드에 표시하도록 보강했다.
  • Chart live queue server projection이 users.display_name을 읽어 veterinarianName을 싣도록 보강했다.
  • Chart handoff cache와 live queue bundle이 veterinarianName을 보존해 Header, queue card, instruction info에서 같은 담당자명을 사용한다.
  • Chart explicit encounter deep link가 live/mock queue fallback에 의해 legacy encounter로 덮어써지지 않도록 guard를 추가했다.

검증 포인트

  • walk-in form의 진료시간 field가 legacy workspace에서 10:45를 표시하고, payload plannedStartAt도 2026-05-01T10:45:00+09:00로 전송되는 것을 확인했다.
  • server persisted readback에 UTC Z timestamp가 들어와도 Reception calendar card가 KST 10:15로 표시되는 것을 확인했다.
  • walk-in 생성 후 Chart deep link가 legacy queue item으로 덮이지 않고 생성 encounter context를 유지하는 것을 확인했다.
  • live chart queue record가 UUID 담당 수의사명(청담 원장, 김도윤)을 hydrate하는 것을 확인했다.

범위 제외

  • DEN-508 입력 UX 개선(생년월일 하이픈, 동물 나이 년/개월 라벨, 빈 검색어 dropdown 숨김)은 구현하지 않았다.
  • DEN-510 캘린더 카드 drawer 전환 및 접수 취소 route/UI는 구현하지 않았다.
  • DEN-511 staging manual QA replay와 claim boundary 업데이트는 아직 수행하지 않았다.
  • 원격 staging DB reset/delete, production deploy, 실데이터/외부 알림/결제/provider side effect는 수행하지 않았다.
