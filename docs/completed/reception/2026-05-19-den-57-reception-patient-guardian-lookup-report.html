DEN-57 Reception Patient Guardian Lookup 보고서

작성일: 2026-05-19

접수 화면에서 환자·보호자를 실제 DB 기반 조회로 전환하기 위한 첫 read boundary를 추가했다. 아직 저장 작업은 하지 않고, 현장 접수 전에 안전하게 환자/보호자를 찾는 기반만 만든 상태다.

무엇을 만들었나

  • GET /api/workspaces/[workspaceId]/reception/patient-guardian-lookup route
  • server-owned lookup core, mock fallback gateway, Supabase reader gateway
  • 환자/보호자 검색용 local-first SQL reader function migration
  • 현장 접수 dialog의 환자 검색 입력, loading/success/empty/error 상태
  • workspace active membership과 patient:view 권한 확인

왜 중요한가

접수 직원이 현장 접수를 만들기 전에 같은 병원 workspace 안의 환자와 보호자를 검색하는 서버 경계가 생겼다. 다음 DEN-58의 최소 신규 환자/보호자 등록 write boundary와 이후 encounter persistence가 이 조회 경계를 기준으로 이어질 수 있다.
