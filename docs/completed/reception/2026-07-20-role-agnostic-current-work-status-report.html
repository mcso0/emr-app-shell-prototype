RECEPTION-PR-018 · 2026-07-20

전 직원의 현재 근무 정보를 실제 근무 데이터에 연결

예약이 있다는 이유로 근무 중처럼 보이던 잘못된 연결을 제거했다. 이제 모든 활성 직원은 역할과 관계없이 게시 근무표, 퇴근, 진료 상태, 연차·휴무에 맞는 카드가 보이고, 접수·예약은 업무현황에만 남는다.

모든 역할수의사·테크니션·데스크·기타 멤버
15명 확인청담 활성 직원 원격 읽기 검증
DB 적용원격 마이그레이션 및 응답 확인

바뀐 내용

  • 오늘 근무 정보는 게시 근무표·출퇴근·휴무·연차·진료실 데이터만 사용한다.
  • 진료중과 진료실은 실제 진료중 encounter와 호출 시 선택한 진료실이 있을 때만 표시한다.
  • 예약과 현장 접수는 환자 업무이므로 업무현황에서만 표시한다.
  • 활성 멤버가 추가되거나 역할이 바뀌면 근무 프로필이 자동으로 동기화된다.

검증

  • 원격 적용 전 전체 SQL 롤백 검증을 통과했다.
  • 청담의 수의사·테크니션·데스크·기타 활성 멤버 15명 모두 09:00-19:00 근무와 현재 업무 종료 상태를 반환했다.
  • TypeScript와 집중 서버·브라우저 테스트로 근무/퇴근/업무 종료/연차/당일 연차/휴무일/병원 휴무일 UI를 확인했다.

범위

  • 일정 탭의 연차·휴무 목록 화면은 이번 구현에 포함하지 않았다.
  • 현재 근무 응답에는 환자명, 보호자명, 근무 메모, 연차 사유를 포함하지 않는다.
