DEN-60 Reception Walk-In Encounter Create 보고서

작성일: 2026-05-19

접수 화면의 현장 접수 생성을 서버 route가 소유하는 저장 경계로 연결했다. 이제 현장 접수는 서버가 환자, 보호자 관계, 권한을 확인한 뒤 encounter와 대기열 row를 함께 만든다.

무엇을 만들었나

  • POST /api/workspaces/[workspaceId]/reception/walk-in-encounters route
  • server-owned walk-in encounter core, mock fallback writer, Supabase writer gateway
  • 현장 접수 encounter와 consultation queue row를 함께 만드는 local-first SQL writer function
  • 접수 진료 접수 dialog의 최종 생성 submit route 연결
  • active workspace membership, reception:create, route-level rate limit 적용
  • 서버 응답으로 받은 persisted-shaped encounter/queue를 local demo UI에 반영

왜 중요한가

접수 업무의 핵심인 "예약 없이 온 환자를 진료대기 상태로 올리는 일"이 서버 경계 뒤로 이동했다. 다음 DEN-59의 예약 접수 전환도 같은 패턴으로 구현할 수 있다.
