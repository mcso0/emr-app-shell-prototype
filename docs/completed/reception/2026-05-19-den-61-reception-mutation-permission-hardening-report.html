DEN-61 Reception Mutation Permission Hardening 보고서

작성일: 2026-05-19

접수에서 데이터를 새로 만드는 세 가지 작업이 같은 권한 기준을 쓰도록 고정했다. 이제 잘못된 workspace나 권한 없는 사용자가 접수 데이터를 만드는 사고를 테스트로 막는다.

적용한 기준

작업 필요 권한 감사 로그 hook 후보
환자/보호자 등록 reception:create reception.patient_guardian.register
현장 접수 encounter 생성 reception:create reception.walk_in.create
예약 접수 check-in reception:create reception.appointment.check_in

차단 확인

  • 로그인 actor 없음: unauthenticated
  • 비활성 사용자: inactive_user
  • 다른 workspace 멤버십만 있음: workspace_membership_missing
  • 비활성 멤버십: workspace_membership_inactive
  • 권한 없는 역할: permission_missing
