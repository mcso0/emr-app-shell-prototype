DEN-391 접수 캘린더 Selection Lifecycle Edge Cases 보고서

역방향 드래그, draft 재선택, 최대 duration 초과 같은 edge case를 Playwright 테스트로 고정했다. draft card는 한 번에 하나만 유지되고, 새 선택이나 다른 일정 선택 시 기존 draft가 정리되는 흐름을 확인했다.

변경 내용

  • drawer open 상태에서 새 15분 slot을 선택하면 기존 draft card가 교체되는 테스트 추가
  • 240분 초과 drag range가 invalid preview를 보이고 drawer를 만들지 않는 테스트 추가
  • 역방향 drag가 14:00-15:30처럼 정상 range로 normalize되는 테스트 추가
  • 기존 cancel/create/another appointment cleanup 회귀를 유지

변경 파일

  • tests/reception.spec.ts

검증

  • npm run lint -- src/features/reception/module.tsx tests/reception.spec.ts 통과
  • PLAYWRIGHT_BASE_URL=http://127.0.0.1:3109 npx playwright test tests/reception.spec.ts --grep "15-minute calendar click|clears the draft schedule card|invalid calendar draft selections|dragged calendar range|reverse dragged calendar range" 통과, 5 tests
  • npx tsc --noEmit는 DEN-392 최종 QA 재실행에서 통과했다.

현재 정책

  • 시작 lane 기준으로 veterinarian을 고정한다.
  • day view 안의 같은 날짜 selection만 생성 대상으로 본다.
  • 최소 duration은 15분, 최대 duration은 240분이다.
  • draft card는 정확히 하나만 유지한다.
