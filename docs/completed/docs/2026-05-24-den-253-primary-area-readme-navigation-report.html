DEN-253 Primary Area README Navigation 리포트

GitBook sidebar를 늘리지 않고도 주요 문서 영역을 탐색할 수 있도록 primary area README 6개를 2차 내비게이션 역할에 맞게 정리했다.

요청

product, design, engineering, work, _meta, completed README가 각 영역의 목적, 현재 기준 문서, 하위 폴더 역할, 추가 위치, current/history 경계를 명확히 설명하게 만든다.

변경 사항

  • docs/product/README.md: product truth, read-first docs, domain/data-model boundary, legacy spec boundary 정리
  • docs/design/README.md: UX/design-system/QA 탐색 경로와 one-off vs reusable rule 경계 정리
  • docs/engineering/README.md: implementation truth, auth/security/data/ops read-first docs, approval-gated 범위 정리
  • docs/work/README.md: PR-sized work, status values, Linear Human Review boundary 정리
  • docs/_meta/README.md: operating rules index와 _meta 범위 정리
  • docs/completed/README.md: completed records가 source of truth가 아니라는 경계와 closeout/report 역할 정리

범위 통제

  • docs/SUMMARY.md sidebar를 확장하지 않았다.
  • docs/engineering/current-status.md와 docs/work/index.md 상태 정리는 DEN-255 범위로 남겼다.
  • 대량 문서 이동, work item status migration, source-doc claim rewrite는 하지 않았다.
  • 기존 invite/OTP, table density, UI 관련 미완료 워크트리 변경은 건드리지 않았다.

검증

  • 통과 npm run docs:check
