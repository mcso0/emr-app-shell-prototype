DEN-176 작업 보고서 - Outpatient Workflow State Model

작성일: 2026-05-20 / Linear: DEN-176

요청

예약/접수부터 진료, 오더, 검사/처치, 수납, 완료까지 이어지는 외래 업무 상태 모델을 제품 언어로 정리한다.

변경 내용

  • docs/product/domain/outpatient-workflow-state-model.md를 추가했다.
  • Appointment, Encounter, Queue, SOAP, Order, Result, Invoice, Payment 상태를 제품 관점에서 정리했다.
  • 정상 전이, 취소/노쇼/중복/권한 없음/미완료 주문/결과 수정 같은 예외 처리 기준을 추가했다.
  • 역할별 상태 변경 범위와 audit expectation, live 전 결정이 필요한 open product decisions를 명시했다.

왜 중요한가

앞으로 기능을 만들 때 버튼이나 화면부터 보지 않고, 어떤 업무 객체의 상태가 어떻게 바뀌는지 먼저 확인할 수 있다. 이 문서는 외래 MVP의 데이터 상태, 권한, 예외 처리, 감사 기록을 연결하는 기준점이다.

핵심 상태 전이

  • Appointment: requested → confirmed/changed → checked_in 또는 cancelled/no_show
  • Encounter: waiting → in_consultation → ordered → ready_for_billing → completed
  • Order: requested → in_progress/confirmed → completed 또는 cancelled
  • Invoice: draft → issued → paid/refund_requested/refunded 또는 voided

승욱 결정이 필요한 상태

  • 검사/영상 vet review가 끝나기 전 수납 발행을 허용할지
  • front desk가 미수 상태로 encounter를 닫을 수 있는지
  • live refund 승인 권한과 절차
  • technician의 order cancel 권한 범위
  • SOAP signed 이후 직접 수정 가능 시간과 amendment-only 전환 기준
