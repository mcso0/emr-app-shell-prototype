DEN-257 GitBook Docs Site Creation Plan Report

요약

GitBook 공식 docs site 모델을 기준으로 CLAiR EMR 문서를 GitBook private/internal docs site로 만드는 계획을 정리했다. 이번 작업은 실제 사이트 생성이나 공개가 아니라, 승욱이 나중에 수동으로 만들 때 따라갈 source-of-truth, access, sync, domain, stop condition을 확정하는 작업이다.

결정

항목 권장안
Site purpose Private/internal reader portal
Source of truth Repo docs/ 유지
GitBook editing 직접 편집은 피하고, repo 변경을 GitBook에 sync하는 흐름 우선
Space/site structure 초기에는 one docs site, one primary docs space
Audience Unpublished/manual review first, then private/internal access
Custom domain 초기에는 기본 GitBook URL 사용, custom domain은 나중에 결정

변경 내용

  • docs/_meta/gitbook-docs-site-creation-plan.md를 추가했다.
  • docs/SUMMARY.md, docs/index.md, docs/_meta/README.md에서 계획 문서를 연결했다.
  • docs/_meta/gitbook-structure-rules.md와 .agents/skills/emr-docs-sync/SKILL.md에 docs-site setup 전 계획 문서를 읽도록 반영했다.
  • docs/engineering/current-status.md에 DEN-252부터 DEN-257까지 Human Review 상태이며, 실제 GitBook site setup은 승욱의 명시 요청 전까지 하지 않는다고 반영했다.

검증

  • npm run docs:check는 계획 문서 추가 직후 1회 통과: 804 docs/agent markdown files checked.
  • 보고서 추가 후 최종 npm run docs:check는 실패. 실패 원인은 이번 작업 범위 밖의 기존 dirty file docs/design/system/table-density-and-grid-ergonomics.md가 없는 docs/completed/design/2026-05-24-den-251-table-cell-text-wrapping-research-report.html를 링크하고 있기 때문이다.
  • DEN-257 touched markdown focused link check 통과.
  • git diff --check 통과: DEN-257 대상 파일 whitespace 문제 없음.
  • Ruby YAML/frontmatter validation 통과: skill, GitBook docs site creation plan, private operations checklist, GitBook structure rules.
  • GitBook 공식 문서 확인: Publish a docs site, Site settings, Site structure, Custom domain, Git Sync, Private publishing with share links.

의도적으로 하지 않은 것

  • GitBook site를 생성하지 않았다.
  • GitBook 설정, audience, share link, authenticated access, custom domain, DNS를 변경하지 않았다.
  • GitBook을 external-public으로 전환하지 않았다.
  • GitHub main push, production publication, remote Supabase, migration, RLS replay, production deploy, real email, payment, provider integration, compliance 작업을 하지 않았다.
  • Linear issue를 Done으로 이동하지 않았다.

다음 추천

DEN-252부터 DEN-257까지 Human Review가 끝나면, 승욱이 원할 때 별도 실행 작업으로 GitBook organization/space/site를 수동 생성하면 된다. 그때도 먼저 private/unpublished 상태로 렌더링과 sidebar만 검수하고, 공유 범위는 별도 승인 후 열어야 한다.
