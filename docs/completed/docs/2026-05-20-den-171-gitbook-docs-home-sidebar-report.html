DEN-171 GitBook 문서 홈 및 사이드바 작업 보고서

요청

GitBook Free를 문서 포털로 쓰기 위해 repo docs/를 원본으로 유지하면서, 승욱과 Codex가 보기 쉬운 문서 홈과 sidebar 기준을 만든다.

변경 내용

  • docs/index.md를 추가해 GitBook/문서 포털의 사람용 시작점을 만들었다.
  • docs/SUMMARY.md를 추가해 GitBook sidebar에 노출할 핵심 문서만 정리했다.
  • docs/README.md의 시작 안내에 GitBook 포털과 원본 repo docs 원칙을 추가했다.

왜 중요한가

문서 원본은 repo에 남기고 GitBook은 보기 좋은 포털로만 쓰도록 역할을 분리했다. 이렇게 하면 Codex는 repo 문서를 안정적으로 읽고, 승욱은 폴더를 뒤지지 않고 GitBook에서 현재 기준 문서를 찾을 수 있다.

검증

  • npm run docs:check 통과
  • docs/SUMMARY.md 상대 링크 존재 여부 별도 확인 통과

주의 사항

  • GitBook 계정/OAuth 연결 자체는 이 이슈 범위 밖이다.
  • GitBook에서 직접 편집하지 않고 repo docs/를 원본으로 유지하는 운영을 권장한다.
  • 민감한 auth, security, DB, launch readiness 문서는 공개 publish 전에 별도 검토가 필요하다.
