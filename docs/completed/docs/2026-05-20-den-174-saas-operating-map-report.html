요청

CLAiR EMR이 누구의 어떤 업무 문제를 해결하는 B2B SaaS인지, 현재 Product MVP가 어디까지 제품으로 볼 수 있는지 한눈에 보는 운영 지도를 만든다.

변경 내용

  • docs/product/service/clair-emr-saas-operating-map.md를 추가했다.
  • 구매자, workspace admin, clinical user, front desk, billing operator, CLAiR operator를 구분했다.
  • 핵심 workflow spine, Product MVP 의미, mock/local-first/live claim 기준, 구현 전 체크리스트를 정리했다.

왜 중요한가

기능을 화면 단위로만 추가하면 제품 기준이 흐려진다. 이번 문서는 구현 전 질문을 “어떤 화면을 만들까?”에서 “어떤 병원 업무 상태, 권한, 데이터 소유권, 감사 경로가 바뀌는가?”로 바꾸는 기준점이다.
