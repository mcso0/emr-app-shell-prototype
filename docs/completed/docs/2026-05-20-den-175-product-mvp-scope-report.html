DEN-175 작업 보고서 - Product MVP Scope

작성일: 2026-05-20 / Linear: DEN-175

요청

Product MVP에서 할 것, 하지 않을 것, 후속으로 미룰 것, 대표 승인이 필요한 범위를 별도 기준 문서로 고정한다.

변경 내용

  • docs/product/roadmap/product-mvp-scope.md를 추가했다.
  • In scope, out of scope, deferred, approval-gated 범위를 분리했다.
  • mock/session-only, local-first, remote staging, production/live claim 기준을 정리했다.
  • 새 요청이 MVP 후보인지, 승인 게이트인지, deferred roadmap인지 판단하는 routing table을 추가했다.

왜 중요한가

앞으로 기능 요청이 들어왔을 때 “지금 MVP에 넣을 일인지”를 매번 다시 판단하지 않아도 된다. 특히 remote Supabase, real data, email, payment, production deploy처럼 위험한 작업은 명시적 승인 없이는 진행하지 않는 기준이 더 선명해졌다.
