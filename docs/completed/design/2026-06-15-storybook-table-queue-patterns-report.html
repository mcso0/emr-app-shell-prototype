Storybook Table/Queue Pattern Entry

반복되는 EMR table/queue 패턴을 Storybook에 처음 진입시켰다. 새 production API는 만들지 않고, 기존 table, status badge, row action menu, segmented control, button primitive를 합성한 Storybook-only helper를 추가했다.

변경 사항

  • Design System/EMR/Table Queue Patterns story를 추가했다.
  • 상태 셀, 액션 셀, 필터 툴바, 빈 테이블 패턴을 합성 예시로 문서화했다.
  • 실제 feature provider나 live data 없이 synthetic demo text만 사용했다.
  • 새 work item DESIGN-SYSTEM-PR-057를 Human Review 상태로 기록했다.

범위 밖

신규 production table/queue abstraction, feature module refactor, provider-backed workflow story, DB/Supabase/권한/배포/외부 연동은 포함하지 않았다.

검증

  • npm run lint 통과. 기존 범위 밖 warning 5개는 유지됨.
  • npx tsc --noEmit 통과.
  • npm run docs:check 통과.
  • npm run build-storybook 통과.
  • npm run storybook -- --ci --smoke-test 통과.
  • Storybook MCP list-all-documentation에서 StorybookTableQueuePatterns 확인.
  • Storybook MCP get-documentation에서 design-system-emr-table-queue-patterns 확인.
  • Storybook MCP run-story-tests focused 실행으로 design-system-emr-table-queue-patterns--status-cell 통과 확인.

주의 사항

첫 focused MCP 실행은 @base-ui/react/menu dependency optimizer reload 때문에 일시 실패했지만, PR-056 정책대로 재실행했고 focused story test가 통과했다.
