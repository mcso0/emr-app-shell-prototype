Storybook Project MCP Client

로컬 Storybook MCP endpoint를 Codex의 프로젝트 범위 설정에 연결했다. 다음 Codex 세션부터 UI 작업자는 디자인시스템 컴포넌트 props와 story 문서를 먼저 조회할 수 있다.

변경 사항

  • .codex/config.toml에 clair_storybook MCP 서버를 추가했다.
  • AGENTS.md에 UI/design-system 작업 시 Storybook MCP를 먼저 조회하라는 규칙을 추가했다.
  • Storybook 운영 규칙에 MCP client 이름, 도구 사용 순서, local-only 경계를 기록했다.
  • 새 work item DESIGN-SYSTEM-PR-053을 Human Review 상태로 기록했다.

범위 밖

전역 Codex 설정 수정, MCP endpoint publish/share/tunnel, hosted Storybook, Chromatic 배포, 신규 story 작성, DB/Supabase/권한/배포/실데이터 작업은 포함하지 않았다.

검증

  • npx tsc --noEmit
  • npm run docs:check
  • npm run storybook -- --ci --smoke-test
  • codex mcp list -c service_tier='"flex"' 기준 clair_storybook 서버 설정 노출 확인
  • 로컬 MCP tools/list, list-all-documentation, run-story-tests focused 확인

주의 사항

Codex는 MCP client 도구를 세션 시작 시 로드하므로, 현재 열린 세션에서는 새 clair_storybook 도구가 바로 보이지 않을 수 있다. 새 Codex 세션 또는 앱 reload 후 확인하는 것이 안전하다. 또한 현재 로컬 전역 Codex 설정에는 CLI가 받아들이지 않는 service_tier = "default" 값이 있어, CLI 검증은 일시적으로 -c service_tier='"flex"' 오버라이드를 사용했다.
