DEN-293 고급 필터 빌더 공용 기반

외부 query builder UI를 그대로 가져오지 않고, CLAiR EMR 컴포넌트로 재사용 가능한 필터 빌더 기반을 만들었다. 데이터 모델은 query-builder 방식으로 설계하되, 현재 제품 정책에 맞게 첫 범위는 단일 AND 조합으로 제한했다.

핵심 결정

처음 열림 상태 조건 1개짜리 빈 draft row만 표시한다. 여러 조건이 채워진 시안 상태는 데모 예시로만 본다.
active filter 계산 필드, 조건, 값이 모두 채워진 row만 active filter와 Filter N에 포함한다.
재사용 구조 화면별 테이블은 허용 필드 config만 넘긴다. checkbox/action/display-only 컬럼은 필드로 노출하지 않는다.
적용 범위 DEN-293은 기반 구축이다. 실제 여러 화면 적용은 DEN-294에서 진행한다.

변경 사항

  • src/components/emr/table-filter-builder-model.ts: draft rule, active count, AND row filtering helper를 추가했다.
  • src/components/emr/table-filter-builder.tsx: EMR/shadcn primitive 기반의 공용 filter builder UI를 추가했다.
  • tests/table-filter-builder-foundation.spec.ts: 첫 draft 상태, incomplete rule ignore, AND 적용, 마지막 rule 삭제 후 draft 복구를 검증했다.
  • docs/design/system/table-sort-filter-behavior.md와 work index에 DEN-293 기반 정책을 기록했다.
