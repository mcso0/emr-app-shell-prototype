Storybook Dropdown Sheet Primitive Stories

기존 UI primitive인 DropdownMenu와 Sheet를 Storybook 문서에 추가했다. overlay 계열 command menu와 side panel 사용 기준을 synthetic demo text로 확인할 수 있다.

변경 사항

  • Design System/UI/DropdownMenu story를 추가했다.
  • Design System/UI/Sheet story를 추가했다.
  • 각 meta에 autodocs, args, argTypes, component description을 포함했다.
  • 각 story 설명에 사용할 때와 쓰지 말아야 할 때를 짧게 적었다.
  • open-state 확인은 storybook/test helper 없이 DOM API 기반 play function으로 유지했다.

범위 밖

runtime component API 변경, feature workflow story, 패키지 업그레이드, DB/Supabase/권한/배포/외부 연동은 포함하지 않았다.

검증

  • npm run lint 통과. 기존 5개 warning은 남아 있다.
  • npx tsc --noEmit 통과.
  • npm run docs:check 통과.
  • npm run build-storybook 통과. 기존 Storybook build warning은 남아 있다.
  • npm run storybook -- --ci --smoke-test 통과.
  • Storybook MCP 문서 노출 확인: design-system-ui-dropdownmenu, design-system-ui-sheet.
  • Storybook MCP focused story test 통과: design-system-ui-dropdownmenu--default, design-system-ui-sheet--default.

주의 사항

focused MCP testing 중 DropdownMenuLabel이 DropdownMenuGroup 밖에 있으면 Base UI group context 오류가 난다는 점을 확인했고, story composition을 수정한 뒤 최종 검증을 통과했다.
