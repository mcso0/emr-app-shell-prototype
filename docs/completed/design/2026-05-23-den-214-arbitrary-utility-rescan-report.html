Arbitrary Spacing / Font Utility Rescan

최신 src/**/*.{ts,tsx} 기준으로 arbitrary spacing, font, width/height, radius, grid utility를 다시 스캔하고 A+ token cleanup 후보를 분류했다. 이번 이슈는 구현 변경이 아니라 후속 DEN-215~220이 안전하게 줄일 수 있는 기준선을 확정하는 작업이다.

대표 판단

A+를 막는 주된 debt는 여전히 typography 계열이다. 전체 in-scope 1,637건 중 1,123건이 typography이고, raw measure 기준으로도 text-[12px], text-[13px], text-[11px], text-[14px] 네 값이 압도적이다.

반대로 grid, table width, viewport calc(), command palette 크기, shell icon micro-geometry는 화면 가독성과 구조를 지탱하는 local exception 가능성이 높다. 따라서 A+ cleanup은 전역 일괄 치환보다 text role → component rhythm → module adoption 순서로 가는 편이 안전하다.

Token / Variant 후보

  1. Typography roles: dense body, dense metadata, micro metadata, compact title, dialog title를 먼저 이름 붙인다. 후속 구현은 DEN-215에서 한다.
  2. Side-panel rhythm: 반복되는 h-[18px], leading-[18px], tracking 값을 src/components/emr primitive 또는 feature-local variant로 흡수한다.
  3. Radius cleanup: 이미 CSS var를 쓰는 radius bracket 값은 --emr-radius-control, --emr-radius-panel 또는 component size/variant를 우선한다.
  4. Width/table recipes: table column width는 DEN-214에서 승격하지 않는다. Project 12 table density contract가 생기기 전까지는 overflow QA와 local exception으로 둔다.

Local Exception 후보

  • dense table column widths and min-widths
  • calendar grid recipes and event positioning values
  • drawer and viewport calc() heights
  • command palette max height/width and shell overlay geometry
  • nav rail icon micro-sizes and generated SVG alignment values
  • w-[var(--anchor-width)] 같은 popover/select anchor matching values
