DEN-404 전역 알림 source navigation 완료 보고서

전역 알림 row의 primary action을 현재 탭 source workflow 이동으로 연결했다. source route가 없는 알림은 조용히 실패하지 않고 drawer 안 fallback detail을 보여준다.

변경

  • drawer row의 source action button을 활성화했다.
  • source.route가 있으면 현재 workspace tab route로 이동하고 drawer를 닫는다.
  • source action을 누른 알림은 이동 또는 fallback 표시 전에 읽음 처리한다.
  • fallback_detail 또는 invalid route는 drawer 안 fallback detail panel로 처리한다.
  • fallback detail에는 실패 이유, title/detail, source/recipient metadata를 표시한다.

검증

  • npm run lint 통과. 기존 경고 4개는 유지된다.
  • npx tsc --noEmit 통과.
  • PLAYWRIGHT_BASE_URL=http://localhost:3333 npx playwright test tests/notification-toast.spec.ts tests/notification-fixtures.spec.ts tests/app-shell.spec.ts -g "notification" 통과: 20 passed.
  • npm run docs:check 통과.

제외 범위

dirty-state confirmation guard는 DEN-405 범위로 남겼다. Server-side permission enforcement, remote Supabase migration/RLS/live validation, provider delivery, external channel은 구현하지 않았다.
