홈 레퍼런스 기반 입원 화면 리디자인 시안 보고서

홈 화면 레퍼런스의 핵심은 왼쪽에서 우선순위를 먼저 보고, 중앙에서 전체 업무를 비교하며, 오른쪽에서 선택한 업무의 실행 맥락을 확인하는 3분할 구조다. 이 구조를 입원 화면에 적용하면 병동 담당자가 어떤 입원 환자를 먼저 확인해야 하는지를 테이블을 읽기 전에 판단할 수 있다.

추천 방향은 Home-Referenced Ward Workspace다. 홈의 다음 행동 / 업무 보드 / 선택한 업무 구조를 입원 도메인에 맞춰 입원 우선순위 / 입원 데이터 테이블 / 입원 상세로 치환한다.

요청과 산출물

요청 홈 화면 레퍼런스의 좌측 우선순위 패널, 중앙 업무 영역, 우측 상세 패널 구조를 참고해 입원 화면 시안을 다시 정리한다.
산출물 홈 레퍼런스 적용 원칙, 입원 화면 재시안, 구현 범위와 제외 범위를 담은 HTML 디자인 보고서.
비고 이번 작업은 구현 변경이 아니다. 앱 코드, Supabase, 배포 alias, 실데이터, 권한 정책은 변경하지 않았다.

현재 화면 진단

좋은 점
  • 입원 환자, 주의 태그, 퇴실 준비, 오늘 입실 수가 상단에서 바로 보인다.
  • 강아지, 고양이, 집중 치료실 그룹 분리가 병동 현황판으로 이해하기 쉽다.
  • dense table과 row drawer 구조는 기존 CLAiR EMR 운영 화면과 잘 맞는다.
개선 필요
  • 주의 태그 11개는 총량 정보라 우선 행동으로 이어지기 어렵다.
  • 필터가 종별 중심이라 집중관리, 퇴실준비, 내 담당 같은 실무 우선순위가 약하다.
  • 테이블이 병동별로 반복되면서 헤더가 중복되고, 실제 환자 수 대비 화면이 넓게 비어 보인다.
  • 퇴실/대기 버튼만으로는 퇴실 체크리스트의 진행 상태를 판단하기 어렵다.

홈 레퍼런스에서 가져올 구조

홈 레퍼런스 입원 화면 적용 이유
다음 행동 왼쪽 패널 입원 우선순위 패널 상단 카드보다 먼저 읽히고, 테이블 세로 공간을 차지하지 않는다.
중앙 업무 보드 중앙 입원 데이터 테이블 입원은 방, 환자, 상태, 담당, 퇴실 준비를 비교해야 하므로 Kanban보다 table이 맞다.
선택한 업무 오른쪽 상세 선택한 입원 환자 상세 drawer row 클릭 후 오늘 케어, 유의사항, 퇴실 체크리스트를 흐름을 막지 않고 확인한다.
Home은 원본 화면 이동 전 확인 입원은 현황 확인과 일부 체크 액션의 전 단계 live workflow mutation은 제외하고, session-only 상세 확인과 원본 행동 진입만 제안한다.

수정 시안: Home-Referenced Ward Workspace

추천 결정

1차 구현 추천: Home-Referenced Ward Workspace

홈 화면의 3분할 구조를 입원 도메인에 맞게 재사용한다. 왼쪽은 입원 우선순위, 중앙은 입원 데이터 테이블, 오른쪽은 선택 row 상세로 두면 시선 순서와 세로 공간 문제를 동시에 해결할 수 있다.

후속 후보: Room Map Board

실제 입원실 배치 정보와 빈 케이지 관리가 중요해질 때 별도 보기 모드로 추가한다. 현재 MVP의 기본 화면으로 쓰기에는 정보 밀도 대비 확장성이 낮다.

후속 후보: Care Timeline Focus

입원 케어 오더, 투약 수행, vital 기록, 지연 알림이 scope에 들어올 때 가장 가치가 커진다. 현재는 현황판 안의 drawer 또는 보조 탭으로 일부만 반영하는 것이 적절하다.

구현 범위 제안

범위 권장 작업 영향
왼쪽 병동 큐 홈의 다음 행동 패널을 참고해 상단 KPI 카드 4개를 입원 우선순위 사이드 패널로 이동한다. 첫 시선에서 우선순위 확인, 중앙 테이블 세로 공간 확보
필터 홈의 업무 렌즈처럼 왼쪽 큐 항목 클릭이 중앙 테이블 필터를 바꾸도록 한다. 전체/집중관리/퇴실준비/오늘입실/강아지/고양이/ICU를 같은 패턴으로 다룬다. 필터와 업무 큐의 의미 통합
테이블 병동별 section 반복을 줄이고 기본은 하나의 기존 데이터 테이블형 worklist로 구성한다. row 선택 상태를 명확히 표시한다. 중복 헤더 감소, 기존 테이블 사용성 유지
Row 정보 환자/보호자, 상태/주의, 진단/오늘 케어, 퇴실 준비 중심으로 셀을 재구성한다. 의미 있는 정보 밀도 증가
Drawer 홈의 non-modal 상세 패널을 참고해 row 클릭 시 오른쪽 상세를 열고, 환자 요약, 케어 포인트, 유의 태그, 퇴실 체크리스트를 보여준다. 중앙 테이블은 스캔, 오른쪽 상세는 확인으로 역할 분리

제외 범위와 주의점

  • 입원 live persistence, Supabase migration, RLS, server enforcement는 이번 디자인 시안 범위가 아니다.
  • 실제 병원/보호자/환자 데이터는 사용하지 않는다. 현재와 동일하게 synthetic demo data 기준으로 판단한다.
  • 퇴실 workflow를 실제로 완료 처리하는 기능은 별도 product/engineering scope가 필요하다.
  • 입원 케어 지연 알림, 투약 수행, vital 기록은 향후 inpatient live workflow 또는 notification scope에서 다뤄야 한다.
