DEN-351 CDS V2 Shell Surfaces & Command Entry Report

작성일: 2026-05-31 / 프로젝트: 17 CLAiR EMR CDS V2 App Shell Refinement

첫 구현 단위로 앱 셸의 배경/패널 색상 계층을 CDS V2 방향에 맞게 밝게 정리하고, 전역 통합 검색 버튼을 topbar에서 nav rail 안으로 옮겼다. 검색 dialog와 Cmd/Ctrl+K 단축키, 환자 검색 후 이동 동작은 그대로 유지했다.

변경 내용

  • GlobalCommandPalette에 nav rail 전용 rail trigger variant를 추가했다.
  • NavRail 상단에 전역 통합 검색 trigger를 배치하고 tooltip을 유지했다.
  • WorkspaceTabsBar에서는 검색 trigger를 제거해 topbar를 다음 이슈에서 다듬기 쉬운 상태로 만들었다.
  • WorkspaceSwitcher를 32px 높이, 고정 폭, hairline border, 작은 logo mark 버튼으로 조정했다.
  • EMR surface/line alias를 CDS V2에 가까운 밝은 gray 계층으로 정리했다.
  • app-shell Playwright 기대값을 nav rail command 위치와 collapsed switcher mark 크기에 맞게 갱신했다.
