Storybook First UI Primitive Stories

빈 Storybook 카탈로그에 첫 CLAiR EMR UI primitive 문서를 추가했다. 이제 Button, Badge, Input을 실제 앱 토큰과 폰트 기준으로 확인할 수 있고, 향후 AI agent가 컴포넌트 사용법을 더 안정적으로 읽을 수 있는 기준이 생겼다.

변경 사항

  • Button, Badge, Input story를 컴포넌트 옆에 추가했다.
  • 각 story에 args, argTypes, autodocs, 사용/비사용 설명을 넣었다.
  • Storybook 운영 규칙 문서를 추가해 repo docs와 Storybook의 역할을 분리했다.
  • 새 work item DESIGN-SYSTEM-PR-049를 Human Review 상태로 기록했다.

범위 밖

SegmentedControl, EmrStatusBadge, EmrInlineAlert, Storybook MCP/AI addon, Chromatic 배포, feature workflow story, DB/Supabase/권한/배포/실데이터 작업은 포함하지 않았다.

검증

  • npm run lint
  • npx tsc --noEmit
  • npm run docs:check
  • npm run build-storybook
  • npm run storybook -- --ci --smoke-test
  • 로컬 Storybook에서 Design System/UI/Button, Badge, Input sidebar와 preview 렌더링 확인
