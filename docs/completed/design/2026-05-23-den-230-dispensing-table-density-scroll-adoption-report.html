DEN-230 Dispensing Table Density Scroll Adoption

조제/처치 order table을 Project 12 shared contract의 첫 adoption surface로 전환했다. table은 compact density와 scroll layout을 명시하고, TanStack total size를 단일 min-width로 사용한다.

Density Behavior

  • density="compact" applies compact table row/header/cell tokens.
  • layout="scroll" keeps horizontal overflow inside the table container.
  • minWidth and visual table width are both derived from table.getTotalSize().
