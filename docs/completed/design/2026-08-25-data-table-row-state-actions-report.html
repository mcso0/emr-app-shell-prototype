구현 및 검증 완료

데이터테이블 행 상태·액션 노출 통합

병원관리 Order에서 모든 행의 작업 메뉴가 상시 노출되고, 열린 상세 drawer의 대상 행을 구분하기 어려웠던 문제를 공용 EmrDataTable 계약으로 정리했다.

변경 결과

  • 작업 컬럼에 always와 contextual 노출 정책을 추가했다. 기본값은 기존 동작을 보존하는 always다.
  • contextual 메뉴는 데스크톱 idle 상태에서 숨고 hover, 키보드 focus, 메뉴 열림, 선택 상태에서 나타난다. 터치와 좁은 화면에서는 항상 보인다.
  • 병원관리 Order와 조제/처치의 활성 행은 열린 drawer 대상에서 직접 계산하며, 체크박스 일괄 선택과 분리했다.
  • 고객관리와 구성원관리는 같은 공용 정책을 사용하고 고객관리의 로컬 reveal CSS는 제거했다.

범위와 비변경 영역

명시적 작업 버튼, 읽기 전용 테이블, Order 세트, 수납, 검사/영상, 감사 로그, 입원관리의 동작은 변경하지 않았다. DB/API, 권한, drawer 폼과 저장 로직도 범위 밖으로 유지했다.

검증

  • 집중 Playwright 10건 통과
  • ESLint와 TypeScript 검사 통과
  • Next.js와 Storybook production build 통과
  • 문서 링크, secret scan, diff 검사 통과

남은 운영 단계

구현 자체의 알려진 잔여 위험은 없다. production 반영은 저장소의 manual Release Check, Preview 확인, 승인 패킷과 rollback 후보 확인을 거쳐 진행한다.
