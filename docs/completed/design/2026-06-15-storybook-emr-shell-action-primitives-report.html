Storybook EMR Shell Action Primitives

EmrDialogShell, EmrRowActionMenu, EmrPageHeader를 Storybook에 추가했다. EMR product shell, row overflow action, page header 기준을 synthetic example로 확인할 수 있다.

변경 사항

  • Design System/EMR/EmrDialogShell story를 추가했다.
  • Design System/EMR/EmrRowActionMenu story를 추가했다.
  • Design System/EMR/EmrPageHeader story를 추가했다.

범위 밖

runtime component API 변경, feature workflow story, DB/Supabase/권한/배포/외부 연동은 포함하지 않았다.

검증

  • npm run lint 통과. 기존 5개 warning은 남아 있다.
  • npx tsc --noEmit 통과.
  • npm run docs:check 통과.
  • npm run build-storybook 통과. 기존 Storybook build warning은 남아 있다.
  • npm run storybook -- --ci --smoke-test 통과.
  • Storybook MCP 문서 노출 확인: design-system-emr-emrdialogshell, design-system-emr-emrrowactionmenu, design-system-emr-emrpageheader.
  • Storybook MCP focused story test 통과: design-system-emr-emrdialogshell--confirm, design-system-emr-emrrowactionmenu--default, design-system-emr-emrpageheader--default.

주의 사항

EmrDialogShell story는 shared Dialog root 안에서 shell을 렌더링한다. EmrRowActionMenu는 portal menu open 상태를 DOM API play function으로 확인한다.
