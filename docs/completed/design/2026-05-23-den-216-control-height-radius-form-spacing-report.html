Linear DEN-216 · Project 11 · Milestone 01 Token / Variant Foundations

Control Height, Radius, Form Spacing Variant Foundation

Input, Select, Button, Textarea, Field, SegmentedControl의 control text, radius, field gap을 EMR shared role로 묶었다. 기능, validation, 저장, 권한 동작은 변경하지 않았다.

대표 판단

기존 control height는 이미 --clair-control-height-*를 쓰고 있어 새 height token을 늘릴 필요는 없었다. 대신 emr-control-text, emr-control-text-compact, emr-control-radius, emr-field-gap, emr-field-group-gap을 추가해 radius와 text rhythm, form spacing을 shared rule로 묶었다.

Changed Variants

  • emr-control-text: default/lg/xl button, input, select, textarea control rhythm.

  • emr-control-radius: shared control radius using --emr-radius-control.
  • emr-field-gap and emr-field-group-gap: shadcn field spacing aliases.
