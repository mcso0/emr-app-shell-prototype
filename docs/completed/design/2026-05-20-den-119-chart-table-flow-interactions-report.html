2026-05-20 · Project 01-M2 · Table Interaction Flow

요약

진료/차트 오더 테이블에서 눌러도 반응이 없던 action affordance를 정리했다. 새 임상/청구 workflow를 추가하지 않고, 현재 UI-only 범위에서 후속 연결 예정임을 toast feedback으로 알려 사용자가 “고장난 버튼”으로 느끼지 않게 했다.

완료한 인터랙션

  • row action 이력 클릭 시 후속 상세 화면 연결 예정 toast를 표시한다.
  • row action 요청 클릭 시 요청 흐름은 후속 작업에서 연결된다는 toast를 표시한다.
  • 상단 Order 출력 클릭 시 문서/프린트 연결 범위임을 toast로 표시한다.
  • 상단 + Order와 table footer + Order 추가하기 클릭 시 오더 카탈로그 연결 범위임을 toast로 표시한다.
  • 수량 입력 오류 상태에는 title을 추가해 숫자 입력 필요성을 보조한다.
  • 삭제 icon button은 기존 비활성 조건을 유지하면서 마지막 오더 삭제 불가 title을 추가했다.

의도적으로 미룬 항목

  • 실제 오더 이력 상세 화면 연결
  • 실제 재요청/request workflow
  • 오더 카탈로그 기반 신규 오더 추가
  • 문서/프린트 출력 연결
  • 서버 저장, billing sync, audit persistence, role/server enforcement 변경
