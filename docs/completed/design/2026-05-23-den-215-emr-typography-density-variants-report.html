Linear DEN-215 · Project 11 · Milestone 01 Token / Variant Foundations

EMR Text Size, Leading, Density Variant Foundation

반복되는 EMR typography arbitrary utility를 먼저 shared role로 묶었다. 이번 변경은 화면 재디자인이 아니라, 후속 DEN-216~220이 같은 텍스트 리듬을 재사용할 수 있게 작은 token/utility foundation을 만든 작업이다.

대표 판단

text-[12px], text-[13px], leading-[18px], tracking-[0.3px] 같은 반복값은 개별 화면보다 src/components/emr/* 공유 surface에서 먼저 정리하는 것이 안전했다. 그래서 EMR typography variables와 utility classes를 추가하고 side panel, queue card, content history, dialog title, dense table surface에 우선 적용했다.
