DEN-132 개인 프로필 설정 UI 구조 개선 보고

개인 프로필 설정 화면의 field error, 저장 상태, layout intent를 정리해 로그인/워크스페이스 폼과 같은 UI 기준에 더 가깝게 맞췄다.

변경 내용

  • src/features/auth/personal-profile-settings.tsx의 field error 표시를 shadcn FieldError로 통일했다.
  • 저장 성공과 저장 실패 notice를 success/error tone으로 분리해 색상만으로 의미를 숨기지 않게 했다.
  • 저장 중에는 입력 필드, checkbox, 저장 버튼을 비활성화하고 버튼 문구를 저장 중으로 바꿨다.
  • 프로필 화면 grid class와 notice tone class를 local 상수로 모아 의도적인 responsive layout 제약을 확인하기 쉽게 했다.

범위 제외

실제 개인 프로필 persistence 정책, 계정 보안 설정, 비밀번호/MFA/identity provider, 권한/역할 정책은 변경하지 않았다. 현재 서버 PATCH와 browser/session 표시 상태 흐름은 그대로 유지했다.

검증

  • npx eslint src/features/auth/personal-profile-settings.tsx tests/auth.spec.ts 통과
  • npx tsc --noEmit 통과
  • npx playwright test tests/auth.spec.ts -g "profile" --reporter=line 통과

리뷰 포인트

저장 중 disabled 상태와 success/error notice tone이 화면 감각에 맞는지 확인하면 된다.
