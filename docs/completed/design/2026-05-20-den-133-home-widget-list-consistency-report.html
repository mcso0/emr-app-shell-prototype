DEN-133 홈 위젯 및 목록 UI 일관성 점검 리포트

2026-05-20 · Project 04-M2 · Home Widget/List Design-System Pass

요약

홈의 주요 위젯과 목록 패널이 각자 직접 만들던 card surface를 홈 전용 HomePanelCard로 모았다. 화면의 정보 구조, mock 데이터, 필터, 링크 동작은 유지했고, shadcn/ui Card 기반 표면을 재사용하도록 정리해 이후 홈 UI 오딧에서 기준점을 잡기 쉽게 만들었다.

일관성 개선

  • src/features/home/components/home-panel-card.tsx를 추가해 홈 패널용 card wrapper를 만들었다.
  • AlertsPanel, HomeWidgetCard, CompactFlowSummary, HospitalFlowBoard, MyWorkPanel의 outer card surface를 같은 wrapper로 통일했다.
  • 기존 밀도와 높이 기준을 보존하기 위해 wrapper 사용 시 gap-0, 기존 padding, 기존 min-height를 유지했다.
  • Badge, Button/link, SegmentedControl 사용은 기존 shadcn/EMR 패턴을 유지했다.

화면 리뷰 메모

  • 홈 대시보드의 위젯, 병원 흐름 요약, 병원 전체 흐름, 내 업무 패널의 card border/background/radius 기준이 더 명확해졌다.
  • 목록 내부 row, empty state, warning/critical status tone은 사용 맥락이 달라 이번 범위에서는 유지했다.
  • 필터 컨트롤은 이미 SegmentedControl을 쓰고 있어 별도 교체 없이 회귀 검증만 했다.

결정 또는 후속 검토

  • 홈 내부의 작은 list row와 Kanban workspace 내부 surface까지 동일 wrapper로 넓힐지는 후속 이슈에서 화면별 밀도 기준을 보고 결정하는 편이 안전하다.
  • 카드의 시맨틱 태그(section/aside/article)는 이번 정리에서 shadcn Card 기반 div로 수렴했다. 접근성 landmark가 필요해지면 공용 Card의 polymorphic 지원 여부를 별도 설계로 다루는 것이 좋다.

제외 범위

  • DB, Supabase, RLS, live persistence, server enforcement, live task operation은 변경하지 않았다.
  • dashboard metric, task state, role content semantics, permission policy는 변경하지 않았다.
  • 대형 IA 재설계나 홈 전체 레이아웃 재구성은 하지 않았다.
