요약

진료/차트 화면의 거대 module.tsx에서 순수 UI 조각과 Tiptap SOAP editor를 feature-local 컴포넌트로 분리했다. 화면 동작이나 저장/서버 경계는 바꾸지 않고, 차트 화면을 다음 이슈에서 더 안전하게 고도화할 수 있도록 읽기 단위를 줄이는 작업이다.

변경 내용

  • ChartSectionTitle을 src/features/chart/components/chart-section-title.tsx로 분리했다.
  • ChartLineTabGroup을 src/features/chart/components/chart-line-tab-group.tsx로 분리했다.
  • Tiptap 기반 SoapRichTextEditor와 toolbar/link popover 로직을 src/features/chart/components/soap-rich-text-editor.tsx로 분리했다.
  • src/features/chart/module.tsx는 기존 화면 조립과 상태 연결 중심으로 줄었고, 줄 수는 약 3518줄에서 3229줄로 감소했다.

화면 리뷰 메모

  • 환자 컨텍스트, 차트 이력 aside, SOAP/진단 grid, 오더 영역, action footer의 의도된 구조를 변경하지 않았다.
  • SOAP 선택 toolbar, bold/italic/list/link popover 동작은 기존 접근성 label과 affordance를 유지했다.
  • 오더 테이블 구조와 플로우는 DEN-121/DEN-119 범위로 남겼다.

주의 및 제외 범위

  • DB, Supabase, RLS, live persistence, server permission, billing sync, clinical data semantics는 변경하지 않았다.
  • 기존 src/features/chart/module.tsx에는 이 작업 전부터 다른 live persistence 관련 변경이 섞여 있었다. 이번 작업은 그 변경을 되돌리거나 확장하지 않았다.
