DEN-127 수납 테이블 및 결제 표면 정리 리포트

2026-05-20 · Project 05-M2 · Billing Table & Payment Surface Pass

요약

수납 화면의 청구 항목 table에서 흩어져 있던 고정 column width를 local column recipe로 모으고, 금액/수량 cell의 숫자 정렬과 overflow 처리를 정리했다. 결제 영역은 실제 결제 연동 없이 세션 전용 상태 변경이라는 점을 계속 드러내도록 안내/오류/action footer 표면을 작은 컴포넌트로 분리했다.

시각 변경

  • 청구 항목 table은 min-w-[720px]와 horizontal overflow wrapper를 사용해 좁은 폭에서 컬럼이 겹치지 않게 했다.
  • 단가, 할인, 청구금액은 tabular-nums와 whitespace-nowrap 기준으로 맞췄다.
  • 긴 청구 항목명은 table column 안에서 truncate되도록 조정했다.
  • 수납 우측 패널의 오류 메시지와 하단 결제 action footer를 작은 컴포넌트로 분리했다.

세션 전용 유지 범위

  • 실제 PG, 영수증, VAT 세부, 부분 결제 입력은 계속 미연동/미지원으로 남겼다.
  • 수납 완료, 미납 처리, 청구 확정은 기존 세션 전용 상태 변경 흐름을 유지한다.
  • invoice domain model, payment persistence, server validation, audit log persistence는 변경하지 않았다.

후속 검토

  • 수납 table column recipe가 다른 금액 table에서도 반복되면 shared EMR dense money table rule로 승격할 수 있다.
  • 실제 결제 모달이 생기기 전까지는 현재 right panel footer를 결제-facing action 기준으로 유지하는 것이 안전하다.
