DEN-276 · 2026-05-25 · Project 13 CLAiR EMR Table Sort & Filter Behavior

Final Sort / Filter Behavior Closeout

Project 13은 테이블 정렬과 필터를 같은 방식으로 쓰기 위한 기준을 정하고, 대표 테이블에 제한 적용한 뒤 QA까지 마쳤다. 결론은 명확하다. 헤더에는 정렬만 두고, 필터는 섹션 우측 Filter 버튼에서 여는 방식이 현재 제품 프로토타입에 맞는 기본 정책이다.

최종 정책

  • 테이블 헤더에는 단일 컬럼 정렬만 제공한다.
  • 필터는 테이블이 속한 섹션 header/action area의 Filter 버튼에서 연다.
  • 필터 조건이 있으면 버튼은 Filter N으로 조건 개수를 표시한다.
  • 필터 builder의 여러 조건은 AND로 적용한다.
  • builder footer에는 초기화, Apply filters, Close를 둔다.
  • checkbox, action, icon-only, summary, total, display-only 컬럼은 정렬/필터 대상에서 제외한다.
  • active chip row, saved view/filter, multi-sort, URL/storage persistence는 이번 프로젝트 범위 밖이다.
