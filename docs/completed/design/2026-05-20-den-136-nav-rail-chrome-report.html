DEN-136 App Shell Nav Rail 최적화 보고

Nav Rail의 반복 sizing/focus class를 local chrome recipe로 묶고, 메뉴 영역의 접근성 라벨을 명시했다.

변경 내용

  • src/shell/nav-rail.tsx에 rail root, item, icon frame class 상수를 추가해 48px rail과 32px item rhythm을 한 곳에서 관리하도록 했다.
  • module panel toggle, module link, action item의 hover/focus class 중복을 같은 recipe로 정리했다.
  • Nav rail에 aria-label="워크스페이스 주요 메뉴"를 추가했다.

의도적 예외

GNB icon별 픽셀 크기는 asset alignment를 맞추기 위한 값이라 module-nav-icons.tsx에 유지했다. Route semantics, panel open/close state, navigation search propagation은 변경하지 않았다.

검증

  • npx eslint src/shell/nav-rail.tsx tests/app-shell.spec.ts 통과
  • npx tsc --noEmit 통과
  • npx playwright test tests/app-shell.spec.ts -g "nav|side|module|shell" --reporter=line 통과
