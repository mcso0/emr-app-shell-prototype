필수 입력 인디케이터 공통화 결과

필수 입력 별표를 공통 EMR 컴포넌트와 Neutral 800 토큰으로 통일해 이후 색상 변경 지점을 하나로 줄였습니다.

요청 내용

보호자 등록 화면의 빨간 필수 표시를 Neutral 800으로 변경하고, 여러 화면에 흩어진 별표 구현을 공통 컴포넌트로 통합했습니다.

변경 결과

항목결과
공통 컴포넌트EmrRequiredIndicator 추가. 장식용 별표와 aria-hidden을 소유합니다.
색상 토큰--emr-form-required-indicator를 --clair-color-atomic-neutral-800에 연결했습니다.
적용 범위보호자·환자 등록, 접수, 프로필, 팝오버, 병원관리, 병원 기본설정의 기존 표시를 교체했습니다.
문서/Storybook디자인 시스템 규칙, 작업 항목, Storybook 스토리를 추가했습니다.

검증

신규 소스 계약 및 보호자 등록 브라우저 테스트는 2개 통과했습니다. 관련 접수 테스트는 9개 중 8개가 통과했고, 1개는 이번 변경과 무관한 기존 다이얼로그 제목 폰트 기대값 불일치로 실패했습니다.

Lint, TypeScript, production build, Storybook build, docs check, secret scan, diff check를 통과했습니다. Production build에는 기존 doc-reader.ts 파일 추적 경고가, Storybook build에는 기존 mdx 패턴·폰트·번들 크기 경고가 남아 있습니다.

범위 밖

필수 표시와 실제 필드의 required/aria-required 전파를 전 화면에 일괄 적용하는 작업, 에러·삭제·기본 액션 색상 변경, DB/API/권한 동작 변경은 포함하지 않았습니다.
