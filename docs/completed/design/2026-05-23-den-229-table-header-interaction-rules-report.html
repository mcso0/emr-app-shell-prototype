DEN-229 Table Header Interaction Rules

CLAiR EMR table header에서 sort/filter/menu affordance를 허용할 column role과 금지할 column role을 정의했다.

Column Role Matrix

  • static: checkbox, action, attachment, memo, warning/change, icon-only, summary.
  • sortable: date/time, amount, quantity, name, explicit status order, room number.
  • filterable: status, 담당자, category/type, department, source, modality.
  • menu: admin-heavy grids where column actions are explicitly scoped.
  • compound: multi-value cells; static until the data field is split.

Accessibility Notes

  • Sort/filter/menu affordance must be reachable by keyboard only when the role allows it.
  • Active state must be visible without hover.
  • Static headers must not expose hidden tab stops or fake hover states.
