UI 리팩토링 완료 기준

승욱이 리뷰 전에 기대해도 되는 것

  • 화면 리팩토링은 기존 workflow와 session-only 동작을 깨지 않아야 한다.
  • DB, Supabase, RLS, live persistence, server enforcement, payment, email, deploy, role/permission policy 변경은 UI 리팩토링에 섞이지 않아야 한다.
  • dialog, drawer, popover, icon button, table, tab, filter는 접근 가능한 label/title/focus 상태를 유지해야 한다.
  • 데스크톱과 필요한 경우 좁은 화면에서 텍스트 겹침, table overflow, side panel collapse, scroll boundary를 확인해야 한다.
  • 공통화한 것, feature-local로 남긴 것, 후속으로 넘긴 것을 한국어 결과 요약에 남겨야 한다.
