Storybook UI Primitive Fourth Batch

기존 UI primitive인 Card, Tabs, RadioGroup, Skeleton을 Storybook에 추가했다. 밀도 높은 EMR 화면에서 쓰는 content container, peer content switching, 단일 선택, loading placeholder 기준을 synthetic example로 확인할 수 있다.

변경 사항

  • Design System/UI/Card story를 추가했다.
  • Design System/UI/Tabs story를 추가했다.
  • Design System/UI/RadioGroup story를 추가했다.
  • Design System/UI/Skeleton story를 추가했다.
  • 새 Base UI-backed stories를 위해 Vitest optimizer include 목록을 갱신했다.

범위 밖

runtime component API 변경, feature workflow story, storybook/test helper migration, DB/Supabase/권한/배포/외부 연동은 포함하지 않았다.

검증

  • npm run lint 통과. 기존 5개 warning은 남아 있다.
  • npx tsc --noEmit 통과.
  • npm run docs:check 통과.
  • npm run build-storybook 통과. 기존 Storybook build warning은 남아 있다.
  • npm run storybook -- --ci --smoke-test 통과.
  • Storybook MCP 문서 노출 확인: design-system-ui-card, design-system-ui-tabs, design-system-ui-radiogroup, design-system-ui-skeleton.
  • Storybook MCP focused story test 통과: design-system-ui-card--default, design-system-ui-tabs--default, design-system-ui-radiogroup--default, design-system-ui-skeleton--default.

주의 사항

Tabs는 panel switching 확인을 위해 DOM API play function을 유지했다. RadioGroup은 Base UI 내부 hidden input 동작에 대한 취약한 DOM assertion을 피하기 위해 rendering story로 유지했다.
