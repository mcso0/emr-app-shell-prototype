DEN-249

UX/UI Research-First Workflow

2026-05-24 · Project 12 CLAiR EMR Table Density & Data Grid Ergonomics

반복 사용되는 UX/UI 패턴을 바로 구현하지 않고, 레퍼런스와 CLAiR 내부 유스케이스를 먼저 조사한 뒤 제안과 합의를 거쳐 구현하도록 운영 기준을 문서화했다.

What Changed

  • 신규 기준 문서 docs/design/system/ux-ui-research-before-implementation.md를 추가했다.
  • docs/_meta/intake-rules.md에 reusable UX/UI pattern 변경 시 research/proposal 이슈를 먼저 만들도록 라우팅 규칙을 추가했다.
  • docs/design/system/ui-refactor-dod.md에 Research-First Gate를 추가해 Human Review 전 확인 기준으로 연결했다.
  • DEN-250과 DEN-251 같은 테이블 header/text policy 조사 이슈가 구현 전에 보고서와 제안을 먼저 만들도록 기준을 고정했다.

Decision

Case Workflow
Reusable table/grid behavior Research report and CLAiR proposal before implementation
Toolbar, drawer, popover, command, tab, filter patterns reused across screens Research-first unless an approved design contract exists
One-off copy, spacing, icon, or regression fix No research issue required
Adoption of an approved design-system contract Implement directly within scoped issue

Why It Matters

CLAiR EMR은 동일한 UI 패턴이 여러 업무 화면에 반복된다. 조사 없이 한 화면에서 바로 구현하면 나중에 전체 화면으로 확산할 때 수정과 되돌림이 커진다. 이 기준은 테이블 정렬/필터/리사이즈, 텍스트 줄바꿈, 툴바 배치처럼 재사용성이 큰 UX/UI 작업을 더 안정적으로 진행하기 위한 운영 장치다.
