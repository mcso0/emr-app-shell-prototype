조사 요약

이름

이 UI는 advanced filter builder 또는 query builder다. 사용자는 rule을 만들고 group에서 AND/OR 관계를 정한다.

구조

  • Rule: field + operator + value
  • Group: combinator + rules/groups
  • Draft row: 미완성 조건, 적용 제외

동작

조건을 완성하면 자동 적용한다. 팝업 바깥 클릭, Escape, 상단 X로 닫힌다. footer는 Add filter와 Clear all만 둔다. 

type FilterRule = {
  id: string;
  field: "status" | "vet";
  operator: "is";
  value: string | string[] | null;
};

type FilterGroup = {
  id: string;
  combinator: "AND" | "OR";
  children: Array<FilterRule | FilterGroup>;
};

function isCompleteRule(rule: FilterRule) {
  return Boolean(rule.field && rule.operator && rule.value);
}
