DEN-405 전역 알림 dirty navigation guard 완료 보고서

전역 알림 source action이 현재 탭을 이동하기 전에 unsaved work를 확인하도록 guard를 추가했다. 사용자가 취소하면 현재 업무 화면과 drawer 상태를 유지하고, 확인하면 기존 source navigation 흐름으로 이동한다.

변경

  • notification navigation 전용 shell dirty flag를 layout store에 추가했다.
  • dirty 상태에서 route-backed source action을 누르면 지정 문구의 confirmation dialog를 표시한다.
  • 취소 시 현재 route, drawer, unread/badge 상태를 보존한다.
  • 확인 시 current-tab source route 이동과 drawer close를 실행한다.
  • source route가 없는 fallback detail은 dirty confirmation 없이 drawer 안에서 계속 표시한다.
  • Playwright에서 cancel/confirm 동작과 문구를 검증하는 테스트 브리지를 추가했다.

검증

  • npm run lint 통과. 기존 경고 4개는 유지된다.
  • npx tsc --noEmit 통과.
  • PLAYWRIGHT_BASE_URL=http://localhost:3333 npx playwright test tests/notification-toast.spec.ts tests/notification-fixtures.spec.ts tests/app-shell.spec.ts -g "notification" 통과: 21 passed.
  • npm run docs:check 통과.

제외 범위

전체 feature dirty-state 시스템 재설계, autosave, draft recovery, new-tab navigation, remote Supabase migration/RLS/live validation, provider delivery, external channel은 구현하지 않았다.
