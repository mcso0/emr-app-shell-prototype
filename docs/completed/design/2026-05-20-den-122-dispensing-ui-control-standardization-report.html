DEN-122 조제/처치 UI 컨트롤 표준화 리포트

2026-05-20 · Project 02-M1 · Dispensing/Treatment UI Controls

요약

조제/처치 작업 화면의 하드코딩 기본 컨트롤을 점검했고, 오더 테이블 담당자 셀에 남아 있던 네이티브 <select>를 기존 shadcn Select 컴포넌트로 교체했다. 담당 배정, 담당취소, 행 클릭으로 상세 패널 열기 흐름은 그대로 유지했다.

변경 내용

  • src/components/emr/emr-data-table.tsx의 담당자 선택 셀을 Select, SelectTrigger, SelectContent, SelectItem 기반으로 표준화했다.
  • 선택 트리거에는 담당자 이름을 직접 표시해 tech-sh 같은 내부 id가 화면에 드러나지 않도록 했다.
  • 드롭다운 트리거와 포털 콘텐츠 이벤트 전파를 막아 담당자 변경 시 오더 상세 drawer가 열리지 않도록 유지했다.
  • tests/app-shell.spec.ts의 담당자 셀 회귀 테스트를 네이티브 select API가 아닌 실제 사용자 클릭/옵션 선택 흐름 기준으로 갱신했다.

화면 리뷰 메모

  • 테이블 행 높이, 담당자 셀 폭, 선택 후 담당자명 표시 밀도는 기존과 같은 compact table 톤을 유지했다.
  • 오더 그룹의 담당하기, 조제중, 조제완료, 담당취소 액션은 기존 shadcn Button과 DropdownMenu 흐름을 유지했다.
  • 상단 PDF/출력/우측 패널 버튼, 오더 그룹 필터 탭, drawer 입력 필드는 이미 shadcn 또는 EMR 컴포넌트를 사용하고 있어 교체하지 않았다.

제외 및 유지 항목

  • DB, Supabase, RLS, live persistence, server permission, order lifecycle, business logic은 변경하지 않았다.
  • 새 src/components/ui/* 컴포넌트는 추가하지 않았다.

Agent Notes

English: Scan covered src/features/dispensing/**/*.tsx and the related local table component src/components/emr/emr-data-table.tsx. The remaining raw <button> is the TanStack column resize grip; it is intentionally local because it is a table layout affordance with pointer resize handlers, not a command button, and replacing it with a standard Button would add visual weight and risk resizing behavior. Existing group status actions, header actions, drawer fields, filter tabs, badges, and inputs already use shadcn/EMR primitives.
