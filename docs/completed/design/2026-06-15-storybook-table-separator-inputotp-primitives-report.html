Storybook Table Separator InputOTP Primitives

기존 UI primitive인 Table, Separator, InputOTP를 Storybook에 추가했다. structured data, subtle dividers, short code input 기준을 synthetic example로 확인할 수 있다.

변경 사항

  • Design System/UI/Table story를 추가했다.
  • Design System/UI/Separator story를 추가했다.
  • Design System/UI/InputOTP story를 추가했다.
  • input-otp를 Storybook Vitest optimizer include 목록에 추가했다.

범위 밖

runtime component API 변경, feature workflow story, 실제 초대/인증/신원 정보 사용, DB/Supabase/권한/배포/외부 연동은 포함하지 않았다.

검증

  • npm run lint 통과. 기존 5개 warning은 남아 있다.
  • npx tsc --noEmit 통과.
  • npm run docs:check 통과.
  • npm run build-storybook 통과. 기존 Storybook build warning은 남아 있다.
  • npm run storybook -- --ci --smoke-test 통과.
  • Storybook MCP 문서 노출 확인: design-system-ui-table, design-system-ui-separator, design-system-ui-inputotp.
  • Storybook MCP focused story test 통과: design-system-ui-table--default, design-system-ui-separator--horizontal, design-system-ui-inputotp--default.

주의 사항

InputOTP story는 controlled synthetic value와 no-op change handler만 사용한다. 실제 초대, 인증, 신원, 결제 코드는 Storybook에 넣지 않는다.
