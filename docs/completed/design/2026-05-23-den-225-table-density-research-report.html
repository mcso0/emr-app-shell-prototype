DEN-225 Table Density Research Report

작성일: 2026-05-23 · Linear: DEN-225 · Project 12 Table Density & Data Grid Ergonomics

요약

CLAiR EMR table UX는 compact / standard / comfortable density, fill / scroll layout contract, column role 기반 header interaction으로 나눠 구현해야 한다. 특히 scroll table은 header/body/row background/border가 같은 inner table width를 가져야 하며, 중간에서 끊기고 오른쪽 blank area가 생기면 blocker로 본다.

외부 리서치

자료핵심 인사이트CLAiR 적용
MUI row heightrow height와 density는 table-level concern이며 compact/standard/comfortable 모델을 제공한다.행 높이, header 높이, padding, text role을 하나의 density contract로 묶는다.
MUI layoutgrid는 parent dimensions가 없으면 올바르게 렌더링되지 않는다.scroll table wrapper와 inner table width를 명시한다.
MUI sorting / filteringsort/filter는 별도 feature로 다루며 column별 제어가 필요하다.모든 header를 interactive로 보이게 하지 않는다.
AG Grid compactness / column menucompactness는 theme parameter이고 column menu는 명시적 기능이다.density token과 menu affordance를 분리한다.
Ant Design Tablesize, scroll, fixed header/columns, sorter/filter를 table API로 분리한다.fill/scroll wrapper와 header role을 table contract로 문서화한다.
TanStack Tableheadless table은 logic/state를 제공하지만 DOM/styles는 제품이 소유한다.CLAiR가 markup, density, scroll containment, accessibility를 소유해야 한다.

결정

  • Density: compact(36/36), standard(44/40), comfortable(52/44)로 시작한다.
  • Layout: fill table과 scroll table을 구분한다.
  • Scroll: outer wrapper는 overflow를, inner table은 unbroken min-width를 소유한다.
  • Header: static, sortable, filterable, menu, compound role로 허용 affordance를 제한한다.
