DEN-401 전역 알림 badge/recipient rule 완료 보고서

shell badge가 전체 unread 수로 커지지 않도록 recipient ownership과 v0 badge 정책을 함께 적용하는 resolver를 구현했다. 이 규칙은 mock/local-first UX 규칙이며 server-side permission enforcement가 아니다.

조건

  • badge count는 recipient가 현재 사용자, active role, 또는 local role queue action owner로 매칭될 때만 가능하다.
  • 매칭된 알림도 unread && !archived && badge_count === true를 만족해야 shell badge에 포함된다.
  • badge_count: false reference row는 unread여도 badge에 포함되지 않는다.
  • role queue ownership 설명에는 현재 브라우저 local-first 제약을 남겼다.

변경

  • NotificationRecipientContext, resolveNotificationRecipientRule, shouldCountNotificationBadge를 추가했다.
  • direct user fixture를 하나 두어 active role과 직접 recipient를 테스트에서 구분할 수 있게 했다.
  • 기존 shell badge는 새 resolver 결과를 계속 사용한다.
  • fixture tests에 direct user, active role, role queue, reference row, archived/read row case를 추가했다.

검증

  • npm run lint 통과. 기존 경고 4개는 유지된다.
  • npx tsc --noEmit 통과.
  • PLAYWRIGHT_BASE_URL=http://localhost:3000 npx playwright test tests/notification-fixtures.spec.ts tests/app-shell.spec.ts -g "notification" 통과: 9 passed.
  • npm run docs:check 통과.

제외 범위

server-side permission enforcement, remote Supabase migration/RLS/live validation, 사용자 간 role queue read/archive 동기화, provider 발송, 외부 채널은 구현하지 않았다. Dedupe/update-bump와 toast stack은 후속 이슈 범위다.
