DEN-402 전역 알림 dedupe/update-bump 완료 보고서

동일 환자, 동일 오더, 동일 event의 반복 미확인 알림이 drawer row를 계속 늘리지 않도록 공통 dedupe/update-bump helper를 구현했다. 이 helper는 row와 toast가 같은 dedupe 정책을 공유할 수 있는 기반이다.

규칙

  • patientId + orderId + eventKey로 dedupe key를 만든다. order가 없는 이벤트는 patient와 event key로 만든다.
  • 같은 dedupe key의 기존 row가 unread이고 archived가 아니면 append하지 않고 update/bump한다.
  • update/bump는 기존 row ID와 read/archive state를 유지하고, 최신 preview/detail/time metadata와 bump count를 반영한다.
  • 다른 환자, 오더, event key는 별도 row로 append한다.
  • 기존 row가 read 또는 archived이면 과거 상태를 되살리지 않고 새 반복 알림을 append한다.

변경

  • createNotificationDedupeKey helper를 추가했다.
  • upsertNotificationByDedupeKey helper를 추가했다.
  • dedupe key 생성, unread bump, 다른 event append, read/archive 이후 append focused tests를 추가했다.

검증

  • npm run lint 통과. 기존 경고 4개는 유지된다.
  • npx tsc --noEmit 통과.
  • PLAYWRIGHT_BASE_URL=http://localhost:3333 npx playwright test tests/notification-fixtures.spec.ts tests/app-shell.spec.ts -g "notification" 통과: 12 passed.
  • npm run docs:check 통과.
