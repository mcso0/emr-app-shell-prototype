Table Density & Full-Width Grid Implementation Report

2026-05-23 · Project 12 CLAiR EMR Table Density & Data Grid Ergonomics

테이블이 넓은 화면에서도 좌측에 고정된 폭으로 남는 문제를 수정하고, 테이블 밀도 컨트롤의 위치와 라벨 정책을 모듈별 사용 맥락에 맞게 정리했다.

Implemented Changes

  • scroll 레이아웃 테이블은 고정 폭 대신 부모의 가로 영역을 채우도록 min-width: 100% 기반으로 정리했다.
  • TanStack 기반 EmrDataTable의 인라인 width 고정을 제거해 넓은 화면에서 테이블이 컨테이너 폭까지 확장되도록 했다.
  • 밀도 컨트롤은 visible text 밀도를 제거하고, 아이콘 전용 3단 컨트롤과 좁게 보기, 기본 보기, 넓게 보기 tooltip/aria-label을 적용했다.
  • 진료/차트, 임상병리검사, 영상검사, 조제/처치, 수납, 입원, 고객관리, 병원관리 테이블의 밀도 컨트롤 위치를 DEN-245 벤치마크 기준에 맞게 재배치했다.
  • 입원 화면의 중복 all 드롭다운을 제거하고, 상단 필터 행에 단일 공용 밀도 컨트롤을 배치했다.

Verification

  • npx tsc --noEmit: pass.
  • Playwright viewport checks at 1440px and 2048px: all target modules have zero visible 밀도 labels, expected density group count, and scroll tables filling the visible container width.
  • Inpatient-specific check: 입원 검색조건 copy/dropdown is absent, and one shared density selector is present.

Notes

Narrower clinical grids still retain horizontal scroll when their meaningful minimum column width is wider than the visible content area. This is expected: the fix is that the table grows with available space and no longer leaves unused blank width when the viewport is wider than the table's minimum.
