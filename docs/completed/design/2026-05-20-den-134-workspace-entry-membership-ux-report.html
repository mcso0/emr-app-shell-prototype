DEN-134 워크스페이스 진입/멤버십 UX 개선 보고

워크스페이스 생성과 구성원 초대 화면을 shared form 기준에 맞춰 정리하고, 권한/멤버십 정책은 그대로 보존했다.

변경 내용

  • src/features/auth/workspace-onboarding.tsx의 validation error를 shadcn FieldError로 통일했다.
  • 워크스페이스 생성 중에는 입력 필드를 disabled 처리해 중복 입력을 줄였다.
  • src/features/auth/workspace-membership-management.tsx의 초대 form을 FieldGroup, Field, FieldSet, FieldError 구조로 정리했다.
  • 초대 저장 중 email/title/department/role checkbox를 disabled 처리했다.
  • 멤버십 table empty row의 colSpan을 실제 6개 column과 맞췄다.

범위 제외

워크스페이스 permission policy, 실제 이메일 발송, 서버 멤버십 enforcement, auth/session model, DB/Supabase/RLS 작업은 변경하지 않았다.

검증

  • npx eslint src/features/auth/workspace-onboarding.tsx src/features/auth/workspace-membership-management.tsx tests/auth.spec.ts 통과. 기존 hook dependency warning은 유지된다.
  • npx tsc --noEmit 통과
  • npx playwright test tests/auth.spec.ts -g "workspace|invitation|member" --reporter=line 통과

리뷰 포인트

초대 form의 field 간격과 저장 중 disabled 상태가 병원관리 화면 안에서 자연스러운지 확인하면 된다.
