병원관리·고객관리 Empty State 화면 적용 결과

CDS.V2의 lg / md(mg) / sm 계약을 실제 누락 화면에 적용하고, 기존 정상 적용 화면의 사이즈를 명시했습니다.

요청 내용

고객관리 삭제 이력과 병원관리 테이블·하위 목록에서 공통 Empty State 누락 및 사이즈 불일치를 확인하고 수정했습니다.

변경 결과

영역적용사이즈
고객관리 삭제 이력공통 Empty State 적용, 검색 결과 없음과 실제 데이터 없음 분리md / mg
병원관리 Order·감사 로그·구성원테이블 본문 공통 Empty State 적용 및 필터 결과 문구 분리md / mg
운영시간·역할·근무표 하위 목록카드·드로어 내부의 작은 빈 목록을 공통 상태로 통일sm
근무표 전체 데이터 없음근무표 콘텐츠 상태를 공통 상태로 통일lg

의도적으로 유지한 상태

로딩, 권한 제한, API 읽기 실패, 저장 실패, 미구현 메뉴는 Empty State로 바꾸지 않았습니다. 이 상태들은 로딩·알림·권한 안내가 의미상 더 정확합니다.

아이콘 영역과 글자 색상은 기존 black-alpha-4, black-alpha-48, black-alpha-36 토큰을 그대로 사용합니다.

검증

새 Empty State 회귀 테스트 4개와 고객관리·감사 로그·병원관리 관련 Playwright 테스트 43개를 통과했습니다. TypeScript와 변경 파일 대상 ESLint도 통과했습니다.

브라우저 안정화 캡처에서 고객 삭제 이력과 감사 로그가 data-size="md"로 렌더링되는 것을 확인했습니다.
