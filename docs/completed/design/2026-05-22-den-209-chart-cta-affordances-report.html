Chart CTA Affordances 보고서

차트 작성완료 확인을 EmrDialogShell variant="confirm" 기준으로 맞추고, 차트/Order 미연결 기능을 EmrInlineAlert severity="info"로 안내하도록 정리했다. 사용자는 상태 변경 CTA와 unavailable CTA를 화면에서 다른 규칙으로 구분할 수 있다.

Human Review 준비 앱 화면 반영

변경 사항

  • 차트 작성완료 dialog를 공통 EmrDialogShell confirm variant로 옮겼다.
  • 작성완료 preflight에 환자/보호자, 차트번호, 진단명/오더 수, 차트 상태, SOAP 상태를 표시한다.
  • 작성완료 저장 실패 시 dialog 내부에 EmrInlineAlert severity="error"와 재시도 action을 보여준다.
  • 차트 공유, Order 출력, + Order, row 이력, row 요청을 unavailable action으로 분류하고 persistent info alert를 남긴다.
