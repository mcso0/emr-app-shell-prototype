DESIGN-SYSTEM-PR-086 · IMPLEMENTATION RESULT

고객관리 동물 테이블 고정 컬럼 구현

동물명을 왼쪽에 유지하면서 환자코드 이후 정보를 가로로 탐색할 수 있도록 구현했다.

origin/main 머지 · 프로덕션 배포 검증 완료

무엇이 바뀌었나

  • 동물명은 184px 고정 컬럼이 되었고 환자코드는 첫 번째 스크롤 컬럼으로 이동했다.
  • 동물명에 28px 공용 동물 아바타 fallback을 추가했다.
  • 환자코드, 보호자명, 상태, 수신 여부, 등록일시 등 모든 환자 데이터는 한 줄로 유지된다.
  • 환자코드는 코드 형태, 상태는 배지, 수신 여부는 아이콘과 텍스트가 있는 배지로 구분했다.
  • 보호자 테이블은 같은 렌더러를 사용하지만 비고정형으로 유지했다.

최신 main과의 통합

최신 origin/main의 고객 테이블은 공용 렌더러와 컬럼 정의로 이미 분리되어 있었다. 이전 단일 파일을 되돌리지 않고 customer-data-table과 customer-table-columns에 기능을 이식해 보호자 목록과 content-top-slot 개선을 보존했다.

구현 선택

새 그리드 패키지를 추가하지 않고 저장소에 이미 설치된 @tanstack/react-table의 row, visibility, sizing, column pinning 상태를 사용했다. 가로 스크롤은 기존 공용 Table layout="scroll" 컨테이너 하나만 소유한다.
