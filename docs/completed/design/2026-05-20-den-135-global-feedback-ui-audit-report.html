DEN-135 전역 피드백 UI 점검 보고

Loading, empty, error, toast, confirmation UI의 현재 기준을 문서화했다. shared primitive code 변경은 만들지 않았다.

변경 내용

  • docs/design/system/global-feedback-ui-audit.md를 추가했다.
  • docs/design/system/README.md에 새 audit 문서를 연결했다.
  • Skeleton, Sonner toaster, FieldError, EmrConfirmDialogContent의 현재 사용 기준과 후속 후보를 정리했다.

범위 제외

Error tracking, server error architecture, persistence/audit logging, workflow behavior changes는 다루지 않았다.

검증

  • npm run docs:check 통과
