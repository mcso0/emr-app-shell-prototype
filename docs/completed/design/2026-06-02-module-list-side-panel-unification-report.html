병원관리 기준 하위 목록 사이드패널 공통화

2026-06-02 · DESIGN-SYSTEM-PR-042

요청과 결과

병원관리와 고객관리 사이드 패널을 업무 큐가 아닌 하위 목록 탐색 패널로 통일했다. 병원관리 UI를 기준으로 고객관리의 하위 목록, 카운트, 후속 메뉴 표현을 맞췄고 두 화면이 같은 공유 컴포넌트를 사용하도록 정리했다.

주요 변경

  • EmrModuleListSidePanel 공유 컴포넌트를 추가했다.
  • 고객관리의 동물/보호자/삭제 목록에 카운트 배지를 붙였다.
  • 고객관리의 스케줄/발송/서류/CS/진료의뢰 영역은 top-level disabled 후속 메뉴로 정리했다.
  • 병원관리의 Order 관리 그룹, leaf 선택, 카운트, Order 세트 후속 배지를 공유 컴포넌트로 옮겼다.
  • 새 패키지 없이 기존 obra-icons-react 래퍼를 확장해 반복되던 파일 아이콘을 의미별 아이콘으로 교체했다.

범위 밖

  • DB, Supabase, RLS, 서버 권한, live persistence는 건드리지 않았다.
  • 고객관리의 스케줄/발송/서류/CS/진료의뢰 실제 기능은 구현하지 않았다.
  • 업무 큐형 사이드패널은 이번 공통화 대상이 아니다.

검증 상태

  • npx tsc --noEmit 통과.
  • npm run lint -- --ignore-pattern '.worktrees/**' 통과. 기존 경고 4개는 남아 있다.
  • npm run docs:check 통과.
  • 브라우저 QA에서 고객관리 후속 메뉴/카운트와 병원관리 Order 관리 패널을 확인했다.
  • tests/customer.spec.ts tests/hospital-admin.spec.ts tests/app-shell.spec.ts focused Playwright 50개가 통과했다.
