Product Design 결정 보고서: 범위 숏컷 + 상세 필터

이 보고서는 DEN-435의 탭/밀도 기준과 DEN-436 대기열 필터·정렬·TASK 액션 방향을 Product Design 관점에서 다시 정리한 시각 시안이다. 캡쳐의 전체 / 예약 / 외래는 상세 필터가 아니라 자주 쓰는 범위 숏컷으로 보고, 아래 필터 아이콘과 역할을 분리한다.

Product Design 추천: 상단은 빠른 범위 숏컷, 아래 아이콘은 상세 필터. 즉 전체 / 예약 / 외래는 유지하고, 문진 완료, 담당 미정, 대기 15분 이상 같은 조건만 필터 아이콘에서 설정한다.

0. 확정해야 할 사안

아래 5개만 결정하면 DEN-436 대기열 화면 구현 방향이 바로 정해진다. 각 사안은 실제 화면에서 어떻게 보이는지 작은 시안으로 비교했다. 초록 테두리는 루멘 추천안, 붉은 테두리는 피하고 싶은 안이다.

4. 피해야 할 방향과 선택할 방향

피해야 할 방향 shortcut expands into filter tabs

빠른 범위 숏컷에 상태/담당/density까지 붙으면, 상단이 다시 복잡한 필터바가 된다.

선택할 방향 scope shortcut + detail filter

전체/예약/외래는 빠른 범위, Filter는 상세 조건, Sort는 순서, 표시 옵션은 보기 설정으로 분리한다.

결정 요약

Scope Shortcut 전체/예약/외래는 자주 쓰는 빠른 범위 숏컷으로 유지하고, 상세 조건과 구분한다.
Density 자주 쓰는 테이블은 icon segmented selector. 좁거나 복잡한 toolbar는 dropdown 허용.
Queue UX 상세 Filter, sort, view options는 toolbar에 역할별로 분리하고, TASK 더보기는 card/action 근처 floating menu로 정리.
