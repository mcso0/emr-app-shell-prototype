DEN-234 Project 12 Table UX Closeout

Project 12 CLAiR EMR Table Density & Data Grid Ergonomics를 A+ 후보 상태로 closeout한다. 테이블 밀도, 내부 가로 스크롤, header interaction 역할 기준이 source doc과 runtime contract로 정리됐고, 대표 EMR table surfaces에 high-confidence adoption이 적용됐다.

비개발자용 요약

조제/처치에서 보였던 “테이블이 중간에서 끊기는” 문제를 공통 table 규칙으로 해결했다. 이제 넓은 테이블은 화면 전체를 밀어내지 않고 table 안에서만 가로 스크롤되며, 좁게/기본/넓게 밀도 기준도 일관된 토큰으로 관리된다.

A+ Candidate Verdict

  • Density model: pass. compact / standard / comfortable가 token과 TypeScript contract로 정의됐다.
  • Scroll containment: pass. adopted scroll tables use explicit layout and minWidth contracts.
  • Header interaction rules: pass. static/sortable/filterable/menu/compound role rules are documented and typed.
  • Responsive QA: pass. 21 screenshot captures across 1440, 1280, 1024 had zero document-level horizontal overflow blockers.
  • Final status: A+ table UX candidate, pending Seungwook approval before any Linear Done transition.
