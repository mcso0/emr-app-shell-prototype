DEN-131 입원 테이블/상태 배지 표준화 리포트

2026-05-20 · Project 06-M2 · Inpatient Table & Status

요약

입원 현황판의 병동 테이블과 상태/주의 배지를 같은 규칙으로 읽히도록 정리했다. 긴 진단명과 메모가 테이블 폭을 흔들지 않게 하고, 좁은 화면에서는 가로 스크롤로 안정적으로 보이게 유지했다.

변경 내용

  • 입원 table column 폭을 local recipe 상수로 모아 관리하게 했다.
  • table을 table-fixed로 맞추고 진단명/입실 메모는 predictable truncate와 title을 적용했다.
  • 입원 상태, 주의 tag, 요약 card tone을 semantic EMR status tone 이름으로 정리했다.
  • EmrStatusBadge는 현재 label 기반 범위가 좁아 inpatient에는 적용하지 않고, local mapper 유지로 결정했다.
  • focused Playwright 테스트에 table recipe와 overflow 확인을 추가했다.

유지한 범위

row 선택, 상세 drawer, 검색, 입원실 그룹 필터, 기준일 선택, 퇴실 버튼 mock 동작은 유지했다. 입원 lifecycle persistence, 퇴실 workflow 구현, 진단/병동 데이터 모델, 서버 검증, audit log, Supabase/DB/RLS는 변경하지 않았다.

Human Review 체크포인트

  • 입원 현황판은 조밀한 표가 맞는 화면이라 고정 min-width를 유지했다.
  • 입원 상태 배지는 아직 feature-local mapper가 더 안전하다.
  • 퇴실 실제 workflow와 저장 구조는 별도 제품/DB 이슈로 분리해야 한다.
