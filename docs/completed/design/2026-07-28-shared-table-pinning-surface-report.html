DESIGN-SYSTEM-PR-087 · 2026-07-28

공통 테이블 고정 컬럼 수정 결과

가로 스크롤 콘텐츠가 왼쪽 고정 컬럼 안으로 비치던 문제를 공통 테이블 계층에서 막고, 동물명 헤더와 행 텍스트 기준선을 맞췄습니다.

검증 완료 · 검토 대기

요청과 해결

  • 고정 셀이 행의 투명 배경을 상속하던 구조를 제거하고, 기본·호버·선택· 로딩 상태마다 불투명 시맨틱 표면을 직접 칠하도록 변경했습니다.
  • 고정 위치, z-index, 좌·우 오프셋, 경계 그림자를 공통 Table primitive로 이동했습니다.
  • 동물명 헤더에는 기존 28px 아바타와 8px 간격을 합친 36px 메타데이터 오프셋을 적용했습니다.

측정 결과

38px → 0px 동물명 헤더와 행 이름의 가로 차이
2px 제목/검색과 행 이름의 가로 차이
0px 1900·1280·1024px 문서 가로 오버플로

1900px에서 제목/검색은 x=419, 동물명 헤더와 행 이름은 모두 x=417로 측정됐습니다. 고정 헤더는 세 검증 폭 모두 스크롤 컨테이너 왼쪽에서 1px 이내를 유지했습니다.

변경 영역

  • 공통: src/components/ui/table.tsx, src/components/emr/table-pinning.ts, src/app/globals.css, Table Storybook
  • 고객관리: 데이터 테이블, 컬럼 헤더, 컬럼 메타데이터, 고객 Playwright 회귀 테스트
  • 문서: 테이블 UX 계약, UI debt inventory, PR-087 업무 항목

검증

  • Secret scan 3480개 파일, docs check 886개 문서 통과
  • ESLint, TypeScript 통과
  • Table Storybook 5/5, 고객 Playwright 15/15 통과
  • Storybook build, Next production build 통과
  • 기본·호버·선택·로딩·보호자 화면과 1900·1280·1024px 시각 QA 통과

범위와 남은 사항

데이터, 검색, 정렬, 필터, 선택, drawer, API, 권한, Supabase, 의존성은 변경하지 않았습니다. 다른 테이블은 실제로 고정 컬럼을 도입할 때 이 공통 계약을 사용하면 됩니다. 아직 push, PR, merge, 배포, production 변경은 하지 않았습니다.

Storybook의 기존 MDX·폰트·lottie·chunk 경고와 Next의 기존 NFT tracing 경고는 남아 있지만 이번 변경으로 새 오류는 발생하지 않았습니다.
