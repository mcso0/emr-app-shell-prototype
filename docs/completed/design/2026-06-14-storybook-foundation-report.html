Storybook Foundation

CLAiR EMR 디자인시스템을 Storybook에서 볼 수 있는 첫 기반을 추가했다. 이번 단계는 컴포넌트 카탈로그 완성이 아니라, Storybook이 앱과 같은 CSS, 폰트, 토큰 기준으로 뜨는지 확인하는 초기 설치 작업이다.

변경 사항

  • Storybook 10과 Next.js Vite framework를 설치했다.
  • npm run storybook, npm run build-storybook 스크립트를 추가했고 telemetry는 비활성화했다.
  • .storybook/preview.tsx에서 src/app/globals.css를 불러와 EMR token, Tailwind, Pretendard 기준을 공유하게 했다.
  • Storybook docs와 Vitest addon 기반을 추가했다.
  • 자동 생성된 예제 story 파일은 CLAiR 디자인시스템과 무관해 제거했다.

범위 밖

Storybook MCP/AI addon, Chromatic 배포, 실제 컴포넌트 story 작성, 업무 화면 story 작성, DB/Supabase/권한/배포 작업은 포함하지 않았다.

검증

  • npx eslint .storybook/main.ts .storybook/preview.tsx vitest.config.ts vitest.shims.d.ts eslint.config.mjs 통과
  • npm run build-storybook 통과
  • npm run storybook -- --ci --smoke-test 통과
  • npm run lint 통과: 기존 warning 6개 남음
  • npx tsc --noEmit 통과

현재 story 파일이 없다는 warning은 의도된 상태다. 다음 단계에서 실제 디자인시스템 컴포넌트 story를 추가하면 사라진다. 별도 Vite 앱인 lottie-ai-chart-writing/는 루트 Next.js 검증 대상에서 제외했다.
