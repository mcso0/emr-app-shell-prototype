2026-05-20 · Project 03-M1 · Lab/Imaging Component Boundary

요약

임상병리와 영상 판독 화면에 중복으로 존재하던 상태 액션 UI를 feature-local 컴포넌트로 분리했다. 검사중/판독중, 완료, 담당취소, 담당하기 흐름은 그대로 유지하면서 모듈 본문에서 반복되던 shadcn Button/DropdownMenu 조합을 한 곳으로 모았다.

변경 내용

  • src/features/lab-imaging/components/status-action.tsx에 LabImagingStatusAction을 추가했다.
  • LabStatusAction과 ImagingStatusAction의 중복 구현을 제거하고, 라벨/상태값만 넘겨 같은 feature-local 액션 컴포넌트를 재사용하도록 바꿨다.
  • src/features/lab-imaging/module.tsx의 상태 액션 관련 import와 중복 로직을 정리했다.
  • 검사/판독 assignment store update, URL/query 기반 detail 선택, queue/history/right panel 렌더링은 변경하지 않았다.

화면 리뷰 메모

  • 검사중/판독중 split button의 색상, 높이, dropdown menu 폭, 담당취소 항목은 기존 화면과 동일하게 유지했다.
  • 검사완료/판독완료 disabled 버튼과 담당하기 primary action의 문구 및 아이콘 배치는 변경하지 않았다.
  • 임상병리 결과 입력, 장비 수신내역, 영상 판독/종합소견, attachment/media 영역은 이번 경계 정리에서 레이아웃을 바꾸지 않았다.
