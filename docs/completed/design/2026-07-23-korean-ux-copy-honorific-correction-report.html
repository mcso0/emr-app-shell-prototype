CLAiR EMR 존댓말 교정 결과

사용자에게 노출되던 명확한 반말을 존댓말로 교정했습니다. 진료·접수·수납 등 기존 업무 동작과 권한, 데이터, 오류 복구 흐름은 변경하지 않았습니다.

Human Review 준비 완료

적용한 임시 기준

시스템 상태·설명 합니다체
사용자 행동 요청 ~해 주세요
확인 질문 ~하시겠습니까?
이번 작업 제외 정상적인 해요체 전면 통일, 용어 사전, 임상 문구 원칙, 사용자 작성 기록

변경 범위

  • Shell 검색, CLAiR Docs, PRD viewer, 구성원 관리
  • 접수, 고객관리, 차트, 수납, Home 운영 안내
  • 병원 근무표 v1·v2, 데모 세션 초기화, 공통 inline alert 예시
  • 정확한 화면 문구를 검증하는 테스트
  • 새 반말 문구 유입을 막는 npm run ux-copy:check

검증 결과

  • 존댓말 검사, TypeScript, ESLint, 문서, 시크릿, diff 검사 통과
  • 프로덕션 빌드 통과
  • 집중 Playwright 15개 중 14개 통과
  • 접수 카드 메뉴 테스트 1개는 Escape 후 메뉴 재오픈 단계에서 타임아웃됐으며, 변경 전 origin/main에서도 같은 줄에서 재현됐습니다. 교정된 문구 검증 단계에는 도달하지 않았습니다.

남은 범위

기존의 정상적인 해요체를 모두 합니다체로 통일할지, 개발 용어를 사용자 언어로 바꿀지, 오류·빈 상태·임상 안내의 구조를 어떻게 표준화할지는 다음 UX 라이팅 원칙 작업에서 결정합니다.
