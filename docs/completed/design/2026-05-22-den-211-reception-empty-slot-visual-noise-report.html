Reception Empty Slot Visual Noise 보고서

접수 캘린더 빈 시간 슬롯의 반복 CTA와 plus 표시를 기본 상태에서 제거하고, hover와 keyboard focus에서만 명확한 + 접수 affordance가 드러나도록 정리했다. 기존 사용자는 캘린더 빈 영역을 이미 조작 가능한 공간으로 이해하므로, 기본 스캔 상태에서는 예약 카드와 시간축을 방해하지 않는다.

Human Review 준비 앱 화면 반영

변경 사항

  • 공통 빈 슬롯 CTA인 EmptyReceptionSlotButton을 추가해 일/주 캘린더가 같은 hover, focus, icon, label 규칙을 사용하게 했다.
  • 기본 상태에서는 빈 슬롯 affordance wrapper를 숨겨 캘린더 격자 자체만 보이게 했다.
  • hover와 keyboard focus에서는 배경, border, + 접수 label이 함께 드러나 접수 가능 상태를 명확히 보여준다.
  • 접수 dialog를 열었다가 취소한 직후에는 underlying slot의 stale hover/focus affordance가 남지 않도록 다음 실제 pointer movement 전까지 빈 슬롯 hover를 억제했다.
  • 진료 접수 dialog의 환자 검색을 두 필드 구조에서 단일 검색 input + 결과 listbox 구조로 통합했다.
  • 대기열에서 재사용되는 EmrSidePanelCollapsibleGroup 카드 목록 간격을 8px로 표준화했다.
  • 화면별 override로 처리했던 진료/차트 대기열 간격은 제거하고, 공통 대기열 그룹 기본값으로 흡수했다.
  • 빈 슬롯 클릭 시 기존 진료 접수 dialog가 열리는 동작과 drawer 정리 동작은 유지했다.
  • Playwright에서 기본, hover, focus 상태와 dialog 진입을 함께 검증했다.

A등급 기준에 주는 효과

  • UXA-01: 캘린더의 정보 밀도를 낮춰 실제 예약/접수 카드가 더 먼저 읽힌다.
  • UXA-02: 일/주 빈 슬롯 CTA가 같은 shared component와 tokenized color/spacing 규칙을 따른다.
  • UXA-04: 접수 생성 행동은 hover/focus에서만 명확히 드러나고, 기본 스캔 상태에서는 과잉 CTA나 plus 반복을 만들지 않는다.
  • UXA-05: 환자 검색은 입력과 선택을 한 컨트롤로 합쳐 사용자가 같은 목적의 필드 두 개를 해석하지 않아도 된다.
  • UXA-06: keyboard focus 상태를 시각적으로 구분하고 Playwright로 회귀 검증했다.
  • UXA-07: 대기열 카드 간격은 재사용 그룹 컴포넌트에서 8px로 통일해 화면별 카드 밀도 흔들림을 줄였다.

접근성 및 상호작용

  • aria-label로 빈 슬롯의 시간/담당의 맥락을 제공한다.
  • hover가 없는 키보드 사용자를 위해 focus-visible 상태에서도 라벨과 border가 표시된다.
  • dialog close 직후 반환 focus나 overlay 아래 hover가 시각적 잔상으로 보이지 않게 억제한다.
  • 환자 검색 결과는 listbox/option 역할로 노출하고, 선택 결과는 같은 input 값으로 반영한다.
  • 기존 data-testid 체계를 유지해 빈 슬롯 선택 회귀 테스트가 안정적으로 동작한다.
