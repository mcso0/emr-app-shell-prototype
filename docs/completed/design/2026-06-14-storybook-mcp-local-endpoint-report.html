Storybook MCP Local Endpoint

Storybook에 MCP addon을 붙여 로컬 AI context endpoint를 열었다. 이제 호환되는 agent는 로컬 Storybook에서 컴포넌트 문서, story, manifest, story test 도구를 읽을 수 있는 기반을 갖췄다.

변경 사항

  • @storybook/addon-mcp를 dev dependency로 추가했다.
  • .storybook/main.ts에 MCP addon을 등록했다.
  • docs/design/system/storybook-operating-rules.md에 로컬 MCP 운영 규칙을 추가했다.
  • 새 work item DESIGN-SYSTEM-PR-051를 Human Review 상태로 기록했다.

범위 밖

Codex/Claude/Cursor/VS Code 같은 agent의 전역 설정 변경, MCP endpoint publish/share, Chromatic 배포, 원격 접근, 컴포넌트 API 변경, 신규 story 추가, DB/Supabase/권한/배포/실데이터 작업은 포함하지 않았다.

검증

  • npm run lint
  • npx tsc --noEmit
  • npm run docs:check
  • npm run build-storybook
  • npm run storybook -- --ci --smoke-test
  • http://127.0.0.1:6006/mcp 로컬 endpoint 확인
  • MCP JSON-RPC initialize 응답 확인
  • MCP tools/list에서 documentation, preview, story-test 도구 노출 확인
  • MCP run-story-tests focused 실행으로 design-system-ui-button--default 통과 확인
  • http://127.0.0.1:6006/manifests/components.json manifest 확인
