DEN-138 Global Command Palette 정리 보고

통합 검색의 mock search/navigation semantics는 유지하면서 dialog와 result row chrome을 local recipe로 정리했다.

변경 내용

  • src/shell/global-command-palette.tsx에 command dialog, result row, result icon, result badge class 상수를 추가했다.
  • 검색 결과 리스트 영역에 aria-label을 추가해 영역 의미를 명확히 했다.
  • Command result는 기존 테스트와 사용자 interaction contract를 지키기 위해 button semantics를 유지했다.

범위 제외

Real global search API, search indexing architecture, route/workflow behavior, permission-filtered search result는 변경하지 않았다.

검증

  • npx eslint src/shell/global-command-palette.tsx tests/app-shell.spec.ts 통과
  • npx tsc --noEmit 통과
  • npx playwright test tests/app-shell.spec.ts -g "global command" --reporter=line 통과

후속 후보

검색 result row와 badge는 향후 다른 EMR search surface가 생기면 src/components/emr/* 승격 후보로 다시 평가하면 된다.
