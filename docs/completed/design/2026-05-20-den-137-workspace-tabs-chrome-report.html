DEN-137 워크스페이스 탭 최적화 보고

워크스페이스 탭의 시각 chrome class를 local recipe로 정리했고, 탭 history/store semantics는 변경하지 않았다.

변경 내용

  • src/shell/workspace-chrome-tabs.tsx에 tab max width, button, close button, icon frame, tooltip class 상수를 추가했다.
  • active/inactive tab, tooltip, close control의 반복 class를 같은 이름의 recipe로 모았다.
  • 긴 title truncate, close button hover/focus reveal, 새 탭 버튼 동작은 그대로 유지했다.

범위 제외

Tab store architecture, persisted tabs, Electron/WebContents, route workflow redesign은 변경하지 않았다.

검증

  • npx eslint src/shell/workspace-chrome-tabs.tsx src/shell/workspace-tabs-bar.tsx tests/app-shell.spec.ts 통과
  • npx tsc --noEmit 통과
  • npx playwright test tests/app-shell.spec.ts -g "workspace tabs|workspace tab" --reporter=line 통과
