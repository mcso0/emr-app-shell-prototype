DEN-120 조제/처치 폼 및 테이블 표준화 리포트

2026-05-20 · Project 02-M2 · Forms & Tables

요약

조제/처치 drawer의 필드 라벨 구조와 오더 테이블의 빈 상태를 기존 shadcn/EMR 패턴에 맞춰 정리했다. 화면의 업무 흐름, 오더 상태 변경, 담당자 배정, session-only 동작은 변경하지 않았다.

변경 내용

  • DispensingDrawerField를 추가해 drawer의 라벨과 입력 필드를 Label + Input 조합으로 연결했다.
  • 읽기 필드와 용량 입력에 안정적인 id/htmlFor 연결을 부여해 접근성과 폼 구조를 개선했다.
  • EmrDataTable에 행이 없을 때의 테이블 빈 상태를 추가했다.
  • 오더 그룹 필터 결과가 비었을 때 표시할 그룹 빈 상태를 추가했다.

화면 리뷰 메모

  • drawer의 라벨 크기, 입력 높이, footer action 정렬은 기존 dense workspace 톤을 유지했다.
  • 테이블 빈 상태는 실제 행 영역 안에 배치해 헤더/컬럼 구조가 유지되도록 했다.
  • 오더 그룹 빈 상태는 필터 영역 아래의 작업 영역에만 노출되며, 정상 데이터가 있을 때는 기존 UI와 동일하다.
  • 검증/에러 메시지는 현재 조제 drawer가 server submit form이 아닌 session-only 편집 표면이라 새로 만들지 않았다.

제외 범위

  • DB, Supabase, RLS, live persistence, server permissions, API submit shape, order lifecycle는 변경하지 않았다.
  • 공용 table system 자체를 재설계하지 않았다.
