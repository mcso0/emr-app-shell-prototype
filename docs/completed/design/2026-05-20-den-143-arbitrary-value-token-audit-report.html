Arbitrary Tailwind 값 및 토큰 승격 후보 오딧

핵심 요약

가장 중요한 styling debt는 색상보다 typography와 dense UI rhythm이다. text-[12px], text-[13px], text-[11px]가 압도적으로 많고, side-panel badge/meta row의 높이·line-height·tracking 값도 반복된다. 반면 table column width와 calendar/grid 값은 업무 화면 가독성을 위한 의도적 local 제약일 가능성이 높아 기계적으로 제거하면 안 된다.

우선순위 후보

  • P1: dense typography role 정의 또는 component class 흡수
  • P1: side-panel badge/meta rhythm을 EMR 컴포넌트가 소유하도록 정리
  • P1: 남은 direct Clair sky selected surface를 EMR selected/info alias로 교체
  • P2: command palette shadow/elevation을 shell-local constant 또는 EMR elevation alias 후보로 정리
  • P2: table column width는 토큰화보다 화면별 의도와 overflow wrapper를 문서화

결정 필요 사항

지금은 audit-only라 추가 결정은 없다. 단, 후속 구현 이슈에서 새 --emr-* 토큰명을 추가하려면 그때 승인을 받는 편이 좋다.

  • 토큰 변경 적용, generated asset rewrite, DB/live/backend 변경은 하지 않았다.
  • npm run docs:check 검증 대상이다.
