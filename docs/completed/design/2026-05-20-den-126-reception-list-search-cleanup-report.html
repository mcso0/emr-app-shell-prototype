DEN-126 접수 목록 및 환자 검색 UI 정리 리포트

2026-05-20 · Project 05-M1 · Reception List/Search Cleanup

요약

접수 사이드 패널의 대기열 검색과 진료 접수 dialog의 환자 검색 입력을 같은 feature-local 검색 컴포넌트로 정리했다. 대기열/캘린더의 loading, error, empty 상태도 같은 작은 표시 컴포넌트를 쓰도록 맞춰서, 검색/목록 UI의 반복 markup을 줄였다.

변경 내용

  • src/features/reception/reception-list-search.tsx를 추가했다.
  • ReceptionSearchInput으로 검색 icon, clear button, aria-label, padding 규칙을 모았다.
  • ReceptionPanelStateMessage로 대기열/캘린더 loading과 error 상태 표시를 통일했다.
  • ReceptionEmptyState로 접수 사이드 목록의 빈 검색 결과 표면을 분리했다.
  • 검색어가 비어 있을 때 환자 lookup effect 안에서 즉시 setState하던 경로를 제거해 lint 경고를 없앴다.

화면 리뷰 메모

  • 대기열 검색과 진료 접수 환자 검색 모두 기존 placeholder와 한국어 label을 유지한다.
  • 검색어 삭제 버튼은 같은 위치와 focus ring을 사용한다.
  • 대기열 read, 캘린더 read, 진료 접수 생성, mock/live fallback 동작은 변경하지 않았다.

제외 범위
