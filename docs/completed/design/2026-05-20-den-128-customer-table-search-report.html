DEN-128 고객관리 테이블 및 검색 UI 정리 리포트

2026-05-20 · Project 05-M2 · Customer Table/Search Pass

요약

고객관리 화면의 table min-width inline style을 local class recipe로 바꾸고, 검색 입력을 CustomerSearchInput으로 분리했다. 긴 동물명/보호자명, 전화번호, 동의 상태, 등록일시는 truncate 또는 nowrap 기준을 더 명확히 해 dense table에서 흔들림을 줄였다.

List/Table/Drawer 개선

  • customerTableWidthClassNames로 동물/보호자 table 폭 기준을 local recipe로 모았다.
  • style={{ minWidth }}를 제거하고 Tailwind class 기반 min-width로 전환했다.
  • CustomerSearchInput을 추가해 검색 icon, clear button, placeholder, aria-label을 한 곳에서 관리한다.
  • 동물명/보호자명은 truncate, 전화번호/수신 여부/등록일시는 nowrap 기준을 적용했다.
  • 환자/보호자 row click과 공용 drawer 진입은 기존 동작을 유지했다.

의도적으로 제외한 placeholder

  • 스케줄 관리, 발송 관리, 서류 관리, CS내역, 진료의뢰수신 하위 항목은 계속 disabled visual-only navigation으로 남겼다.
  • 새 고객 workflow, 외부 메시징, 문서/CS/진료의뢰 연동은 구현하지 않았다.

후속 추천

  • 고객관리 table recipe가 병원관리/수납 table과 더 겹치면 shared EMR data table sizing rule로 승격할 수 있다.
  • placeholder 영역은 제품 범위가 확정된 뒤 별도 이슈로 각 업무 화면을 연결하는 편이 안전하다.
