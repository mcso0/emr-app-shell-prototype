공용 테이블 밀도 드롭다운 선택기 완료 보고

작성일: 2026-07-12 · 작업: DESIGN-SYSTEM-PR-074

결론: 모든 EmrTableDensitySelector 사용처가 현재 선택값을 보여 주는 단일 드롭다운 버튼을 사용한다. 행 높이와 데이터 동작은 변경하지 않았다.

변경 내용

  • 기존 아이콘 3개 토글을 [밀도 아이콘 · 현재값 · 아래 화살표] 버튼으로 교체했다.
  • 메뉴는 좁게, 기본, 넓게 단일 선택 라디오 항목과 현재 선택 체크 상태를 제공한다.
  • 트리거 접근성 이름에 현재값을 포함했다. 예: 테이블 보기 밀도: 좁게.
  • 공용 디자인 계약을 새 드롭다운 기본값으로 갱신했다. 저장된 보기, URL 상태, 사용자 설정 저장은 추가하지 않았다.

검증

  • Storybook 상호작용 테스트: 통과
  • 차트 오더 테이블에서 좁게 → 넓게 변경 및 data-emr-density="comfortable" 확인: 통과
  • npm run lint, npx tsc --noEmit, npm run docs:check: 통과
  • npm run build, npm run build-storybook: 통과
  • Storybook 미리보기에서 트리거와 세 개의 메뉴 항목, 선택 상태를 직접 확인했다.

유의사항

작업공간의 별도 lockfile 때문에 Next.js가 workspace-root 경고를 출력했고, Storybook은 기존 의존성의 문서 생성·폰트·번들 크기 경고를 출력했다. 모두 빌드 성공 상태이며 이번 선택기 변경으로 새로 발생한 오류는 아니다.
