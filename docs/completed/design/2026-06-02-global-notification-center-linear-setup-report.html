CLAiR 전역 알림 센터 v0 Linear 등록 완료 보고서

2026-06-02 기준, 기존 Linear 프로젝트 20 CLAiR EMR Global Notification Center v0에 기획 HTML 링크, 5개 마일스톤, 15개 PR-sized 이슈를 등록했다.

요청

오른쪽 drawer형 전역 알림 센터 v0 기획안을 기준으로 DEN 팀 Linear 프로젝트에 실행 가능한 마일스톤과 PR-sized 이슈를 등록한다. 새 프로젝트를 만들지 않고 기존 프로젝트에 이어서 등록하며, 이슈는 Done으로 이동하지 않는다.

등록 결과

  • 기존 프로젝트 존재 확인: 완료.
  • 프로젝트 설명 확인: 기획 HTML, repo path, v0 핵심 결정, 이벤트 범위, 제외 범위가 이미 포함되어 있어 추가 수정하지 않았다.
  • 프로젝트 리소스 추가: Linear 문서 전역 알림 센터 v0 기획 HTML 링크 생성.
  • 마일스톤 생성: 5개.
  • PR-sized 이슈 생성: 15개, 모두 Backlog 상태.

범위 고정

  • v0는 오른쪽 drawer형 전역 알림 센터를 기본으로 한다.
  • badge 숫자는 unread && badge_count === true 기준이다.
  • requires_action, badge_count, toast_policy를 이벤트 규칙 핵심 필드로 둔다.
  • 저장소는 localStorage read/archive state이며, 역할 큐 read/archive는 브라우저/사용자 간 동기화하지 않는다.
  • 알림 primary action은 현재 탭에서 원본 업무 화면으로 이동하고 dirty state confirmation guard를 거친다.
  • 동일 환자+동일 오더+동일 event의 미확인 알림은 update/bump한다.
  • toast는 동시에 최대 3개 노출하고 이후 toast는 queue 대기한다.

제외 범위

live push, service worker, provider 발송, Kakao/SMS/email, remote Supabase migration/RLS/live validation, 공지 발행 시스템, 자유 멘션 시스템, 알림 안 임상/수납 final action 직접 수행, 역할 큐 read/archive 클라이언트 간 실시간 동기화는 등록 이슈 범위에서 제외했다.
