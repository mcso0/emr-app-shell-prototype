Storybook EMR Component Stories

Storybook 카탈로그를 Button, Badge, Input에서 다음 재사용 컴포넌트까지 확장했다. 이제 필터/모드 전환, EMR 상태 표시, 지속형 인라인 피드백을 Storybook에서 직접 확인할 수 있다.

변경 사항

  • SegmentedControl story를 추가하고 필터, count, tabs variant, 축약 라벨 접근성 예시를 넣었다.
  • EmrStatusBadge story를 추가하고 지원 상태, marker 제거, unknown label fallback 경계를 문서화했다.
  • EmrInlineAlert story를 추가하고 severity, recovery action, icon 제거 경계를 문서화했다.
  • 새 work item DESIGN-SYSTEM-PR-050를 Human Review 상태로 기록했다.

범위 밖

Storybook MCP/AI addon, Chromatic 배포, feature workflow story, 새 status resolver API, DB/Supabase/권한/배포/실데이터 작업은 포함하지 않았다.

검증

  • npm run lint
  • npx tsc --noEmit
  • npm run docs:check
  • npm run build-storybook
  • npm run storybook -- --ci --smoke-test
  • 로컬 Storybook에서 새 3개 컴포넌트 sidebar와 preview 렌더링 확인

다음 단계

여섯 개 story의 사용/비사용 설명을 검토한 뒤, Storybook MCP/AI addon을 붙여 agent가 카탈로그를 읽는 경로를 검증하는 것이 적절하다.
