Storybook Vitest Optimizer Stability

Storybook MCP focused test 첫 실행에서 반복되던 Vite dependency optimizer reload를 줄이기 위해 Vitest Storybook project config에 Base UI 패키지 preload 목록을 명시했다.

변경 사항

  • vitest.config.ts에 optimizeDeps.include를 추가했다.
  • 현재 Storybook primitive와 pattern에서 쓰는 Base UI 하위 패키지를 명시했다.
  • runtime component나 story behavior는 변경하지 않았다.
  • 새 work item DESIGN-SYSTEM-PR-062를 Human Review 상태로 기록했다.

범위 밖

패키지 업그레이드, storybook/test helper migration, runtime API 변경, DB/Supabase/권한/배포/외부 연동은 포함하지 않았다.

검증

  • npm run lint 통과. 기존 5개 warning은 남아 있다.
  • npx tsc --noEmit 통과.
  • npm run docs:check 통과.
  • npm run build-storybook 통과. 기존 Storybook build warning은 남아 있다.
  • npm run storybook -- --ci --smoke-test 통과.
  • Storybook MCP focused story test 통과: design-system-ui-dialog--default, design-system-ui-popover--default, design-system-emr-table-queue-patterns--sortable-filterable-header.

주의 사항

이 변경은 첫 실행 reload를 줄이는 안정화다. Storybook 서버를 깨끗하게 재시작한 뒤 대표 focused test는 이전 Base UI optimizer reload 실패 없이 첫 실행에서 통과했다. 향후 새 Base UI 하위 패키지를 Storybook에 추가하면 같은 목록에 포함할지 검토해야 한다.
