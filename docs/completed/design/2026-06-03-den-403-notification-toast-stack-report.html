DEN-403 전역 알림 toast stack 완료 보고서

전역 알림 v0의 in-app toast가 한 번에 세 개를 넘지 않도록 stack/queue rule과 status variant를 구현했다. service worker, OS notification, 외부 채널, live provider delivery는 포함하지 않았다.

정책

  • 전역 Sonner Toaster는 visibleToasts={3}로 제한된다.
  • notification 전용 stack helper는 visible 3개와 queued overflow를 분리한다.
  • visible toast dismiss 후 queued 첫 항목이 visible stack으로 승격된다.
  • visible 또는 queued 안에 같은 dedupe key가 있으면 새 toast를 append하지 않고 update/bump한다.
  • variant는 urgent, high, warning, info, success로 정리했다.

변경

  • notification-toast-rules.ts에 stack/queue/dedupe/variant rule을 추가했다.
  • NotificationToastCard 컴포넌트에 상태 아이콘, 업무 타입 badge, 상대 시간, source navigation action을 반영했다.
  • source action label이 final clinical/billing/reception action으로 흐르지 않도록 focused test를 추가했다.

검증

  • npm run lint 통과. 기존 경고 4개는 유지된다.
  • npx tsc --noEmit 통과.
  • PLAYWRIGHT_BASE_URL=http://localhost:3333 npx playwright test tests/notification-toast.spec.ts tests/notification-fixtures.spec.ts tests/app-shell.spec.ts -g "notification" 통과: 17 passed.
  • npm run docs:check 통과.

리스크와 후속

이번 범위는 stack model과 reusable card를 제공한다. 실제 event emission, source navigation, dirty-state guard, fallback detail은 후속 DEN-404/DEN-405에서 연결한다. Toast card width는 360px 이하로 제한해 desktop/mobile에서 주요 컨트롤을 과도하게 덮지 않도록 설계했다.
