DEN-406 전역 알림 surface QA 완료 보고서

v0 이벤트가 drawer, toast, inline alert surface에서 어떤 조건으로 보이는지 테스트 가능한 정책으로 정리했다. 모든 알림은 drawer에 남고, transient surface는 toast_policy, 수신자, 현재 source context에 따라 제한된다.

변경

  • resolveNotificationSurfaceVisibility로 drawer/toast/inline alert eligibility를 고정했다.
  • drawer_only와 inline_first 이벤트가 toast로 튀지 않도록 검증했다.
  • role_active toast는 current recipient ownership과 unread/unarchived 상태를 기준으로 제한했다.
  • source_context_only toast는 같은 source workflow 근처에서만 보이도록 검증했다.
  • NotificationInlineAlert를 추가해 inline-first 복구 알림을 EmrInlineAlert 표면으로 표현할 수 있게 했다.
  • source action copy가 final clinical/billing/reception action을 직접 수행하지 않는다는 테스트를 유지했다.

QA 메모

  • Drawer: 모든 v0 fixture가 reviewable surface로 남는다.
  • Toast: 최대 3개 stack/queue/dedupe와 variant 테스트를 기존 suite에 유지했다.
  • Inline alert: 장비 결과 매칭 실패 같은 inline_first 이벤트는 toast보다 source workflow recovery surface를 우선한다.
