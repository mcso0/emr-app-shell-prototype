Storybook Empty Info Feedback Patterns

Empty state, info box, inline alert boundary를 Storybook에서 비교할 수 있도록 EMR pattern story를 추가했다. 새 runtime component를 만들지 않고 기존 design-system 계약을 실행 가능한 예시로 정리했다.

변경 사항

  • Design System/EMR/Empty Info Feedback Patterns story를 추가했다.
  • empty, info, alert-boundary 세 가지 예시를 synthetic demo text로 구성했다.
  • alert-boundary 예시는 기존 EmrInlineAlert를 사용했다.
  • 공유 EmrEmptyState 또는 EmrInfoBox runtime API는 만들지 않았다.

범위 밖

feature-local empty state 적용, runtime component 추출, EmrInlineAlert behavior 변경, DB/Supabase/권한/배포/외부 연동은 포함하지 않았다.

검증

  • npm run lint 통과. 기존 5개 warning은 남아 있다.
  • npx tsc --noEmit 통과.
  • npm run docs:check 통과.
  • npm run build-storybook 통과. 기존 Storybook build warning은 남아 있다.
  • npm run storybook -- --ci --smoke-test 통과.
  • Storybook MCP 문서 노출 확인: design-system-emr-empty-info-feedback-patterns.
  • Storybook MCP focused story test 통과: design-system-emr-empty-info-feedback-patterns--empty-state.

주의 사항

이 작업은 Empty/info/error shared pattern의 판단 기준을 Storybook에 등록한 것이다. 실제 공유 runtime component는 반복되는 화면 구조가 더 증명된 뒤 별도 작업으로 판단한다.
