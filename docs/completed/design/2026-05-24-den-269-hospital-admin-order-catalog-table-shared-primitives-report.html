DEN-269 병원관리 Order 카탈로그 테이블 Primitive 적용

2026-05-24 · Project 12 CLAiR EMR Table Density & Data Grid Ergonomics · Human Review

무엇을 바꿨나

병원관리의 Order 관리 목록에 DEN-264에서 만든 EmrTableHeaderCell과 EmrTableCellText를 제한 적용했다. 이번 변경은 병원관리 Order 카탈로그 테이블에만 국한되며, 전체 테이블 일괄 전환이나 새 정렬/필터/resize 동작 구현은 포함하지 않았다.

왜 중요한가

병원관리 Order 카탈로그는 임상 오더명, 원내명, 청구서명, 판매금액, 사용여부가 한 화면에서 함께 읽혀야 하는 dense master-data 표다. 공통 primitive를 적용해 헤더 역할과 셀 텍스트 줄 수 정책을 명시해 두면, 이후 다른 테이블로 확장할 때 각 표가 임의의 truncate/class 조합으로 흩어지는 일을 줄일 수 있다.
