DEN-352 Topbar Tabs Chrome 작업 결과

CDS V2 topbar 컴포넌트 기준으로 상단 탭/아이콘/프로필 영역의 간격, 색상, 상태 표현을 정리했다. 기존 탭 생성, 닫기, 활성 탭 전환, 탭별 히스토리 동작은 유지했다.

변경 내용

  • topbar 전용 EMR 토큰 alias를 추가해 32px 컨트롤, 8px/10px/16px 간격, divider, icon, tab state 색상을 관리하도록 했다.
  • WorkspaceTabsBar를 Figma 구조에 맞춰 좌측 chrome 그룹과 우측 action 그룹으로 재정렬했다.
  • WorkspaceChromeTabs의 active/inactive/hover surface, 14px/20px 탭 타이포그래피, 닫기 affordance를 CDS V2 기준으로 맞췄다.
  • AuthProfileMenu trigger를 48x32 profile button 형태로 맞추고 avatar/chevron 구성을 정리했다.
