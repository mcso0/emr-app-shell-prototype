Row Action Menu & Overlay Close 보고서

고객관리, 접수/예약, 병원관리의 대표 행/카드 작업 메뉴를 공통 EmrRowActionMenu 기준으로 맞췄다. 사용자는 화면마다 다른 메뉴 규칙을 다시 학습하지 않고, 미연결 작업도 화면 안의 persistent 안내로 확인할 수 있다.

Human Review 준비 앱 화면 반영

변경 사항

  • 공통 EmrRowActionMenu를 추가해 행/카드 메뉴 trigger, item layout, separator, disabled tone, event propagation 규칙을 한 곳으로 모았다.
  • 고객관리 동물/보호자 row menu를 공통 메뉴로 교체하고, 차트/카카오톡 미연결 action은 info alert로 안내한다.
  • 접수 side panel 환자 카드 menu를 공통 메뉴로 교체하고, 외부 발송 미연결 상태를 카드 영역 안에서 안내한다.
  • 병원관리 Order row menu를 공통 메뉴로 교체하고, 상세 보기와 복제 action의 item copy를 정리했다.
  • Escape, item selection, row click isolation을 대표 화면별 Playwright interaction으로 검증했다.

A등급 기준에 주는 효과

  • UXA-02: 대표 행/카드 메뉴가 shared component, tokenized spacing/color, 동일 trigger 크기를 따른다.
  • UXA-05: unavailable action이 silent item이나 transient toast에만 의존하지 않고 inline feedback을 남긴다.
  • UXA-06: Escape와 item selection 닫힘 규칙을 고객/접수/병원관리에서 같은 방식으로 검증했다.
  • UXA-08: 카카오톡, 차트 이동 등 미연결 경계를 화면별로 숨기지 않고 현재 MVP 범위로 설명한다.

적용 화면

  • 고객관리: 동물/보호자 table row action menu
  • 접수/예약: side panel 환자 카드 action menu
  • 병원관리: Order catalog table row action menu

남은 메뉴 부채

  • 프로필 drawer header action은 아직 버튼 row와 mock 안내 패턴을 유지한다.
  • 컬럼 표시, 필터, 캘린더 옵션 menu는 각 기능 목적이 달라 이번 대표 범위에서 제외했다.
  • Order queue side panel의 단일 카드 action은 향후 Order queue scope에서 별도 판단이 필요하다.
  • 삭제/권한 기반 destructive flow는 기존 confirm/permission 규칙을 유지한다.

제외 범위

  • 전체 menu 전수 migration
  • routing 구조 변경
  • role/permission policy 변경
  • live Supabase, DB migration, RLS 변경
