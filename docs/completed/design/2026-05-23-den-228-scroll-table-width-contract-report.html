DEN-228 Scroll Table Width Contract

컬럼이 많은 EMR table이 viewport 안에서만 가로 스크롤되고, header/body/empty/warning row가 같은 table width를 공유하도록 wrapper contract를 확정했다.

Wrapper Contract

  • <Table layout="scroll" minWidth={...}>를 scroll table의 표준 진입점으로 사용한다.
  • outer data-slot="table-container"만 overflow-x-auto를 소유한다.
  • inner table surface만 단일 minWidth를 소유한다.
  • TableHeader, TableBody, empty state, warning/change row를 별도 overflow wrapper로 분리하지 않는다.

Affected Surfaces

  • P0: dispensing/treatment order table.
  • P1: chart order draft and billing invoice line tables.
  • P2: customer, hospital admin catalog, lab result/order, inpatient ward tables.

Deferred

Sticky/frozen columns are deferred. They need explicit keyboard focus, hover, shadow, and row action alignment rules beyond the current Project 12 scope.

Verification

  • npm run docs:check: passed.
