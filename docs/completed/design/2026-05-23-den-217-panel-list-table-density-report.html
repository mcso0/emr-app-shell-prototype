DEN-217 Panel/List/Table Density Closeout

작성일: 2026-05-23 · Linear: DEN-217 · Project 11 A+ Token & Responsive Hardening

요약

Panel, queue card, list, table cell spacing을 새 화면 구조로 바꾸지 않고 기존 EMR primitive의 density class로 묶었다. 결과적으로 side panel과 order table의 반복 padding/gap 규칙을 한곳에서 설명할 수 있게 됐고, Project 12 table contract가 나오기 전까지 고정 width와 scroll 예외는 local로 보존했다.

변경 범위

영역변경
Global utilitiesemr-density-stack-sm/md, emr-density-panel-inset, emr-density-card, emr-density-list-compact/item, emr-table-* spacing utilities 추가
Panel/list primitivesEmrSubpanel, EmrContentHistoryList, EmrSidePanelCollapsibleGroup, EmrListItem의 반복 gap/padding class를 density utility로 대체
Queue/table primitivesEmrSidePanelCard card padding과 EmrDataTable header/body/warning cell rhythm을 shared utility로 정리

예외와 후속

Fixed table column width, horizontal scroll wrapper, sort/filter/menu affordance는 DEN-217에서 직접 해결하지 않았다. 이 항목은 Project 12의 table density and data grid ergonomics gate에서 research 후 contract로 다루는 것이 안전하다.
