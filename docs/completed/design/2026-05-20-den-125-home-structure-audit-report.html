요약

홈 Kanban/workspace에서 반복되던 업무 상태/우선순위 badge와 pill 표현을 feature-local 컴포넌트로 분리했다. 홈 대시보드와 업무 현황의 데이터, 필터, 카드 동작은 그대로 두고, 상태 표현 규칙을 한 파일로 모아 다음 정리 작업이 더 안전하게 이어지도록 했다.

변경 내용

  • src/features/home/components/home-task-badges.tsx를 추가해 업무 판단 badge, 상태 badge, 다음 행동 priority badge, 카드 pill을 모았다.
  • home-kanban-workspace.tsx의 상세 패널, 다음 행동 카드, 아웃라인 table, kanban task card가 새 badge/pill 컴포넌트를 재사용하도록 정리했다.
  • 홈 내부 첫 탭의 보이는 라벨을 문서/회귀 기준에 맞춰 홈으로 맞췄다.
  • 상단 workspace tab 홈과 내부 홈 탭의 접근성 이름 충돌을 피하기 위해 내부 탭 aria-label을 대시보드 보기로 분리했다.

화면 리뷰 메모

  • 상태 색상, 위험/주의/미배정 의미, 카드 높이, 필터, 업무 이동 action은 유지했다.
  • 홈/업무 현황 탭의 visible label은 기존 제품 문구에 맞춰 정리했고, 스크린리더/테스트 selector 충돌만 줄였다.
  • Kanban 컬럼, summary panel, role preset, 모바일 레이아웃은 기존 회귀 테스트로 확인했다.
