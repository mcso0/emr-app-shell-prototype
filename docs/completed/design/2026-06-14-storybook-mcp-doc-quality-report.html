Storybook MCP Documentation Quality

Storybook MCP가 읽는 컴포넌트 문서 품질을 보강했다. 이제 기존 6개 디자인시스템 컴포넌트는 prop 타입뿐 아니라 사용 목적과 오용 경계를 더 명확히 드러낸다.

변경 사항

  • Button, Badge, Input에 exported prop alias와 JSDoc 설명을 추가했다.
  • SegmentedControl, EmrStatusBadge, EmrInlineAlert의 props와 component summary를 문서화했다.
  • Storybook prop extraction을 react-docgen-typescript로 전환했다.
  • Storybook 운영 규칙에 MCP용 source JSDoc/docgen 품질 기준을 추가했다.
  • 새 work item DESIGN-SYSTEM-PR-052를 Human Review 상태로 기록했다.

범위 밖

신규 컴포넌트/story 추가, 런타임 동작 변경, 외부 agent 연결, MCP endpoint publish/share, DB/Supabase/권한/배포/실데이터 작업은 포함하지 않았다.

검증

  • npm run lint
  • npx tsc --noEmit
  • npm run docs:check
  • npm run build-storybook
  • npm run storybook -- --ci --smoke-test
  • 로컬 MCP components manifest에 6개 디자인시스템 컴포넌트 노출 확인
  • MCP run-story-tests focused 실행 확인
