DEN-409 전역 알림 Human Review readiness 보고서

전역 알림 센터 v0는 대표자 Human Review로 넘길 준비가 됐다. 새로 진행한 DEN-398~DEN-409는 Done으로 이동하지 않고 Human Review 상태로 유지했다.

대표자 확인 항목

  • Shell badge가 전체 unread가 아니라 중요 badge-count 알림만 세는지 확인한다.
  • Drawer row에서 read/archive/restore/all-read가 업무 완료처럼 보이지 않는지 확인한다.
  • 역할 큐 read/archive가 현재 브라우저 local state라는 안내가 충분히 명확한지 확인한다.
  • Source action이 현재 탭에서 원본 업무 화면으로 이동하고, missing source는 fallback detail을 보여주는지 확인한다.
  • Dirty state confirmation 문구가 실제 사용자에게 충분히 이해되는지 확인한다.
  • Toast/inline/drawer-only 정책이 과도한 알림 noise를 만들지 않는지 확인한다.

Known limitation

  • Toast stack/card/rules는 구현됐지만 live event stream에서 toast를 자동 발생시키는 wiring은 v0 범위 밖이다.
  • NotificationInlineAlert는 inline-first 정책 표면으로 준비됐지만, 각 도메인 모듈의 live inline alert 자동 노출은 후속 통합 범위다.
  • Dirty guard는 shell-level flag를 사용한다. 실제 feature module들이 자신의 dirty state를 이 flag에 연결하는 작업은 후속 통합에서 다뤄야 한다.
  • 역할 큐 read/archive는 브라우저 local state라 사용자/브라우저 간 동기화되지 않는다.
  • 현재 워크트리에는 notification 작업 외 auth/home 관련 기존 변경도 섞여 있으므로, 코드 리뷰 때 notification 범위와 분리해 확인해야 한다.
