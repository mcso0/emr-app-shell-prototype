DEN-294 고급 필터 빌더 테이블 적용

DEN-293에서 만든 공용 advanced filter builder를 실제 수납과 진료/차트 오더 테이블에 적용했다. 두 화면 모두 기존 정렬 정책은 유지하고, 필터는 섹션 Filter 버튼에서 열리는 공용 builder로 동작한다.

적용 범위

수납 청구 항목 업무, 청구금액 필드를 공용 builder config로 연결했다.
진료/차트 오더 상태, 수의사 필드를 공용 builder config로 연결했다.
첫 open 상태 조건 1개짜리 빈 draft row만 표시한다.
active 계산 필드, 조건, 값이 완성된 row만 필터와 Filter N에 반영한다.

변경 사항

  • src/features/billing/module.tsx: feature-local billing filter builder를 공용 builder로 교체했다.
  • src/features/chart/module.tsx: feature-local chart/order filter builder를 공용 builder로 교체했다.
  • src/components/ui/select.tsx: filter popover 안의 select dropdown이 클릭 가능하도록 overlay layer를 조정했다.
  • tests/billing.spec.ts, tests/chart.spec.ts, tests/table-sort-filter-qa.spec.ts: 새 auto-apply builder UX에 맞춰 검증을 갱신했다.
