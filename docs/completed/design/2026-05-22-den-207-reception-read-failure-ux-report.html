Reception Read Failure UX 보고서

접수 화면의 서버 대기열/캘린더 read failure를 작은 상태 문구에서 복구 행동이 있는 EmrInlineAlert로 바꿨다. 사용자는 서버 read 실패, 로컬 데모/세션 데이터 유지, 재시도 가능성을 같은 자리에서 확인할 수 있다.

Human Review 준비 앱 화면 반영

변경 사항

  • 접수 side panel의 queue read failure를 EmrInlineAlert severity="warning"로 교체하고 대기열 다시 시도 action을 추가했다.
  • 중앙 calendar read failure를 EmrInlineAlert severity="warning"로 교체하고 캘린더 다시 시도 action을 추가했다.
  • store에 readRetryNonce와 requestReceptionReadRetry를 추가해 두 read effect를 동일한 retry trigger로 다시 실행하게 했다.
  • failure copy가 권한/session/Supabase client/read failure를 구분하고, 로컬 데모/세션 데이터 경계를 명시한다.
