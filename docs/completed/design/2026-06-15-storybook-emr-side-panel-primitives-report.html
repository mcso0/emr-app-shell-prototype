Storybook EMR Side Panel Primitives

4순위까지 남아 있던 EMR side-panel/list primitive와 shell 보조 컴포넌트를 Storybook에 등록했다. 모든 예시는 합성 텍스트만 사용하고 runtime API는 변경하지 않았다.

변경 사항

  • EmrIconButton, EmrPopoverShell, EmrSubpanel story를 추가했다.
  • EmrSidePanelStateIcon, EmrSidePanelCollapsibleGroup, EmrSidePanelCard, EmrTaskQueueCard story를 추가했다.
  • EmrContentAsidePanel, EmrContentHistoryList, EmrTextSidePanel, EmrModuleListSidePanel story를 추가했다.
  • OrderQueueSelectionSummary, EmrOrderQueueSidePanel story를 synthetic fixture로 추가했다.
  • Storybook README coverage와 work index에 PR-069를 반영했다.

검증

  • npm run lint 통과: 기존 unrelated warning 5건만 유지.
  • npx tsc --noEmit 통과.
  • npm run docs:check 통과.
  • npm run build-storybook 통과: 기존 Storybook build warning만 유지.
  • npm run storybook -- --ci --smoke-test 통과.
  • Storybook MCP 문서 목록에서 신규 13개 항목을 확인했다.
  • Focused MCP story tests 통과. 최초 1회 Vite 동적 import reload성 실패가 있었고, focused 재실행에서 통과했다.
