DEN-124 검사/영상 테이블 UI 리포트

2026-05-20 · Project 03-M2 · Lab/Imaging Table UX

요약

임상병리 결과 입력 테이블과 영상 Order 상세 테이블의 overflow, 빈 상태, 긴 텍스트 표시를 정리했다. 결과값, 정상범위, 판정, 판독 데이터는 변경하지 않고 테이블을 더 안정적으로 스캔할 수 있게 만드는 작업에만 집중했다.

변경 내용

  • 임상병리 결과 테이블을 가로 스크롤 래퍼와 min-w-[860px] 기반 table layout으로 감싸 좁은 폭에서 컬럼이 과도하게 눌리지 않도록 했다.
  • 임상병리 결과 행이 없을 때 표시할 검사 결과가 없습니다. 빈 상태를 테이블 body 안에 추가했다.
  • 영상 Order 상세 테이블의 최소 폭을 넓히고 row hover/background를 다른 EMR 테이블 톤에 맞췄다.
  • 영상 검사명/영문명은 줄바꿈을 허용하고, 요청자/요청 일시/담당자는 truncate 처리해 긴 이름과 날짜가 테이블 밖으로 밀리지 않게 했다.

화면 리뷰 메모

  • 검사 결과 input, 정상범위 chart, 판정 badge의 의미와 위치는 유지했다.
  • 영상 상세 테이블의 PACS 액션, modality badge, 요청/담당 정보는 기존 정보 구조를 유지했다.
  • 좁은 viewport에서는 테이블 영역이 가로 스크롤로 버티고, 긴 한글/영상 용어는 셀 안에서 줄바꿈 또는 말줄임 처리된다.

제외 범위

  • DB, Supabase, RLS, live persistence, device/PACS integration, server permission은 변경하지 않았다.
  • 검사 결과값, reference range, 영상 판독 로직은 변경하지 않았다.
  • full data-grid replacement는 하지 않았다.
