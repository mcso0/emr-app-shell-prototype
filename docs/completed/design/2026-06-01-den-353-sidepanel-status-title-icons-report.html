DEN-353 Side Panel Status Title Icons 작업 결과

CDS V2 sidebar/list title 컴포넌트 기준으로 왼쪽 사이드 패널의 상태 그룹 타이틀에 의미별 아이콘을 추가했다. 재요청, 진행중, 대기중, 완료, 취소 같은 상태를 더 빠르게 구분할 수 있고, 기존 접기/펼치기 동작은 유지했다.

변경 내용

  • side-panel list title 전용 EMR 토큰 alias를 추가해 32px title row, 16px state icon, 24px collapse action, hover surface를 관리하도록 했다.
  • EmrSidePanelStateIcon을 추가해 Figma stateIcon의 done, in-progress, to-do, cancel, rework, stop SVG variant를 재사용할 수 있게 했다.
  • EmrSidePanelCollapsibleGroup를 Figma의 listGroupTitle 구조에 맞춰 state icon, label, neutral count, collapse affordance로 정리했다.
  • getEmrSidePanelStatusIconState을 추가해 상태명/상태 ID/color token을 공통 stateIcon variant로 해석하도록 했다.
  • 조제/처치 order queue 상태 그룹에 새 status icon title 처리를 적용했다.
