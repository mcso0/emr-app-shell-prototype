DEN-129 병원어드민 테이블/폼 표준화 리포트

2026-05-20 · Project 06-M1 · Admin Table & Forms

요약

병원관리의 처방/수가 카탈로그 화면에서 테이블 폭 규칙과 drawer 폼 구조를 더 예측 가능하게 정리했다. 화면 동작은 그대로 두고, 반복 수정하기 쉬운 구조로 바꾼 작업이다.

변경 내용

  • 처방 카탈로그 테이블의 column 폭을 local recipe 상수로 모아 관리하게 했다.
  • drawer 입력 row를 shadcn Field 기반 구조로 바꿔 label, 설명, 입력 영역의 역할을 분리했다.
  • drawer 하단 저장/삭제 footer가 내용 위에 겹치지 않도록 layout flow 안으로 넣었다.
  • 삭제 버튼은 shadcn destructive variant를 쓰도록 맞췄다.
  • 병원관리 audit review effect의 lint 경고를 동작 변경 없이 정리했다.

유지한 범위

이번 작업은 frontend UI 표준화만 다뤘다. Supabase, DB, RLS, migration, API persistence, 권한 정책, 수가/청구 업무 로직, 실제 환자/병원 데이터는 건드리지 않았다.

Human Review 체크포인트

  • 테이블의 고정 min-width는 좁은 화면에서 가로 스크롤을 전제로 유지했다.
  • 카탈로그 전용 select는 아직 feature-local로 두었다.
  • 정책/저장/수가 계산 변경은 후속 제품 결정이 필요하다.
