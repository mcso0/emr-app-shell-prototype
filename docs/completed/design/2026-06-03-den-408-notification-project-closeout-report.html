CLAiR 전역 알림 센터 v0 프로젝트 완료 보고서

전역 알림 센터 v0는 오른쪽 drawer 기반의 in-app 알림으로 구현됐다. 사용자는 shell badge로 중요한 미확인 알림을 확인하고, drawer에서 read/archive 상태를 정리하며, 원본 업무 화면으로 현재 탭 이동할 수 있다.

대표 결과

  • Badge 숫자는 전체 unread가 아니라 unread && badge_count === true 기준으로 동작한다.
  • 10개 v0 이벤트 범위가 synthetic fixture와 event rule로 표현된다.
  • Read/archive 상태는 localStorage v0 키에 저장되고, 역할 큐 상태는 브라우저 간 동기화하지 않는다.
  • 동일 환자+동일 오더+동일 event의 반복 unread 알림은 append 대신 update/bump된다.
  • Toast는 최대 3개 visible stack과 queue/dedupe 규칙을 갖는다.
  • Primary action은 현재 탭 source navigation이며, dirty state가 있으면 지정 confirmation을 먼저 띄운다.
