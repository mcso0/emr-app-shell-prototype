DEN-396 전역 알림 센터 v0 이벤트 정책 완료 보고서

전역 알림 센터 v0의 이벤트 매트릭스와 UX 문구, badge/toast/dedupe 정책을 구현자가 바로 참조할 수 있는 정책 문서로 정리했다. 이제 fixture, drawer, badge resolver, toast stack 구현은 이 기준을 따르면 된다.

요청

v0 이벤트별 recipient, trigger, requires_action, badge_count, toast_policy, source target을 확정하고, 알림 title/detail/action 문구 규칙과 drawer/toast/inline alert 사용 기준을 정리한다.

변경

  • 새 정책 문서 docs/product/features/notifications/global-notification-center-v0-event-policy.md를 추가했다.
  • v0 이벤트 10개를 trigger, recipient, badge, toast, source, title/detail 기준으로 정리했다.
  • drawer row, toast, inline alert, drawer-only surface 정책을 분리했다.
  • badge 계산을 전체 unread가 아닌 unread && badge_count === true 기준으로 재확정했다.
  • toast max 3, queue, urgent/recheck 우선, dedupe update/bump 정책을 문서화했다.
  • 업무 타입 badge, title, detail, action label, relative time 작성 규칙을 정리했다.
  • 알림 안에서 임상/수납/접수 final action을 유도하는 문구를 제외했다.

문서 연결

  • Notification README와 base contract에서 새 event policy로 연결했다.
  • Docs portal, GitBook summary, Product README에 event policy 링크를 추가했다.
  • 새 work item NOTIFICATION-PR-002를 추가했다.

제외 범위

live push, service worker, provider/device delivery, Kakao/SMS/email, remote Supabase migration/RLS/live validation, notification publisher/admin system, 자유 멘션/댓글 알림, 수납 금액 검증/차단 알림, 보안 정책 알림은 v0 이벤트 정책에서 제외했다.

  • 코드 구현은 하지 않았기 때문에 lint/typecheck/build는 실행 대상이 아니다.
  • 후속 구현은 DEN-397부터 이 정책을 기준으로 진행한다.
