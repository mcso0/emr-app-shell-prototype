CLAiR · CHART-PR-035 · 2026.09.06 · 디자인 검토 대기

익숙한 오더를 검색하고,
바로 다음 오더를 추가합니다.

마지막 오더 아래에서 시작하는 빠른 추가행의 기획과 클릭 가능한 시안을 준비했습니다. 실제 앱 구현은 다음 단계입니다.

클릭 가능한 시안 열기상세 기획 문서

합의한 방향

승욱이 브라우저 시안과 ‘추가 후 검색창을 유지하는 연속 입력’을 선택했습니다. 기존 상단 + Order는 유지하고, 익숙한 오더를 위한 짧은 경로를 추가합니다.

단계동작
첫 오더오더 0개에서는 하단 빠른 추가를 숨기고 기존 빈 상태의 + Order로 시작합니다. 첫 추가 뒤 나타나고 마지막 삭제 뒤 다시 숨깁니다. 현재 분류만 비어 있으면 빠른 추가를 유지합니다.
열기분류 열에 맞춘 + Order 추가를 누르면 입력창에 포커스가 갑니다.
검색분류 선택 없이 전체 오더명·청구명으로 검색합니다. 결과에는 분류·오더명·가격을 표시하고, 오더명 아래 보조 설명은 표시하지 않습니다.
추가클릭이나 방향키·Enter로 미확정 오더를 추가합니다. 세트는 구성 확인을 거칩니다.
이어가기검색어만 비우고 입력창을 유지합니다. 저장 중과 저장 완료를 구분합니다.

리뷰에서 확정한 표시 규칙

  • 분류 제목과 값은 왼쪽 정렬. 버튼은 보조 문구 없이 ‘+ Order 추가’로 표시합니다.
  • 버튼·입력창·결과창은 분류 열 시작부터 고정된 Order 명 열 오른쪽까지 같은 너비로 맞춥니다(현재 332px).
  • 입력창은 ‘오더명·청구명 검색’. 입력 전 결과 영역은 제목·건수·예시 없이 ‘오더명 또는 청구명을 입력해 주세요.’로 안내합니다.
  • 검색 후 제목과 건수를 ‘검색 결과 3건’처럼 6px 간격으로 붙입니다. 결과 없음은 0건, 검색 실패는 제목과 건수를 숨깁니다.
  • 검색 결과에는 분류·오더명·가격만 표시하고 보조 설명을 넣지 않습니다. 실제 결과가 넘칠 때만 스크롤바를 표시합니다.
  • 닫기는 CDS X 아이콘, 접근성 이름은 ‘빠른 검색 닫기’. ‘상세 오더 검색’에는 CDS 오른쪽 꺾쇠를 사용합니다.
  • 상세 검색은 상단·빈 상태의 + Order와 동일한 기존 오더 추가 다이얼로그로 연결하고 검색어를 이어받습니다.

시안에서 확인할 수 있는 것

상단 상황 선택에서 기본·검색·첫 오더·긴 목록·검색 실패·저장 실패·읽기 전용을 전환할 수 있습니다. 좁은 패널과 오더 집중 보기도 지원합니다. CBC, 방사선, 세트를 검색해 보세요.

긴 목록에서는 입력 공간을 따로 확보해 행을 가리지 않습니다. 가로 스크롤해도 입력창은 유지됩니다. 검색 결과는 남는 공간에 맞춰 위·아래로 열립니다.

검증 결과

  • 오더 0 → 1 → 0 전환에서 빠른 추가 숨김·표시·재숨김과 기존 빈 상태 버튼 연결 확인.
  • 현재 분류가 비어 있어도 다른 분류에 오더가 있으면 빠른 추가 유지 확인.
  • 1280×720 화면 및 780px 패널 모드에서 시각 확인.
  • 키보드 연속 추가: 3 → 4 → 5개, 기존 행 보존·검색어 초기화·포커스 유지 확인.
  • 중복 안내, 검색 결과 없음, 검색 재시도, 저장 실패 후 중복 없는 재저장 확인.
  • 세트 구성 확인 및 전체 카탈로그 검색어 전달·다중 선택 확인.
  • 분류 밖 항목 추가 안내와 전체 보기, 읽기 전용 진입점 비활성화 확인.
  • 브라우저 경고·오류 로그 없음. 자세한 검증 범위는 기획 문서에 기록.

시안 스크립트 문법과 새 문서의 내부 링크 12개는 통과했습니다. 저장소 전체 문서 검사에는 이번 변경과 무관한 기존 persona 가이드 링크 오류 2건이 남아 있습니다.

구현 전 검토할 부분

추가행의 위치, 결과창 크기, 연속 입력의 시선 이동, 긴 목록의 고정 방식이 편한지 확인하면 됩니다. 다음 구현은 기존 카탈로그 조회·미확정 추가·세트 구성·저장 흐름을 재사용하는 작은 범위로 진행합니다.

현재 상태: 기획·시안 완성, 앱 구현 전

모든 데이터·금액·저장은 가상 예시입니다. 실제 차트·DB·청구 데이터는 수정하지 않았습니다. 정렬, 한글 입력기 실기기 동작, 동시 저장 충돌, 환자 전환, 실제 서버·가격 검증과 실사용자 사용성 검증은 다음 단계에 남아 있습니다.
