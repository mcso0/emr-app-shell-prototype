Storybook MCP Dogfood Pass

Storybook MCP가 실제 UI 작업에 쓸 수 있는지 작은 합성 예시로 검증했다. MCP로 문서화된 컴포넌트와 story 작성 지침을 조회한 뒤, 허용된 Button, Input, Badge props만 사용해 recipe story를 추가했다.

변경 사항

  • Design System/Recipes/Storybook MCP Dogfood story를 추가했다.
  • MCP manifest 품질을 위해 Storybook-only helper 컴포넌트를 분리했다. 앱 component API에는 export하지 않았다.
  • 검색 form recipe와 disabled recipe를 추가했다.
  • 검색 form recipe에 focused play interaction을 추가했다.
  • Storybook 운영 규칙에 Design System/Recipes/* dogfood 기준을 추가했다.
  • 새 work item DESIGN-SYSTEM-PR-054를 Human Review 상태로 기록했다.

범위 밖

신규 production 컴포넌트, 앱 런타임 API 변경, 실제 feature workflow story, DB/Supabase/권한/배포/실데이터 작업, MCP endpoint publish/share는 포함하지 않았다.

검증

  • npm run lint
  • npx tsc --noEmit
  • npm run docs:check
  • npm run build-storybook
  • npm run storybook -- --ci --smoke-test
  • MCP list-all-documentation, get-documentation, run-story-tests focused 확인

주의 사항

현재 로컬 Storybook 10.4.4 / addon-vitest 10.4.4 조합에서 storybook/test helper import가 MCP run-story-tests 실행 중 초기화 오류를 냈다. 그래서 이번 recipe의 play function은 DOM API 기반으로 작성했고, focused story test는 통과했다.
