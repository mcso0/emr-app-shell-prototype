DEN-277 Login Production Entry Polish

로그인 화면을 넓은 중립 배경 위의 중심 진입 카드로 정리해, 실제 제품 첫 화면처럼 보이도록 다듬었다. 기존 mock 세션, Supabase password login, invite OTP, invite password setup 흐름은 유지했다.

What Changed

  • 기본 로그인 화면을 CLAiR EMR 브랜드 마크, 이메일, 비밀번호, 주요 로그인 버튼 중심의 단일 카드로 재구성했다.
  • MVP 테스트 옵션은 제품 로그인 흐름과 경쟁하지 않도록 카드 아래 보조 패널로 내렸다.
  • invite OTP와 invite password setup 화면도 같은 시각 체계 안에서 동작하도록 레이아웃을 맞췄다.
  • 초대 이메일 인증 코드는 shadcn Input OTP 패턴을 CLAiR EMR 토큰으로 감싸 8개의 슬롯으로 입력하도록 바꿨다.
  • Google, social login, OAuth, password reset full flow는 이번 범위에서 추가하지 않았다.

Safety Notes

  • Production Supabase, production deploy, DB, RLS, migration은 변경하지 않았다.
  • 실고객 데이터와 실고객 메일은 사용하지 않았다.
  • Secret, OTP 원문, magic link, raw invite token, password 값은 문서에 남기지 않았다.

Visual QA

  • Desktop 기본 로그인 화면: 중심 카드와 하단 보조 패널 렌더링 확인.
  • Mobile 390x844 기본 로그인 화면: 텍스트 겹침, 버튼 overflow, clipped field 없음 확인.
  • Invite OTP mock 화면: 초대 이메일 인증 heading, 8개 OTP slot, one-time-code autocomplete, 초대 context panel 확인.
  • Browser console: 확인한 화면에서 error/warning 없음.
