컴포넌트 책임 매핑

영역 주요 파일 핵심 기준
Shell / 배경 / 워크스페이스 src/shell/*, src/styles/tokens/emr-foundation.css 라우팅, 탭, 드로어 상태는 유지하고 CDS V2 surface와 density만 맞춘다.
네비바 커맨드 진입점 nav-rail.tsx, global-command-palette.tsx 빠른 검색은 네비바에서 열리되 기존 커맨드 팔레트 동작과 키보드 접근성을 보존한다.
좌측 리스트 타이틀/카드 side-panel-collapsible-group.tsx, side-panel-card.tsx 상태 아이콘과 카드 메타데이터는 shared EMR 컴포넌트 계층에서 처리한다.
환자/문서/컨텐츠 정보 영역 patient-context-bar.tsx, instruction-header-stack.tsx, content-aside-panel.tsx 정보 구조와 상호작용은 보존하고 시각 계층, surface, chip/card 패턴을 맞춘다.

후속 진행 순서

  1. DEN-351: shell surface, workspace switcher, nav command entry를 먼저 정리한다.
  2. DEN-352: command 이동 후 topbar/tabs chrome을 정돈한다.
  3. DEN-353, DEN-354: side panel title icon과 task card를 같은 맥락에서 처리한다.
  4. DEN-355, DEN-356: patient/document info bar와 content aside를 surface 기준에 맞춘다.
  5. DEN-357: 전체 frame visual QA와 closeout을 진행한다.

검증

DEN-350은 문서/범위 이슈이므로 앱 코드는 수정하지 않았다. 검증은 npm run docs:check로 수행한다.

남은 리스크

  • 후속 구현에서 src/shell/*와 src/features/dispensing/module.tsx를 동시에 건드릴 가능성이 있어 병렬 작업 전 merge 확인이 필요하다.
  • 중앙 오더 테이블 본문은 이번 프로젝트 범위가 아니므로, 시각적으로 아쉬워도 DEN-357에서 별도 후속 이슈로 분리해야 한다.
  • 현재 로컬 worktree에는 다른 제품/API 작업의 미커밋 변경이 있으므로 Project 17 변경과 섞지 않는 것이 중요하다.
