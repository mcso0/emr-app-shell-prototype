Storybook UI Primitive Third Batch

기존 앱에서 실제 사용 중인 Checkbox, Switch, Tooltip primitive를 Storybook에 추가했다. 새 runtime API는 만들지 않고 co-located story로만 문서화했다.

변경 사항

  • Design System/UI/Checkbox story를 추가했다.
  • Design System/UI/Switch story를 추가했다.
  • Design System/UI/Tooltip story를 추가했다.
  • 각 story에 autodocs, args, argTypes, component description, 사용/비사용 기준을 넣었다.
  • Design System README의 Storybook coverage 표를 업데이트했다.
  • 새 work item DESIGN-SYSTEM-PR-059를 Human Review 상태로 기록했다.

범위 밖

primitive runtime refactor, 신규 shared API, Dialog/Popover 계열 story, DB/Supabase/권한/배포/외부 연동은 포함하지 않았다.

검증

  • npm run lint 통과. 기존 범위 밖 warning 5개는 유지됨.
  • npx tsc --noEmit 통과.
  • npm run docs:check 통과.
  • npm run build-storybook 통과.
  • npm run storybook -- --ci --smoke-test 통과.
  • Storybook MCP list-all-documentation에서 Checkbox, Switch, Tooltip 확인.
  • Storybook MCP get-documentation에서 신규 3개 컴포넌트 문서 확인.
  • Storybook MCP run-story-tests focused 실행으로 design-system-ui-checkbox--default 통과 확인.

주의 사항

첫 focused MCP 실행은 Vite dependency optimizer 관련 dynamic import 실패가 있었지만, PR-056 정책대로 재실행했고 focused story test가 통과했다.
