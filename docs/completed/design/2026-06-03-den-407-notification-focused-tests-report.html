DEN-407 전역 알림 focused tests 완료 보고서

badge, read/archive, dedupe, localStorage 정책 회귀를 빠르게 잡을 focused test를 보강했다. v0의 local-first 제약과 badge-count 기준을 유지하면서 live/remote 범위로 확장하지 않았다.

추가 테스트

  • read, archived, reference-only unread row가 shell badge에 포함되지 않는지 확인했다.
  • localStorage 값이 없으면 fixture 기본 read/archive 상태로 fallback되는지 확인했다.
  • unknown persisted id는 무시하고 malformed archive JSON은 안전하게 fallback되는지 확인했다.
  • read/archive state가 contract key에 기록되고 fixture에 적용되는지 확인했다.
  • local state 적용이 원본 fixture를 mutate하지 않는지 확인했다.

검증

  • npm run lint 통과. 기존 경고 4개는 유지된다.
  • npx tsc --noEmit 통과.
  • PLAYWRIGHT_BASE_URL=http://localhost:3333 npx playwright test tests/notification-fixtures.spec.ts -g "notification" 통과: 11 passed.
  • PLAYWRIGHT_BASE_URL=http://localhost:3333 npx playwright test tests/notification-surfaces.spec.ts tests/notification-toast.spec.ts tests/notification-fixtures.spec.ts tests/app-shell.spec.ts -g "notification" 통과: 29 passed.
  • npm run docs:check 통과.
