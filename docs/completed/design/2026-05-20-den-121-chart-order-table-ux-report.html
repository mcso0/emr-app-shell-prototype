DEN-121 진료/차트 오더 테이블 UX 리포트

2026-05-20 · Project 01-M2 · Table & Flow Hardening

요약

진료/차트 오더 테이블의 읽기성과 밀도를 다듬었다. 기존 shadcn Table과 EMR checkbox primitive를 유지하면서, 좁은 화면에서 긴 오더명과 청구서명이 덜 흔들리고 선택/변경/빈 상태가 더 명확하게 보이도록 정리했다.

변경 내용

  • 테이블 wrapper에 EMR radius/border를 적용해 가로 스크롤 경계를 명확히 했다.
  • header를 sticky 처리하고 column width를 재조정해 Order명, 청구서명, 금액 열의 스캔성을 높였다.
  • 기존 Checkbox 대신 EmrTableCheckbox를 사용해 shared EMR table selection 표현과 맞췄다.
  • 선택 row는 data-state=selected, 변경 row는 data-dirty=true로 상태 surface를 분리했다.
  • 단가/청구금액/수량 입력은 right align과 tabular number를 적용해 숫자 비교가 쉬워졌다.
  • 긴 그룹명, 오더명, 지시문, 담당자명에는 truncate/title을 적용해 dense table에서 텍스트 충돌을 줄였다.
  • 빈 상태는 제목과 설명을 분리해 현재 필터에 표시할 오더가 없다는 맥락을 더 명확히 했다.

리뷰 메모

  • 오더 계산, draft 저장, row 삭제, 선택 합계, Order 청구/확정 confirmation 의미는 변경하지 않았다.
  • 정렬 UI는 구현하지 않았다. 아직 실제 sort state가 없기 때문에 가짜 sort affordance를 추가하지 않는 쪽으로 남겼다.
  • billing tab의 실제 청구 후보 연결은 후속 범위이며, 이번 이슈에서는 empty state만 더 명확히 했다.

검증 결과

  • npx tsc --noEmit --pretty false 통과
  • npx eslint src/features/chart/components/chart-section-title.tsx src/features/chart/components/chart-line-tab-group.tsx src/features/chart/components/soap-rich-text-editor.tsx 통과
  • npx playwright test tests/chart.spec.ts --grep "chart order checkboxes|chart order table edits" --reporter=line 통과: 2 passed
  • npm run docs:check는 리포트 추가 후 실행 예정이다.

주의 및 제외 범위

  • DB, Supabase, RLS, live persistence, server permission, billing sync, order calculation은 변경하지 않았다.
  • npx eslint src/features/chart/module.tsx는 기존 hook lint 오류로 실패한다. 이번 테이블 UX 변경이 새로 추가한 오류는 아니며, 해당 정리는 별도 live persistence/hook cleanup 범위로 분리하는 편이 안전하다.
  • 전체 tests/chart.spec.ts는 앞선 DEN-118 검증에서 5개 통과 후 dev server 연결 종료로 중단되었다. DEN-121의 핵심 order table 회귀는 focused Playwright로 통과했다.
