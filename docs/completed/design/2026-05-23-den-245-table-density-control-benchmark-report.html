DEN-245 Table Density Control Benchmark Report

작성일: 2026-05-23 · Linear: DEN-245 · Project 12 Table Density & Data Grid Ergonomics

Executive Summary

CLAiR EMR의 table density는 항상 보이는 텍스트 라벨형 설정이 아니라, 테이블 toolbar/action cluster에 붙는 icon-only 단일 선택 컨트롤로 제공하는 것이 맞다. `밀도` 라벨은 모든 화면에서 제거하고, 각 옵션은 tooltip과 `aria-label`로 설명한다.

조사한 제품과 grid 라이브러리의 공통점은 density/row height를 데이터 자체가 아닌 view-level 또는 table-level presentation setting으로 다룬다는 점이다. CLAiR도 density를 탭처럼 콘텐츠를 바꾸는 장치로 보이게 하면 안 된다.

조사 결론

  • 컨트롤 타입: shadcn/Radix 기반 `ToggleGroup` 또는 기존 shared segmented control을 사용한다. `Tabs`는 쓰지 않는다.
  • 노출: icon-only 3단계 selector를 기본으로 한다. 텍스트 `밀도` 라벨은 제거한다.
  • 설명: Radix/shadcn `Tooltip`을 사용하고 keyboard focus에서도 열린다.
  • 옵션 이름: `좁게 보기`, `기본 보기`, `넓게 보기`를 tooltip과 `aria-label`에 사용한다.
  • 아이콘 방향: 3개 아이콘 모두 row/list density를 표현해야 한다. 정렬, 메뉴, 컬럼 설정처럼 보이는 아이콘은 피한다.
  • 반복 제어: 같은 화면에 같은 역할의 테이블이 반복되면 selector도 반복하지 않는다. 입원 화면은 상단 filter row에서 한 번만 제어한다.

Retool Table component inspector에서 width, height, overflow, pagination, sorting/filtering을 설정한다. builder configuration 성격. end-user density toggle은 core doc에서 전면 기능이 아니다. admin builder와 달리 CLAiR end-user에게는 단순하고 낮은 노이즈의 preset만 제공한다.
shadcn/ui Data Table TanStack Table composition. view options, column toggle, row actions를 DropdownMenu/Button으로 조합. View options는 toolbar 오른쪽의 `View`/Settings button 패턴. CLAiR density selector도 shadcn composition으로 만들되, density는 숨김 메뉴보다 즉시성이 필요한 화면에만 icon group으로 둔다.

아이콘 후보

옵션 추천 아이콘 방향 Tooltip / aria-label 비고
compact 좁은 간격의 3줄/row icon. lucide Rows3를 기준으로 stroke 간격을 가장 좁게 보이게 조정. 좁게 보기 행 수를 많이 봐야 하는 clinical/admin dense table에 맞다.
standard 중간 간격의 3줄/row icon. 같은 glyph family를 유지. 기본 보기 기본 selected state. 텍스트 없이도 가운데 옵션이 default처럼 보여야 한다.
comfortable 넓은 간격의 3줄/row icon. row gap을 가장 크게 표현. 넓게 보기 검토/판독/메모가 많은 table에서만 유용하다.

주의: `ListFilter`, `Settings`, `SlidersHorizontal`, `Columns3` 계열은 filter/column settings로 오해될 수 있으므로 density 단계 아이콘으로 쓰지 않는다.

shadcn/ui 및 Radix 구현 권장안

  • selector root는 Radix Toggle Group의 single value 패턴을 따른다. Radix Toggle Group은 keyboard navigation과 controlled/uncontrolled 상태를 지원한다.
  • 각 item은 `Button` visual과 `ToggleGroup.Item` semantics를 결합한다.
  • 각 item은 Radix/shadcn Tooltip으로 hover/focus 설명을 제공한다. Tooltip은 hover와 keyboard focus에서 열리는 패턴이므로 icon-only control에 적합하다.
  • selected state는 배경, border, icon contrast를 함께 바꾼다. hover와 selected가 같은 강도로 보이면 안 된다.
  • tab order는 selector group 하나로 들어가고 arrow key로 내부 이동하는 것이 이상적이다.
  • screen reader 이름은 `테이블 보기 밀도` group label과 각 option의 `좁게 보기`, `기본 보기`, `넓게 보기`를 사용한다.

DEN-243 Implementation Checklist

  • 공통 density selector component에서 visible label prop을 제거하거나 default hidden 처리한다.
  • selector item에 tooltip과 `aria-label`을 추가한다.
  • selector icon은 compact/standard/comfortable의 line spacing 차이가 보이게 정리한다.
  • 각 table wrapper가 `width: 100%`를 갖고, table이 fill 또는 scroll contract를 따른다.
  • scroll table은 header/body/row background/border가 같은 inner width를 사용한다.
  • 입원 화면의 `all` dropdown 제거 후 shared density selector로 대체한다.
  • 진료/차트, lab, imaging, dispensing, billing, inpatient, customer, orders 화면에서 위치와 width behavior를 캡처로 검증한다.
