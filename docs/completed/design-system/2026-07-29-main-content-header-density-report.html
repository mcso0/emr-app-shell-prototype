DESIGN-SYSTEM-PR-089

Main Content Header 공통화

페이지마다 따로 두던 56px·48px·상단 여백을 하나의 공통 Header와 디자인 토큰으로 통합했습니다. 이제 높이 정책을 한 곳에서 변경하면서도 진료 화면의 환자 정보와 병원·고객관리의 기존 업무 흐름은 그대로 유지할 수 있습니다.

구현 및 로컬 품질 게이트 통과
8개 항상 56px인 상단 메뉴
13개 Adaptive 검증 화면
1곳 높이 토큰·breakpoint 관리

최종 높이 정책

정책 대상 계산 높이
Fixed 원내 현황, 접수/예약, 진료/차트, 검사, 영상, 조제, 수납, 입원 항상 56px
Adaptive 병원관리 10개 화면, 고객관리의 동물·보호자·삭제된 고객 viewport 너비 1024px 이상이면서 높이 820px 이하일 때만 44px, 그 외 56px

구조 변경

  • EmrMainContentHeader가 fixed·adaptive 모드와 data-slot 검증 계약을 제공합니다.
  • 기본 56px, 압축 44px, Adaptive media query를 공통 EMR 토큰 스타일 한 곳에서 관리합니다.
  • 모든 상단 메뉴는 Main Content에 정확히 하나의 공통 Header를 렌더링합니다.
  • 진료·검사·영상·조제·수납은 선택 전에도 빈 56px 프레임을 유지하고, 선택 후에는 기존 환자 정보 내용을 그 안에 렌더링합니다.
  • 역할 및 권한·공간 관리의 뒤로가기 버튼은 기존 페이지가 계속 소유하며 공통 Header 안에서 표시됩니다.
