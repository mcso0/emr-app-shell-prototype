EMR 엠티 스테이트 XL 구현 및 적용 결과

넓은 진료 작업 영역에서 기존 LG 엠티 스테이트가 작게 보이던 문제를 해결했다. CDS.V2 Figma의 XL 기본형·1액션·2액션 노드를 공용 컴포넌트 계약으로 옮기고, 진료 화면을 기준으로 Home, 검사, 영상, 조제/처치, 수납의 전체 작업영역에도 적용했다.

변경 범위

  • EmrEmptyStateSize에 xl을 추가했다.
  • 기존 lg, md, sm 기본 매핑은 변경하지 않았다.
  • Home, 진료, 검사, 영상, 조제/처치, 수납의 전체 작업영역 빈 상태를 XL로 전환했다.
  • 업무 없음 문구를 도메인별 제목·설명·새로고침 규칙으로 통일했다.
  • 복구 버튼을 Figma XL의 32px rounded outline 계약으로 맞췄다.
  • 대기열, 데이터 로딩, 권한, API, RLS, 저장 동작은 변경하지 않았다.

검증

  • Storybook 상호작용 테스트 14개 통과.
  • 운영 화면 6종의 XL 속성·중심 정렬·상세 패널 비노출 회귀 검증을 추가했다.
  • 집중 Chromium 라우트 테스트 3개 통과.
  • Secret scan, TypeScript, 전체 ESLint, 문서 링크 검사 통과.
  • Next.js 프로덕션 빌드 통과. 기존 NFT 추적 경고 1건은 이번 변경 범위 밖이다.

남은 확인 사항

큐, 표, 드로어, 위젯, 근무표 상태 패널은 전체 작업영역이 아니므로 기존 MD/SM/LG 계약을 유지한다. 공용 content 기본값도 LG로 유지해 부분 화면이 의도치 않게 커지는 회귀를 막았다.
