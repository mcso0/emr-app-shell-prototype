EMR 엠티 스테이트 XL 구현 결과

넓은 진료 작업 영역에서 기존 LG 엠티 스테이트가 작게 보이던 문제를 해결했다. CDS.V2 Figma의 XL 기본형·1액션·2액션 노드를 공용 컴포넌트 계약으로 옮기고, 진료 화면 중앙 빈 상태에 먼저 적용했다.

변경 범위

  • EmrEmptyStateSize에 xl을 추가했다.
  • 기존 lg, md, sm 기본 매핑은 변경하지 않았다.
  • 진료 화면의 전체 작업영역 빈 상태와 새로고침 버튼만 XL로 전환했다.
  • 대기열, 데이터 로딩, 권한, API, RLS, 저장 동작은 변경하지 않았다.

검증

  • Storybook 상호작용 테스트 14개 통과.
  • 진료 빈 상태 브라우저 테스트 2개 통과.
  • TypeScript, 변경 파일 ESLint, 문서 링크 검사 통과.
  • Next.js 프로덕션 빌드 통과. 기존 NFT 추적 경고 1건은 이번 변경 범위 밖이다.

남은 확인 사항

이번 적용은 진료 화면 한 곳으로 제한했다. 다른 메인 업무 화면에 XL을 확대 적용하려면 각 화면이 정말 전체 작업영역 빈 상태인지 확인한 뒤 별도로 채택해야 한다.
