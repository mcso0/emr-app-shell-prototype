고객관리 보호자 목록 Figma 구현 결과

CDS.V2 보호자 목록 시안을 기준으로 UI를 재구성하고, 기존 고객 데이터와 검색·필터·정렬·선택·상세 열기 동작은 유지했다.

구현 완료 · 사용자 검토 대기

무엇이 바뀌었나

  • 설치돼 있던 TanStack Table과 프로젝트 Table 프리미티브를 조합해 customer feature 전용 데이터 테이블 경계를 만들었다.
  • 108px 목록 헤더, 36px 컬럼 헤더, 기본 40px 행, 64px 푸터와 48/20/10px 인셋을 Figma 기준으로 적용했다.
  • 컬럼은 typed ColumnDef schema로 유지하고, 텍스트뿐 아니라 Badge, Button, Avatar 같은 ReactNode 셀을 수용하도록 분리했다.
  • 모든 데이터 헤더는 라벨과 정렬 아이콘을 하나의 버튼으로 렌더링한다. 현재 데이터 계약이 있는 보호자명·등록일시만 정렬을 실행한다.
  • shared Checkbox는 기존 shadcn/Base UI API를 유지하면서 Figma의 checked, mixed, focus, invalid, disabled 표면과 exact SVG indicator를 적용했다.
  • 실제 페이지네이션은 추가하지 않고, 푸터에 1/1 페이지와 비활성 이전·다음 버튼만 표시했다.

남은 결정

휴대전화·연결 동물·동의 상태·최근 CS·최근 발송/업무는 Figma처럼 버튼 모양을 유지하지만, 비교 기준과 빈 값 정렬 규칙이 정해질 때까지 비활성이다. 실제 페이지네이션 역시 별도 데이터 계약 승인 전에는 추가하지 않는다.

공용 Checkbox 소비처 확인에서 billing, home, hospital-admin은 통과했다. dispensing 2개와 chart 1개는 Checkbox 검증 전 기존 데모 행 또는 문구가 없어 실패했으므로 별도 baseline 후속 항목으로 남겼다.
