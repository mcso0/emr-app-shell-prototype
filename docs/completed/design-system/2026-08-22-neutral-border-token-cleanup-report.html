DESIGN-SYSTEM-PR-093

Neutral 구조 보더 토큰 정리 보고서

구조용 보더를 neutral 100/200/300 역할 체계로 통일하고, 기존 gray 기반 --emr-line-* 구조 토큰을 런타임에서 제거했다.

구현 및 로컬 검증 완료

최종 역할 체계

역할토큰값용도
Subtle--emr-border-subtle#F5F5F5작고 조용한 내부 구분선
Default--emr-border-default#E5E5E5일반 컨트롤, 카드, 행, 패널 내부 경계
Strong--emr-border-strong#D4D4D4큰 패널, 드로어, 워크스페이스 외곽

변경 결과

  • 최신 기준선에서 확인한 116개 사용처를 역할에 따라 전환했다.
  • 레거시 구조 토큰 정의 4개와 미사용 호환 유틸리티 2개를 삭제했다.
  • 전역 --border와 --input은 neutral/200으로 연결했다.
  • 차트 4개 패널 외곽은 neutral/300, 내부 툴바는 neutral/200, 작은 액션 구분선은 neutral/100을 사용한다.
  • 선택·포커스·상태·브랜드 보더는 구조 보더와 합치지 않고 기존 의미 토큰을 유지했다.

검증

  • 재귀 소스 검사에서 제거 대상 구조 토큰 참조 0건
  • 토큰 및 차트 Playwright 집중 검사 4개 통과
  • 대표 Storybook interaction 9개 파일, 33개 검사 통과
  • 변경 TypeScript ESLint 및 TypeScript no-emit 통과
  • 전체 저장소 린트, 문서 링크, 비밀정보 검사, diff 검사 통과
  • Next 프로덕션 빌드와 Storybook 빌드 통과

기준선 확인

확장 Storybook 실행에서 pinned-table interaction 1건이 실패했지만, 동일한 실패를 깨끗한 origin/main에서도 재현했다. 이번 보더 변경으로 생긴 회귀가 아니다. 생성된 Clair/shadcn 토큰 파일, 데이터, 권한, 저장 동작, 레이아웃은 변경하지 않았다.
