DESIGN-SYSTEM-PR-097

컬럼이 포인터를 실시간으로 따라가도록 수정

병원관리에서는 놓는 순간에만 반영되던 컬럼 폭을 드래그 중 바로 반영하고, 고객관리에서는 빠져 있던 가변 데이터 컬럼 그립을 같은 계약으로 활성화했다.

Implemented
3수정한 테이블 구성
onChange드래그 중 폭 반영 모드
0데이터·권한 계약 변경

원인과 해결

영역기존 상태수정 결과
병원관리 개별 OrderTanStack 기본 onEnd원내 Order명 등이 드래그 중 즉시 변경
병원관리 Order 세트TanStack 기본 onEndOrder 세트명 등이 드래그 중 즉시 변경
고객관리실시간 모드와 데이터 컬럼 opt-in 모두 없음가변 데이터 컬럼은 그립과 실시간 변경 제공
고정 컬럼선택·환자코드·행 작업기존처럼 리사이즈 제외

회귀 방지

  • 마우스를 누른 채 그립을 이동하고, 놓기 전에 헤더 폭이 증가했는지 측정한다.
  • 고객관리 환자코드와 행 작업 컬럼이 계속 none 정책인지 확인한다.
  • 기존 정렬·필터·고정 컬럼·행 선택·drawer 흐름은 같은 대표 시나리오에서 함께 검증한다.

검증 결과

  • 고객관리 동물·보호자와 병원관리 개별 Order·Order 세트의 관련 Playwright 시나리오 통과.
  • lint, TypeScript, production build, 문서 링크, 한국어 UX copy, secret scan, diff check 통과.
  • 넓은 70건 실행에서 발견한 리사이즈 버튼 관련 locator 2건은 정확한 역할 기준으로 보정 후 통과.
  • 이번 변경과 무관한 main-content header 56px 기대값 3건은 현재 44px runtime과의 기존 기준선 드리프트로 별도 기록.

공용 테이블 API나 새 의존성은 추가하지 않았다. 컬럼 폭은 현재 세션 UI 상태이며 사용자별·워크스페이스별 영구 저장은 이번 범위에 포함하지 않는다.
