구현 및 검증 완료

우측 사이드패널 공통 헤더 높이 56px 적용

접수 상세 한 곳을 보정하는 대신, 콘텐츠 영역 우측 패널의 공통 헤더 컴포넌트와 전용 토큰을 만들었다. 이제 접수, 임상병리, 영상검사, 수납의 우측 패널 헤더가 같은 56px 높이를 사용한다.

변경 내용

  • EmrRightPanelHeader 공통 컴포넌트와 --emr-rightpanel-header-height 토큰 추가
  • Reception, Lab, Imaging, Billing 우측 패널 적용
  • 모듈 사이드패널, 전역 drawer, 콘텐츠 aside, 툴바, 모달 높이는 변경하지 않음

검증 결과

  • Playwright: 4개 우측 패널 56px, 1024px 56px 유지, 767px 기존 숨김 동작 확인 — 3개 테스트 통과
  • Focused ESLint, TypeScript, production build, docs check, secret scan, diff check 통과
  • 빌드의 기존 worktree root 추론 및 문서 reader trace 경고는 남지만 빌드는 성공

남은 위험

기능·데이터·권한·라우팅 변경은 없다. 우측 패널이 모바일에서 숨겨지는 기존 반응형 정책도 유지한다.
