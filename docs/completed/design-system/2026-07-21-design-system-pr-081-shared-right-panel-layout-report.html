우측 사이드패널 공통 레이아웃 구현 결과

접수 생성 폼의 하단 액션이 잘리던 문제를 한 화면의 높이 보정이 아니라, 표준 우측 패널의 공통 구조로 해결했다. 긴 입력 내용은 본문에서만 스크롤되고 하단 액션은 패널 내부의 고정 행으로 계속 보인다.

변경 내용

  • EmrRightPanel, EmrRightPanelBody, EmrRightPanelFooter를 추가했다.
  • Header는 기존 56px을 유지하고, Body만 남은 높이를 사용한다.
  • Footer는 Imaging 53px, Reception 65px, Billing 105px이며 Lab은 Footer 없이 Body가 끝까지 채운다.
  • Reception의 접수 생성, 예약 생성, 예약 접수, 상세 화면과 Lab, Imaging, Billing에 공통 구조를 적용했다.
  • WorkspaceFrame, 기존 반응형 정책, overlay drawer, content aside, staff profile 전용 패널은 변경하지 않았다.

남은 확인 사항

이번 변경은 로컬 격리 브랜치에서 검증됐다. production 배포나 main 병합은 포함하지 않았다. Next build에서는 NFT 추적 경고가, Storybook build에서는 asset/chunk 경고가 출력됐지만, 두 빌드는 성공했다.
