DESIGN-SYSTEM-PR-098

고정 경계는 한 줄만 남기고 리사이즈는 유지

고정 영역과 스크롤 영역 사이에 겹쳐 보이던 리사이즈 세로선을 숨겼다. 눈에는 공용 경계선 하나만 보이지만 같은 위치를 잡아 컬럼 너비를 계속 조절할 수 있다.

Implemented
1px남는 공용 경계선
8px유지한 리사이즈 히트 영역
0데이터·권한 계약 변경

수정 결과

대상시각 표시동작
마지막 왼쪽 고정 컬럼그립 세로선 숨김마우스·터치·키보드 리사이즈 유지
공용 고정 경계1px 디바이더 유지스크롤 딤머와 독립적으로 동작
일반 스크롤 컬럼기존 그립 세로선 유지실시간 리사이즈 유지

회귀 방지

  • 공용 Storybook에서 고정 경계 그립의 선은 숨고 8px 히트 영역과 커서는 남는지 검사한다.
  • 병원관리 Order 화면에서 숨은 경계 그립과 보이는 일반 그립을 각각 드래그하고, 포인터를 놓기 전에 너비 변화를 확인한다.
  • 오른쪽 고정 컬럼과 일반 컬럼에는 왼쪽 경계 예외를 적용하지 않는다.

검증 결과

  • 공용 EmrDataTable Storybook 25개 시나리오 통과.
  • 병원관리 Order 공용 헤더·리사이즈 집중 Playwright 시나리오 통과.
  • 전체 lint, TypeScript, production build, 문서 링크, secret scan, diff check 통과.
  • 빌드에는 기존 docs reader NFT tracing 경고가 남았지만 컴파일과 정적 페이지 생성은 정상 완료.

컬럼 크기 계산, 고정 위치, 스크롤 딤머, 데이터, API, 권한은 변경하지 않았다. 공용 헤더가 이미 받는 핀 상태만 사용해 별도 의존성이나 기능별 조건도 추가하지 않았다.
