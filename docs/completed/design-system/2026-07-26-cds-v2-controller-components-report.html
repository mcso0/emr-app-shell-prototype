CDS.V2 컨트롤러 컴포넌트 구현 결과

Figma의 Toggle, ToggleGroup, Switch 시각 계약을 기존 Base UI 기반 공유 컴포넌트에 흡수했다. 기존 화면의 의미와 선택 동작은 유지하면서 크기, 상태, 그룹 배치, 접근성 문서와 검증 범위를 확장했다.

구현 및 회귀 검증 완료 · 사용자 검토 대기

Figma 대조 결과

항목Figma구현결과
Toggle 크기sm 32px, md 36px동일, 기존 소형은 xs로 보존일치
Toggle 시각primary, ghost, outline동일, default는 ghost 호환 별칭일치
ToggleGroupprimary 4px/6px, ghost 0px, outline 연결형동일 컨테이너·모서리 규칙일치
Switch sm32×18px, thumb 16px동일, 이동 14px일치
Switch md44×24px, thumb 20px동일, 이동 20px일치

변경 범위

  • Toggle에 CDS.V2 variant, size, 아이콘 전용 배치를 추가했다.
  • ToggleGroup에 primary 컨테이너와 연결형 outline 배치를 추가했다.
  • Switch에 xs/sm/md 크기와 neutral on/off 상태를 추가했다.
  • 접수의 소형 Switch는 xs로 고정하고, 최신 운영 요일 화면의 전용 스타일은 보존했다.
  • 라벨은 외부 label 합성, 필수 단일 선택은 SegmentedControl 책임으로 유지했다.
  • 신규 의존성, 전역 토큰, API, 저장 동작, 권한, Figma 파일은 변경하지 않았다.

검증

  • Storybook 상호작용 테스트 16개 통과.
  • 병원 운영일, 역할·직무, 권한 화면, 접수 등록 회귀 테스트 4개 통과.
  • Toggle, ToggleGroup, Switch의 실제 브라우저 치수와 상태 전환을 확인했다.
  • TypeScript, 전체 ESLint, 문서 링크 검사, diff 검사 통과.
  • Storybook 및 Next.js 프로덕션 빌드 통과.

남은 확인 사항

배포와 Figma 파일 수정은 수행하지 않았다. Storybook의 기존 Pretendard 경로, Lottie eval, 번들 크기 경고와 Next.js NFT 추적 경고는 이번 변경에서 새로 발생한 문제가 아니며 별도 정리가 필요하다.
