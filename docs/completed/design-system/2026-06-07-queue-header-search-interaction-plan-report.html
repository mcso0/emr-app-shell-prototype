대기열 헤더 검색 인터랙션 기획 및 시안

진료/조제/검사/영상 등 사이드 대기열 헤더의 검색 아이콘을 눌렀을 때, 헤더가 인라인 검색 모드로 전환되고 현재 대기열 카드가 즉시 필터링되는 UX 제안서다.

작성일 2026-06-07 대상: 사이드 대기열 헤더 산출물: 기능 기획 + 인터랙션 HTML 시안 구현 범위 아님
핵심 판단: 승욱이 말한 “노션처럼 검색 모드로 전환” 방향이 맞다. 다만 상단 모듈명/날짜/탭은 유지하고, 대기열 헤더 한 줄만 검색 입력 상태로 바꾸는 쪽이 업무 맥락 손실이 적다.

1. 권장 UX 요약

  • 검색 아이콘 클릭: 대기열 헤더의 라벨, 카운트, 정렬/필터/검색 아이콘을 숨기고 검색 input을 즉시 focus한다.
  • 오른쪽 X 버튼: 검색어를 비우고 검색 모드를 종료하며 기존 헤더 상태로 돌아간다.
  • 입력 중 필터링: 현재 선택된 상단 탭, 정렬, 상세 필터 조건을 유지한 상태에서 검색어가 매칭되는 task card만 남긴다.
  • 검색 대상: 환자명, 보호자명, 접수 유형, 오더/검사명, 방문 목적/메모 요약, 요청자, 담당자, 상태, 시간, 차트/오더 식별자를 포함한다.
  • 결과 표시: 검색 모드 아래에 “검색 결과 N건”을 보여주고, 카드 내 매칭 텍스트는 highlight한다.
  • 빈 결과: 리스트 영역에 빈 상태를 보여주고, X 또는 전체 삭제로 복귀한다.

상세 화면은 그대로 유지

검색은 사이드 대기열의 탐색 모드다. 입력 중에도 오른쪽 상세 화면은 마지막 선택 항목을 유지하고, 사용자가 검색 결과 카드를 선택했을 때만 상세가 바뀐다.

설계 포인트: 검색어 입력만으로 상세 화면이 자동 변경되면 사용자가 읽던 차트/SOAP 맥락을 잃는다. 따라서 결과 리스트만 갱신하고 선택 변경은 명시 클릭으로 제한한다.

3. 사용자가 말한 방향에서 보강할 점

  • 검색 범위 표시: 현재 “전체/예약/외래” 탭과 필터가 적용된 결과인지 명확히 보여줘야 한다.
  • 선택 상태 유지: 검색 결과가 기존 선택 항목을 숨겨도 상세 화면은 유지하고, 카드 선택 시에만 바꾼다.
  • 빈 결과 복구: 빈 상태에서 “검색어 지우기”와 “필터 초기화” 액션이 필요하다.
  • 키보드 플로우: Esc로 닫기, Enter로 첫 결과 선택, ↑/↓로 결과 이동을 지원하면 반복 업무가 빨라진다.
  • 매칭 하이라이트: 왜 이 카드가 남았는지 카드 안에서 보여줘야 신뢰감이 생긴다.
  • 검색어 유지 여부: 모듈 이동/날짜 변경 시 검색어는 초기화하고, 같은 탭 안에서 정렬/필터 변경 시에는 유지하는 쪽이 자연스럽다.

5. 상세 기능 기획

  1. 검색 진입: 검색 버튼 클릭 시 header row를 `searchActive=true`로 전환하고 input에 focus한다.
  2. 검색 적용 순서: 상단 탭 필터 → 상세 필터 → 검색어 필터 → 정렬 순서로 적용한다.
  3. 검색 토큰: 공백 기준 AND 검색을 기본으로 한다. 예: “코코 이수지”는 두 단어가 모두 매칭되는 카드만 표시한다.
  4. 한글/영문: 대소문자는 무시한다. 초성 검색은 후속 옵션으로 둔다.
  5. 선택 처리: 검색 결과 첫 항목 자동 선택은 하지 않는다. 사용자가 클릭하거나 Enter를 눌렀을 때만 선택한다.
  6. 카운트: 헤더 카운트는 검색 결과 수로 바꾼다. 검색 종료 시 기존 visible count로 복귀한다.

Enter 현재 active 결과 카드 선택

↑↓ 결과 카드 active 이동

  • 검색 input label은 “대기열 검색”으로 제공한다.
  • 결과 수 변경은 `aria-live="polite"` 영역으로 안내한다.
  • X 버튼은 “검색 닫기”로 읽히게 한다.
  • 검색 진입/종료 시 focus 이동이 예측 가능해야 한다.

7. 구현 시 수용 기준

구분완료 기준
기본 동작 검색 아이콘 클릭 시 헤더가 input + X 버튼으로 전환되고 input이 focus된다.
필터링 검색어 입력 시 현재 대기열 task card가 환자/보호자/오더/담당자/상태/시간 기준으로 즉시 필터링된다.
기존 조건 유지 상단 탭, 상세 필터, 정렬 상태는 검색 모드에서도 유지된다.
복귀 X 또는 Esc로 검색어를 지우고 기존 헤더로 돌아간다.
빈 상태 검색 결과 0건일 때 명확한 빈 상태와 복구 액션을 제공한다.
공통 적용 진료/조제/검사/영상 등 같은 대기열 헤더 패턴에 동일하게 적용 가능해야 한다.
