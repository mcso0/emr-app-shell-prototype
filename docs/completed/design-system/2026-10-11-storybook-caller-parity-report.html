이 결과는 합성 데이터와 로컬 fixture로 확인한 Storybook 범위야. 모든 내부 분기, 실제 로그인·DB·RLS·결제·운영 환경을 검증했다는 뜻은 아니야. 기존에 승인한 Home·표 변경은 유지했고, 이번 작업에서 제품 런타임 동작을 추가로 수정하지 않았어.

승욱이 결정할 5개

현재 제품 동작을 감추거나 예시만 정상처럼 바꾸지 않았어. 아래 항목의 제품 수정은 별도 범위야.

01

근무표 저장 뒤에도 변경 경고가 남음

저장 요청과 표 갱신을 확인한 뒤에도 미저장 변경 경고가 남는 현재 동작을 재현했어.

저장 성공 시 변경 경고를 해제하도록 제품 동작을 수정할지 결정해 줘.

실제 예시 열기 ↗
02

조제 표에 내부 영문 필드명이 표시됨

실제 공통 표 조합에서 한국어 열 제목 대신 내부 필드명이 표시되는 경로가 있어.

공통 표의 제목 규칙을 수정할지 결정해 줘. 영향받는 다른 표도 함께 확인해야 해.

실제 예시 열기 ↗
03

동작이 연결되지 않은 활성 버튼

조제 이력·필터, 고객센터·도움말, 입원 추가·관리·차트·퇴실 등 일부 실제 버튼은 클릭 뒤 연결된 동작이 없어.

지금 기능을 연결할지, 준비 중 표시나 비활성 상태로 바꿀지 결정해 줘.

실제 예시 열기 ↗
04

SOAP 제목에서 Enter가 빈 제목을 추가함

현재 편집기는 제목에서 Enter를 누르면 접기 대신 새 빈 제목을 추가해. 예시는 이 실제 동작을 유지했어.

편집 동작을 유지할지, 접기 동작과 단축키를 별도로 정할지 결정해 줘.

실제 예시 열기 ↗
05

전체 검색의 동적 결과가 필터에서 사라짐

검색 결과의 필터용 값이 빠진 경로에서 표시되어야 할 동적 결과가 숨겨져.

전체 검색의 필터 키를 제품 코드에서 수정할지 결정해 줘.

실제 예시 열기 ↗
