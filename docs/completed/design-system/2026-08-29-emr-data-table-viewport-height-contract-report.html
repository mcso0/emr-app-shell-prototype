EmrDataTable viewport 높이 계약 통합

테이블의 높이 의도를 fill과 content로 명시하고, 가로 스크롤바가 데이터 본문 viewport의 실제 하단에 놓이도록 공용 컴포넌트가 높이·flex·overflow를 소유하게 정리했다.
