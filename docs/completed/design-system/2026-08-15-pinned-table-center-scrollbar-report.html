DESIGN-SYSTEM-PR-092

고정 테이블 중앙 스크롤바 수정 보고서

Plan/Order와 고객관리 테이블에서 고정 컬럼 아래까지 보이던 가로 스크롤바를 데이터 컬럼 영역에만 표시하도록 공용 컴포넌트에서 수정했다.

구현 및 로컬 검증 완료

결정

  • 새 라이브러리를 추가하지 않고 기존 shadcn/Base UI Scroll Area를 재사용했다.
  • 고정 테이블의 스크롤 소유자를 하나의 공용 viewport로 통합했다.
  • 가로 스크롤바는 왼쪽·오른쪽 고정 컬럼 너비를 제외한 중앙에만 표시한다.

영향 범위

공용 EmrDataTable과 pinned viewport, Storybook 회귀, Plan/Order·고객관리·병원관리 Playwright 검증, 관련 설계 문서를 변경했다. 데이터, 정렬, 필터, 선택, 저장 계약은 유지했다.

검증

  • 관련 Playwright 회귀: 8개 통과
  • EmrDataTable Storybook interaction: 7개 통과
  • ESLint, TypeScript, 문서 링크, 비밀정보, diff 검사 통과
  • Next production build와 Storybook build 통과
  • 수동 geometry: 왼쪽 224px, 오른쪽 72px 고정 구간을 스크롤바에서 제외

위험 및 제외 범위

비고정 테이블과 프로필 패널 스크롤은 변경하지 않았다. 전체 영향을 넓히지 않기 위해 pinned EmrDataTable에만 새 스크롤 소유권 계약을 적용했다.
