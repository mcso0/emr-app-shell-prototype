토스트를 왼쪽 위로 옮기고,
닫기 버튼 상태 색상을 맞췄어.

구현과 로컬 검증 완료 · PR 및 배포 상태는 해당 PR에서 확인

저장·오류 등 작업 결과 토스트가 헤더 아래까지 내려가던 위치 계산을 제거했어. 시스템이 다크 모드여도 토스트는 앱의 밝은 화면과 같은 테마를 사용해.

최종 표시 기준

항목검증한 값
데스크톱·모바일 위치표시 영역 왼쪽·위에서 각각 16px
닫기 버튼 기본 배경투명
마우스를 올렸을 때검정 4% 토큰
누르는 동안검정 6% 토큰
키보드Alt+T → Tab 이동, 포커스 링, Enter로 닫기

닫기는 선택이 유지되는 동작이 아니야. 이번 6% 누름 처리는 토스트 닫기 버튼에만 적용했고, 공통 hover·selected·active 토큰의 4%·6%·8% 규칙은 유지했어.

검증 결과

  • 화면 검사 4개 통과: 1440px·390px 화면 × 시스템 라이트·다크 설정.
  • 기존 알림 스택·중복·상태·액션 검사 6개 통과. 총 10개 통과.
  • lint 오류 0개, 기존 스크립트 경고 5개. 수정 파일 lint 및 타입 검사 통과.
  • 문서 링크·UX 문구·비밀값·diff 검사와 기본 프로덕션 빌드 통과.

모바일에서는 기존 새 탭 버튼이 숨겨져, 실제 앱에서 생성한 토스트를 모바일 화면으로 전환해 검사했어. 개발 서버의 Turbopack 캐시 오류는 Webpack 개발 서버로 우회했고, 기본 Turbopack 프로덕션 빌드는 통과했어.
