변경 요약

대기열 헤더의 검색 아이콘을 실제 검색 모드 트리거로 연결했다. 클릭하면 기존 제목, 카운트, 정렬, 필터 액션이 인라인 검색 입력창과 닫기 버튼으로 전환되고, 입력값은 현재 탭과 필터 조건 안에서 보이는 task card만 필터링한다.

  • 검색 입력창은 열리자마자 focus 된다.
  • 검색 중에는 검색 결과 N건만 간결하게 표시한다.
  • 0건일 때는 빈 상태와 검색어 지우기 복구 액션을 제공한다.
  • 닫기 또는 focused empty input의 Escape는 검색어를 지우고 기존 헤더로 복귀한다.

인터랙션 흐름

1. 헤더 검색 아이콘 클릭
2. 헤더가 inline search input + X 버튼으로 전환되고 input focus
3. 입력값 기준으로 현재 scope 안의 카드만 필터링
4. 결과가 있으면 compact count, 없으면 empty state + clear action
5. X 또는 Escape로 검색 모드 종료, 기존 헤더 액션 복귀
