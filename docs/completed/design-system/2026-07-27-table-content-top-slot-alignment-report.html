핵심 구현

  • 제목 영역 앞에 포커스를 받지 않는 장식용 56px 슬롯을 추가했습니다.
  • 콘텐츠 프레임과 제목·필터 영역은 #FCFCFC를 사용합니다.
  • 테이블 데이터 면은 흰색, 고객관리 컬럼 헤더는 #FAFAFA를 유지합니다.
  • 테이블 헤더와 첫 Row 사이에 별도 margin·padding·wrapper를 추가하지 않았습니다.
  • 전역 셸은 변경하지 않아 이미 56px 바를 가진 진료·접수 화면의 중복 여백을 방지했습니다.

검증 결과

  • ESLint와 TypeScript 검사 통과
  • 고객관리 핵심 Playwright 3/3 통과
  • 병원관리 Order·감사 로그 핵심 Playwright 3/3 통과
  • 고객관리·병원관리 전체 47개 중 46개 통과, 실패 1개는 격리 재실행 통과
  • 프로덕션 빌드 통과
  • 1540×1024 실제 화면 검토에서 겹침과 의도하지 않은 여백 없음

전체 실행에서 병원 바이탈 설정의 되돌리기 버튼 대기 테스트 1개가 30초 타임아웃으로 실패했지만, 같은 테스트를 단독 재실행했을 때는 8.8초에 통과했습니다. 이번 변경과 직접 연결된 테스트는 모두 통과했습니다.

의도적으로 제외한 범위

삭제 목록, 병원 구성원·설정 화면, 전역 셸, 데이터/API/권한, 프로덕션 배포는 이번 변경에 포함하지 않았습니다.
