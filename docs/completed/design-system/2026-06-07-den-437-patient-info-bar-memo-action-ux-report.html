Human Review 준비

요청과 결정

환자정보바에 여러 메모 버튼이 나란히 표시되던 구조를 정리했다. 메모는 primary action이 아니라 환자 맥락을 보조로 확인하는 secondary context action으로 정의하고, 하나의 메모 버튼에서 방문목적, 보호자 메모, 환자 메모, 수납 메모 상태를 확인하도록 바꿨다.

변경 내용

  • EmrPatientContextBar의 메모 영역을 단일 버튼과 popover 구조로 변경했다.
  • 메모 버튼은 E1 action affordance를 유지하고, popover는 기존 EMR floating surface를 재사용한다.
  • Chart, Lab, Imaging 헤더는 기존 mock/local-first 데이터에서 가능한 메모 요약을 표시한다.
  • Dispensing/Treatment 헤더는 현재 큐 스냅샷에 없는 메모를 명확한 disabled 설명으로 표시한다.
  • 수납 메모는 수납 화면 소유로 남겨, 환자정보바에서 live persistence나 cross-module edit을 암시하지 않는다.
