Storybook 작업 마무리

합의한 Storybook 정렬, 승인한 후속 수정, 테스트 안정화와 접근성 진단을 완료했다. 새로 발견한 문제는 별도로 남기고 작업 범위를 닫는다.

로컬 구현·검증 완료기존 작업 보존커밋·푸시·배포 없음

01 · 변경 사항

  • Storybook 정렬: origin/main 기준 실제 컴포넌트와 화면 조합에 맞춰 예제·합성 데이터·문서·상호작용 테스트를 보완했다. UI 소스 231개를 분류하고 MCP 예제와 타입 정보도 검증했다.
  • 승인한 동작 수정: 근무표 저장·닫기 및 저장 중 편집, 비활성 입원 버튼의 행 클릭 전파, 홈의 긴 날짜 표시를 수정했다. 조제 표 머리글, 미연결 버튼의 준비 중 표시, SOAP 키보드 토글, 통합 검색 필터 동작도 반영했다.
  • 테스트·검사 정비: 홈 모바일 테스트를 기존 모달 동작에 맞췄다. 검색 응답 순서 역전과 닫기 후 응답 검증을 추가했다. 차트 확인창은 열림 애니메이션 이후 같은 가시성 조건을 검사하도록 수정했다. 승인된 스크립트 lint 오류·경고도 정리했다.
  • 유지보수 규칙: AGENTS.md에 UI 변경 시 관련 Storybook 수정·검증을 함께 수행하도록 추가했다. 무관한 문제는 별도 기록하고, 별도 승인 없이 작업 범위를 넓히지 않는다.

02 · 검증 결과

검증기록된 결과와 범위
Storybook 전체705개 실행에서 704개 통과, 차트 가시성 테스트 1개 실패. 이후 원인을 수정하고 아래 반복 검증을 통과했다. 수정 후 전체 705개를 다시 실행한 결과는 아니다.
차트 안정화70/70 통과. 관련 예제 7개를 새 프로세스로 10회 실행했다. 재시도 옵션 없이 저장 대상·버전·기존 기록 보존 검증을 유지했다.
회귀 테스트관련 예제 31개, 홈·입원 앱 테스트 36개 통과 확인. 각각 초기 실행과 실패 항목의 수정 후 재검증을 합한 결과다. 최종 검색 정리 변경 후 앱 셸 예제 12개도 통과했다.
정적 검사·빌드타입 검사·Storybook 정적 빌드·문서·diff 검사 통과. 후속 수정 단계에서 전체 lint 오류·경고 0개. 이후 차트 테스트 변경 파일 lint도 통과했다. AGENTS.md 변경 시 문서 1,108개 검사와 diff 검사를 통과했다.
자동 접근성axe-core로 초기 상태 705개 + 추가 상태 5개를 검사했다. 최종 검사 대상은 모두 정상 렌더했다. 문제가 남아 있으므로 접근성 통과 판정은 아니다.

로컬 합성 데이터 기준이다. 모든 화면 상태·화면 폭·스크린리더·실데이터·운영 환경을 검증한 결과는 아니다. 각 검사는 해당 변경 단계의 결과이며, 이번 마무리에서는 재실행하지 않았다.

03 · 별도로 남겨둔 문제

  • 우선 검토 · 검색과 이름 누락
    통합 검색 결과의 ARIA 역할·선택 상태 관계, SOAP 입력·일부 아이콘 버튼·첨부 파일 입력의 접근 가능한 이름 누락. 수정은 시작하지 않았다.
  • 추가 접근성 개선
    클릭 요소 중첩, 텍스트 대비, 좁은 클릭 영역, 일부 목록·제목·표 구조와 포커스 동작을 별도로 검토해야 한다.
  • 정적 미리보기 안정성
    정적 빌드는 통과했지만 정적 미리보기 검사 시 동적 모듈 로딩 실패가 있었다. 최종 접근성 결과는 개발 Canvas에서 확보했다. 로딩 실패의 원인 해결은 남아 있다.
  • 좁은 화면 조제 표
    420px에서 기존 그룹 머리글이 조밀하게 보이는 문제를 별도로 남겼다.

초기 상태 629개에서 자동 검사 지적이 나왔다. 단독 예제의 페이지 맥락 규칙(main·h1·region) 3개를 제외하면 242개에 검토 항목이 남는다. 같은 공용 컴포넌트가 반복되므로 242개의 독립된 버그를 뜻하지 않는다. 판정이 확정되지 않은 항목도 수동 확인 대상으로 남겼다.

여기서 작업을 마무리한다. Storybook 결과는 별도 로컬 작업 폴더에 있고, 유지보수 규칙은 기본 작업 폴더의 AGENTS.md에 반영했다. main 반영과 배포는 하지 않았다. 남은 문제의 수정은 별도 작업으로 다룬다.
