현재 소스와 맞춘 부분

공통 UI와 EMR

누락된 기본 컴포넌트와 상태를 추가했어. 메뉴·대화상자·팝오버는 실제 포인터/키보드 이벤트와 상태 조건으로 검증해. Input·Textarea는 입력 후 값을 확인해. 대기열은 초기 선택 행 이동이 끝난 뒤 같은 viewport 안에서 위치 유지 여부를 확인해.

기능별 실제 조합

고객 목록의 검색·정렬·선택, 홈의 업무 칸반·목록·내 업무, 차트 평가·사전 문진·금액 상세, 업무 상태 전이, 검사 상태, 알림을 합성 데이터로 확장했어. 서버 조회·저장·라우팅의 대역과 정리 함수를 명시했어.

MCP Props와 코드 예시

스토리 내부 wrapper의 Props를 이름이 비슷한 실제 컴포넌트 Props로 잘못 설명하던 추출 경로를 수정했어. 106그룹의 예시는 소스 args·render·fixture hook을 보존해. play는 제외한 초기 상태 예시라고 표시했어. 63그룹·511 Props와 zero-arg 6개를 소스와 비교했어.

독립 실행 환경

Supabase 클라이언트와 Kakao 주소 검색은 Storybook 전용 대역을 사용해. Vite 의존성 사전 최적화로 테스트 도중 페이지가 다시 로드되던 원인을 줄였어. 정적 빌드의 Pretendard 상대 경로 404는 정확한 로컬 asset alias로 고쳤고 font/woff2 HTTP 200을 확인했어.

이전 작업에서 재사용한 것과 제외한 것

이전 감사의 inventory/checker, Storybook 문서 추출 및 격리 설정을 검토 후 가져왔어. 각 lane의 스토리는 현재 main에 맞게 다시 검토했어. 이전 checkout의 Tabs·ToggleGroup, 차트 저장·삭제 등 제품 런타임 변경은 복사하지 않았어. 새 후보의 근거와 이전 감사 결과를 작업 문서에서 분리했어.
